# ADR-003：任务执行权威与调度边界

- 状态：选定设计方案，2026-11-19；正式实现未实施，设计稿待评审。
- 关联：[CR-016](../PRD/CR-016-需求派发与自主研发任务系统.md)、[PRD-002](../PRD/PRD-002-需求派发与自主执行.md)、[ADR-001](ADR-001-文档正文与统一能力网关.md)、FEAT-018～020 / STORY-038～043。
- 依据：用户要求一次派发、并行与依赖等待，随后明确本轮增加完整需求和设计；不是当前执行或验收授权。

## 1. 运行权威与需求权威分离

选定 Markdown 作为需求/AC/Story 状态权威，SQLite 作为批次、执行步骤、尝试、租约、锁、事件、证据、集成和交付的权威；运行快照不可变且仅保存授权输入/摘要与受检内容，不提供第二个需求编辑入口。界面读取两类投影并标明同步情况。

备选「所有运行状态写 Markdown」无法原子领取/互斥，不采用；备选「需求全部转 DB」会失去现有文档审阅和唯一事实来源，不采用；备选「复用会话消息当任务」缺 DAG/租约/产物修订，不采用。现有 RUNNING 会话注册表仅内存，不能作持久化任务权威。

DB 交付后经 outbox/CAS 写回正文；文件替换、DB 事务不存在跨介质原子事务，采用可对账幂等写回。冲突不覆盖，文件已写而 DB 未确认时读取 hash/交付 ID 对账后补记；保留失败历史。

## 2. 独立 runner 而非页面调度

选定 Rust 独立本机 runner，UI/Tauri 命令仅作为受管客户端。runner 唯一调度进程通过本机互斥与 DB 租约协调，多客户端不能创建双写。控制通道需本机身份校验、受限 ACL 和协议版本握手，不在网络暴露。

备选「React timer」关闭页面即丢运行语义，不采用；备选「Tauri 主进程内队列」可用于明确应用生命周期模式，但不能满足退出 UI 继续运行；备选云服务超出单用户本地范围，不采用。独立 runner 的安装、自启和进程管理仍需正式实现和验证；本轮评审稿不部署它。

关窗口继续任务，退出 UI 主进程不等于退出 runner。退出 runner 必须停止领取、终止并确认旧写进程，再 checkpoint；崩溃/主机重启后先恢复对账，安全副作用才可重试，不能证明则 blocked。未知旧进程存活时不发新租约，fencing 防旧回调但不能代替物理进程停止。

## 3. 业务树与产物 DAG 分离

业务父子树只决定派发范围；执行 DAG 根据明确依赖与 requiredArtifact/verificationGate/consumedRevision 控制放行。范围外依赖不自动扩大授权。失败、取消、无证据及不可消费产物均不放行；环拒绝。

资源锁和全局/项目并发槽在短 SQLite 事务内领取，执行层校验写入范围。独立 worktree 解决代码混写，不是 OS 沙箱，也不保证语义兼容。需要密钥/知识/文件/网络隔离的任务，必须有平台强制边界；能力缺失时拒绝，不静默退回直连。

## 4. 串行本地集成与验证基线

任务在独立分支产物验证后进入允许的本地非保护集成分支队列；一个项目/基线串行推进，集成回归通过才公布新基线。下游只消费确切验证修订，不能用 exit 0 或「前置完成」标签代替。

备选并行合并同一基线存在 HEAD 竞争，不采用；直接合主分支或推送超出默认授权，不采用。未授权集成则只交独立产物，依赖该集成基线的后继阻塞，报告不隐藏未交付项。

## 5. 有限自动执行与真实验收

CLI/模型/难度能力和预算在派发时冻结并二次校验，不点名绕规则、不静默替换。暂时故障有限重试，认证/额度/配置/权限停止，代码验证失败有限返工，不改 AC。

技术成功要求修订绑定证据、差异审查及适用集成回归。默认 Story 待验收；预授权客观自动验收才允许已完成。未知 usage 不估造账单，硬费用门槛不可测则拒绝或由用户另授权可控非费用预算。

## 6. 影响与验证边界

新增独立执行表与 runner 客户端/协议；复用现有 project、配置引用、知识网关及 Git 参数数组调用机制，不在本轮修改或迁移。代价是进程生命周期、安全隔离、对账、跨介质写回和兼容版本维护；收益是可追踪、可恢复且不重复副作用的执行管理。
