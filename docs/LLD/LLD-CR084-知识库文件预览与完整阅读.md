## 0. 实际实现记录（v2）

- 前端：`PagedDocumentPreview.tsx` 用 pdf.js 4.10.38 的 `PDFDataRangeTransport` 按 64KiB 分段取字节；`TextLayer` 仅生成可选文字，不建注解／链接／脚本层；缩放以 100% 为基准，「适合宽度」按容器宽计算；页面画布像素比上限 2 且单页像素上限约 2400 万。
- 后端：`kb_preview.rs` 以窗口+库+请求为租约键；源文件以只读句柄钉住并流式 SHA-256 作修订；每次读取复检库启用状态、源实体与修订；Office 为「复制到私有任务目录→有界 OpenXML 检查→独立 profile headless 转换→输出 PDF」，宏安全级别 3、禁止执行宏、不更新外链；`LoadPrinter=false`；仅放行 `ppt/printerSettings/printerSettings<digits>.bin`。派生目录只在任务私有路径，关闭后按实体校验递归清理。
- 偏差与替代：缩略图导航未实现（保持页号导航，设计同样只登记页号）；Excel 仅打印页预览；旧二进制格式返回 `UNSUPPORTED_RESTRICTED`。转换器依赖部署准备脚本，不随仓库提交。
- 验证：后端 8/8、预览界面 24/24、Markdown 22/22、vite 构建 exit 0（tsc 联编受并行 CR-085 未同步夹具阻断），见 [REPORT-CR084](../Test/REPORT-CR084-正式实现与验证.md)。

## 1. 当前实现与最小影响面

- `src-tauri/src/commands/knowledge_files.rs` 的 `info` 将 PDF／Office 设为不可预览；`data` 对这些格式仅返回元信息。`src/modules/knowledge/Reader.tsx:681` 对其落入附件状态。
- 现有 Markdown 由 `ZyDocEditor` 进入 `MarkdownContent`；Worker 超大 token 可降级完整原文，但组件累计超过 16,000 个元素或 4×1024×1024 HTML JS 字符后终止解析，留下前缀。limited 与 error 独立显示，可能同时声称完整和不完整。
- 后端小文本上限为 1MiB UTF-8 字节，整件超限报错；大文本另有 64KiB 窗口、nextOffset／eof。JS 字符限制、文件字节限制和 DOM 节点限制不能互相代换。窗口已有明确「当前片段不是全文」，不得移除。
- 拟议正式范围：知识阅读组件、专用本机预览命令／适配器与对应 API 类型；不改检索引擎、grant、工具目录、办公项目、数据根或应用整体导航。共享注册／API 变更只为本 Feature 接线。

## 2. Markdown 完整阅读

1. 保持源文本为权威；排版进度、覆盖范围、EOF、错误使用单一状态，禁止 limited=true 被当作全文完成。
2. 先估算下一批预算；不足时转入原文分段状态，继续使用现有源范围读取剩余内容。维护连续源范围，不能只显示已排版前缀，也不能把 HTML 的文本长度拿来推导源偏移。
3. 整件原文模式仍过大时使用现有只读窗口协议，显示字节范围、前后页与 EOF。长单段／围栏／表格跨窗口需保留范围，不强求每窗口独立解析为正确 Markdown。
4. UI 同一时刻只呈现一个覆盖结论：加载中／全文排版完成／全文原文可读／分段阅读／读取失败。局部排版失败必须给原文入口，不自动改写或保存内容。
5. 不重建活动编辑器实现退化；逐文件保留草稿、选区、撤销。复制／查找必须说明范围，不能把当前挂载窗口伪装成全文。Worker 取消后拒绝旧 requestId 的迟到消息。

## 3. PDF 与 Office 只读预览候选路线

- PDF 使用应用控制的页面渲染器（候选 PDF.js，非原生浏览器插件），页画布＋可用时的文本层，按需加载可见页；不启用脚本、启动动作、附件执行、自动外链请求。使用自有滚动容器遵守 UI-SCROLL-001。
- Word／PPT／表格经本机独立转换进程生成 PDF 派生件，再走同一阅读器。候选为受限运行的 headless 转换器；必须先核对许可证、Windows 便携分发、宏禁用、外部资源阻断、进程树取消／超时、字体与恶意包资源上限。**候选未实测，不承诺已可用，不修改依赖。**
- 先探测格式与转换能力，再返回能力状态；不只根据后缀把 `previewSupported` 从 false 改 true。转换器不可用是可诊断失败，不可记支持成功。
- 静态转换不保证动画、媒体、公式重算或原版字体；Word／PPT 标签「转换预览」，Excel 标签「打印页预览」。不把 xlsx 打印页说成全工作表。扫描 PDF 无文本层也可看页面，不擅自加入 OCR。
- 预览不经过公网 Office Viewer 或第三方上传服务。本机只读预览成功不改变 metadata_only 索引或 AI 可读能力。

## 4. 拟议接口与身份约束

| 接口职责（名称待实现时沿仓库约定） | 输入／结果 | 边界 |
| --- | --- | --- |
| 请求预览 | libraryId、noteId、期望源修订 → requestId、状态、格式、转换类型 | 沿 SafeRoot 与稳定文件身份；不接受任意主机路径 |
| 读预览状态 | requestId → preparing／ready／failed／cancelled／stale，实际页数（若已知）、错误码 | 进度未知只给阶段与耗时；不模拟百分比 |
| 取页数据 | previewId、page、sourceRevision → 有界页面／文本资源 | 仅当前所有者阅读路径；句柄不可成为 AI／其他库的访问入口 |
| 取消／释放 | requestId／previewId → 终止或解除引用 | 关闭／切换停止旧任务；迟到响应不覆盖新文件 |

错误码至少区分 `UNSUPPORTED`、`CONVERTER_UNAVAILABLE`、`PASSWORD_REQUIRED`、`CORRUPT`、`TIMEOUT`、`SOURCE_CHANGED`、`MISSING`、`ACCESS_DENIED`。密码输入与持久保存不在本轮设计；加密文件就地提示并保留原件下载（仍需本机权限）。

## 5. 数据、缓存与兼容

- 原件、库根、身份与授权复用 [DB-FEAT-008](../DB/DB-FEAT-008-知识原件切片与全文索引.md)。预览文件仅可重建派生数据，无新业务表、无原件迁移，不把 PDF 页写入知识正文表。
- 缓存键至少含库身份、noteId、完整源修订、转换器版本和参数。索引代际不替代原件修订。预览准备和读取结束再复检源；源变化失效、同名替换不能复用旧页。
- 派生缓存放既有数据根 `index` 类别下独立目录，只有预览管理器可清理；原件、草稿和活动句柄不参与缓存清理。输出临时件验证成功后发布，失败清自己任务的临时件。
- 不将整份大二进制经 base64 JSON 一次传前端；采用有界页／资源或范围读取。文件头与真实类型核对，错误信息不暴露敏感绝对路径。
