## 3. 实现要点

1. **六组**：个人资料／外观与显示／会话与行为／新建主机默认值／数据与存储／关于，每组卡头含图标与可选标签。
2. **头像字段**：个人资料第一行“头像”，控件只有 40px 小头像按钮；点击打开既有「更换头像」弹窗（5 种样式＋自定义裁剪＋恢复默认＋取消/应用），应用即生效，不进入本页草稿。
3. **单一草稿**：除头像外所有控件只改 `form`；顶部粘附条显示“N 项未保存”并提供放弃/保存；主题与密度在选择时即时预览，放弃或关闭回滚。
4. **主题三态**：`theme` 键扩展 `system`；`AppProvider` 派生实际色并监听 `prefers-color-scheme`；顶栏切换在 `system` 下切到相反固定值。
5. **内联校验**：邮箱、名称、角色、字号、Tab、端口、用户名、时区；错误字段 `aria-invalid`＋红色原因＋聚焦首个错误，保存前不写任何键。
6. **关闭保护**：`settings:general-dirty` 事件把 dirty/count 交给 `SettingsCenter`，X／Escape／遮罩均先弹「放弃未保存的更改？」。
7. **数据与存储**：读取 `storage_data_dir`，保存走 `storage_set_data_dir`，`restartRequired` 时提示重启；知识库/日志路径只读提供复制。
8. **关于**：版本取自 `getVersion()`；检查更新调用既有 `update_check`；恢复本页默认只改草稿。

## 4. 与设计的差异（已登记）

| 编号 | 差异 | 原因与处置 |
| --- | --- | --- |
| D-CR091-01 | 头像编辑复用既有「更换头像」弹窗（680×660 modal），不是设计稿曾画的 318px 浮层 | 复用成熟裁剪能力，避免两套头像体验；设计稿已同步为“点击打开更换头像弹窗（应用即生效）” |
| BUG-CR091-01 | 修复从设置弹窗内打开头像弹窗被 `<dialog>` backdrop 遮挡的问题 | 头像弹窗改为 `<dialog>` 宿主（top layer）；已用隔离预览断言“弹窗打开且在 top layer 可交互” |
| D-CR091-02 | “占用明细（数字＋占比条）”改为“位置分类（目录标签）” | 无真实占用统计命令；不做假数字，界面明确“占用统计尚未接入” |
| D-CR091-03 | “打开目录”改为“复制路径” | 未接系统文件管理器打开能力；复制路径可用且不伪造能力 |
| D-CR091-04 | 完成后通知、启动时恢复窗口仅保存偏好 | 真实消费点未接入；界面明写“尚未接入”，不宣称已生效 |
| D-CR091-05 | 关于组版本来自 `getVersion()`；隔离预览下可能显示“未知” | 真实安装运行时可读 |
