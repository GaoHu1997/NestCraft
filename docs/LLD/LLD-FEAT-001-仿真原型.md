## CR-005：项目知识授权、需求树与统一 AI 工作台（v2.4 设计基线）

关联 [PRD-001 CR-005](../PRD/PRD-001-个人Agent界面需求.md#cr-005项目知识授权与统一-ai-工作台)、[STORY-009](../Plan/Story/STORY-009-知识库项目授权与AI检索.md)、[STORY-010](../Plan/Story/STORY-010-需求树与详细文档预览.md)、[STORY-011](../Plan/Story/STORY-011-AI侧栏上下文与会话.md)、[STORY-012](../Plan/Story/STORY-012-统一配置与CLI能力适配.md)。本节替代上文关于知识库骨架、code 主从需求布局及全局当前引擎的设计；服务器和办公职责不变，CR-003 待确认的规则不自动生效。

### 1. 两层交付边界

- **本轮设计仿真**：仍在单文件 HTML 中使用内存对象；模拟知识库授权/检索、树形需求、详情弹窗、汇总预览、设计稿入口、CLI 选择、附件元信息、@候选、/技能与会话历史。明确标注仿真，不调用 CLI、MCP、模型，不上传文件正文，不存数据库，刷新清空。本轮无需业务构建、迁移或发布。
- **正式实现方案**：需求正文采用项目目录 Markdown；SQLite 管理可重建索引、项目授权、配置引用及会话元数据，附件存受管目录。详见 [ADR-001](ADR-001-文档正文与统一能力网关.md) 和 [DB-FEAT-001](../DB/DB-FEAT-001-知识授权与工作台数据设计.md)。这些是后续实现契约，不是已接通功能。

### 2. code 需求页与文档

- `project/{id}/design` 保持兼容，展示两栏：**整个需求内容区为一个树形列表 + 右侧 AI**，没有常驻左目录和中间详情。树包含愿景 → Epic → Feature → Story，Bug 仍挂 Feature 并关联 Story。父节点的展开操作和“查看详情”分开；节点整行含编号、标题、类型、负责人、状态和文档入口，支持键盘。
- 详情使用原生 `<dialog>`，Story 的目标、范围/不包含、背景、流程、规则、AC、依赖、设计/交付链接、验证与变更记录全部可查看；弹窗关闭后保留树选择和展开状态。编辑、验证和推进在弹窗里进行；编辑弹窗与详情分阶段打开，避免嵌套 modal；进入编码时关闭弹窗，返回仍定位该 Story。
- 页头提供“预览”“设计稿”“新建 Story”。预览为单页连续汇总：愿景、Epic、Feature、Story 全部正文与关联（非仅标题或当前选中项）；可定位节点、返回需求树，状态变更后重新汇总。设计稿进入仿真设计浏览区，展示当前项目适用页面及跳转，不把真实生产页面当作设计资源。
- 源文件沿用 `docs/Plan/` 层级，Story 的稳定 ID 与元数据写入 front matter，正文为唯一事实来源；解析器依据 ID/parent/type 建树，不以物理目录位置确定层级。树/预览都由同一版本源生成，数据索引不得维护第二份正文。正式编辑用基线 hash 检查并原子写回；索引延迟时显示同步状态，不能假报保存成功。非法父关系、重复 ID、断链、路径越界应拒绝并定位；既有文档保留编号，通过导入映射索引，不强行改名。

### 3. 知识库项目授权与工具契约

- 个人工作台所有者在知识库卡片点“项目授权”，勾选项目并保存；未授权默认不可用，空授权不是公开库，取消不变更。项目 AI 显示可用库，不出现未授权库名、数量、摘要或候选。授权仅包含只读检索与阅读，不暗含修改、删除、导出权限。
- 最小工具集：`knowledge.list`（可用库）、`knowledge.search`（关键词）、`knowledge.read`（单篇/范围）、`knowledge.read_many`（批量）。输入分别为 `{cursor?,limit?}`、`{query,libraryId?,cursor?,limit?}`、`{libraryId,noteId,range?}`、`{items:[{libraryId,noteId}]}`；输出包含稳定库/笔记 ID、标题、路径别名、匹配片段或正文、源版本、可追溯引用。分页上限默认 20、最大 100，批读最大 20 项，长文按范围读取。笔记链接作为同一库内受检的导航引用，不提供写入/全库自动改链工具。
- 网关从登录主体/托管会话解析 `projectId`，不接受 AI 自报项目切换。每次执行重新校验项目-库授权和能力开关，拒绝伪造 ID、跨项目、跨库链接与路径穿越；未授权 ID 返回统一不可访问错误，避免泄露是否存在。批读逐项判定，返回允许项与统一拒绝项，不在失败信息泄露文档信息。搜索必须先按授权过滤再计算命中/数量，不能先全库搜索后仅遮标题。
- `@知识库`、自动检索、引用打开和工具调用共用网关。知识库内容视为资料，不作系统指令；引用可追溯版本，失效链接明确提示。撤权后中止涉及该库的运行/提案、使检索缓存和桥接令牌失效；后续输入不得重放被撤权正文。用户已看过的内容不可“收回”，历史可显示撤权提示；原生 CLI 不能安全清理上下文时终止其线程并要求新会话，不能继续旧线程冒充隔离。
- **强边界不是 MCP 提示词**：正式托管 CLI 不获得知识库真实路径/凭证，读写与执行工具必须受同一执行策略管理，禁止通过 shell、通用文件工具、任意 MCP 或网络绕过读取知识库目录。原生任意执行模式需要可验证的 OS/容器隔离；某 CLI/平台没有隔离能力时禁止启动需项目知识隔离的任务并说明原因，不能宣称所有 CLI 原生工具已经隔离。本轮只验证仿真网关逻辑，不证明主机级安全。

### 4. AI 侧栏与会话上下文

- 面板头部右上：新建会话、会话历史；新建保留旧会话而非清空。历史按项目隔离，服务器会话按主机隔离，记录标题、CLI、更新时间；恢复同项目消息、引用、草稿和 CLI，跨项目不能恢复。
- 输入框左上“+”：选择本地文件（仿真仅记录名称/大小/类型）、添加项目文件或当前 Story/授权知识引用。附件可移除，发送前显示传送范围；正式上传需扫描/限额与解析，失败不能显示已可用。本轮不读取附件正文，不能声称 AI 已理解本地文件。正式 MVP 建议单文件 20 MiB/单次 5 个，敏感文件提示确认，不承诺解析所有扩展名。
- 输入 `@` 弹候选：当前项目文件、需求节点、已授权库/笔记；选择形成结构化引用 chip，发送再检查授权/版本。`/` 弹启用技能与受支持命令列表，停用技能即便手输也不能执行。上下文和技能分别编译，不把用户正文里的任意路径/命令自动执行；支持上下键、Enter、Escape，中文输入法组合期间不触发发送。Enter 发送，Shift+Enter 换行。
- 输入框左下：CLI 下拉（`codex-cli`、`claude-code` 等来自 SDK 管理）；模型/思考选择从统一模型设置读取；右下发送。未安装、停用、模型/必需能力不兼容的选项显示原因。会话绑定 CLI；运行或待审提案时禁止切换；空会话可以选择，非空会话切换需确认新建并继承经授权复检的可见上下文，不伪造跨 CLI 原生线程续接。
- 仿真历史仅同标签页内存保留；正式会话历史用数据库保存消息、附件引用与原生线程 ID，密钥不进入历史。项目的需求/编码共用项目会话容器，恢复时更新当前可见上下文而不串到办公或其他项目。

### 5. 一处配置、按能力适配

- Settings Registry 唯一管理 provider/baseURL/secretRef/model/reasoning、引擎安装信息、MCP 连接/启用、Skill 包与 Tools 策略；项目授权和会话选择只能进一步收窄，不能重新配置同一凭证。优先级：全局默认 → 项目可用范围 → 会话选择；**权限取交集**，会话不能扩大范围。
- Gateway 编译 `EffectiveCapabilities{projectId,sessionId,cliId,modelRef,configRevision,knowledgeGrantRevision,tools,skills,mcp}`；工具与 MCP 经统一网关暴露，适配器生成受管的短期 CLI 配置/启动参数；Skill 按目标引擎支持方式转换为指令/命令或桥接。不得覆盖用户原生配置，不把明文密钥复制到仓库；配置版本/能力摘要可供诊断，不含秘密。
- Context Compiler 区分 `tool/resource/prompt/skill/client-command`：@先解析稳定对象并由宿主校验/读取后注入，不假设非交互CLI能解析@文本；MCP资源走resources/list-read、模板走prompts/list-get、工具走tools/list-call，适配后显示来源/分页和注入状态。工具schema/CLI版本发生变化重新预检，不能把连接成功当全部能力可用。
- 兼容矩阵区分“原生支持 / 网关适配 / 不支持 / 未验证”；支持任意 provider、推理档位、工具、原生技能或历史不是所有 CLI 的天然事实。启动前预检模型、网络协议、桥接连接和必需工具；不兼容时提供修复入口或让用户明确换引擎，**不静默换模型、回落 CLI、忽略技能或关闭安全门槛**。

## CR-011：引用浮层、多会话与子智能体用量（v2.9）

关联 [STORY-020](../Plan/Story/STORY-020-引用与能力检索浮层.md)、[STORY-021](../Plan/Story/STORY-021-多会话历史与后台任务.md)、[STORY-022](../Plan/Story/STORY-022-按需子智能体与用量统计.md)。用户2026-11-18新增四项。本节优先于旧“新会话清空/待审或逆向禁止新建”的限制：**新建/切换只改变查看指针，不终止旧任务**；权限撤销、源/Git/版本冲突仍须失效，不能承诺永不停止。

### 引用与检索

- 输入框左上+是引用，不立即执行能力。点击在textarea上方打开同宽浮层，最大高为textarea高度2倍，可内部滚动；首行为选择文件，触发本地系统文件选择；后续知识库、项目文件、本项目会话记录、能力（Skill/MCP/Tools）。本轮本地文件仍仅元信息，不读正文/不上传。
- @关键词检索文件名/路径、授权知识笔记标题/正文等引用；/关键词检索启用能力并引用，都用同一浮层，不在普通页面下方展开。选择形成稳定ID对象/chip，发送前复检；选择本身不等于工具调用或授权。Skill可保兼容命令文本，但未发送不执行，风险工具仍审批。
- 知识/文件/历史/能力候选按当前项目/主机与权限过滤，不能引用他项目或停用能力；历史内容发送时重新剔除撤权资料，不把旧会话授权当新授权。候选受限分页，空/加载/失败与无权限区分；键盘/IME/ESC/点击外部可操作。

### 多会话与历史

- 历史图标放AI头部左侧，桌面向左打开与AI面板同高的浮层，内部列表滚动；窄屏限制视口内，不产生横溢出。行显示标题/CLI/状态/更新时间；未读项前圆点：成功绿、失败红、待处理黄，带文字/可访问标签，进入会话标已读。
- 消息/运行/提案/草稿/配置属于sessionId，项目当前会话只为显示指针。新建保旧会话（包括运行任务与待审提案），恢复不暂停新会话任务；异步输出写所属会话，不写当前会话。后台新结果/状态变化标未读，新建操作本身不伪造未读。
- 逆向任务按创建时sessionId查会话，不再读取当前会话；同会话运行时CLI/模型不可原地更改，新空会话可以独立选择。新建不触发旧任务会话基线失效；真正会话/配置/目录/Git/权限变化仍拦截。
- 项目草稿共享但任务结果独立；多个提案应用前检验目标hash/revision/所属会话与项目，先应用者使旧冲突提案失效。任会话运行或待审时，涉及项目Git/源码写操作必须按冲突规则处理，不能新建空会话绕过锁；只读浏览允许。

### 子智能体与统计

- 主模型先评估任务价值/复杂度/独立子目标/依赖与权限，输出是否委派、理由、任务和写入边界；普通问答/单点任务不默认开子智能体。不得仅按关键词或用户点名绕开配置难度/数量/预算门槛。真实CLI/模型/工具从统一设置与有效权限交集提供，不重配。
- 并行子任务各绑定parentSessionId/projectId、模型/CLI、源版本和各自文件边界；互不覆盖，共享结果由父任务审查/验证后提案应用。子任务不能自动扩权/批准高风险动作或把源内容当系统指令。新会话不会取消这些任务。
- 会话页顶部仅有子任务时显示“n个子智能体”下拉，行有任务名、状态、执行时间、token值/来源，支持查看输出；失败/取消/超时明示，不把日志数量当进度。
- 输入框下方一行：本会话对话轮数、请求次数、tokens（含子智能体）、上下文占比。轮数按用户消息；请求/tokens以requestId去重，父自身+全部后代各一次，不能重复加已聚合子数，也不串其他会话。子摘要再次输入父模型是一笔新请求，不按文本相同去重。
- 真实usage来自CLI/provider适配事件（input/output/cache/reasoning等按实际契约），缺失标未知。上下文占比只当前会话窗口，用模型可信额度，不能把所有子独立上下文相加；额度未知不假造百分比。
- 本轮无真实模型调用：按固定“独立并行评审”示例模拟模型判断与多个异步只读子任务，普通任务不开；用量标仿真/估算，演示上下文预算不代表模型实际窗口。不能把它报为真实账单或语义智能已接通。

### 数据/验证

复用DB会话/消息/执行快照，增加会话查看指针/未读与状态、引用对象、子任务父链和usage事件账本。事件含sessionId/taskId/requestId/source/estimated，统计可重建；无本轮真实迁移。

验证：浮层位置/同宽/限高、本地文件触发/@和/候选及撤权；历史左侧/同高/未读颜色与已读；运行/待审旧会话新建恢复不打断、消息归属与原逆向推进；普通任务不委派、独立示例并行/下拉与父子统计去重/不串会话/上下文估算标签；既有差异、知识与Git规则及双视口回归。真实智能体执行/usage/context额度和系统隔离未接通，后续须实测。
