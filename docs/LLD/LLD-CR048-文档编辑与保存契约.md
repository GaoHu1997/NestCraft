# LLD-CR048：文档编辑与保存契约（设计增量）

- 依据：[CR-048](../PRD/CR-048-文档自动保存与预览内编辑.md)／[UI-CR048-v2](../UI/文档/UI-CR048-文档自动保存与预览内编辑.md)。只在可操作原型中演示，不修改正式软件或数据库，不授权跨Feature编码。
- 业务归属沿各源Story，正式实现必须分成FEAT-003／004／006／007／008／009独立执行包；本方案仅固定统一交互契约，不把跨域协调改名成共享Feature。

## 1. 设计模型

1. 正文编辑器使用稳定tuple：`kind + projectId/libraryId + fileId`。每对象保存独立缓冲、成功基线、定时器、撤销重做、读写态和错误；写入闭包绑定原对象，不能在回调时读取全局当前选中文件。
2. 正文输入先更新内存缓冲与本页TOC，900ms无输入后尝试提交；失焦／切页／快捷键提前提交同一缓冲。输入法composition期间不保存半个汉字，结束后再计时。
3. 正常保存不弹窗，不存在日常保存按钮；状态有已保存、待处理、保存中、失败和冲突。失败保全文，提供重试；冲突不可由重试强写绕过。关闭视图保留模型，不能因为卸载清掉失败内容或重开恢复旧正文。
4. Markdown可视编辑保留标题、段落、内联格式、列表、表格和代码块的语义。未改变的块保原Markdown片段与分隔字节，不以通用innerText重组全篇。源码文件用代码编辑器。知识阅读态锁正文且格式工具条隐藏，编辑态仍为排版，不显示整页Markdown语法框。
5. 自动保存不清撤销重做。已保存误改可撤销成新缓冲并再次自动保存；不依靠一个「恢复上次保存」按钮模拟误改保护。

## 2. 范围与新建

- 编码原型只处理已有合成工程文件；源不存在不将空串当成功读取。路径与后端真实CAS沿原正式方案，本批未实现。
- 需求正文只处理已提供正文的源节点；元信息事务、AC维护、派发和汇总仍各自保持原语义。合成情景愿景按项目保留，不反复生成覆盖用户编辑。
- 设计文档自动保存只标待同步，不自动确认关联需求或运行资格。不能把元信息、模型设计或供应商配置的提交一概取消。
- 知识源同库／文档独立，只读项目AI不获写权限。新文档标题字段是文件命名，Enter／失焦明确确认完整名称后才以create-only新增；命名未确认／非法／同名保存拒绝，内容保留。后续正文自动保存核基线，不改同名原件。
- 办公原件保持只读，可先创建编辑副本；Markdown／基础Word文字在排版内改，Sheets沿公式条、PPT沿页面正文。模型原有AI候选审阅门槛继续有效，自动保存不得替代接受／拒绝。

## 3. 原型与正式软件分开

[公共原型资源](../UI/workbench-v4/live-doc.js)使用浏览器contenteditable和本地格式动作，仅回答交互设计问题，不是选定正式编辑器，也不承诺全部Markdown扩展语法无损往返。正式实现需选已有成熟Markdown结构编辑器，核许可证、UTF-16映射、表格／代码／链接／未支持节点／粘贴安全和导入导出测试；不能直接把演示序列化器拿去覆盖用户文件。

正式保存要有后端原子写／CAS、队列代次、可靠恢复缓冲与失败关闭保护。正文仍是文件权威；派生索引失败独立反馈，不把旧索引回写文件。复用[文档与授权数据设计](../DB/DB-FEAT-001-知识授权与工作台数据设计.md)及[办公版本数据设计](../DB/DB-FEAT-006-办公文件与提案版本.md)，本批不改表、不迁移、不写第二份正文。持久恢复模型／配额若需新增存储，进入相应Feature正式数据设计，不假装纯内存已满足。

## 4. 安全与验证

- 原型只合成内存，不接真实本机文件、私密库、SSH、CLI、模型和外部网络；HTML／SVG不运行，图片与外链不自动加载，富文本粘贴只接纯文本。权限不以隐藏按钮代验。
- 按[UI-CR048](../UI/文档/UI-CR048-文档自动保存与预览内编辑.md)检查编码MD、代码、知识阅读／编辑／新建／失败／冲突、需求正文、设计正文、办公基础编辑、浅深和窄屏。
- [设计验证脚本](../Test/cr048-browser-check.mjs)运行隔离Chrome并记录原型操作与截图；[实际报告](../Test/REPORT-CR048-文档编辑设计验证.md)记录失败、复测与未执行项。代码CAS和磁盘持久化、完整格式／崩溃恢复、正式软件同条件截图未执行，不计完成。

## 5. 继续开发前门槛

每个责任Feature必须另有正式编码授权、全部AC义务包、UI-CR048-v2或后续有效版本、成熟编辑器／存储方案及数据结论，然后执行软件功能和逐场景视觉对照。本轮只完成设计交付，不发布、构建、提交或推送。
