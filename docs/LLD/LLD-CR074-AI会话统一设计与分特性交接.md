## 1. 当前问题与选定方向

用户反馈集中在双布局功能／样式割裂、输入聚焦内框、过大工作标识、模型位置／图形／思考顺序、统计字段和历史关闭／搜索交互。共享CSS或使用相同组件名不能证明会话状态与事件同源，也不能替代视觉对照。

选定方向：项目级会话控制源只管理一次身份、消息、草稿、队列、运行／配置与统计；composer、history、模型／统计和消息呈现复用同一实现，工作台与侧栏只提供布局外壳。原型为纯演示，不接真实网络／业务；正式软件的实例、订阅与根因需要后续授权后的隔离复现，不把只读检查当实测。

## 2. 共享契约与边界

| 契约编号 | 强约束 |
| --- | --- |
| IF-074-01 会话身份 | 两布局共享当前sessionId、配置、消息与运行控制；布局变化不新建、不重复订阅／发送，能力输入不因宿主不同而丢失 |
| IF-074-02 公共呈现 | composer／history动作同源；历史常驻／浮层只改变外壳。模型弹层锚定当前可见按钮，不借第二AI实例；保留附件／引用、发送／停止／队列及各既有入口 |
| IF-074-03 模型／档位 | 候选仍来自已配置且兼容的可用集合；浏览供应商不自动提交，显式选模型保留会话ID。展示排序与wire值映射分离；未知自定义档位不删、不猜其强弱，运行／审批锁定与失效原值禁发不回落保持 |
| IF-074-04 计量 | 轮／步／TPS、Token／缓存命中、当前上下文比例分别使用可信字段；按现行requestId去重及root归因，缓存互斥。累计token与当前窗口不混用；未知为—，零值保留；步数不得在Q-CR074-01解决前映射消息／请求／计划数量 |
| IF-074-05 搜索／菜单 | 原始搜索草稿与规范化查询分离，IME组合期间不提交中间查询，结束后查询最终文字；旧响应不能覆盖新词。局部结果更新保留输入DOM、焦点与选区；外点仅关菜单不拦目标动作，不抢搜索焦点 |

本批不新建／修改持久数据结构：会话身份、模型偏好、消息及已有usage继续复用；历史沿用[DB-CR063分页索引](../DB/DB-CR063-会话历史分页索引.md)与[DB-CR065置顶字段](../DB/DB-CR065-会话置顶字段与索引.md)。无需迁移或生产数据操作；步数可信源若后续必须新增持久字段，先解决口径并另行登记数据设计，不能借UI调整直接迁移。

## 4. 必需义务与验证计划

- 各包必须携带[UI-CR074-v1的SC-074-01～10](../UI/文档/UI-CR074-AI会话双布局统一.md#2-页面状态覆盖登记)、完整责任AC、采用资源版本／实际hash及不包含项；设计缺口或未决视觉冲突不准入。
- **UI-SCROLL-001**必须同时读取[UI-CR049-v1](../UI/文档/UI-CR049-滚动条按需显示.md)与[CR-049](../PRD/CR-049-滚动条仅在滚动时显示.md)。消息、历史、模型两列及textarea覆盖初始隐藏、实际滚动显示、连续重置、最后滚动后700ms隐藏、嵌套隔离、编辑／光标／选区保持；不禁滚、不改宽，hover／focus不唤醒。每包登记责任文件与动态证据，不能仅传截图而漏此义务。
- 设计侧与软件侧分开：浅／深、1440×900与390×844、同夹具／缩放／字体／状态的成对视觉；动态滚动序列无测试专用隐藏样式。每条AC实际标通过／失败／未执行／有依据的不适用，构建exit0或DOM断言不能替代视觉。
- 正式开发授权后才运行相关软件测试／构建；本轮不发布、不迁移、不推送或操作真实私密会话。可逆代码回退只在对应Feature受控变更范围内，禁止重置并行修改；设计变更先登记新版，旧证据受影响即失效。
