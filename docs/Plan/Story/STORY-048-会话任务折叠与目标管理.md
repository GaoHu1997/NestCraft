# STORY-048：会话任务折叠与目标管理

- 类型：用户故事；所属 [FEAT-011](../Feature/FEAT-011-会话历史与后台任务.md)。
- PRD：[CR-019](../../PRD/CR-019-AI会话完整控制与统计设计.md)；来源与确认依据：2026-11-19用户第1项完整要求及本轮仍只设计。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / 待验收 / 当前统一稿会话身份、目标与任务引用。
- 目标：用户在输入前了解本会话任务进度，折叠细节但能维护目标；目标与原需求Run状态保持独立。
- 包含：任务摘要/展开列表、任务名称/状态、目标创建编辑/暂停恢复/删除确认、空态/忙碌/错误、状态与会话隔离。
