## 验收标准

- **AC-STORY-101-01**（成功路径）：给定项目已加载目录树，当在目录节点右键选择「新建文件」或「新建文件夹」，则出现行内输入框，输入合法名称并回车后在**正确父目录**下创建，树中即时出现该项；新建文件后该文件在编辑区打开。验证方式：设计原型操作 + 自动化。
- **AC-STORY-101-02**（键盘可达）：给定文件树中某节点获得焦点，当按 F2／F5／Delete，则分别进入重命名行内编辑／刷新当前目录／弹出删除确认；按 Escape 取消命名，且不改变文件。验证方式：设计原型操作 + 手工键盘走查。
- **AC-STORY-101-03**（边界：重名／非法字符／空目录）：给定父目录已存在同名项、或输入含非法字符（`/ \ : * ? " < > |`）、或在空目录中新建，当提交命名，则重名与非法字符被拒并就地提示错误、不产生文件、不关闭输入框；空目录可正常新建。验证方式：自动化 + 手工。
- **AC-STORY-101-04**（失败与恢复：删除确认）：给定选中文件，当执行删除并确认，则文件被删除；取消则不删除；操作失败（只读/被占用）显示失败提示，且**不丢失已打开文件的编辑内容或未保存缓冲**。验证方式：手工 + 自动化。
- **AC-STORY-101-05**（权限／越界）：给定目标路径试图逃出项目根（如 `../`、符号链接越界）或目标为只读，当执行新建／重命名／删除，则后端拒绝并提示，磁盘无越界写入，编辑内容不变。验证方式：自动化（路径校验）+ 手工。
- **AC-STORY-101-06**（超大目录／深色窄屏）：给定含数千项的大目录或窄屏深色主题，当打开右键菜单与行内输入，则菜单可见不溢出、滚动按需（UI-SCROLL-001）、行内输入可用、不破版。验证方式：设计原型操作 + 视觉对照。
