# STORY-026：工作台界面与导航调整

- 类型：用户故事（界面细化）
- 所属 Feature：[FEAT-001 工作台框架与可操作评审](../Feature/FEAT-001-工作台框架与可操作评审.md)
- 关联：CR-014；FEAT-002（视觉）、FEAT-003/004（需求与设计）、FEAT-007（文件与 Git）、FEAT-009（知识阅读）、FEAT-010/011（会话）、FEAT-013/014/015（设置）、FEAT-016（服务器）
- 来源与确认依据：2026-11-19 用户以十三张截图逐项指定调整范围，并明确"严格按下面调整、不要自由发挥、不要询问、只要结果"
- 负责人 / 优先级 / 状态 / 依赖：lead / 高 / 待验收（技术验证通过）/ 无外部依赖
- 目标：作为工作台使用者，我希望导航、知识库、项目工作台、服务器工作台与设置中心采用同一套简洁视觉与完整可用的交互，以便不跳页、不丢上下文地完成评审。

## 本次包含

1. 全局视觉改为白色分层、浅灰底、蓝色主操作、细分隔线、无衬线标题；项目分类改为编码/办公，项目页签改为需求/设计/编码。
2. 项目管理、知识库、服务器三个列表都在全局导航内原地切换；只有进入项目、知识库内部或主机才切局部页面；移除知识库"快速目录"。
3. 知识库内部为空间/搜索/目录、文档正文、标题目录三栏。
4. 需求树只含史诗/特性/用户故事，编号可见，悬浮或键盘聚焦显示新增子项与编辑/删除；愿景移入项目信息；顶部不显示基线。
5. 需求页与 AI 会话分为两个独立满高区域；需求页右上只有预览与新建史诗。
6. 需求预览按史诗 h1 / 特性 h2 / 用户故事 h3 连续展示，带右侧目录，并保留 AI 会话。
7. 设计工作区为极窄图标栏（UI 设计、模型设计）；UI 稿直接可见并可外部打开；模型设计逐表显示字段表、右侧表目录，可编辑并生成 Markdown。
8. 编码工作区为文件树、行号编辑器、文件页签与满高会话。
9. Git 为未提交 / 分支 / 提交历史三段纵向布局，提交框固定，保留暂存、提交与分支操作。
10. AI 会话为深色会话条、居中空状态、任务/子代理/编辑工具条与底部模型控制。
11. 服务器列表在全局壳内展示；工作台为文件树、终端（欢迎信息、快捷命令）、实时监控（系统信息、CPU 每核、内存）。
12. 基础设置统一管理用户信息、外观与代码样式。
13. 供应商编辑四页签：密钥表、显示名称、协议分段、API 地址；模型折叠行、模态、思考档位、默认强度、上下文窗口与最大输出；高级请求头与请求伪装；逐模型指纹。
14. SDK 设置含 registry、内置子代理提示与可展开 CLI 版本卡；Skill/MCP 开关后无文字且可创建。

## 本次不包含

- 真实 AI/CLI/SSH/Git/npm/数据库调用、真实凭证存储、附件上传、真实模型指纹判定。
- 新增业务范围、权限规则、计费或发布流程。

## 验收标准

- AC-STORY-026-01：给定任一列表页，当点击左侧项目管理/知识库/服务器，则内容在右侧切换且全局导航保留；进入单库、单主机或项目后才出现局部页面。
- AC-STORY-026-02：给定知识库列表，当查看操作区，则不存在"快速目录"入口。
- AC-STORY-026-03：给定知识库内部，当打开一篇文档，则显示空间/目录、正文、标题目录三栏；标题只渲染一次，点目录可定位。
- AC-STORY-026-04：给定项目需求页，当查看树与页头，则只有史诗/特性/用户故事三级并显示编号；页头只有预览与新建史诗；愿景不出现在树中。
- AC-STORY-026-05：给定需求行，当悬浮或键盘聚焦，则出现对应新增子项、编辑与删除操作。
- AC-STORY-026-06：给定需求预览，当滚动正文，则史诗为一级、特性为二级、用户故事为三级标题，右侧目录可定位，AI 输入区保持可用且不重建会话。
- AC-STORY-026-07：给定设计页，当切换 UI 设计/模型设计，则只有极窄图标项；UI 稿直接显示且可外部打开；模型设计每个表有描述与字段表，右侧表目录一一对应，可生成 Markdown。
- AC-STORY-026-08：给定编码页，当打开文件，则显示文件树、文件页签、带行号编辑器与满高会话。
- AC-STORY-026-09：给定 Git 页，当查看布局，则未提交、分支、提交历史三段纵向排列，提交框固定，暂存与提交仍执行原校验。
- AC-STORY-026-10：给定服务器工作台，当已连接演示主机，则显示文件树、终端欢迎信息与快捷命令、实时监控指标。
- AC-STORY-026-11：给定基础设置，当保存用户信息、外观或代码样式，则本页生效且不写真实配置。
- AC-STORY-026-12：给定供应商编辑，当切换四个页签，则密钥表、模型配置、请求头与指纹视图分别可见；模型展开后思考档位与容量字段可用，默认档位必须属于已选档位。
- AC-STORY-026-13：给定 SDK 设置，当查看列表，则只有 Claude/Codex/Grok 三个可装卸 CLI，内置子代理仅提示不可作为 CLI；会话候选只含已安装且启用的 CLI。
- AC-STORY-026-14：给定 Skill/MCP/Tool，当切换开关，则开关后没有文字（保留无障碍名称）；Skill 与 MCP 可创建并在重名或必填缺失时拒绝。
