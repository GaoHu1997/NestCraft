## 验收标准

- AC-STORY-002-01：给定 code 项目，当进入项目时，则展示三栏：左侧目录树、中间代码内容（tab + 语法高亮 + 状态条）、右侧 AI 助手（工具卡片、diff 卡片、权限模式、模型/思考等级、上下文用量）。
- AC-STORY-002-02：给定 work 项目设计 tab，当打开时，则顶部展示迭代概览条（迭代周期、进度条、状态统计 chips、新建 Story）；左侧需求树支持 Epic → Feature → Story 层级，并支持 Bug 节点与八种状态点 + 图例（含缺陷色）。
- AC-STORY-002-03：给定选中的 Story，当查看详情时，则展示完整闭环字段：目标、验收标准（AC 编号 + Gherkin 式描述 + 勾选态）、关联与交付（PRD / 参考 / 知识库 / 交付物）、验证记录（各 AC 的验证方式、结果、日期、阻塞项）、状态流转按钮（推进到下一状态）。
- AC-STORY-002-04：给定 work 项目编码 tab，当切换时，则左侧为办公文件树（md / docx / xlsx / pptx / pdf），中间为对应预览（xlsx 含公式条与 sheet 页），右侧 AI 助手。
- AC-STORY-002-05：给定 1440×900 视口，当渲染以上 3 屏时，则布局完整、无遮挡、无渲染缺陷。
