# STORY-011：AI 侧栏上下文与会话

- 类型：用户故事；所属 [FEAT-010 AI 上下文与能力引用](../Feature/FEAT-010-AI上下文与能力引用.md) / [PRD-001 CR-005](../../PRD/PRD-001-个人Agent界面需求.md#cr-005项目知识授权与统一-ai-工作台)。
- 来源与确认依据：2026-11-18 用户指定会话框左下 CLI、左上 + 文件上传、@ / 能力，侧栏右上新建会话与历史。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / 设计中（仿真待评审）/ [STORY-009](STORY-009-知识库项目授权与AI检索.md) 的权限过滤、[STORY-012](STORY-012-统一配置与CLI能力适配.md) 的配置适配。

## 用户价值

作为项目使用者，我希望在同一个 AI 侧栏选择执行 CLI、明确添加上下文并恢复历史会话，以便持续处理需求或文件，不重复找资料、不丢失会话，也不把项目上下文串到别处。

## 布局与行为

- 面板右上：新建会话、会话历史。新建归档/保留当前会话，不等同“清空聊天”；历史按项目/主机隔离，含标题、更新时间、CLI，恢复消息、草稿、附件/引用和 CLI。
- 输入区左上 +：选择本地文件、项目文件、当前需求或授权知识引用；附件 chip 显示名称/状态/范围、可移除。正式流程为选择 → 本地校验 → 上传/解析 → 可用或失败 → 发送前确认；不能在上传失败时显示 AI 已读取。
- 输入 @：候选来自本项目文件、需求和授权知识；选择形成带稳定 ID 的引用。输入 /：启用技能/受支持命令，区分 skill、client-command、MCP prompt；不把普通字符串直接当 shell 或 tool call。
- 左下 CLI，模型与思考可选；右下发送。CLI 来自 SDK 清单，禁用/未安装/不兼容状态提示原因；设置默认与会话选择独立。
- 空会话可选择 CLI；非空切换需确认另建会话、继承允许上下文，不假装不同 CLI 共享原生 thread。运行或待审时不能切换；历史恢复重新检查配置、权限和附件有效性，不恢复过期可执行提案。
- 键盘：候选上下键/Enter 选择，Escape 关闭；候选未激活时 Enter 发送、Shift+Enter 换行，IME 组合输入不误发送；附件和菜单可键盘操作。
- 本轮边界：本地附件只取名称、大小、类型，**不读正文、不上传、不解析**；显示“仅元信息仿真”。历史仅内存、刷新重置。真实 MVP 建议单文件 20 MiB、每次 5 个，超限/不可解析提示；不默认支持任意格式，不增加真实上传服务。

## 验收标准

| 编号 | 给定 / 当 / 则 | 本轮方式 |
| --- | --- | --- |
| AC-STORY-011-01 | 给定任意项目/主机 AI，当查看侧栏，则右上有新建和历史，输入左上 +、左下 CLI、右下发送；来源/执行目标清晰。 | UI 检查 |
| AC-STORY-011-02 | 给定本地文件，当选择或移除，则显示/移除元信息 chip，明确未上传和未读正文；取消选择不新增附件，超限有错误。 | 浏览器 File 样例与 chip |
| AC-STORY-011-03 | 给定项目上下文，当输入 @ 或 / 并用键盘选取，则只出现可用项并形成引用/命令；Escape 关闭不发送，IME 不误发送；禁用技能手输带参数也不能执行。 | 键盘 + 禁用回归 |
| AC-STORY-011-04 | 给定已有消息/草稿/附件，当新建并恢复历史，则旧会话保留且正确恢复；同项目需求/编码共享，其他项目或主机不能恢复。 | 会话隔离断言 |
| AC-STORY-011-05 | 给定非空会话，当切 CLI，则须确认新建而非原生线程续接；取消保持原 CLI/会话，待审或运行时不能切换。 | CLI 切换/取消/禁用 |
| AC-STORY-011-06 | 给定权限撤销、工具禁用或附件失效，当恢复历史或发送，则复查并提示不可用，不把旧引用或提案自动执行；新会话不扩权。 | 仿真引用与审批；真实线程/附件恢复待实现 |
| AC-STORY-011-07 | 给定真实上传/解析失败或非交互 CLI 不识别 @，当发送，则说明注入状态并拒绝伪称已读取；宿主解析为结构化上下文后才交给执行目标。 | 正式接入测试，本轮未执行 |
