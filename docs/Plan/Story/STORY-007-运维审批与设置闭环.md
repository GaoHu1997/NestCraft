# STORY-007：运维审批与设置闭环

- 类型 / 归属：[FEAT-017 运维授权与操作审批](../Feature/FEAT-017-运维授权与操作审批.md)下的用户故事；规格见 [PRD-001 CR-003](../../PRD/PRD-001-个人Agent界面需求.md#cr-003闭环需求规格待评审尚未实现)。
- 来源：2026-11-18 用户要求补全闭环；规则待评审。
- 优先级 / 负责人 / 状态：P1 / 本轮负责代理 / 待确认。
- 用户价值：能区分连接、授权、批准与操作结果；失败或撤权后知道为何未执行、如何重新发起。
- 范围：已有服务器工作台、设置及仿真审批；只读样例和固定成功/失败场景，不访问真实主机或凭证；不预设正式权限策略。

## 验收标准

| 编号 | 给定 / 当 | 则 |
| --- | --- | --- |
| AC-STORY-007-01 | 手动尝试模拟连接离线主机，或在在线但未授权主机请求 AI；从另一授权主机切回来 | 离线时给失败原因和重试入口，授权不改变；三项前置条件分别可见，另一主机的授权不继承；未授权时不生成可批准提案。 |
| AC-STORY-007-02 | high-risk 仿真提案等待确认；依次演练拒绝、断开、撤权、停用工具中的任一项，再恢复条件 | 每个分支都留可关联的终态和原因，无执行成功结果；恢复条件不能恢复原提案，必须重新申请。 |
| AC-STORY-007-03 | 批准一条满足前置条件的提案，分别选固定成功和固定失败场景；尝试再次批准或重试失败 | 批准和模拟结果各自可查；失败有原因、无成功记录，旧申请不能重复执行；重试产生新申请，需再次批准。 |
| AC-STORY-007-04 | 在设置修改默认模型、会话选择，停用失败会影响当前会话的引擎或 Skill | 默认配置与会话配置影响范围明确；无可用引擎不可发送，提示设置入口；停用 Skill 后快捷入口和手输命令均无法触发；MCP 不建立实际连接。 |

- 依赖：仿真主机、模型/SDK/能力开关；Q7 仅决定正式权限策略，不作为展开本地单次确认场景的依据。
- 验证与交付：待评审后补设计与仿真用例；当前新增规则未实现、未做功能验证。
