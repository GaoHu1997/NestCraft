# STORY-040：依赖与资源约束自动调度

- 类型：用户故事（新增能力）。
- 所属：[FEAT-019 依赖调度与受管执行](../Feature/FEAT-019-依赖调度与受管执行.md)。
- PRD：[PRD-002](../../PRD/PRD-002-需求派发与自主执行.md)。
- 来源与确认依据：[CR-016](../../PRD/CR-016-需求派发与自主研发任务系统.md)，2026-11-19 用户要求完整需求与设计；不授权本轮真实调度。
- 负责人：文档代理；优先级：P1；状态：设计中；依赖：STORY-038 快照；STORY-041 租约与执行控制；STORY-042 产物验证/集成门槛。
- 目标：作为研发使用者，我希望独立任务并行而有依赖或共享冲突的任务自动等待，以便一次派发后安全利用并发能力。
- 本次包含：执行 DAG、产物门槛、并发槽、规范化资源锁、队列公平性、独立分支继续与批次聚合。
- 不包含：按业务父子顺序盲目排队、自动扩需求、实际 OS/CLI执行或默认合并主分支。

## 验收标准

| 编号 | 可观察标准 | 验证方式 |
| --- | --- | --- |
| AC-STORY-040-01 | 给定业务层级与显式执行依赖，当创建 DAG 时二者分别保存；自依赖、循环与跨项目非法边拒绝并返回闭环/非法边，不启动任一节点。 | 图验证测试 |
| AC-STORY-040-02 | 给定无依赖且资源独立的合格任务，当授权最大并发为 N 时自动同时启动不超过 N 个；并发不足时等待而不是额外启动，释放槽后自动推进。 | 调度时序测试 |
| AC-STORY-040-03 | 给定前置产物，当其验证门槛通过且修订已进入当前可消费基线时才放行后继；仅 exit 0、失败、取消、证据失效或产物不可消费均不放行。 | artifact gate 测试 |
| AC-STORY-040-04 | 给定两个任务声明重叠的写资源或相同集成/迁移资源，当领取时锁与槽在一个事务内获取，仅一个持有独占锁；UI 标明另一个的占用者，任务提示词无法越过锁。 | 锁互斥/规范化测试 |
| AC-STORY-040-05 | 给定允许的资源已释放，当队列推进时按优先级再按入队时间稳定选择，等待任务无空转抢占；租约失效但旧进程未停不能将写锁交给新进程。 | 公平性/租约测试 |
| AC-STORY-040-06 | 给定前置失败/取消或外部依赖不可用，当后继阻塞时记录原因及需要的产物/决定，独立节点继续；队列静止且混合成果时批次成为 partial，不永久显示运行中。 | 分支隔离/聚合测试 |
| AC-STORY-040-07 | 给定任务领取后配置撤权、预算不足或输入修订失效，当真正启动前重检时阻止 spawn 并持久化阻塞原因；不通过改 AC、换引擎或删依赖自动解阻塞。 | 启动二次校验测试 |
| AC-STORY-040-08 | 给定集成资源可用且多个产物待集成，当派送到本地允许集成分支时串行处理，后继明确消费新验证基线；未获集成授权时仅保留独立产物和可审阅报告。 | 串行队列/消费基线测试 |
