# STORY-021：多会话历史与后台任务

- 类型：用户故事；所属 [FEAT-011 会话历史与后台任务](../Feature/FEAT-011-会话历史与后台任务.md) / [PRD-001 CR011](../../PRD/PRD-001-个人Agent界面需求.md#cr-011引用浮层多会话与子智能体用量)。
- 来源：2026-11-18用户指定左历史浮层/未读绿红黄点、多会话新建不打断当前任务。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / 设计中 / 会话ID、任务绑定、权限与提案版本。

作为项目使用者，我希望在多个会话间切换而后台任务继续，并明确知道哪些会话有未读结果和待处理事项。

- 历史图标在AI头部左侧，桌面向左打开同面板高度的浮层；窄屏保持视口内可滚。
- 未读项圆点成功绿、失败红、待处理黄并有文字；查看标已读，后台新结果/状态改变才标未读。
- 新建/恢复只变查看指针，旧运行/待审/草稿保留。回复按任务所属sessionId写入，不能写当前新会话；同运行会话不能原地改CLI/模型，新空会话可选不同配置。
- 源/权限/版本变更仍会安全失效；共享项目写入按冲突门，不能新建会话绕旧锁，不承诺永不停止。
