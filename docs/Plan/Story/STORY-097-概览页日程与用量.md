### 日程 Tab

- AC-STORY-097-04：月历显示 7 列（一～日）与「YYYY年M月」，可切上一年 / 上月 / 下月 / 下一年与「本月」；今天有高亮；点击任一天切换选中并同步右侧详情。
- AC-STORY-097-05：法定节日显示红色角标；传统节日显示节日名；二十四节气显示绿色角标；农历日名每月初一显示月名、闰月带「闰」、除夕优先；同日节日与节气上下两行并存。2025–2027 年调休显示「休 / 班」，其他年份不显示。
- AC-STORY-097-06：三个入口（月历右上按钮、单元格悬停「+」、详情栏按钮）均可打开新建日程弹窗；标题必填，结束日期不早于开始日期，保存后月历与详情栏即时刷新并写入本机库。
- AC-STORY-097-07：跨天日程在月历上以连续条带横跨多日（起始左圆角、结束右圆角、中间平直），跨月时在相邻月从月初或到月末截断；单元格最多显示 3 条，超出显示「+N」。
- AC-STORY-097-08：点击日期后右侧出现详情栏，**高度与月历卡相等且顶部对齐**；**顶部蓝条显示当前位置天气**（位置「城市 · 区」、当前温度、天气文字、低温 / 高温、更新时间；不含农历干支）；含日期标题与今天 / 未来 / 过去标识、黄历（农历、年月日干支、生肖、值日、宜 / 忌）、当天节日 / 节气；黄历下方为「日程 / 待办」**两个可切换页签**：日程页签列出当天日程（含跨天覆盖），待办页签列出当天待办。
- AC-STORY-097-09：待办页签内可勾选完成、回车新增；日程页签内可删除日程（需确认）；切换页签不改变选中日期，右栏保持与月历等高。
- AC-STORY-097-17（编辑日程，v6，2026-11-25）：详情栏日程行提供「编辑」入口、点击月历条带也可进入编辑；弹窗回填原标题 / 日期 / 时间 / 颜色 / 备注，保存后以同一 id 更新原日程，不新增重复条目。
- AC-STORY-097-18（选中态不撞色，v6，2026-11-25）：选中日期为「中性浅底 + 主色描边」，与蓝 / 绿 / 琥珀 / 紫 / 玫红五种日程条带色可区分；浅色与深色主题下均成立。
- AC-STORY-097-19（编辑待办，v6，2026-11-25）：待办行提供「编辑」入口，点击后行内编辑标题；Enter 或失焦保存、Esc 取消，空标题不覆盖原值；勾选完成与新增行为不变。
- AC-STORY-097-20（年月快速切换，v7，2026-11-25）：月历表头提供上一年 / 上月 / 下月 / 下一年 4 个独立按钮（« ‹ › »）与「今天」；点击「YYYY年M月」弹出年月选择器，可步进年、点月份直接跳转，点遮罩或 Esc 关闭；从任意年月点「今天」回到当前月。
- AC-STORY-097-08b（天气降级，决策已定）：定位未授权 / 失败时显示上次缓存位置或「位置未知」；网络失败显示缓存 +「更新失败 · 重试」；无缓存无网络显示「天气不可用」且蓝条不塌陷。

### 用量 Tab

- AC-STORY-097-10：用量页含六指标卡（总 / 输入 / 输出 / 缓存 Tokens、缓存命中率、请求量）、周期切换（今日 / 近 3 天 / 近 7 天 / 近 1 月 / 近 3 月 / 自定义）、统计截止时间与刷新。
- AC-STORY-097-11：用量统计覆盖 CLI 会话、平台主代理会话、子智能体与工具循环内的模型调用；数据来自落库用量，不按字符数估算；某来源缺量时对应指标不累加，排行榜显示「未上报」。
- AC-STORY-097-12：活跃热力图为完整矩阵：行 = 周一～周日、列 = 周数（首列按周一对齐补空位、末列补到整周），**所有格子都渲染**——有数据按五档色阶，无数据 / 范围外为带边线白框；各格宽高间距一致，月份标签与列严格对齐，图例「较少 → 较多」。
- AC-STORY-097-13：按小时趋势为 24 桶堆叠柱（输入 / 输出 / 缓存）+ 缓存命中率折线（右轴 0–100%）。
- AC-STORY-097-14：按模型、按供应商两栏排行显示用量、占比条、缓存命中率，按用量降序。
