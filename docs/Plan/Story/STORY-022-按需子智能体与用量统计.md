# STORY-022：按需子智能体与用量统计

- 类型：用户故事；所属 [FEAT-012 子智能体进展与会话用量](../Feature/FEAT-012-子智能体进展与会话用量.md) / [PRD-001 CR011](../../PRD/PRD-001-个人Agent界面需求.md#cr-011引用浮层多会话与子智能体用量)。
- 来源：2026-11-18用户要求模型按必要性开子智能体并行，顶部数量下拉任务/时间/tokens，输入下方轮数/请求/tokens含子消耗与上下文占比。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / 设计中 / 模型决策、会话父链、统一usage事件。

作为AI使用者，我希望复杂任务适度并行而普通任务不滥开子智能体，并看到当前会话的全部消耗和进度。

- 主模型语义评估必要性/独立任务/依赖/风险与预算，不每任务自动开、不能以关键词绕门槛。子任务继承权限交集、只在指定文件范围执行，父审查/验证合并后才提案写入。
- 有子任务才显示顶部n个下拉；任务名/状态/耗时/token与来源明确，失败/超时不假成功，切新会话不取消。
- 下方用量：当前用户消息轮数、请求次数、tokens含全部后代、当前上下文比例。requestId去重，每事件一次，不把已聚合子数再加；不串其它会话。上下文是当前窗口，不把所有子窗口相加。
- 真实usage来自适配事件，未知不填0；真实context额度未知不伪造比例。本轮固定独立评审示例模拟决策与并行、字符估算tokens/演示窗口均标仿真，不表示真实账单或模型智能已接。
