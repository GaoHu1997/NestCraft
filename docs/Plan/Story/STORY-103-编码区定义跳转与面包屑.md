## 验收标准

- **AC-STORY-103-01**（同文件定义）：给定受支持语言的源文件，当按住 Ctrl 悬停某符号，则出现下划线；Ctrl+点击该符号，则跳转到**同文件内**的定义位置并定位高亮，**只读导航、不修改文件内容**。验证方式：设计原型操作 + 手工。
- **AC-STORY-103-02**（跨文件 import 定义）：给定符号由 import 引入自另一文件，当 Ctrl+点击该符号，则打开目标文件对应页签并定位到其定义，导航历史记录可返回。验证方式：手工 + 自动化（符号索引）。
- **AC-STORY-103-03**（多目标）：给定某符号存在多个候选定义，当 Ctrl+点击，则弹出多目标选择器，列出每个目标的「文件:行」与源码预览，选定后跳转。验证方式：设计原型操作 + 手工。
- **AC-STORY-103-04**（无目标）：给定符号无定义（如内置符号或拼写错误），当 Ctrl+点击，则给出「找不到声明」类提示，不跳转、不崩溃，**编辑内容不变**。验证方式：手工 + 自动化。
- **AC-STORY-103-05**（不支持的语言文件）：给定语言不在第一版符号索引白名单内，当 Ctrl+悬停或 Ctrl+点击，则不下划线、不跳转，并给出「该语言暂不支持导航」类说明，**编辑内容不变**。验证方式：手工 + 自动化（语言白名单）。
- **AC-STORY-103-06**（面包屑与导航历史）：给定打开某文件，当显示面包屑「文件 › 符号链」并点击符号则跳转到该符号；Alt+←／→ 在导航历史中前后切换；面包屑随光标/文件更新，且均为**只读导航、不改文件内容**。验证方式：设计原型操作 + 手工。
