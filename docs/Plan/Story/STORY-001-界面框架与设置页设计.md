# STORY-001：界面框架与设置页设计

- 类型：用户故事（设计交付）
- 所属 Feature / PRD：[FEAT-001 工作台框架与可操作评审](../Feature/FEAT-001-工作台框架与可操作评审.md) / [PRD-001](../../PRD/PRD-001-个人Agent界面需求.md)
- 来源与确认依据：用户 2026-11-18 设计指令及 CR-001 修正反馈
- 负责人 / 优先级 / 状态 / 依赖：负责代理（本轮会话）/ 高 / 待验收 / 无
- 目标：作为个人 Agent 的使用者，我希望有一个清晰的主框架（项目管理 / 知识库 / 服务器管理 + 底部设置入口）和完整的设置中心（模型 / SDK / 能力三类并列菜单，能力下含 Skill、MCP、Tools），以便统一管理智能体的全部配置。
- 本次包含：主框架侧边栏（v2 导航结构）、项目管理卡片页、知识库骨架页、设置 · 模型管理、设置 · SDK 管理、能力 · Skill、能力 · MCP、能力 · Tools，共 8 屏。
- 不包含：设置「通用」页（未出图，交互定义中说明）、新建/编辑表单交互、深色模式。

## 验收标准

- AC-STORY-001-01：给定主界面，当打开项目管理页时，则左侧菜单展示「项目管理 / 知识库 / 服务器管理」三个同级项，底部仅有「设置」入口（无子项常驻）；内容区以卡片展示项目名称、类型徽标（code/work）、负责人、创建时间与迭代信息。
- AC-STORY-001-02：给定底部设置入口，当点击设置时，则进入设置视图，左侧出现并列菜单（通用 / 模型管理 / SDK 管理 / 能力管理）；模型管理中每个模型具备思考等级选择器（关闭/低/中/高）、Key 状态与默认模型标识。
- AC-STORY-001-03：给定 SDK 管理，当打开时，则按「AI 引擎适配」与「能力 SDK」分组展示安装状态、版本、渠道配置。
- AC-STORY-001-04：给定能力管理，当切换 Skill / MCP / Tools 子页时，则分别展示 Skill 列表（/命令、版本、来源、调用统计）、MCP 服务器列表（传输类型、工具数、连接状态）、内置工具注册表（风险等级、权限模式、调用统计）。
- AC-STORY-001-05：给定 1440×900 视口，当渲染以上 8 屏时，则布局完整、无遮挡、无文字换行或溢出缺陷。
