# STORY-072：右侧预览面板

- 类型：用户故事
- 所属 Feature / PRD：[FEAT-021 会话中心工作台](../Feature/FEAT-021-会话中心工作台.md) / [CR-054](../../PRD/CR-054-会话中心工作台.md)
- 来源与确认依据：2026-11-21 用户提出“点击会话返回的文件，在侧栏预览；点击会话的需求在侧栏预览”，确认纳入首期。仅需求确认，未授权正式编码。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / 设计中（UI 与 LLD 待制作）/ 依赖 STORY-071 右栏容器、CR-034 定位事件、现有文件/需求/知识/办公预览器、UI-SCROLL-001。
- 目标：作为编码项目用户，我希望点击会话里的文件或需求就在右侧栏看到内容，以便不离开当前会话、不丢上下文。
- 本次包含：右栏只读预览文件/需求/知识文件/办公文件；点击会话链接自动开栏；定位分流；“在编码/需求中打开”回退；错误与无权限显式；宽度/滚动条。
- 不包含：编辑或保存、上传/下载扩展、浏览器、AI 写操作、新权限、跨项目预览。

## 验收标准

- AC-STORY-072-01：给定右栏关闭，当点击会话中的文件链接（含行号）时，则右栏自动打开并加载该文件，显示到目标行；不切换项目页签。
- AC-STORY-072-02：给定右栏关闭，当点击会话中的需求链接时，则右栏自动打开并预览对应实体正文；实体身份、项目和版本提示正确；不切换项目页签。
- AC-STORY-072-03：给定知识文件或办公文件链接，当点击时，则按现有能力在右栏只读预览；不支持的格式显式说明，并提供现有能力范围内的打开/下载入口，不伪造正文。
- AC-STORY-072-04：给定右栏已打开，当点击另一个预览目标时，则右栏切换到新目标；不产生重复面板或重复请求；返回或关闭右栏不改变当前会话、草稿和运行状态。
- AC-STORY-072-05：给定右栏预览中，当用户选择“在编码中打开／在需求中打开”时，则跳转对应页签并定位目标；右栏保持或关闭按设计执行，行为可预期。
- AC-STORY-072-06：预览为只读；不得修改原文档、触发自动保存、改变编辑草稿/选区，也不得读取现有权限之外的内容。
- AC-STORY-072-07：给定目标不存在、无权限、加载失败或格式不支持，则显示明确错误与可用下一步；不伪造正文、不阻塞会话输入。
- AC-STORY-072-08：右栏宽度可拖动、按项目记忆、受限幅；滚动区域按 UI-SCROLL-001 初始隐藏、滚动显示、停止隐藏；窄屏降级不丢失当前预览。
- AC-STORY-072-09：给定 UI 设计已登记版本，则按同视口、缩放、主题和样例数据做设计/软件对照；未执行或未目视判读的范围不得记为通过。
