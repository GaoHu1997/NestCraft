# STORY-063：主界面视觉重构与仿真样例补全

- 类型：用户故事（界面设计）；仅需求／可操作设计，不是正式软件开发。
- 所属 Feature：[FEAT-001](../Feature/FEAT-001-工作台框架与可操作评审.md)；PRD：[CR-035](../../PRD/CR-035-主界面重构与仿真样例补全.md)。
- 来源与确认依据：2026-11-19 用户直接反馈「UI 重做；样例数据要全、要仿真；我要的是仿真原型 UI，不是示意图」，并在同轮确认参考基准为 CR-014 的十三张参考截图（白蓝研发管理风：PingCode / zyplayer / cc-gui / TermX / openidea）。该指令作为设计范围确认，不是正式编码授权。
- 负责人 / 优先级 / 状态 / 依赖：lead / 高 / 设计中（设计待视觉评审；正式软件未修改） / 既有管理页、项目工作区、知识库、服务器与设置能力。
- 目标：作为工作台使用者，我希望打开一个可直接操作、数据完整、视觉统一的仿真原型，走通项目、需求、任务、知识、服务器与设置的主要路径，以便在进入正式开发前评审信息层级与交互细节。
- 本次包含：白蓝研发管理视觉基线与组件规范；固定管理首页＋独立窗口导航；项目工作区的需求／设计／任务／编码；知识库列表、授权拦截与三栏阅读；服务器列表、终端与指标；设置中心七类；AI 侧栏会话、工具卡、审批、任务与后台记录；浅／深主题与窄屏重排；完整虚构夹具。
- 本次不包含：正式软件源码、依赖、构建或发布；真实 CLI／SSH／Git／模型调用；账号与权限模型变更；旧原型历史文件删除；生产数据采集。

## 验收标准

| 编号 | 给定／当／则 |
| --- | --- |
| AC-STORY-063-01 | 给定唯一公开入口，当打开原型，则进入可直接操作的工作台：顶栏、侧栏、窗口页签、内容区与 AI 侧栏在 1440 宽度下层级清晰，无整页横向溢出。 |
| AC-STORY-063-02 | 给定管理首页，当点击项目／知识库／服务器，则在独立窗口打开对应对象；重复打开同一对象只聚焦原窗口；窗口可切换与关闭，首页不被打断。 |
| AC-STORY-063-03 | 给定预约服务项目，当走通「需求→派发预检→确认→任务→产物／日志」路径，则每一步都可操作并给出对应状态；未就绪范围在预检中列为范围外。 |
| AC-STORY-063-04 | 给定知识库，当打开未授权库，则显示授权说明并阻止读取；授权后可检索、查看命中与三栏阅读，正文与目录同源。 |
| AC-STORY-063-05 | 给定服务器，当打开工作台并执行白名单命令，则终端返回夹具输出；非白名单命令被拒绝；离线主机显示失败原因。 |
| AC-STORY-063-06 | 给定设置中心，当在通用／模型／智能体／SDK／Skill／MCP／Tools 间切换，则每类都有完整样例与说明，切换不丢状态。 |
| AC-STORY-063-07 | 给定 AI 侧栏，当发送消息、批准工具写入或打开后台任务，则分别产生回复、更新审批状态与展示后台记录；不发起真实模型或命令调用。 |
| AC-STORY-063-08 | 给定浅色与深色主题、1440 与 390 宽度，当切换主题或缩放窗口，则布局按容器重排、无关键信息截断；移动端可通过导航按钮打开侧栏。 |
| AC-STORY-063-09 | 给定样例数据，则项目、需求、任务、知识、服务器与设置的统计相互自洽（数量、状态、进度），不出现同一对象在不同页面数字矛盾。 |
| AC-STORY-063-10 | 给定旧原型，当新稿上线，则旧文件原位保留为历史资源，不删除、不当第二公开入口；正式软件与构建产物本批未被修改。 |
