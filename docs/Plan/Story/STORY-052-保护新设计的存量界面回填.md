# STORY-052：保护新设计的存量界面回填

- 类型：设计维护任务；所属：[FEAT-001](../Feature/FEAT-001-工作台框架与可操作评审.md)。
- PRD：[PRD-001](../../PRD/PRD-001-个人Agent界面需求.md)；来源：[CR-022](../../PRD/CR-022-存量设计回填与Agent思想承接.md)，2026-11-19 用户明确要求软件现状补到 UI，但保护后续新增／调整设计。
- 负责人：lead／设计代理；优先级：P0；状态：待验收（仅本批设计）；依赖：已授权存量需求及当前原型。无正式编码授权。
- 目标：把已授权、未被用户新设计替代的软件界面补进现有原型，使评审不再只看到简化 Runtime 或只读历史表单。
- 包含：供应商／模型／SDK／能力设置、知识管理与只读授权、主机配置和认证的设计回填；这是统一设计资源维护，不改变各业务 Story 的唯一父项或历史验收。
- 不包含：修改软件、执行安装／SSH／CLI、known_hosts、免认证 none、知识源写入、重画 CR-017/018/019/021 或品牌。
- 关联存量依据：[STORY-029](STORY-029-模型供应商配置正式实现.md)、[030](STORY-030-CLI-SDK管理正式实现.md)、[031](STORY-031-Skill-MCP-Tool能力管理正式实现.md)、[035](STORY-035-服务器管理正式实现.md)、[036](STORY-036-知识库正式实现.md)；只作覆盖关联，不迁移归属。

## 验收标准

- AC-STORY-052-01：给定存在新设计的区域，回填前登记保护范围及版本／hash，最终只增加缺口；软件旧布局和未知来源不得覆盖新设计。并行他方变化独立记录，不回退。
- AC-STORY-052-02：从原正常设置入口可评审供应商分类和模型展开、SDK 版本与作业／卸载确认及 Skill/MCP/Tool 的真实字段语义；Runtime 修复、AI 库存和正式未知状态明确区分。取消、校验、失败反馈可操作，不以只读 viewer 代替。
- AC-STORY-052-03：从原知识库管理可评审建库／扫描和明确项目的只读授权／撤权，进入库继续沿用 CR-021 三栏阅读与父级返回。空库、搜索无结果、加载失败和撤权有不同反馈，不增加知识写入。
- AC-STORY-052-04：从原服务器管理可评审新建／编辑主机及密码／密钥文件／私钥文本占位，连接与 AI 授权独立；校验、取消、未连接／失败可辨。不新增免认证或已验证主机信任承诺。
- AC-STORY-052-05：新增设计于 1440 与窄屏浅深色实际打开、保存本次证据；字段与关键动作不遮挡、无整页横溢出；未核查场景明确登记，不声称软件全量视觉一致。
- AC-STORY-052-06：设计运行不访问真实业务网络、不执行 CLI/SSH/安装，不保存真实凭证；正式源码／依赖／配置未由本次修改，最终差异审查和实际验证留痕。
