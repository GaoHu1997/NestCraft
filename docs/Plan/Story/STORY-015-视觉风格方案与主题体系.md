# STORY-015：视觉风格方案与主题体系

- 类型：设计（UI 视觉风格）；所属 [FEAT-002 视觉风格评审与主题](../Feature/FEAT-002-视觉风格评审与主题.md) / [PRD-001 CR-008](../../PRD/PRD-001-个人Agent界面需求.md#cr-008视觉风格方案与主题体系)。
- 来源与依据：2026-11-18 用户明确「现在的 UI 设计样式我不满意，帮我出几个样式风格供我选择，然后统一调整」；随后在候选中选定 **A 纸感暖白** 为浅色主主题，并要求保留**深色可选模式**。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / **待验收（技术验证通过，实现已落地）** / 现行 v3.0 原型、UI-FEAT-001 v2.6、设计图总览。

## 目标与范围

作为工作台使用者，我希望先看到几种气质明显不同的整体视觉方案，并能操控真实组件即时对比，以便选定一种后统一应用到全部页面，而不是逐页零散微调。

- 提供 1 个基线（原 v2.5）+ 5 个候选方向：A 纸感暖白、B 深色工作室、C 玻璃渐变、D 企业高密度、E 编辑风硬边。
- 对比件必须使用**同一套真实组件**（项目列表、需求与 AI 工作台三栏、按钮/标签/表格/提示/终端/弹窗），切换风格只改视觉不改结构。
- 每个方向给出定位、适用场景、取舍风险与关键色板，色板标签在浅底/深底上可读。
- 建立**主题令牌契约**：颜色、圆角、字体全部走变量；组件只引用变量，不写死色值。
- 用户已选定：**浅色主主题 = A 纸感暖白；深色 = 暖石墨（吸收 B 的分层，主色沿用赤陶系以保持同一品牌）**。C/D/E 与旧青绿 v2.5 保留为选型记录，不再落地。
- 不包含：品牌命名与 Logo（Q1）、真实业务/CLI/数据库改动、逐页重写交互逻辑。主题切换只是视觉，不影响会话、授权、Git 与审批行为。
