# STORY-044：统一设计入口与CLI任务标识

- 类型：用户故事；所属：[FEAT-018](../Feature/FEAT-018-需求派发与项目任务追踪.md)。
- PRD：[PRD-002](../../PRD/PRD-002-需求派发与自主执行.md)；来源与确认依据：[CR-017](../../PRD/CR-017-统一设计入口与需求任务闭环.md)，2026-11-19用户明确要求Tab无数字、任务开头用CLI Logo、设计统一入口。
- 负责人：lead；优先级：P1；状态：设计中（正式能力未实现，设计稿待评审）；依赖：STORY-039任务投影、STORY-045/046闭环数据及事件。
- 目标：作为工作台使用者，我希望在一个设计入口完成需求、任务和交付操作，并从任务开头识别实际CLI，以便不用在多个补充稿间寻找关联。
- 本次包含：统一工作台导航、项目四页签、任务/运行/会话标识、状态联动入口、离线图形和可访问性。
- 不包含：复制受限UI代码、替换产品品牌、真实CLI/云服务/生产发布。
