## 验收标准

- **AC-STORY-114-01**：给定打开知识库某空间，当查看左栏顶部，则不出现独立的「上传」按钮，只有「首页／切换空间」；文件树「空间目录」的 `+` 菜单仍含「上传」项。
- **AC-STORY-114-02**：给定打开任一目录行的 `+` 菜单或把文件拖入目录，则仍可完成上传／移动，功能与现状一致，不因移除顶部按钮而丢失。
- **AC-STORY-114-03**：给定选择 `.pdf` 文件，则直接进入 PDF 只读预览并可翻页，不出现“未找到本机 Office 转换组件”，也不请求转换器。
- **AC-STORY-114-04**：给定打开 Word／PPT／Excel 且本机转换组件缺失，则显示状态卡：说明“需要本机受管转换组件”、提供「准备组件」「下载原件」「重试」；不再只有一行错误码。
- **AC-STORY-114-05**：给定转换组件就绪，则 Word／PPT／Excel 可只读分页预览，显示实际页数与导出原件；转换中可取消，失败提示原因。
- **AC-STORY-114-06**：给定已安装或首次下载本地语义模型，则模型文件位于数据根下 `semantic-model`；若旧 `%APPDATA%` 目录存在，启动时逐文件补齐到新目录且不覆盖已有完整文件，迁移幂等。
- **AC-STORY-114-07**：给定打开知识库右侧“本地语义模型”或设置→数据与存储，则显示模型实际目录，且该目录位于统一数据根内；模型缺失时检索回落关键词并标注。
- **AC-STORY-114-08**：给定正文中的图片，当点击图片，则打开查看器；查看器支持“适应窗口”“100%”“放大／缩小”“滚轮缩放”“拖拽平移”，缩放范围 10%–800%。
- **AC-STORY-114-09**：给定查看器打开，按 Esc 或关闭后焦点回到原图片；缩放与平移不修改原文件，不发起写操作。
- **AC-STORY-114-10**：给定 Markdown 阅读页，右上「编辑／更多」操作组默认不可见且不接收指针（按钮仍可键盘聚焦）；鼠标进入或键盘聚焦时浮现并可操作；`hover:none` 触摸设备常显。实现时发现 `visibility:hidden` 会让键盘永远聚焦不到，故采用 `opacity:0 + pointer-events:none`（见 REPORT §4）。
- **AC-STORY-114-11**：给定长 Markdown 文档，正文可纵向滚动到文末（含代码块、表格），不再只显示第一屏；滚动条只在滚动时出现、停止后隐藏（UI-SCROLL-001），编辑草稿与光标不因滚动丢失。
- **AC-STORY-114-12**：设计稿覆盖 SC-097-01～05 与浅／深主题及 390 窄屏，留有设计断言与截图证据；软件实现后补充同条件成对视觉对照。
