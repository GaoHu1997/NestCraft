# STORY-065：办公项目资料与连续编辑

- 类型：用户故事／需求设计。
- 所属 Feature：[FEAT-006](../Feature/FEAT-006-办公资料解读与产物预览.md)；需求：[CR-038](../../PRD/CR-038-办公类型项目文档协作.md)。
- 来源：2026-11-19 用户要求参考同类产品调整需求设计，明确限定「项目类型为办公的」。
- 负责人／优先级／状态：lead／P0／设计中（待评审，非正式实现）；依赖 CR-004、CR-028、CR-033、CR-036。
- 目标：作为办公项目使用者，我能打开资料立即阅读或编辑，切换后不丢内容，不必先学习研发需求管理。
- 范围：work 文档／成果导航、资料搜索与导入、分格式编辑、连续草稿及错误恢复。不改 code、全局导航或配置。

## 验收标准

| 编号 | 给定／当／则 |
| --- | --- |
| AC-STORY-065-01 | 给定已有／新建 work 项目，从项目管理打开或重开时，进入文档／成果而不是需求／设计／任务／编码；旧 work 文件／设计入口仍在同项目落到文档，code 页签保持。 |
| AC-STORY-065-02 | 给定空项目或资料列表，添加资料前明确名称、类型与来源；取消无副作用，同名拒绝覆盖；搜索可清除，空结果与空项目可恢复；导入失败不丢原条目。 |
| AC-STORY-065-03 | 给定 MD／DOCX／XLSX／PPTX／PDF，按格式呈现阅读与允许的基础编辑；表格选格与公式条、PPT缩略图与选页、PDF分页只读；未支持、扫描件、加密或解析失败说明限制而非伪解析成功。原型是合成内容，不算真实格式兼容验证。 |
| AC-STORY-065-04 | 给定未保存编辑，切文件、切项目、收起AI再返回，草稿与选中文档仍在；保存成功后才更新版本，失败保留输入可重试；关闭有编辑时可保存／不保存并关闭／继续编辑。原件只读，可创建副本。 |
| AC-STORY-065-05 | 给定两个work项目，切换与复开时，资料、草稿、AI输入、提案、成果互不混用；不出现另一项目代码会话或隐式读取。 |
| AC-STORY-065-06 | 给定1440×900、1280×800和390×844及浅深主题，文字可读、操作焦点可见、弹窗可Esc退出，正文和AI独立滚动；窄屏可切文件／正文／AI，不出现整页横向溢出。 |

## CR-043：文件树与公共视觉（2026-11-19提出，11-20更新）

用户指定左侧为可创建文件夹的树，整体与其他模块一致，内容用仿真样例。[需求](../../PRD/CR-043-办公文件树与统一AI侧栏.md)／[UI-CR043](../../UI/文档/UI-CR043-办公文件树与统一侧栏.md)／[验证](../../Test/REPORT-CR043-办公文件树与统一侧栏.md)。本批仍仅设计，原AC与历史结果保留。

| 编号 | 给定／当／则 |
| --- | --- |
| AC-STORY-065-07 | 给定任意work项目，左侧为文件夹／文件单一层级树；可展开折叠、选择文件夹、点击文件阅读；文件类型与草稿状态同源，折叠不丢编辑；搜索命中保留祖先，清空恢复展开状态。 |
| AC-STORY-065-08 | 给定根或选中目录，新建文件夹明确父路径；提交后新增子节点并展开父级，取消无副作用；同父内文件/文件夹重名、空名、路径越界及保留名拒绝；跨目录同名允许，新建文件／导入进入所选目录。 |
| AC-STORY-065-09 | 给定办公与编码同条件截图，导航、树行／图标／工具条／字号／间距沿用公共风格；办公不另造大欢迎区或重复输入条；浅深主题及390窄屏可读可操作，无整页横溢出。 |
| AC-STORY-065-10 | 给定两个预置办公项目，文件树中有各自连贯的MD、报告、数据表、PPT、PDF与成果样例；引用/数字可核算且相互一致，明确合成而非真实调查；新项目不自动覆盖或加载样例。 |
