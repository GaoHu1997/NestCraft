# STORY-080：子智能体只读详情

- 类型：用户故事
- 所属 Feature / PRD：[FEAT-012 子智能体进展与会话用量](../Feature/FEAT-012-子智能体进展与会话用量.md) / [CR-062](../../PRD/CR-062-AI侧栏子智能体只读详情.md)
- 来源与确认依据：2026-11-22 用户提出复用侧栏查看子智能体；同日明确“子智能体先只读、面包屑第一级固定主会话”，并授权“需求/设计/编码全部完成”。
- 负责人：主代理。优先级：P1。状态：验证中。依赖：无新增外部依赖。
- 目标：作为主会话使用者，我希望在 AI 侧栏点开某个子智能体查看它的过程与产出，再一键回到主会话，以便判断它做了什么而不丢失主会话上下文。

## 本次包含 / 不包含

包含：顶部下拉行与消息卡片两个入口；只读详情；面包屑「主会话 / 子任务名」；返回图标、面包屑、底部按钮、Escape 返回；元信息与事件时间线；未知字段与失效兜底；滚动规范。

不包含：向子智能体发指令、停止/重试、兄弟切换、多级面包屑、记录持久化、后台任务详情。
