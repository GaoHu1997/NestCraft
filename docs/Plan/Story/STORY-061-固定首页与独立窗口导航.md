# STORY-061：固定管理首页与独立窗口导航

- 类型：用户故事（导航体验）；需求／设计调整，不是正式软件开发。
- 所属 Feature：[FEAT-001](../Feature/FEAT-001-工作台框架与可操作评审.md)；PRD：[CR-033](../../PRD/CR-033-固定首页与独立窗口导航.md)。
- 来源与确认依据：2026-11-19 用户确定“首页固定，点击项目/知识库/服务器打开新的窗口，同一个项目再次打开只定位到已打开页面”，并明确原返回按钮不再需要；此前多项目顶部标签仅调研。
- 负责人 / 优先级 / 状态 / 依赖：lead / 高 / 设计中（设计待视觉评审；正式软件未修改） / 既有管理页、项目工作区、知识库阅读与服务器工作台的合成样例。
- 目标：作为工作台使用者，我希望管理首页始终可用，而从首页打开的项目、知识库和服务器各自成为独立窗口，重复打开只聚焦原窗口，以便并行查看且不丢失页面状态。
- 本次包含：固定管理首页；三类对象的独立窗口；类型＋稳定 ID 去重与聚焦；窗口内状态保留；窗口栏切换与关闭；关闭草稿／运行中任务保护；取消详情返回按钮；设计资源与场景覆盖。
- 本次不包含：系统级多窗口实现、真实 CLI／SSH／Git／AI 接入、并发写入隔离、账号权限模型变更、任务或验收规则调整；不改正式源码、依赖、配置、构建或发布产物。

## 验收标准

| 编号 | 给定／当／则 |
| --- | --- |
| AC-STORY-061-01 | 给定已加载应用，当进入工作台，则默认显示管理首页（项目管理／知识库／服务器管理可切换），打开详情不替换、不清空或不占位管理首页；关闭窗口后仍回到原管理页。 |
| AC-STORY-061-02 | 给定管理首页的项目、知识库或服务器条目，当执行打开，则在独立窗口展示对应工作区；窗口标题显示类型、名称与稳定 ID，不覆盖管理首页内容。 |
| AC-STORY-061-03 | 给定同一对象已打开窗口，当再次从任意入口打开同一对象，则只激活原窗口（置前并定位到其当前页面），不新建、不重载、不重置页签、选中项、滚动、草稿或 AI 会话；名称相同但 ID 不同不得误聚焦。 |
| AC-STORY-061-04 | 给定多个窗口与首页，当在窗口间切换、回首页、再聚焦，则每个窗口保留各自页签／笔记／主机与内部状态；关闭后再打开同一对象为新的初始窗口状态，不冒充原窗口恢复。 |
| AC-STORY-061-05 | 给定任一详情窗口，则不存在“返回项目管理／知识库／服务器”按钮或等价返回入口；关闭窗口是回到管理首页的路径，键盘可完成且焦点不丢失。 |
| AC-STORY-061-06 | 给定无草稿无运行任务的窗口，当关闭，则直接关闭且其他窗口不受影响；给定有未保存草稿，则先确认，可取消并保留草稿或明确丢弃；给定有运行中任务，则提示任务继续在后台，关闭不停止、不取消、不重置任务。 |
| AC-STORY-061-07 | 给定已打开窗口，则窗口栏列出首页与各窗口并标出当前窗口，可点击切换与关闭；窄屏可横向滚动，1440／390／320 与浅深主题均无整页横向溢出。 |
| AC-STORY-061-08 | 给定窗口切换，则只改变当前查看的窗口，不复制、串改或重置其他窗口状态；AI 会话、任务与终端仍绑定所属项目／对象；同仓库并行写入限制以文档约束记录，本批不实现。 |

## CR-044：首页与统一对象 Tab（2026-11-20）

本轮用户明确先更新需求／设计再改代码；以应用内唯一对象 Tab 替代本故事历史“独立窗口”呈现，不实现多OS窗口，不改变业务／权限。关联 [CR-044](../../PRD/CR-044-窗口融合图标与Tab导航.md)／[UI-CR044](../../UI/文档/UI-CR044-窗口图标与导航规范.md)。本轮状态设计中，正式编码范围已授权但可视稿登记完成前不改软件。

- AC-STORY-061-09：管理首页的工作台／项目／知识／服务器列表仅在主内容切换，不新增列表Tab；离开再回到首页保留对应列表搜索／筛选／滚动。
- AC-STORY-061-10：进入具体项目／知识库／服务器时隐藏全局主菜单，Tab栏整宽从左开始，最左固定“首页”不可关闭；点击首页恢复管理主菜单。
- AC-STORY-061-11：打开同类型同稳定ID对象只聚焦已存在Tab，不重新载入／重置子页签、选择或草稿；同名不同ID允许各自Tab，显式定位不创建重复对象。
- AC-STORY-061-12：关闭对象只影响该Tab，未保存或状态未知先确认，取消无损；切Tab不终止会话／终端，关闭动作与窗口系统关闭独立定义。浅深／390窄屏Tab栏内部滚动，不引入整页横溢出。

历史 AC-02／05 的独立OS窗口／无首页返回入口叙述不再作为本轮现行导航；其他状态隔离、对象身份与默认拒绝边界继续。
