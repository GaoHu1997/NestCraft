# STORY-067：办公项目成果检查与导出

- 类型：用户故事／需求设计。
- 所属 Feature：[FEAT-006](../Feature/FEAT-006-办公资料解读与产物预览.md)；需求：[CR-038](../../PRD/CR-038-办公类型项目文档协作.md)。
- 来源：2026-11-19 用户要求办公类型项目需求与设计达到好用。
- 负责人／优先级／状态：lead／P0／设计中（待评审，非正式实现）。依赖 [STORY-065](STORY-065-办公项目资料与连续编辑.md)、[STORY-066](STORY-066-办公项目AI协作与修改审阅.md)。
- 目标：作为办公用户，我能找到已保存成果、核查来源与版本，并知道导出的是哪一版、是否真正可用。
- 范围：同源成果视图、版本恢复、导出前检查和失败处理；不包含自动分享／发布，不伪造原生Office下载。

## 验收标准

| 编号 | 给定／当／则 |
| --- | --- |
| AC-STORY-067-01 | 给定已接受且保存成功的草稿，成果列表增加对应文件版本，来源引用与检查状态可查，点击仍打开同一文件；重复保存无变化不重复产生成果。 |
| AC-STORY-067-02 | 给定多个版本，查看历史不改当前正文；恢复创建新草稿，经保存生成新版本，旧版本不被覆盖。 |
| AC-STORY-067-03 | 给定导出，目标格式／文件名／版本／位置清楚，检查未保存、未处理提案、版本冲突与格式兼容；同名默认新名称，权限拒绝／空间不足／引擎不可用时显示失败原因并保留输入。 |
| AC-STORY-067-04 | 给定离线原型，Office导出明确未接引擎，下载禁用；模拟检查成功不冒充文件已导出。正式实现须导出合法原生格式并在独立查看器打开验证，不以改扩展名或模型自评替代。 |
