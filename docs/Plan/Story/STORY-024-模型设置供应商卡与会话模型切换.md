- 类型：用户故事；所属 [FEAT-014 供应商模型与能力适配](../Feature/FEAT-014-供应商模型与能力适配.md) / [PRD-001 CR-012](../../PRD/PRD-001-个人Agent界面需求.md#cr-012设置中心弹框模型供应商与会话切换sdk-装卸)。
- 来源与确认依据：2026-11-18 用户要求“模型设置参考 dsh-model-think-level：供应商一行小卡片，可禁用/编辑/删除；点编辑向下展开，含供应商配置/模型配置/高级配置/指纹检测四个 tab；供应商可配多密钥多端点；模型可配生图/视觉/文本与思考等级；会话框右侧可切换模型，形式参考思考等级交互，按当前 CLI 支持的协议过滤可选”。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / 待验收（仿真回归 80/80 通过，等待用户验收）/ 设置菜单、SDK 已安装 CLI、会话能力快照。
- 目标：作为工作台使用者，我希望用一个供应商列表管理多家模型服务和各自密钥/端点，并在会话框就地把当前模型与思考等级切到该 CLI 支持的组合，以便不必为每个 CLI 重复配置凭证。

## 本次包含 / 不包含

- 包含：供应商行卡片（名称、协议族、端点数量、密钥状态、模型数量）；行内禁用/启用、编辑、删除；编辑向下展开同一行内编辑区，四个 tab（供应商配置 / 模型配置 / 高级配置 / 指纹检测）；供应商多密钥、多端点；模型条目标记 文本 / 视觉 / 生图 能力与思考等级（含默认档位）；会话框右侧模型切换控件，按当前 CLI 支持的协议族与已启用供应商过滤候选，切换形态与思考等级一致。
- 不包含：真实密钥托管与加密、真实端点连通性与余额查询、真实指纹检测网络请求、真实生图调用、真实思考等级下发。原型内一律标注仿真，不读取或上传真实凭证。

## 行为与边界

- 供应商卡片一行一个，不用表格；卡片本身不展开。禁用后：该供应商留在列表（否则无法恢复），其模型从会话切换候选里消失，已选该供应商模型的会话显示“供应商已停用”并要求改选，不静默回落。
- 删除需二次确认（行内确认条），确认后删除该供应商及其模型条目；若已有会话正用其模型，删除后这些会话进入“模型不可用”状态并提示改选，历史消息保持。
- 编辑入口向下展开：展开区在该卡片下方，同一时刻只展开一个；为保存中/校验失败状态保留可见错误，不因重新渲染丢失焦点所在字段。
- 供应商 tab：显示名称、协议族（OpenAI 兼容 / Anthropic 兼容）、基础地址列表（多端点，可增删停用，同协议族内去重）、密钥列表（多条，标签可选，默认选中项，可增删并显示掩码）、以及“新增密钥/新增端点”按钮；至少需要一条启用密钥与一条启用端点才能把该供应商视为可用。
- 模型 tab：每条模型一行，可增删；字段为模型名、能力（文本 / 视觉 / 生图，三选多，生图与文本互斥，因为生图模型不能服务对话轮次）、思考等级集合（关闭/低/中/高，可多选）与默认档位（须在已选集合内）；未勾任何思考等级的模型，会话里只显示“默认”，不显示档位选择。
- 高级配置 tab：请求头键值、超时、并发或重试上限、代理地址、是否透传协议方言；只做内存样例，不说明为真实生效。
- 指纹检测 tab：列出对该供应商可做的检测项（协议方言、视觉能力、思考等级映射、流式），可“开始检测”，检测以固定样例结果返回“通过/无法判定/不通过”，并明确标注未发起真实请求；检测结果不自动改模型能力勾选，需用户手动采纳。
- 会话框右侧切换：模型按钮显示当前模型与档位；点开为浮层，分“供应商 → 该供应商的可用模型”两栏，顶部有搜索，底部为思考等级分段条，在同一浮层内切换，不跳二级页；选模型不关闭浮层，方便紧接着选档位。
- 过滤规则：候选只来自 (a) 已安装且已启用的 CLI，(b) 该 CLI 支持的协议族所对应的端点协议，(c) 未被禁用的供应商，(d) 至少有一条可用密钥与端点，(e) 非生图模型。任一条件不满足都不出现在候选；候选为空时给出“当前 CLI 不支持任何已配置模型”的明确原因与修复入口，不回落到别的 CLI 或别的模型。
- 切 CLI 与切模型的关系：会话已有消息时切换 CLI 走既有的“确认新建会话”，切换模型只改当前会话的模型与档位，不新建会话；运行中或待审批时该会话的模型触发器禁用、CLI 与上下文选择锁死，但按 CR-011 仍可新建或恢复其它会话而不停止旧任务。
- 失效与不回落：模型或供应商被删除、停用后，会话保留原选择的 id（不做替换），界面显示“当前会话模型不可用”并禁止发送，直到用户显式重选；不自动改选同供应商或其它供应商的模型。
- 视角差异：服务器工作台复用同一控件与同一过滤规则，因为能力快照同源；不另设一套模型配置。
