# STORY-085：Git 管理面板按参考图重构

- 类型：用户故事（界面重构 + 新能力）
- 所属 Feature / PRD：[FEAT-007 文件草稿与分支上下文](../Feature/FEAT-007-文件草稿与分支上下文.md) / [CR-067](../../PRD/CR-067-Git管理面板按参考图重构.md)
- 来源与确认依据：用户 2026-11-23「编码 tab 的 git 管理页面设计不太对，根据这个参考图一比一复刻」；随后选择「设计稿 + 正式软件一起改」与「国内加速／密钥配置纳入设计」，并澄清参考图为侧栏裁剪。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / 验证中（实现完成，待视觉对照与验收）/ 依赖现有 `git_*` 命令与受管密钥存储。
- 目标：作为编码项目的使用者，我希望 Git 管理侧栏的结构、层级与控件与参考设计一致，并能直接在国内网络下加速拉取和为私有仓库配置令牌，以便在一个侧栏内完成日常版本管理。

## 本次包含

- 顶栏：仓库路径药丸、国内加速（含开关与镜像前缀）、密钥配置、刷新。
- 未提交变更卡：已暂存／未暂存分组、全部暂存与全部取消暂存、行勾选、状态徽标、路径、`git add`／`git reset` 提示。
- 提交区：文本域、AI 生成、拆分提交按钮、提交并推送、提示行。
- 分支卡：本地／远程两棵树、全部展开／折叠、管理远程、搜索、新建分支、当前分支高亮与 ↑↓。
- 提交历史卡：图谱车道、refs 徽章、绝对时间、提交人／分支／时间筛选、行内展开变更文件、加载更多。
- 国内加速：按前缀重写 GitHub 读取（`insteadOf`），写操作仍直连。
- 密钥配置：按远端主机保存令牌，掩码列表，保存不回显，空值保留原值。
- 滚动条按需显示（UI-SCROLL-001）。

## 本次不包含

- 提交右键菜单（复制、在提交处建分支／打标签、推送标签）、worktree 管理、设备流 OAuth 登录、远程删除分支。
- 侧栏位置、宽度调节、编辑器与 AI 侧栏、项目页签。

- AC-STORY-085-01：顶栏显示仓库路径药丸与国内加速／密钥配置／刷新三个入口；加速启用时按钮显示绿点。（对应 AC-CR067-01、AC-CR067-06）

- AC-STORY-085-03：变更行勾选即暂存／取消暂存；两个「全部」按钮作用于对应分组；提交按钮双侧门禁与 ▾ 菜单一致。（AC-CR067-02）
- AC-STORY-085-04：分支为本地／远程两棵树，当前分支整行高亮带 ✓ 与 ↑↓；全部展开／折叠同时生效；搜索同时过滤两棵树。（AC-CR067-03）
- AC-STORY-085-05：提交历史显示图谱、refs 徽章与绝对时间；点击行展开变更文件且同时只开一条。（AC-CR067-04）
