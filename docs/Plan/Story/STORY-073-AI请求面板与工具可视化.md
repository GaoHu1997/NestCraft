# STORY-073：AI 请求面板与工具可视化

- 类型：用户故事
- 所属 Feature / PRD：[FEAT-021 会话中心工作台](../Feature/FEAT-021-会话中心工作台.md) / [CR-054](../../PRD/CR-054-会话中心工作台.md)
- 来源与确认依据：2026-11-21 用户提出“侧栏默认关闭，但是 AI 和用户都可以打开这个侧栏。侧栏提供一些工具给 AI 使用，比如浏览器”。首期只确认布局与预览；AI 开栏与工具可视化的权限/交互规则尚未确认，本 Story 保持待确认。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P1 / 待确认（规则未定；无设计、无编码准入）/ 依赖 STORY-071 右栏容器、STORY-072 预览、现有工具/审批机制、CR-037 运行事件。
- 目标：作为编码项目用户，我希望 AI 在需要时打开右侧面板展示文件、需求或工具结果，同时我始终保有控制权，以便看到 AI 的依据而不被强行打断。
- 本次包含（草案）：AI 请求打开只读面板；工具执行与结果在右栏可视化；用户关闭优先与防抢焦点；写/网络操作仍走现有审批；不扩大工具权限。
- 不包含：内置浏览器/网页抓取/浏览器自动化内核；自动执行未授权操作；新审批体系；跨项目工具结果；AI 自动修改用户正在编辑的文档。

## 验收标准（草案，待确认后生效）

- AC-STORY-073-01：AI 只能**请求**打开面板，不能直接强制；前端按当前页签、用户设置与授权决定是否执行，并在拒绝时给 AI 可读结果。
- AC-STORY-073-02：用户手动关闭面板后，AI 不得在同一轮自动重开抢焦点；再次打开需新请求或用户操作。
- AC-STORY-073-03：AI 请求打开的目标必须是当前项目内、当前权限可读的只读内容；越权、跨项目或不可读目标明确拒绝并记录原因。
- AC-STORY-073-04：工具执行在右栏或会话步骤区显示名称、状态、耗时与结果摘要；失败显式，不伪造成功；不替代现有步骤/统计口径。
- AC-STORY-073-05：涉及写入、命令执行、网络访问或外部系统的工具仍按现有审批与授权执行；侧栏打开本身不构成授权。
- AC-STORY-073-06：面板打开/关闭/切换不新建会话、不中断执行、不改变当前会话；多会话运行时不串扰。
- AC-STORY-073-07：无权限、目标不存在、工具不可用或审批拒绝时，显式提示且不阻塞会话继续。
- AC-STORY-073-08：UI 与 LLD 登记版本后，按同条件做设计/软件对照与工具执行实测；未执行不得记为通过。
