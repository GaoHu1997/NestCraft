# STORY-084：会话历史状态标识与行操作

- 类型：用户故事
- 所属 Feature：[FEAT-011 会话历史与后台任务](../Feature/FEAT-011-会话历史与后台任务.md)
- 所属 PRD：[CR-065 会话历史列表的状态标识与行操作](../../PRD/CR-065-会话历史状态标识与行操作.md)
- 来源与确认依据：用户 2026-11-22 六条编号要求（去「已读/未读/当前」文字、选中只高亮、状态点/loading、去新会话入口与底部栏、重置按钮、行操作菜单）。
- 负责人：主代理。优先级：高。状态：待验收（已实现并通过技术验证）。依赖：`session` 表新增 `pinnedAt`、新命令 `chat_session_fork` / `chat_session_pin`。
- 目标：作为长期使用 AI 侧栏的用户，我希望历史列表只保留必要信息、状态一眼可见、常用操作收进行内菜单，以便列表更安静、操作更快。

## 本次包含 / 不包含

- 包含：选中态纯背景高亮、四种状态标识（运行/成功未读/失败未读/待处理未读）与已读无标识、去状态文字与「当前」徽标、去新增会话入口与底部栏、重置按钮、行 hover「…」菜单（复制 ID / 分叉 / 置顶 / 重命名 / 删除）、行内原位重命名。
- 不包含：多选/批量、拖拽排序、置顶分组标题、外部依赖、原生绑定复制。

## 验收标准

- **AC-01 选中态无边框**：给定任一当前会话，当列表渲染，则该行只有背景色（`--node-sel-bg`），计算样式 `border-width` 为 0 或透明，切换选中时行高与横向位置不跳动。
- **AC-02 状态标识正确**：给定运行中 / 已读 / 成功未读 / 失败未读 / 待处理五个会话，则左侧依次显示 spinner / 空 / 绿点 / 红点 / 橘点；**行内不出现**「已读」「未读」「运行中」「成功」「失败」「待处理」等文字。
- **AC-03 未读点进入后消失**：给定成功未读会话，当点击进入并 `markRead` 成功后，该行绿点消失；后端更新失败时保留点并提示。
- **AC-04 无新增会话入口**：历史浮层底部不存在「新会话」按钮；AI 侧栏头部 `+`（`aria-label="新会话"`）仍可用。
- **AC-05 底部无汇总**：历史浮层底部不显示「本会话消耗 … tok」一类汇总文字，也不保留按钮栏；列表直接延伸到底；每行元信息中的 tokens 保留。
- **AC-06 重置按钮**：搜索态下按钮文案为「重置」，点击后清空关键词、回到第 1 页 20 条；非搜索态按钮 `disabled`。
- **AC-07 行操作入口**：行 hover 或键盘聚焦时出现「…」按钮；按钮占用固定宽度，hover 不引起标题/状态位置跳动。
- **AC-08 菜单完整**：点击「…」出现菜单，含「复制会话 ID / 分叉会话 / 置顶（或取消置顶）/ 重命名 / 删除」；同一时刻只开一个，外点/Escape/滚动关闭。
- **AC-09 复制会话 ID**：点击后 ID 写入剪贴板并提示「已复制会话 ID」；`navigator.clipboard` 不可用或拒绝时回退隐藏 textarea 复制，仍失败提示手动复制；不把 ID 写进日志。
- **AC-10 分叉会话**：给定有 4 条消息的普通会话（无执行中轮次），点击分叉后：新会话标题为「分叉 · 原标题」、消息 4 条且内容一致、`nativeThreadRef` 为空、未读为空、出现在列表顶部并被选中；运行中的会话分叉项禁用并给出原因。
- **AC-11 置顶**：点击置顶后 `pinnedAt` 持久化，重启后仍在最前；置顶组内按置顶时间倒序；标题前显示图钉图标；再次选择「取消置顶」后回到时间序；分批与搜索计数不受影响。
- **AC-12 原位重命名**：菜单点击「重命名」后，该行标题原位变成输入框并自动聚焦、全选；Enter 或失焦保存、Escape 取消；空标题提示并恢复原标题；保存成功后列表标题立即更新并持久化；全过程不出现弹窗。
