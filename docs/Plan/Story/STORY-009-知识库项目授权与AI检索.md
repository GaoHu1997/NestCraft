# STORY-009：知识库项目授权与 AI 检索

- 类型：用户故事；所属 [FEAT-008 项目知识授权与只读检索](../Feature/FEAT-008-项目知识授权与只读检索.md) / [PRD-001 CR-005](../../PRD/PRD-001-个人Agent界面需求.md#cr-005项目知识授权与统一-ai-工作台)。
- 来源与确认依据：2026-11-18 用户明确“授权给哪个项目，哪个项目才能用，需要提供工具给 AI 查找知识库”。确认功能方向及设计调整，不代表真实权限实现或原型已验收。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / 设计中（仿真待评审）/ 项目身份、知识库样例、统一能力网关；真实接入必须先完成执行层权限控制。

## 用户价值与背景

作为个人工作台所有者，我希望把知识库只授权给指定项目，并让该项目 AI 查找和读取资料，以便复用知识而不把其他项目资料自动放入上下文。

知识库管理视图属于所有者，可以管理全部库；项目 AI 的可见范围与管理视图不同。未授权不是“只隐藏卡片”，而是所有检索、读取、引用、批读和上下文注入路径均不可用。

## 范围与规则

- 包含：项目授权多选、保存与取消、默认无授权、只读列表/关键词检索/单篇读取/批量读取、版本引用、同库关联笔记导航、撤权反馈。
- 不包含：知识库写入/删除/全库自动改链、语义或向量检索、真实导入连接、跨项目授权继承、多用户角色系统。
- 主流程：打开知识库 → 选择授权项目 → 保存 → 项目 AI 查看可用库 → 搜索 → 读取命中 → 显示引用 → 打开来源。
- 异常：空结果与调用失败分开；无权限/不存在/非法 ID 使用统一不可访问错误；批读允许项可返回，拒绝项不得泄露标题、路径或摘要；停用能力后不能继续调用。
- 撤权：后续调用重新检查授权，旧引用不能继续读、候选删除、缓存失效；涉及该库的待审提案失效。已显示的历史不能声称被收回，后续模型输入不能重放该正文。无法清理原生 CLI 上下文时停止旧线程并要求新会话。

## CR-030：本地知识索引与按需引用

- 依据：[CR-030](../../PRD/CR-030-本地知识索引与按需引用.md)，2026-11-19 用户选定本地全文索引方向并授权需求／设计闭环，不授权正式编码。负责人／优先级：主代理／P0；新增范围设计中、设计待评审。唯一父项仍FEAT-008，依赖STORY-036当前代际切片、宿主会话身份／轮次预算和执行隔离；不复制项目授权表。
- 现行增量：先查授权内索引，再取必要切片，原整篇read/read_many须转有界兼容且不得默认整篇注入。8KiB单次UTF-8响应／32KiB每宿主轮次、5命中每片400Unicode码点为本版拟议可逆协议护栏；完整envelope/出处/usage计入，token未知不虚构。项目资料按需工具沿CR-027，不借该索引绕过知识授权。
- 覆盖：AI知识候选、选片段／相邻阅读、引用定位、分页／关系、预算和去重、旧整篇引用重新选择、发送预检、撤权／停用／源变更／历史恢复失效；不含知识写入、自动语义关系或模型建库。
