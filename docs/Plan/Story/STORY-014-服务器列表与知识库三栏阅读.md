# STORY-014：服务器列表与知识库三栏阅读

- 类型：用户故事；所属 [FEAT-009 知识库目录与正文阅读](../Feature/FEAT-009-知识库目录与正文阅读.md) / [PRD-001 CR-007](../../PRD/PRD-001-个人Agent界面需求.md#cr-007服务器列表与知识库三栏阅读)。
- 来源与依据：2026-11-18 用户明确服务器改为列表卡片，知识库进入后为左目录树、中正文、右文件内容目录；右栏定义为正文标题目录，不是 AI。本次为设计与仿真，不扩大真实服务。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / CR-045增量验证中（待技术验证收敛，未用户验收）；CR-007历史设计状态保留 / 已有服务器样例、知识库笔记和项目授权设计。

## 价值、范围与规则

> 下方只读／不含导入编辑是CR-007历史范围；本轮用户显式文件操作、真实格式边界与新增AC见[CR-045记录](#cr-045文档工作区与可调侧栏)，不扩大项目AI权限或CR-030解析验收。

作为工作台使用者，我希望快速纵向浏览服务器信息，并在知识库内通过文件树和正文目录阅读资料，避免卡片难以比较或正文定位困难。

- 服务器采用单列列表卡片，横向组织名称/主机/环境/规格、连接与资源状态、AI授权与进入操作；窄屏卡片内换行，不改变连接、授权和审批规则。
- 知识库入口保留全部库的所有者管理及项目授权；点击进入库后，左侧目录树、中间所选文件正文、右侧正文目录。文件树按笔记路径分组，展开/选择分开，保留当前库选择与展开状态。
- 正文目录由当前正文标题生成，保持级别与顺序，点击定位段落；切换文件即切目录，重复标题锚点唯一，无标题明确提示而非生成假目录。目录不是第二棵文件树或 AI 面板。
- Markdown 只读渲染，正文HTML作为不可信内容处理，不执行脚本；正文中的同库链接继续受访问规则校验。样例具有可定位标题，无标题样例仍可阅读。
- 空库、无匹配、未选文件、不存在/读取失败、无标题、长文/窄屏分别显示反馈；回列表保留上下文，失败不显示上一文件正文冒充成功。
- 不包含：知识库真实导入/同步/编辑、服务器真实连接、AI侧栏替代正文目录、改变项目授权或知识工具边界。所有者阅读与项目AI工具范围不混用；AI引用不得借管理页路径扩权。
