# STORY-003：服务器管理界面设计

- 类型：用户故事（设计交付）
- 所属 Feature / PRD：[FEAT-016 主机列表与连接工作台](../Feature/FEAT-016-主机列表与连接工作台.md) / [PRD-001](../../PRD/PRD-001-个人Agent界面需求.md)
- 来源与确认依据：用户 2026-11-18 CR-001 反馈——项目管理同级增加服务器管理，可提供工具给 AI 操作服务器，也可手动连接
- 负责人 / 优先级 / 状态 / 依赖：负责代理（本轮会话）/ 高 / 待验收 / STORY-001（共用框架与 AI 面板）
- 目标：作为服务器管理者，我希望在一个页面集中管理我的服务器，既能自己手动连接操作（终端 / 文件 / SFTP），也能授权 AI 通过工具执行巡检、日志分析等运维任务，以便把日常运维工作交给智能体同时保留人工把关。
- 本次包含：服务器管理列表页、服务器工作台页，共 2 屏。
- 不包含：新增服务器表单、SFTP 面板细节（列表页/工作台已留入口）、监控图表页。

## 验收标准

- AC-STORY-003-01：给定服务器管理页，当打开时，则以卡片展示服务器：名称、环境标签（生产/测试/开发）、主机与端口、认证方式、系统与规格、在线状态、CPU/内存概览条、最近连接时间；提供「新增服务器」入口与 AI 授权说明。
- AC-STORY-003-02：给定服务器卡片，当点击「进入工作台」时，则展示三栏：左侧服务器文件树 + 服务器信息（系统、内核、运行时间、AI 可操作状态）；中间实时终端（提示符、命令输出、资源指标条 CPU/内存/磁盘/负载）；右侧 AI 运维助手。
- AC-STORY-003-03：给定 AI 运维助手，当执行巡检任务时，则以工具卡片展示每条命令的执行与结果（如 uptime、free -h、df -h），并给出结论与建议；高风险命令卡片带风险标注，输入区提示「高风险命令需确认」。
- AC-STORY-003-04：给定 1440×900 视口，当渲染以上 2 屏时，则布局完整、无遮挡、无渲染缺陷；终端输出对齐真实（docker ps / free -h 等表格列对齐）。
