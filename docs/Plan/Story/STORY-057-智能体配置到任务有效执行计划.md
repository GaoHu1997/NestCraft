# STORY-057：智能体配置到任务有效执行计划

- 类型：用户故事；所属[FEAT-018](../Feature/FEAT-018-需求派发与项目任务追踪.md)。
- 来源/确认：[CR026](../../PRD/CR-026-统一任务执行计划与能力闭环.md)，2026-11-19用户要求研究后结合调整，仅设计。
- 负责人/优先级/状态/依赖：主代理/P0/待验收/既有管理、供应商、项目与任务预检。
- 目标：每个任务在授权前明确实际执行者/模型/权限/能力和选择来源，管理配置不再与任务独立。

## 验收标准

- AC-STORY-057-01：管理模板、任务覆盖、项目/系统默认逐字段解析，CLI/供应商模型/档位/Runtime都有具体值与来源，不留未解析继承。
- AC-STORY-057-02：任务显式指定优先且不可用阻塞；自动路由按工作类型/难度/能力和已允许回退，结果/原因在预检显示，不静默换。
- AC-STORY-057-03：供应商/SDK/能力目录唯一可编辑来源，规范化快照只读；设置变更即时影响新预检，不维护第二套任务库存。
- AC-STORY-057-04：协议/端点凭据引用/档位映射/版本能力/Runtime就绪复检，未核实不按安装推定，缺/失效有定位修复入口。
- AC-STORY-057-05：预检逐任务同时展示主执行与阶段评审/内部子委派计划，角色配置区分，全部在父授权内。
- AC-STORY-057-06：确认前展示请求与最终有效权限差异、Tool/Skill/MCP清单与排除原因；必要能力缺失不能启动。
- AC-STORY-057-07：管理变更使未确认预检失效，确认原子重检计划hash与基线；新增任务不进旧scope，取消不创建Run。
- AC-STORY-057-08：现CLI/SDK两tab、原侧栏/导航/任务闭环不删；只DEMO，不真实运行软件/CLI/改依赖。
