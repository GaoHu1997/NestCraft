- 类型：用户故事（正式能力增量）
- 所属 Feature / PRD：[FEAT-007 文件草稿与分支上下文](../Feature/FEAT-007-文件草稿与分支上下文.md)／[CR-090](../../PRD/CR-090-编码区文件操作与代码导航.md)
- 来源与确认依据：CR-090（S2）；用户 2026-11-25「可以，做吧，但是需要开子代理并行开发」确认本轮范围。
- 负责人 / 优先级 / 状态 / 依赖：lead（集成）／P0／验证中（源码已实现，技术验证部分通过，视觉与真机交互待验）／依赖 [STORY-034](../Story/STORY-034-编码区正式实现.md) 现有页签与 [STORY-101](../Story/STORY-101-编码区文件树操作.md) 文件树打开入口。
- 目标：作为使用者，我希望页签能拖拽排序、可切换单击/双击打开、有预览页签且关闭脏页签会确认，以便像成熟编辑器一样管理打开的文件。
- 本次包含：页签拖拽排序；「单击打开」开关（默认关，默认双击打开）；预览页签（斜体、可被替换、双击或编辑即固定）；关闭脏页签的确认。
- 不包含：分屏编辑、拖出成独立窗口、双击最大化、页签右键菜单分组、同名文件目录消歧以外的高级关闭语义。

## 验收标准

- **AC-STORY-102-01**（成功路径：拖拽排序）：给定已打开多个页签，当把一个页签拖到新位置，则页签顺序改变并正确落位（无错位/丢失），会话内保持该顺序。验证方式：设计原型操作 + 手工。
- **AC-STORY-102-02**（单击打开开关）：给定「单击打开」开关默认关闭，当单击文件，则只选中不打开（双击才打开）；打开该开关后单击即打开；切换即时生效并持久化。验证方式：设计原型操作 + 自动化。
- **AC-STORY-102-03**（预览页签）：给定打开某文件，当以预览方式打开（单击且开关关闭/或按预览规则），则以斜体预览页签出现，被下一个预览替换；当双击该预览页签或开始编辑，则固定为正式页签（取消斜体）。验证方式：设计原型操作 + 手工。
- **AC-STORY-102-04**（关闭脏页签确认）：给定页签有未保存修改，当点击关闭，则弹出保存／不保存／取消确认；选择取消保留页签与内容；不保存关闭不写盘；保存失败保留页签与内容。验证方式：手工 + 自动化。
- **AC-STORY-102-05**（边界／失败）：给定只读或超大只读窗口文件、或页签数量多到溢出，当打开／关闭／拖动，则溢出走「更多」下拉而不横向滚动，只读页签不误标脏，操作失败有提示且不丢内容。验证方式：手工 + 视觉对照。
- **AC-STORY-102-06**（键盘可达／深色窄屏）：给定键盘操作与深色窄屏，当用键盘切换／关闭页签、或窄屏下拖动排序，则焦点可见、快捷键有效、布局不破、滚动按需（UI-SCROLL-001）。验证方式：设计原型操作 + 视觉对照。
