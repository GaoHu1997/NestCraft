# STORY-060：项目设计资料索引与按需读取

- 类型：用户故事。
- 所属 Feature：[FEAT-010](../Feature/FEAT-010-AI上下文与能力引用.md)；关联[CR-027](../../PRD/CR-027-Code项目设计资料与按需加载.md)。
- 来源：2026-11-19用户要求提供工具让AI知道资料位置和每文件内容、按需自动加载而非全部给AI，以节约token与上下文。
- 负责人/优先级/状态：主代理 / P0 / **设计中（离线设计验证完成，正式工具未实现，视觉待评审）**。
- 目标：作为Code项目使用者，我希望AI先检索设计资料摘要再读取必要片段，以便使用同项目可信版本而不浪费上下文。
- 包含：PRD/UI/方案/数据库模型同一受管索引、两只读工具、分段/引用/版本/缓存/权限/预算契约与离线演示。
- 不包含：真实工具注册、正式AI/CLI接入、全库RAG、全文自动注入、AI写权限、执行SQL、宿主配置修改；不新增Feature或另一会话/任务源。

## 验收标准

| 编号 | 给定/当/则 |
| --- | --- |
| AC-STORY-060-01 | 给定当前Code项目，当AI需要设计资料，则有两工具发现信息；list只返回受管ID/标题/定位/简短摘要/版本/同步状态与分页，不能返回全文或自动遍历全部资料。 |
| AC-STORY-060-02 | 给定list返回的资源及版本，当read指定章节/行/字段，则只载入该片段并返回范围、来源、截断/续读；UI默认说明，不打包全HTML及依赖。 |
| AC-STORY-060-03 | 给定未保存草稿或源版本已变，当调用read，则不读取私有草稿，不混旧/新段，失效引用或摘要明确拒绝/标状态。 |
| AC-STORY-060-04 | 给定会话/项目/授权变化，当list/read/缓存复用/发送，则宿主重验范围与权限；未授权资料标题/统计也不泄露，AI不可传任意路径/项目，子代理只接授权内必要片段。 |
| AC-STORY-060-05 | 给定当前模型窗口，当检索/编译上下文，则按实际system/工具/历史/输入/片段和输出预留计量，逐片段与字节/行预算截断；未知tokens不是0，缓存/重试不绕预算。 |
| AC-STORY-060-06 | 给定人类在四分类间阅读/编辑或切换资源，当使用工作区，则不自动给AI注入整篇或整项目资料，右索引菜单不挤占AI侧栏，原会话/草稿保持且与项目Run来源分离。 |
