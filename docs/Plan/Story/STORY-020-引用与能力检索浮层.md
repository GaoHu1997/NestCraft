# STORY-020：引用与能力检索浮层

- 类型：用户故事；所属 [FEAT-010 AI 上下文与能力引用](../Feature/FEAT-010-AI上下文与能力引用.md) / [PRD-001 CR011](../../PRD/PRD-001-个人Agent界面需求.md#cr-011引用浮层多会话与子智能体用量)。
- 来源：2026-11-18用户指定+引用浮层、文件/知识/项目记录/能力、@与/关键词检索。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / 设计中 / 统一能力和项目授权、会话引用。

作为项目使用者，我希望在输入处快速检索并引用上下文和能力，以便明确AI可用来源，而不是跳出聊天或自动执行工具。

- +位于输入框左上，等宽浮层向上、高度至多输入框两倍；首行本地文件选择，随后知识库、项目文件、本项目记录与Skill/MCP/Tools。
- @检索文件/知识等，/检索启用能力并引用；同一浮层、稳定ID和可移除chip。引用不是执行/扩权，发送才按模型/工具规则调用。
- 候选/发送均按当前项目权限，停用/撤权不能重放；历史消息引用需要过滤已失效资料。本轮本地文件只元信息，不真上传解析。

## 验收标准

| 编号 | 给定 / 当 / 则 |
| --- | --- |
| AC-STORY-020-01 | 给定输入框，当点+，则浮层在其上方、同宽且高不超过两倍，可滚动。 |
| AC-STORY-020-02 | 给定浮层，当看首行或点击，则首行为选择文件并打开本地选择；取消不新增，本轮明确元信息仿真。 |
| AC-STORY-020-03 | 给定项目，当选择后续类别，则只显示本范围知识、文件、记录和有效能力，不串项目或复制凭证。 |
| AC-STORY-020-04 | 给定@/关键词，当输入检索，则引用/能力候选在浮层按关键字筛选，空结果/错误有反馈。 |
| AC-STORY-020-05 | 给定候选，当键盘/点击选取，则形成引用并可移除，不在选择时执行工具；IME/ESC/外部关闭有效。 |
| AC-STORY-020-06 | 给定撤权/禁用/历史失效，当发送，则复检拒绝，不重放旧知识或把引用当授权。 |
| AC-STORY-020-07 | 给定两种视口，当浮层/引用/本地选择，则无横溢出，原权限和审批回归保持。 |
