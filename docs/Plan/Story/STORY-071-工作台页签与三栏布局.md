# STORY-071：工作台页签与三栏布局

- 类型：用户故事
- 所属 Feature / PRD：[FEAT-021 会话中心工作台](../Feature/FEAT-021-会话中心工作台.md) / [CR-054](../../PRD/CR-054-会话中心工作台.md)
- 来源与确认依据：2026-11-21 用户提出编码模式下的会话中心页签与三栏布局，确认“可以”，并补充“整个项目中 AI 会话都是一起的不要隔离，历史会话都要显示，执行中的会话点击到其他页面不中断、不新建、还是那个会话在旁边执行”。2026-11-22 用户明确：**两类项目默认进入工作台**；同日追加要求工作台页签改为**纯图标「坐在电脑前的小人」、不显示文字**，且**左栏会话列表与会话框须对齐 AI 侧栏近期改版**。仅需求与设计层，未授权正式编码。
- 负责人 / 优先级 / 状态 / 依赖：主代理 / P0 / 设计中（需求确认，原型已同步；LLD 待制作）/ 依赖现有会话存储与运行时、CR-037 续接机制、CR-045 可调栏、UI-SCROLL-001。
- 目标：作为编码项目用户，我希望进入项目就以当前会话为中心工作，随时看到全部历史会话，并在切换页签或页面后继续原来的会话，以便不中断思路、不重复建会话。
- 本次包含：代码类与办公类项目均新增“工作台”页签（最前、新建窗口默认进入、名称与图标已确认）；左历史会话常驻、中当前会话、右辅助栏容器；项目级会话共享与跨页签/页面连续执行；单实例/单订阅；不自动新建；恢复显式。
- 不包含：右侧预览内容（STORY-072）；AI 请求开栏与工具结果（STORY-073）；浏览器内核；跨项目会话；办公项目独立的第二套会话界面；新会话存储模型、权限或审批变更。

## 验收标准

- AC-STORY-071-01：给定代码类或办公类项目，当**新建窗口打开项目时**，则页签最前显示工作台并默认选中；**CR-082 起**工作台页签显示**电脑（显示器）图标 `monitor` 16px + 文字「工作台」**（不再是“纯图标、不显示文字”），`aria-label`／`title` 仍为「工作台」；代码类为“工作台／需求／设计／任务／编码”，办公类为“工作台／文档／成果”；两类共用同一工作台容器与会话运行时；用户之后主动切到其他页签时，切页签或恢复窗口不强制拉回工作台；页签溢出、键盘操作与 `aria-selected` 符合现有页签规范。
- AC-STORY-071-02c：给定工作台输入区，则具备 `+` 添加、CLI、权限模式、模型/思考档位、发送/停止与统计行，全部复用 AI 侧栏 `.ai-composer` 结构；不得以简化三按钮替代。
- AC-STORY-071-02e：给定工作台输入区，则 CLI／权限／模型／`+` **点击必须真实生效**：浮层有真实尺寸并贴近被点按钮；选择后状态与 chip 同步更新、浮层关闭；不得只响应状态而无可见结果。
- AC-STORY-071-02f：给定工作台统计行，则内容相对输入框水平居中（与 AI 侧栏同一口径），不得左对齐或偏置。
- AC-STORY-071-02d：**CR-082 起**给定工作台页签为「电脑图标 16px + 文字「工作台」」，则图标与文字垂直中心对齐（误差 ≤1px）、间距 6px，页签高度与选中下划线内缩与相邻文字页签同一口径；未选中态与深色主题下图标与文字均可见。
- AC-STORY-071-02b：给定工作台，则左栏会话列表、中间会话消息与执行步骤**复用 AI 侧栏现行结构与公共样式**（历史列表行、状态标识、已加载/全部计数、搜索与重置、置顶、分批「继续加载」、消息与工具卡、步骤折叠框）；不得出现与 AI 侧栏不一致的第二套外观。
- AC-STORY-071-02：给定工作台页签，则界面为左历史、中会话、右辅助栏三栏；右辅助栏默认关闭；用户可打开/关闭；左右栏可拖动、按项目独立记忆、受最小/最大限幅，中间保持最小可用宽度；窄屏按设计降级且不丢失当前会话；代码与办公两类项目的三栏结构一致，仅中间区回退目标与右栏预览资料类型不同。
- AC-STORY-071-03：给定当前项目存在多个会话（含其他页签创建、执行中、已完成、失败、未读），当查看工作台左栏与现有历史浮层时，则两处按 CR-063 分批加载并可访问当前项目全部会话，顺序、分组、状态标识一致，不隐藏任何入口创建的会话；分批不构成数据裁剪。
- AC-STORY-071-04：给定一个执行中的会话，当切换到需求/设计/任务/编码页签（办公项目为文档/成果页签）并返回工作台时，则仍是同一会话；流式输出、步骤、统计和运行状态连续，不重置、不新建、不重复发送。
- AC-STORY-071-05：给定一个执行中的会话，当切到首页、其他项目、知识库或服务器页面再返回原项目时，则执行不中断；返回后显示同一会话及最新进度；不自动新建；项目窗口隐藏不得卸载会话视图或丢失订阅。
- AC-STORY-071-06：给定同一会话，当工作台主区与对应页签右侧 AI 栏同时可见或先后切换时，则两处显示同一消息、步骤、统计、草稿与运行状态；在任一视图发送、停止、切换会话或修改草稿，另一视图同步；不得出现双实例、双订阅或重复消息；代码与办公项目均适用。
- AC-STORY-071-07：当用户切换页签、切换页面、改变布局或视图重新挂载时，则不创建新会话；只有用户显式“新会话”或既有执行派发规则可新建，并能记录新建来源。
- AC-STORY-071-08：给定前端重建、窗口关闭后再打开或原线程续接失败，则按 CR-037 既有机制显式提示并恢复原会话；不得静默新建、丢失历史或把失败伪装成成功。
- AC-STORY-071-09：给定模型不可用、CLI 不存在、权限不足或发送失败，则历史会话仍完整可见，错误显式呈现，当前会话不被替换或新建。
- AC-STORY-071-10：给定 UI 设计已登记版本，则实现后按同视口、缩放、主题和运行状态做设计/软件对照；滚动区域按 UI-SCROLL-001 提供初始隐藏、滚动显示、停止隐藏的动态证据；未执行或未目视判读的范围不得记为通过。
