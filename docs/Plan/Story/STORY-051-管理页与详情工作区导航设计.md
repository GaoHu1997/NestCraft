# STORY-051：管理页与详情工作区导航设计

- 类型：用户故事，需求／设计调整；不是正式软件开发。
- 所属 Feature：[FEAT-001](../Feature/FEAT-001-工作台框架与可操作评审.md)；PRD：[PRD-001 CR-021](../../PRD/PRD-001-个人Agent界面需求.md#cr-021管理页与详情工作区导航设计)。
- 来源与确认依据：2026-11-19 用户要求进入某项目／某知识库／某服务器后隐藏左侧三个管理菜单，左上保留返回，回管理页恢复左栏；用户随后明确“没有明确让写代码的所有都是需求／设计调整”。
- 负责人 / 优先级 / 状态 / 依赖：lead / 高 / 待验收（设计9/9、原设计回归18/18、AI设计25/25通过；正式软件未实施） / 原统一设计稿、原模块 DEMO 样例。
- 目标：作为工作台使用者，我希望详情不被一级管理栏占位，并能清晰返回所属管理页。
- 包含：三模块管理／详情导航、知识库列表到阅读路径、项目各页签／办公、窄屏和深色设计；返回保留原查看与草稿状态。
- 不包含：正式源码修改、真实 AI／SSH／知识接口、完整管理表单重做、构建／部署／发布；不能借本次补导航宣称全软件设计补齐。

## 验收标准

| 编号 | 给定／当／则 |
| --- | --- |
| AC-STORY-051-01 | 给定三个管理页，则完整管理栏可见并选中当前模块；从详情返回后恢复（窄屏恢复原上方模块导航）。 |
| AC-STORY-051-02 | 进入研发或办公项目，则隐藏整条一级管理栏并回收占位，左上唯一父级返回为项目管理，所有内部页签保持此布局。 |
| AC-STORY-051-03 | 从知识库管理进入具体库，则隐藏管理栏、保留目录／正文／正文目录；返回回到知识库管理而非项目管理，选中笔记与原搜索状态不被清空。 |
| AC-STORY-051-04 | 进入某服务器，则隐藏管理栏、保留终端／文件／监控；左上返回所属服务器管理，不触发连接、授权或重置。 |
| AC-STORY-051-05 | 在1440×900／390×844浅深色及键盘操作中，返回始终可达，无空白管理轨道和整页横向溢出；详情不显示窄屏三模块菜单。 |
| AC-STORY-051-06 | 空库、搜索无匹配、非法库、无需求或主机未连接／离线失败等内容状态不改变详情导航；仅设计稿变化，正式源码受保护，不以设计检查冒充软件验收。 |
