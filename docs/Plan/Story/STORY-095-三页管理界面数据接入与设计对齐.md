## 目标

作为使用者，我希望项目管理、知识库、服务器管理三页看起来与设计稿一致，并显示真实的项目描述/负责人/标签/需求进度/运行数、知识库描述/负责人、服务器指标与系统信息，以便一眼掌握状态。

## 本次包含 / 不包含

- 包含：三页卡片结构、信息层级、搜索/副标题/页脚文案对齐；上述数据字段的后端与数据库接入；项目/知识库负责人·描述·标签的编辑。
- 不包含：预置演示样例、改写真实数据、授权/审批/运行语义、其它页面。

## 验收标准

- **AC-STORY-095-01（项目卡片结构）**：给定进入项目管理页，则每张卡片含 图标砖、名称、`项目编号 · 类型`、描述、标签（可含 `N 个运行`）、需求进度条与 `完成/总数`、负责人头像+姓名、更新时间、打开按钮，与设计稿结构一致。
- **AC-STORY-095-02（项目搜索）**：给定在搜索框输入负责人或标签或描述关键词，则筛选出匹配项目；placeholder 为「搜索项目、负责人或标签」。
- **AC-STORY-095-03（项目数据）**：给定项目有 owner/描述/标签，则列表正确显示；`需求进度` 显示 `requirement_index` 中 story 完成数/总数；`运行数` 显示 `execution_task` 活跃任务数；无数据为 0/0 与不显示运行标签。
- **AC-STORY-095-04（项目编辑）**：给定新建或编辑项目，则可填写并保存 负责人/描述/标签，保存后列表即时反映。
- **AC-STORY-095-05（知识库卡片结构）**：给定进入知识库页，则卡片为单列结构，含图标、名称、「描述 · 负责人」、授权项目名标签、篇数·更新时间、图标/管理授权/进入。
- **AC-STORY-095-06（知识库数据与编辑）**：给定知识库有描述/负责人，则卡片显示；可编辑并保存描述/负责人。
- **AC-STORY-095-07（服务器卡片结构）**：给定进入服务器页，则卡片含 名称、地址、在线状态、CPU/内存/磁盘 百分比、分组·系统(OS)、更新时间；主交互点击进入工作台。
- **AC-STORY-095-08（服务器数据）**：给定主机已连接并采样，则显示 CPU/内存/磁盘 与 OS；未连接/未采样显示「—/未知」，不虚构数值。
- **AC-STORY-095-09（文案对齐）**：三页副标题、搜索 placeholder、页脚统计文案与设计稿对应（页脚用真实口径）。
- **AC-STORY-095-10（构建与回归）**：`cargo test --lib` 与前端 `npm run build`（含 tsc）通过；三页交互功能回归通过；提供设计—软件同条件对照证据。
