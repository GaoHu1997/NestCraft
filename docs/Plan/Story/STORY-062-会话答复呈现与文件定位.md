- 类型：用户故事（既有能力细化 + 呈现缺陷）
- 所属 Feature：[FEAT-010 AI 上下文与能力引用](../Feature/FEAT-010-AI上下文与能力引用.md)
- PRD：[CR-034](../../PRD/CR-034-会话答复呈现与文件定位.md)
- 来源与确认依据：2026-11-19 用户提出会话答复样式需逐项核对（工具使用、思考、结果、折叠、代码框、图片框、文件链接、点击定位到行）；同日要求把不合格项写进需求与设计。实测判定见 [REPORT-022](../../Test/REPORT-022-会话答复呈现实测.md)。
- 负责人 / 优先级 / 状态 / 依赖：lead / 高 / 设计中（仅需求与设计，未授权编码）/ 依赖编码区文件打开能力（已具备）
- 目标：作为会话使用者，我希望模型答复里的工具调用、思考、结果、代码、图片与文件路径都以恰当的可操作形态呈现，并能在左侧定位到具体代码行，以便不必手工复制路径即可查看来源。

## 本次包含

1. 工具调用与结果按 `toolId` 配对，形成统一工具块（头部：工具名/参数摘要/状态/耗时；结果默认折叠；失败展开摘要）。
2. 图片预览框：容器内等比缩放、边框、说明、点击放大、失败占位。
3. 文件定位链接：`路径:行[:列]` 渲染为链接样式。
4. 点击链接在编码页签左侧打开文件、滚动并高亮目标行；跨页签时切换后可返回。
5. 执行配置回填：已存 CLI/模型/档位显示实际值，失效值保留并标注。
6. 思考块收起态显示内容规模提示。

## 不包含

- 会话控制（模型/档位/权限/子智能体/统计）——属 CR-019。
- 附件上传与解析、外部 URL 图片自动抓取。
- 后端工具审批通道、事件协议变更（前端即可完成配对）。
- 本次不修改正式软件源码；实现需另行编码授权。
