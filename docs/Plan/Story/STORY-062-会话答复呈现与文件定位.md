# STORY-062：会话答复呈现与文件定位

- 类型：用户故事（既有能力细化 + 呈现缺陷）
- 所属 Feature：[FEAT-010 AI 上下文与能力引用](../Feature/FEAT-010-AI上下文与能力引用.md)
- PRD：[CR-034](../../PRD/CR-034-会话答复呈现与文件定位.md)
- 来源与确认依据：2026-11-19 用户提出会话答复样式需逐项核对（工具使用、思考、结果、折叠、代码框、图片框、文件链接、点击定位到行）；同日要求把不合格项写进需求与设计。实测判定见 [REPORT-022](../../Test/REPORT-022-会话答复呈现实测.md)。
- 负责人 / 优先级 / 状态 / 依赖：lead / 高 / 设计中（仅需求与设计，未授权编码）/ 依赖编码区文件打开能力（已具备）
- 目标：作为会话使用者，我希望模型答复里的工具调用、思考、结果、代码、图片与文件路径都以恰当的可操作形态呈现，并能在左侧定位到具体代码行，以便不必手工复制路径即可查看来源。

## 本次包含

1. 工具调用与结果按 `toolId` 配对，形成统一工具块（头部：工具名/参数摘要/状态/耗时；结果默认折叠；失败展开摘要）。
2. 图片预览框：容器内等比缩放、边框、说明、点击放大、失败占位。
3. 文件定位链接：`路径:行[:列]` 渲染为链接样式。
4. 点击链接在编码页签左侧打开文件、滚动并高亮目标行；跨页签时切换后可返回。
5. 执行配置回填：已存 CLI/模型/档位显示实际值，失效值保留并标注。
6. 思考块收起态显示内容规模提示。

## 不包含

- 会话控制（模型/档位/权限/子智能体/统计）——属 CR-019。
- 附件上传与解析、外部 URL 图片自动抓取。
- 后端工具审批通道、事件协议变更（前端即可完成配对）。
- 本次不修改正式软件源码；实现需另行编码授权。

- AC-STORY-062-15：给定当前会话存在分步骤执行，当显示，则在消息流末尾、输入框之前显示与消息区等宽的折叠框；头部包含「执行步骤」、已完成/总数与整体状态（进行中／已完成／有失败／等待继续）；无步骤的会话不显示空框。

## 验收标准

- AC-STORY-062-01：同一 `toolId` 的调用与结果合并为一个工具块，头部含工具名、参数摘要与状态。
- AC-STORY-062-02：工具结果默认折叠；失败时展开错误摘要并保留尾部诊断；空结果标注「无输出」。
- AC-STORY-062-03：配对缺失时单侧成块并标注原因（「结果未返回」/「来源调用未记录」），不伪造配对。
- AC-STORY-062-04：图片在消息卡内等比缩放（宽 ≤100%、高 ≤360px），有边框与 `alt`/文件名说明，不撑破容器、不裁切。
- AC-STORY-062-05：点击图片打开放大浮层，Esc 与点击遮罩关闭，关闭后焦点回到原图。
- AC-STORY-062-06：图片加载失败显示占位框、失败文案与原始路径。
- AC-STORY-062-07：`路径:行[:列]` 渲染为可点击链接（主色、hover、可键盘聚焦），并显示行号。
- AC-STORY-062-08：点击链接后编码页签左侧打开目标文件，编辑器滚动到目标行并高亮行号槽。
- AC-STORY-062-09：从需求/设计页签点击时切换到编码页签完成定位，用户可返回原页签且原上下文保留。
- AC-STORY-062-10：路径越界或文件不存在时给出明确失败提示，不改变当前已打开文件。
- AC-STORY-062-11：非项目上下文（服务器会话/无项目）链接退化为复制路径并说明原因。
- AC-STORY-062-12：会话已存执行配置时底部控件显示实际值；值失效时保留显示并标注、阻止发送且给出修复入口。
- AC-STORY-062-13：思考块收起态显示内容规模提示（字数或行数）。
- AC-STORY-062-14：深色主题与 390×844 窄视口下，上述场景无横向溢出与遮挡。
