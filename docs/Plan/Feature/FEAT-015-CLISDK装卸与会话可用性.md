# FEAT-015：CLI SDK 装卸与会话可用性

- 类型：Feature
- 所属 Epic：[EPIC-007 AI 设置与引擎管理](../Epic/EPIC-007-AI设置与引擎管理.md)
- 目标用户与价值：用户能了解引擎安装状态并从可用引擎中选择。
- 范围与边界：三个 CLI SDK 仿真安装、更新、卸载和候选同步。
- 负责人：主代理。优先级、依赖和迭代沿用所属 Story 记录。
- 当前状态：历史v3.0仿真待用户验收；原三种SDK范围不变。CR-053 命令工具（Shell）选择已于 2026-11-21 实现到正式软件（待验收）。CR-059 D/E（CLI 任务模型路由单行折叠、中文权限五档、移除难度/类型、缓存先行＋并发检测、SDK 卡片与 10 稳定版＋当前补入、Grok 画布收敛）**2026-11-23 已实现，验证中、待用户验收**；路由表在派发链路的实际消费属 FEAT-019，未实现。
- 整体验收：装卸后会话候选及时更新，失败时保留上次成功状态。
