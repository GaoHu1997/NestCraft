# FEAT-021：会话中心工作台

- 类型：Feature
- 所属 Epic：[EPIC-001 工作台导航与视觉体验](../Epic/EPIC-001-工作台导航与视觉体验.md)
- 目标用户与价值：编码项目用户进入项目即可在会话中推进实现，同时随时查看全部历史会话、文件和需求上下文，不必在页签之间反复切换，也不会因切换页面丢失正在执行的会话。
- 范围 / 不包含：代码类项目新增“工作台”页签、三栏布局、项目级会话共享与连续执行、右侧只读预览面板。不包含 AI 主动开栏、工具执行可视化、内置浏览器、跨项目会话、办公项目工作台、新会话存储模型或权限升级。
- 优先级 / 依赖 / 负责人：P0；依赖现有会话存储与运行时、CR-034 文件/需求定位、CR-045 可调栏、UI-SCROLL-001；负责人主代理。
- 状态 / 所属迭代：**验证中（2026-11-23 正式软件已实现，待用户验收）**。STORY-071／072 已实现三栏与只读预览；STORY-073 的 AI 请求开栏已通过 `workbench.open_panel` 工具接通。界面实机视觉对照与窄屏未验证。
- 关联：[PRD CR-054](../../PRD/CR-054-会话中心工作台.md)；[FEAT-010](FEAT-010-AI上下文与能力引用.md)（能力引用与输入）、[FEAT-011](FEAT-011-会话历史与后台任务.md)（会话历史与运行）、[FEAT-003](FEAT-003-需求维护与交付验收.md)（需求阅读）、[FEAT-007](FEAT-007-文件草稿与分支上下文.md)（编码与文件）、[FEAT-009](FEAT-009-知识库目录与正文阅读.md)（知识阅读）、[FEAT-006](FEAT-006-办公资料解读与产物预览.md)（办公预览）。
- 整体验收：同一项目内所有页签共享同一会话集合与当前会话；切换页签或页面不新建、不中断；历史会话全部可见；右侧预览不扩大权限、不修改原文档；设计/软件视觉对照通过且滚动条动态证据完整。

## 设计状态

- UI：待制作。必须覆盖三栏布局、右栏关闭/打开/拖宽、历史列表执行中/未读/失败状态、会话在页签间切换的连续状态、右栏各类预览与“在编码/需求中打开”回退、窄屏降级、浅/深主题、滚动条按需显示。
- LLD：待制作。重点为会话运行时与视图解耦、单实例/单订阅、工作台与右侧 AI 栏共享状态、右栏面板注册与预览路由、页面隐藏/重建后的恢复。
- DB：复用现有会话/消息存储，无新增表；若 LLD 发现需要新增字段，另立 DB 变更，不在本 Feature 预设。
- Test：待建。至少覆盖跨页签连续执行、历史全显、不自动新建、双视图同步、预览只读、权限不扩大、窄屏与滚动条。
