# FEAT-010：AI 上下文与能力引用

- 类型：Feature
- 所属 Epic：[EPIC-006 AI 会话与任务协作](../Epic/EPIC-006-AI会话与任务协作.md)
- 目标用户与价值：用户能在输入处选择、检索并核对将用于 AI 会话的资料和能力。
- 范围与边界：AI 侧栏、附件/引用、@ 和 / 搜索、上下文范围。会话生命周期见独立特性。
- 负责人：主代理。优先级、依赖和迭代沿用所属 Story 记录。
- 当前状态：设计中，真实上传和能力调用未验证。
- 整体验收：候选范围与当前会话一致，引用清晰可见且不会触发能力执行。
