# FEAT-011：会话历史与后台任务

- 类型：Feature
- 所属 Epic：[EPIC-006 AI 会话与任务协作](../Epic/EPIC-006-AI会话与任务协作.md)
- 目标用户与价值：用户切换会话时仍能跟踪原任务，回到原会话查看结果。
- 范围与边界：新建、历史、后台结果、未读和所属会话；CR-019补充本会话任务折叠与目标管理的纯设计，项目Task/Run仍为独立执行权威。
- 负责人：主代理。优先级、依赖和迭代沿用所属 Story 记录。
- 当前状态：设计中，现有证据为本地仿真。
- 整体验收：新建或切换后后台结果仍写回原会话，未读状态随后台事件与查看更新。
