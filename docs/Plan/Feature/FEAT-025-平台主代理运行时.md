# FEAT-025：平台主代理运行时

- 类型：Feature
- 所属 Epic：[EPIC-006 AI 会话与任务协作](../Epic/EPIC-006-AI会话与任务协作.md)（唯一父项；会话与任务协作是本 Feature 的业务成果）
- 目标用户与价值：使用 AI 侧栏与项目工作台的项目使用者。用户不必先理解「哪个 CLI 支持哪个协议」就能开始对话；平台已经管理的模型、密钥、Skill、知识与工具直接可用，工作代理仍由受管执行统一调度。
- 范围 / 不包含：见 [CR-069 §3](../../PRD/CR-069-平台主代理运行时与受管执行接入.md)。包含：平台会话运行通道、平台模型调用客户端、工具白名单循环、派发接入工具。不包含：外部 Agent 框架依赖、真实 worker 进程 spawn（M1）、协议转换网关、UI 视觉改造、自学习路由。
- 优先级 / 依赖 / 负责人：高（用户直接诉求）；依赖供应商模型配置（FEAT-014）、能力管理（FEAT-013）、内置工具集（FEAT-023）、受管执行状态机（FEAT-019 已实现的存储与状态机部分）、主代理协作契约（CR-037 设计）。负责人：主代理。
- 状态 / 所属迭代：CR-069 后端与 UI-v2 前端已合入 main（`0b39d40`），真实应用端到端及视觉遗留仍待验收；CR-071 上下文增量方案自评通过，后端已实现、验证中，视觉/真实模型摘要质量不计通过。此前“未授权／未实现”结论为建立时历史，不作为当前状态。
- 本增量验证：CR-071后端43项新增测试与默认完整lib **500 passed / 0 failed / 8既有ignored**，cargo全目标检查及前端构建通过；源码仍在独立分支未提交/合并；[逐AC报告](../../Test/REPORT-CR071-执行与验证.md)保留真机/视觉/真实摘要质量未执行范围。
- 当前增量：[CR-071](../../PRD/CR-071-平台会话分层上下文与安全找回.md)；本轮用户明确授权执行者评审通过后直接开发，不含自动合并或发布。
- 子项：见下方「子项」章节（层级检查脚本按 `## 子项` 小节解析父子关系）。

## 边界说明（与其他 Feature 的关系）

- **FEAT-015（CLI SDK 装卸与会话可用性）**：CLI 的安装、检测、版本、启停仍归 FEAT-015。本 Feature 只是让会话不再**依赖** CLI，不移除 CLI 能力。
- **FEAT-019（依赖调度与受管执行）**：批次、任务、领取、状态机、租约、恢复仍在 FEAT-019。本 Feature 只新增**主代理侧的接入调用**，不复制调度逻辑。
- **FEAT-023（AI 内置工作台工具集）**：工具实现与启停仍在 FEAT-023。本 Feature 复用 `run_tool` 与 `tool_enabled`，不新增第二套工具实现。
- **CR-037（主代理协调与答疑）**：角色与权威不变。本 Feature 交付其「协调者」角色的可运行载体之一，不改变协调者的权限边界。
