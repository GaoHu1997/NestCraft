# FEAT-019：依赖调度与受管执行

- 类型：Feature（新增能力）。
- 所属 Epic：[EPIC-002 研发需求与交付](../Epic/EPIC-002-研发需求与交付.md)。
- 来源：[CR-016](../../PRD/CR-016-需求派发与自主研发任务系统.md)，2026-11-19 用户明确要求新增完整需求与设计；本轮不授权真实执行。
- 目标用户与价值：派发后独立任务自动并行，依赖或冲突任务自动等待，在受管权限和资源边界内执行，并能如实恢复或停止。
- 优先级：P1；负责人：文档代理，集成负责人为主代理；所属迭代：CR-016 设计评审。
- 状态：设计中；正式持久化任务引擎、runner 和安全隔离未实现，设计稿待评审。
- 依赖：FEAT-018 冻结任务范围/策略；FEAT-020 定义产物验证门槛与集成队列；统一配置/能力网关作为复用基础而非完整安全保证。

## 范围与边界

包含业务树以外的任务 DAG、产物门槛、资源锁/并发槽、CLI 能力准入、独立分支/worktree、领取租约/心跳/fencing、故障分类/有限重试、暂停取消、旧进程停止确认和恢复。持续运行拟由独立 runner 负责，UI 计时器不是后台服务。

不包含无限重试、静默换 CLI/模型、绕过密钥或知识权限、把 worktree 当 OS 安全边界、远端合并/推送、生产发布。本轮仅计划，既有内存会话注册表不承担任务调度权威。
