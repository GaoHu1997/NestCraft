# FEAT-008：项目知识授权与只读检索

- 类型：Feature
- 所属 Epic：[EPIC-005 知识阅读与项目授权](../Epic/EPIC-005-知识阅读与项目授权.md)
- 目标用户与价值：所有者可按项目分享知识，项目 AI 可引用授权来源。
- 范围与边界：授权、撤权、确定性解析后的本地全文检索与有界按需读取。原件为文件权威，索引为可重建派生数据；禁止模型建库／OCR、向量检索、自动语义关系和知识写入。
- 负责人：主代理。优先级、依赖和迭代沿所属Story记录。
- 当前状态：正式能力设计中；CR-030新增范围设计待评审、尚未实现和验收。
- 整体验收：授权项目能对来源有效修订检索、按片段引用并溯源；未授权、撤权、源变化和过期引用被拒；旧全文读取路径不能越过片段预算。
