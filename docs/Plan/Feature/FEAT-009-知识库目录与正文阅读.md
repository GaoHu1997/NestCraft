# FEAT-009：知识库目录与正文阅读

- 类型：Feature
- 所属 Epic：[EPIC-005 知识阅读与项目授权](../Epic/EPIC-005-知识阅读与项目授权.md)
- 目标用户与价值：用户能在文件树、格式定位、正文和标题／结构目录之间快速定位本地资料。
- 范围与边界：知识浏览、基于同一索引的搜索定位与阅读。格式能力按CR-030逐项验证，不把受限抽取宣传为高保真预览。服务器验收覆盖沿用STORY-014；AI授权由FEAT-008唯一管理。
- 负责人：主代理。优先级、依赖和迭代沿用所属Story记录。
- 当前状态：设计中；CR-030可视设计待评审，正式新格式／索引读取未实现／未验证。
- 整体验收：切换来源时正文与目录／定位同步，格式状态和限制可见，失败不残留旧内容；点击搜索命中能定位实际来源。
