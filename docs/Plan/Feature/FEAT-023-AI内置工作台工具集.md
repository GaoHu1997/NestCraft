# FEAT-023：AI 内置工作台工具集
- 类型：Feature
- 所属 Epic：[EPIC-006 AI 会话与任务协作](../Epic/EPIC-006-AI会话与任务协作.md)（唯一父项；AI 在会话中直接操作工作台配置）
- 目标用户与价值：使用 AI 侧栏的用户。用户用自然语言下达配置意图（建项目、写需求文档、建知识库、登记服务器），AI 直接在软件中完成操作，无需逐界面手工点按；操作过程以真实工具步骤可见、可审计、可停用。
- 范围 / 不包含：见 [CR-060 §2](../../PRD/CR-060-AI内置工作台工具集.md)。包含：应用自带 MCP stdio 服务器、12 个 `workbench_*` 工具（项目/需求文档/知识库/服务器四域）、派发自动注入、能力页治理与开关、AI 侧栏步骤中文名映射。不包含：删除类操作、知识内容写入、供应商与密钥配置、服务器远程执行、grok CLI 注入。
- 优先级 / 依赖 / 负责人：高（用户直接指令）；依赖既有派发层 MCP 注入（LLD-FEAT-002 §3.1.1）、需求文档扫描（FEAT-003）、知识库管理（FEAT-008/009）、服务器管理（FEAT-016）、能力注册表（FEAT-014 能力页）；负责人：主代理（用户授权需求/设计/编码一体完成）。
- 状态 / 所属迭代：实现完成、自动化验证通过；端到端真实模型演示待验收。
- 子项：见下方「子项」章节（层级检查脚本按 `## 子项` 小节解析父子关系）。
