# FEAT-027：AI 搜索工具

- 类型：Feature
- 所属 Epic：[EPIC-006 AI 会话与任务协作](EPIC-006-AI会话与任务协作.md)
- 目标用户与价值：让 AI 在会话中直接检索项目文件内容与路径、并具备联网搜索与网页阅读能力；本地搜索默认跟随会话项目根，不要求用户单独配置授权目录。
- 范围：
  - 本地：`fs_grep`（正则内容检索）、`fs_glob`（文件名/路径匹配），默认范围＝会话绑定项目根，会话额外目录仅本会话有效，规划模式只保留项目根。
  - 联网：`web_search`（默认免 key 抓取，可配 Tavily）、`web_fetch`（网页转 Markdown）。
- 不包含：整机全盘预索引、Everything SDK、跨设备搜索、强制商业搜索 API。
- 优先级 / 依赖 / 负责人：高；依赖项目数据与角色绑定、能力注册表；负责人 lead。
- 状态：已实现（技术验证通过，待用户验收）。
- 子项：[STORY-117 本地搜索会话级授权](STORY-117-本地搜索会话级授权.md)
- 关联：[CR-093](../../PRD/CR-093-AI本地与联网搜索工具.md)／[CR-104](../../PRD/CR-104-本地搜索授权会话化.md)／[LLD-CR093](../../LLD/LLD-CR093-AI搜索工具.md)／[UI-CR093](../../UI/文档/UI-CR093-设置搜索.md)／[UI-CR104](../../UI/文档/UI-CR104-搜索授权会话化.md)／[DB-CR104](../../DB/DB-CR104-会话搜索授权与权限档位.md)／[REPORT-CR093](../../Test/REPORT-CR093-AI搜索工具验证.md)
- 整体验收：本地搜索在绑定项目后零配置可用、越界可读拒绝并指向会话授权；联网搜索在无 key 时可用、配置 Tavily 后可回退；工具在平台 runtime 与 CLI workbench MCP 均可见。
