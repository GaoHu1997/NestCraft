# EPIC-005：知识阅读与项目授权

- 类型：Epic
- 所属愿景：[VISION-001](../VISION-001-产品愿景.md)
- 目标用户与价值：工作台所有者能浏览本地知识资料，并授权指定项目的 AI 检索和有限引用。
- 范围与边界：库内树／正文／结构目录、逐格式确定性解析、增量全文索引、项目授权与撤权、有界只读检索。图片扫描件没有OCR时只按元数据处理；不含模型建库、自动语义图谱或知识写入。
- 负责人：主代理。依赖、优先级和排期按各Feature下Story跟踪。
- 当前状态：正式能力设计中；CR-030新增需求与UI设计待评审，真实增量未实现／验收。
- 整体验收：用户能定位当前版本原件的有效文本，授权项目按有限片段检索并溯源；未授权、撤权、过期代际及解析／索引失败均fail-closed。

## 子项

- [FEAT-008 项目知识授权与只读检索](../Feature/FEAT-008-项目知识授权与只读检索.md)。所有者按项目授权知识；AI只使用当前可见资料及受限片段。
- [FEAT-009 知识库目录与正文阅读](../Feature/FEAT-009-知识库目录与正文阅读.md)。用户按文档树、结构定位和当前正文阅读，状态与索引同源。

- 需求基线与变更记录见 [PRD-001](../../PRD/PRD-001-个人Agent界面需求.md)。
