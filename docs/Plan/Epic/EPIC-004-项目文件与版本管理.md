# EPIC-004：项目文件与版本管理

- 类型：Epic
- 所属愿景：[VISION-001](../VISION-001-产品愿景.md)
- 目标用户与价值：研发或办公项目使用者能管理工作目录下的文件和版本，并识别 AI 提案依赖的文件版本与分支。
- 范围与边界：文件草稿、版本、文件/Git 视图、AI 分支上下文。项目接管与会话管理由各自 Epic 负责。
- 负责人：主代理。依赖、优先级和排期按各 Feature 的 Story 跟踪。
- 当前状态：正式 Git 能力设计中，CR-003 文件版本增补规则待确认。
- 整体验收：能从当前工作区定位文件及分支，过期或冲突提案有明确反馈，且不会覆盖用户编辑。

## 子项

- [FEAT-007 文件草稿与分支上下文](../Feature/FEAT-007-文件草稿与分支上下文.md)。用户能核对文件和分支的版本基线，再决定是否应用 AI 提案。

- 需求基线与变更记录见 [PRD-001](../../PRD/PRD-001-个人Agent界面需求.md)。
