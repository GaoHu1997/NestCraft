# EPIC-001：工作台导航与视觉体验

- 类型：Epic
- 所属愿景：[VISION-001](../VISION-001-产品愿景.md)
- 目标用户与价值：工作台使用者能找到主要入口，并在一致的界面中完成评审。
- 范围与边界：工作台通用框架、基础评审环境及视觉风格；CR-022 维护固定原型位置、可信样例和保护新设计的存量补稿，各业务授权及验收仍按原 Story。各模块业务流程由相应 Epic 管理。
- 负责人：主代理。依赖、优先级和排期按各 Feature 的 Story 跟踪。
- 当前状态：基础原型为历史交付，原型浅深主题已落地，待用户验收。
- 整体验收：主要入口可找到并能返回，评审者可复现基础演示，并在各工作区切换已选浅色与深色主题。

## 子项

- [FEAT-001 工作台框架与可操作评审](../Feature/FEAT-001-工作台框架与可操作评审.md)。用户可由全局入口进入相应工作区，并在本地重置和复现基础流程。
- [FEAT-002 视觉风格评审与主题](../Feature/FEAT-002-视觉风格评审与主题.md)。用户可对比候选视觉方向，并在各工作区切换浅色和深色。

- 需求基线与变更记录见 [PRD-001](../../PRD/PRD-001-个人Agent界面需求.md)。
