# EPIC-007：AI 设置与引擎管理

- 类型：Epic
- 所属愿景：[VISION-001](../VISION-001-产品愿景.md)
- 目标用户与价值：工作台使用者能配置一次供应商、模型和能力，并在会话中使用兼容的 CLI 和模型。
- 范围与边界：设置入口、能力配置、模型供应商、协议适配、CLI SDK 管理。真实凭证、真实 SDK 装卸和适配验证沿用现行边界。
- 负责人：主代理。依赖、优先级和排期按各 Feature 的 Story 跟踪。
- 当前状态：CR-012 仿真待用户验收，真实适配仍在设计。
- 整体验收：设置可就地管理，候选与启用状态、安装状态和协议相符，配置失效时能看到原因并改选。

## 子项

- [FEAT-013 统一设置入口与菜单](../Feature/FEAT-013-统一设置入口与菜单.md)。用户能从当前工作页面直接打开设置并返回原位置。
- [FEAT-014 供应商模型与能力适配](../Feature/FEAT-014-供应商模型与能力适配.md)。用户能跨 CLI 复用配置，并在会话中切换兼容模型及思考等级。
- [FEAT-015 CLI SDK 装卸与会话可用性](../Feature/FEAT-015-CLISDK装卸与会话可用性.md)。用户能了解引擎安装状态并从可用引擎中选择。

- 需求基线与变更记录见 [PRD-001](../../PRD/PRD-001-个人Agent界面需求.md)。
