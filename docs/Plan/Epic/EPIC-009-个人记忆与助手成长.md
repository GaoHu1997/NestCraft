# EPIC-009：个人记忆与助手成长

> CR-092（2026-11-25）：新建本 Epic，承载 [FEAT-026 个人记忆层](../Feature/FEAT-026-个人记忆层.md)。用户「按照推荐执行全部执行，一次做完，需要开子代理并行开发」为正式编码授权；D1～D5 按 [RESEARCH-008](../../调研/RESEARCH-008-个人记忆层与默认个人知识库方案建议.md) 推荐取值。见[需求](../../PRD/CR-092-个人记忆层与默认记忆库.md)／[方案](../../LLD/LLD-FEAT-026-个人记忆层实现.md)／[数据](../../DB/DB-FEAT-026-个人记忆数据设计.md)。

- 类型：Epic
- 所属愿景：[VISION-001](../VISION-001-产品愿景.md)
- 目标用户与价值：工作台所有者无需手动整理，就能让 AI 在长期使用中逐渐记住其偏好、目标与事实，越用越懂自己，而数据始终留在本地、可查可改可删。
- 范围与边界：默认个人记忆库、对话到记忆的自动抽取与沉淀、用户画像与上下文注入、记忆读写工具、记忆管理界面。不含云端 embedding、独立向量数据库、多租户/IM 同步；不改变现有知识库检索口径与项目授权语义。
- 负责人：主代理。依赖、优先级与排期见各 Feature/Story。
- 当前状态：待验收（代码已实现，技术验证通过：`cargo test --lib` 607/0、`npm run build` exit 0；真实端到端与视觉待验证。见 [REPORT-FEAT-026](../../Test/REPORT-FEAT-026-个人记忆层验证.md)）。
- 整体验收：新会话能自动"记得"上次告知的偏好；同一事实不重复记录；记忆可检索、可查看、可编辑、可删除并溯源；关闭记忆注入后行为回到现状。
