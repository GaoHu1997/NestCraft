# EPIC-008：服务器管理与运维审批

- 类型：Epic
- 所属愿景：[VISION-001](../VISION-001-产品愿景.md)
- 目标用户与价值：运维使用者能了解主机状态，并明确控制 AI 何时可以协助操作。
- 范围与边界：主机列表与连接入口、工作台、授权和风险审批的本地仿真。真实主机接入和正式权限策略仍待实现。
- 负责人：主代理。依赖、优先级和排期按各 Feature 的 Story 跟踪。
- 当前状态：仅设计与本地仿真，CR-003 独立审批规则待确认。
- 整体验收：能比较主机状态，分辨连接、授权、审批和执行结果，失败或撤权时能看到被拦截原因。

## 子项

- [FEAT-016 主机列表与连接工作台](../Feature/FEAT-016-主机列表与连接工作台.md)。运维使用者能比较主机状态并进入对应工作台。
- [FEAT-017 运维授权与操作审批](../Feature/FEAT-017-运维授权与操作审批.md)。运维使用者能在人工把关下模拟 AI 运维并追溯执行结果。

- 需求基线与变更记录见 [PRD-001](../../PRD/PRD-001-个人Agent界面需求.md)。
