# CLI 标识资源来源与许可

本目录仅用于在统一设计稿中标识实际CLI，不是本项目产品Logo，也不表示获得相应品牌的赞助或商标授权。UI代码和任务逻辑为本项目独立实现，没有复制任务参考产品的界面代码。

| 资源 | 已读取来源 | 处理 |
| --- | --- | --- |
| `claude.svg` | zhukunpenglinyutong/jetbrains-cc-gui，`docs/illustrations/icons/claude-code.svg` | 保留原图形与品牌颜色，本机复制；来源仓库MIT |
| `codex.svg` | zhukunpenglinyutong/jetbrains-cc-gui，`docs/illustrations/icons/codex.svg` | 保留原Codex图形与渐变，本机复制；来源仓库MIT |
| `grok.svg` | CC Switch项目源文件 `src/icons/extracted/grok.svg` | 保留图形，加入白色底和固定深色图形以适配浅/深主题；来源仓库MIT，另保留LobeHub图标MIT归属 |

SVG落地时解析XML并拒绝script、foreignObject、事件处理器或外部href/src；无动态网络请求。代码许可不替代品牌使用规范；正式分发前应复核品牌标识使用方式。本轮只用于可识别CLI的设计演示。
