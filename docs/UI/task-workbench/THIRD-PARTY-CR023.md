# CR-023派生样式许可

本设计中的子智能体目录与智能体管理卡片几何样式派生自 dsh-maestro-codex 的 CliCatalogChip.tsx / MaestroCard.tsx。仅移植可许可的前端样式结构并映射本项目主题令牌，不包含其宿主服务、执行/安装接口。执行器Logo沿用原有许可资源，技术标识不构成官方背书。
