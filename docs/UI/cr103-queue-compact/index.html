规则摘要

编号规则
R-CR103-1每条排队消息固定单行：超宽截断省略，完整内容悬浮 title；行高与面板总高不随消息长度增长
R-CR103-2「编辑／立即发送／删除」收进条目行右侧，删除为危险色，不再单独占行
R-CR103-3引用/附件以紧凑小标内联（🔗n / 📎n），仅有内容时显示；「已暂停」不逐条重复（待确认默认值）
R-CR103-4编辑态例外：仅该条目展开为编辑框 + 保存／取消，其余保持单行
R-CR103-5列表限高约 5 行（待确认），超出列表自身滚动，适用 UI-SCROLL-001（静止隐藏、滚动显示、停止 700ms 隐藏、悬停不唤醒）
R-CR103-6头部（待发队列 N + 暂停/继续）与底注保留不变；队列操作行为与内存口径不变
R-CR103-7浅/深、侧栏 390 与工作台两布局单行不溢出、无横向滚动、动作可达
R-CR103-8面板可折叠：头部左侧 ▾/▸ 切换，折叠时仅保留头部一行（≈29px），条目与底注隐藏不销毁，队列与暂停状态不受影响；默认展开，状态会话内记忆（待确认默认值）
