## 2. 布局与视觉规范

### 2.1 结构

```text
┌ 仓库路径药丸 ───────────── ⚡国内加速 ● │ 🔑密钥配置 │ ↻ ┐
├ 未提交变更  [5]              ↓提取 ↓更新当前分支 ↑推送当前分支 ┴
│  已暂存 2                                    全部取消暂存
│   ☑ M src/booking/service.ts            git reset
│  未暂存 3                                       全部暂存
│   ☐ M src/web/BookingForm.tsx             git add
│  ┌ 提交信息（feat: …） ───────────────────────┐
│  │                                            │
│  └────────────────────────────────────────────┘
│  [✨ AI 生成]                        [ 提交 ][▾]
│  填写提交信息后可提交
├ 分支  [⌕ 搜索分支]      全部展开  全部折叠  管理远程  [+ 新建分支]
│  ⌄ 本地 3
│    ✓ feature/booking-idempotency          ↓0 ↑3
│  › 远程 3
├ 提交历史              [提交人] [所有分支 ▾] [全部 ▾]
│  ●  feat(booking): 幂等键…   HEAD -> main  origin/main   2026/11/22 13:26
│     周野
```

### 2.2 主要尺寸与令牌

- 三张卡片：`flex 2 / 1 / 2`，圆角 10px，`1px solid var(--line)`，白底 `var(--surface)`；侧栏高度不足时按最小高度保底（变更 330px、分支 170px、历史 300px），由卡片列整体滚动。
- 卡片内边距：段头 `8px 12px`，段体 `10px 12px`，卡片间距 `10px`。
- 变更行四列：`14px 18px minmax(0,1fr) auto`，行高约 22px，状态徽标 16×16、圆角 4px。
- 提交输入框最小高 52px、圆角 8px；提交按钮主面 `padding 6px 16px`、caret `6px 8px`。
- 分支行三列：`20px minmax(0,1fr) auto`，当前分支 `var(--primary-soft)` + `inset 2px 0 0 var(--primary)`。
- 历史行：图谱列宽 = 车道数 × 14px + 4px；时间列 `tabular-nums`；窄于 400px（容器查询）时时间行移到主题下方。
- 颜色语义沿用既有令牌：状态 M=`--warning`、A=`--success`、D=`--danger`、R/C=`--violet`、?=`--muted-2`；refs `HEAD`=墨色、`tag`=警告色、`origin/*`=紫、本地=绿。

### 2.3 滚动条（UI-SCROLL-001 / CR-049）

- 生效区域：`.gitp2-scroll`（卡片列）、`.gitp2-changes`（变更列表）、`.gitp2-body.scroll`（分支树、提交历史）。
- 规则：默认隐藏外观，实际滚动时仅目标容器显示，停止后按 `scrollbar.js` 的 700ms 隐藏；不使用 `overflow:hidden` 禁滚，不改变正文宽度。
- 验证：`scripts/shot-cr067-design.mjs` 断言 `before=false / during=true / after=false`。

## 3. 交互规则

- 勾选即暂存／取消暂存；`全部暂存`／`全部取消暂存` 作用于对应分组；操作期间禁用行控件。
- 提交按钮可用条件：`已暂存数 > 0 && 提交信息非空`；▾ 菜单与主面同门禁。
- 分支树：`全部展开`／`全部折叠` 同时作用于本地与远程；搜索框输入即过滤（本地与远程各自过滤，组头数量随之变化）。
- 提交历史：点击行展开／收起变更文件（同时只开一条）；筛选变化重新查询；`加载更多` 仅在还有下一页时显示。
- 弹层：点击顶栏按钮开关，点外部或 Esc 关闭；取消丢弃未保存编辑。
- 危险动作（推送、切换分支、新建并切换）在软件侧保留确认框，设计稿只演示状态变化。

## 5. 已知差异与限制

- 参考图为宽面板截图（约 900px）；本项目侧栏默认 260px（可拖至 480px）。窄宽下顶栏改为两行、历史时间列移到主题下方，其余视觉保持一致。这是侧栏约束下的适配，不是设计变更。
- 参考实现的右键菜单（复制 hash、在提交处新建分支／打标签、推送标签）不在本次范围，见 PRD §2.3。
- 国内加速的真实镜像可用性依赖外网条件，设计稿只演示开关与前缀，不代表镜像实测可用。
