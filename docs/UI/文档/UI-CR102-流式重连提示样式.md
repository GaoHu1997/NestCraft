# UI-CR102-v1：会话流式重连提示样式

- 关联：[CR-102](../../PRD/CR-102-会话流式重连提示样式修正.md)；Story 增量：[STORY-062](../../Plan/Story/STORY-062-会话答复呈现与文件定位.md)（消息流）；工作台布局继承。
- 版本：**UI-CR102-v1**（2026-11-26）
- 设计稿：[session-reconnect-design/index.html](../session-reconnect-design/index.html)（自包含，可直接打开；浅／深切换、桌面 720／侧栏 390 切换）
- 前序：无独立旧版；被替代的现状样式见设计稿「现状对照」节（粉块＋整段英文＋悬浮重试按钮），仅留档不作为基准。

## 1. 场景覆盖

| 场景编号 | 场景 | 呈现 |
| --- | --- | --- |
| SC-102-01 | 重试进行中（默认折叠） | 一行无色块中文摘要：`⟳ 正在重试 n/5 · 原因摘要`，后随「详情」「立即重试」文字链；前文流式输出原位保留 |
| SC-102-02 | 详情展开 | 状态码、URL、request id、原始返回原文；等宽 12px、细左线（2px `--line-2`）、透明背景、可复制、可收起 |
| SC-102-03 | 最终失败（5/5） | 转现行错误卡（细红左边线，非大面积色块）：「自动重试 5 次后仍失败，本轮已停止」＋「重新发送／继续」 |
| SC-102-04 | 重试成功 | 指示消失；留一行灰色小字「✓ 途中上游中断，已自动重试 n 次后恢复」（留痕与否待用户确认） |
| 不适用 | 手动暂停／取消 | 沿用现行运行指示，不在本版范围 |

## 2. 视觉与文案基准

- 无色块：透明背景、无边框；文字用主题 `--muted`，计数用 `--ink` 加粗，动作为 `--accent` 文字链；错误终态才允许红色（`--danger`）且只用于文字与 3px 左边线。
- 原因摘要为中文短语＋状态码括注（如「上游暂时不可用（502）」）；完整报错原文只在展开区出现。
- 展开区 `pre` 使用 `--mono`、`--muted`；最大高 170px，超高时自身滚动；「复制错误详情」在剪贴板成功后提示「已复制」。
- 图标：进行中用旋转 `⟳`（遵循 `prefers-reduced-motion` 时静止）；成功用 `✓`（`--ok`）。
- 主题：浅／深成对；视口 720 桌面与 390 侧栏窄档；侧栏下摘要行允许换行但动作不折断（`overflow-wrap:anywhere` 仅用于展开区）。

## 3. 滚动条（UI-SCROLL-001）

本版**新增一个滚动容器**：展开详情区（SC-102-02，超高时）。该区按 [UI-CR049 规范](UI-CR049-滚动条按需显示.md) 实现：初始透明，实际滚动时显示（浅 `#a4abb5`／深 `#7d8794`），连续滚动保持，停止 700ms 后隐藏，悬停不单独唤醒，`scrollbar-width:thin`、WebKit 10px 轨道 3px 透明内边 8px 圆角，禁止切宽度或 `display`。消息流本体不因本版新增滚动行为。适用场景登记为 SC-049-03（AI 消息区）继承。

## 4. 覆盖核对与准入

- 列出受影响存量界面：AI 侧栏会话消息流、工作台会话消息流（同一组件）；错误卡、运行指示不变。
- 设计确认依据：2026-11-26 用户三条明确样式要求（见 CR-102 确认记录）；纯设计交付，**不自动授权软件实现**。
- 实现位置：软件源码中重连提示渲染链路待开发授权后只读核对补记（CR-100 相关文件链路：`ChatPanel` 会话消息流）。
- 对照验证计划：实现后按同视口／主题成对截图本稿与软件，覆盖 SC-102-01～04 浅／深×720／390，展开态需动态滚动条证据（截图序列或录屏），登记于 Test 报告；断言脚本可复用本稿的 DOM 结构（`#retryLine`、`#detailBox`、`#detailPre`）。

## 5. 验证记录（设计侧，2026-11-26）

- 无头 Edge（未使用 `--hide-scrollbars`）三组合截图，渲染核对通过：浅色 1100（[cr102-design-light-1100.png](../../Test/screenshots/cr102-design-light-1100.png)）、深色 1100（[cr102-design-dark-1100.png](../../Test/screenshots/cr102-design-dark-1100.png)）、窄档 420（[cr102-design-narrow-light-420.png](../../Test/screenshots/cr102-design-narrow-light-420.png)）。
- 核对结论：SC-102-01～04 均呈现；重连摘要行无色块；错误卡动作链接两主题均为 `--accent` 蓝色（放大取样核对）；深色下红块对照区为留档样式，非新设计。
- 过程缺陷与修复：初版 `<html>` 未默认 `data-theme="light"`，浅色 token 未生效（卡片底色丢失），已修复并支持 `?theme=dark` 直达深色；修复后三组合复验通过。
- **未验证**：展开详情区的滚动条按需显示动态行为（需交互，静态截图不能证明；实现后按 §3 要求以动态证据验收）；真实软件对照（未授权编码，未实现）；`prefers-reduced-motion` 实机表现。
