## 2. 精度边界（重要）

路线 A 是**语法级索引**，不运行编译器、不接 LSP。下列限制不是实现注脚：每种语言都必须在代码区上方以**一行可见文案**常驻呈现（`.precision` 横条），不能让用户只从文档得知。

| 语言 | 能识别 | 识别不到 | 界面常驻文案（可见） |
| --- | --- | --- | --- |
| Java | 显式 `implements`／`extends`、抽象类与接口声明、直接与经抽象基类的间接实现 | 匿名类 `new IFoo(){}`、Lambda、泛型实参中的实现、跨 jar 依赖的实现 | Java：语法索引仅识别显式 implements／extends；匿名类 new IFoo(){}、Lambda、泛型实参与跨 jar 依赖的实现看不到。 |
| C# | `class A : Base, IFoo`（含抽象类）、`using` 命名空间行、接口/类的子类型列表 | **语法无法区分基类与接口**；partial class 分散多文件；显式接口实现 `void IFoo.M()` 可能漏 | C#：class A : Base, IFoo 可见，但语法无法区分基类与接口（统一按「父类型」呈现）；partial class 分散多文件、显式接口实现 void IFoo.M() 可能漏。 |
| Python | 类定义中的基类列表、直接与经中间基类的多级继承、多基类 | 鸭子类型、`IFoo.register(Bar)` 虚拟子类、`__subclasshook__`、运行时动态绑定 | Python：基于语法索引，动态绑定与 ABC 注册无法识别；鸭子类型、IFoo.register(Bar) 虚拟子类与 __subclasshook__ 也看不到（仅类定义中的基类列表可见）。 |
| Go／Vue（不支持继承） | 仅沿用 CR-090 的定义跳转（本稿不重复演示） | 继承／实现关系 | Go 暂不支持继承跳转，可跳转到定义。／Vue 暂不支持继承跳转，可跳转到定义。 |
| `.txt` | 纯文本阅读 | 全部代码导航 | 纯文本（.txt）完全不提供代码导航。 |

**呈现规则**

1. 精度横条与语言切换联动：切 Java／C#／Python 即换对应句子；Go／Vue／纯文本使用「语言支持」红色标签，不伪装有继承能力。
2. 选择器标题按语言用语：Java「`X` 的实现」、C#「`X` 的子类型」、Python「`X` 的子类」；父级方向 C#／Java「父类型」，Python「基类」。
3. C# 不显示「基类 vs 接口」的二分标签，统一用「父类型」，避免语法级索引伪造语义结论。
4. Python 的 `ABC` 外部基类不建立可跳转链接，只在源码中保留原文；不制造「外部库已索引」的假象。

## 4. 实现与设计边界

- **本稿是预期基准，软件截图才是实现证据**。设计稿不冒充软件，软件不得以「已有实现」反向压低本稿。
- 索引能力限定为「读代码」：不启动进程、不编译、不执行用户代码；不读取真实仓库，仅内存合成夹具。
- 双向跳转只对显式语法声明生效；界面文案使用「语法索引」而非「语义分析」。
- **滚动条（UI-SCROLL-001）**：文件树、页签条、代码区、选择器列表均使用 `overflow:auto` 保留原生滚动占位，仅实际滚动时着色，停止 700ms 后隐藏；不使用 `overflow:hidden`、不切换宽度/`display` 假装，不因显隐丢失光标与选区。
- 对外状态：`window.designState()` 返回 `{scenario, lang, pickerOpen, markerKinds, markerDetail, theme, narrow, activeFile, openTabs, cursor, pickerCount, pickerFiltered, breadcrumb, notice, scrollbars, languages}`，供脚本核对；DOM／几何只作辅助，不能替代目视。
- 语言按钮在 SC-094-03／04 固定语言；切到其他语言时进入 SC-094-02 的同语言对照，避免在「C# 专用场景」里显示 Java 却仍标 C#。

### 5.1 滚动条验证项（单列，UI-SCROLL-001）

1. 文件树超高：初始无着色 → 实际滚动显示 → 连续滚动保持 → 停止 700ms 隐藏；栏宽与内容宽度不变。
2. 多实现选择器列表（13 项）：列表内部独立滚动与计时，外层编辑区不跟随唤醒；过滤后列表高度变化仍正确。
3. 代码区横向/纵向滚动：滚动时显示，停止隐藏；光标行高亮与横向位置不因显隐跳动。
4. 嵌套隔离：文件树、选择器、代码区任一处滚动，不同时唤醒其他容器。
5. 不使用 `overflow:hidden`、不切滚动条宽度或 `display` 实现隐藏；原生输入/选区保持。
6. 证据为同条件动态序列（隐藏→显示→隐藏），不以静态无滚动条截图或 `--hide-scrollbars` 充数。
