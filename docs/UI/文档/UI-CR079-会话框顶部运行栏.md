# UI-CR079-v1：会话框顶部运行栏

- 关联：[CR-079](../../PRD/CR-079-会话框顶部运行栏.md)；状态：**已按本版实现到正式软件，待验收**（2026-11-25）。唯一查看入口：[仿真原型UI.html](../仿真原型UI.html)（进入项目 → 工作台／AI 侧栏查看输入框上方）。
- 资源：`workbench-v4/ai.js`（composerBlock 帽子栏）、`workbench-v4/cr079.js`、`workbench-v4/cr079.css`、`workbench-v4/index.html`；版本 UI-CR079-v1。
- 依据：2026-11-24 用户参考截图与描述。

## 1. 视觉与交互基准

| 部位 | 基准 |
| --- | --- |
| 帽子栏 | 输入框上方浅灰条，**与输入框同属一张卡片**（卡片顶部运行栏，底部一条分隔线与输入区分开），随卡片宽度（工作台 860px 居中）；高度约 34px，角落随卡片圆角。 |
| 运行通道分段 | 「CLI ／ 助理」分段控件：未选中文字灰、选中淡主色底＋主色文字加粗；运行中两端禁用。助理使用星芒 sparkles 图标（2026-11-25 由「大管家」更名并换图标）。 |
| 分支 chip | 右侧，图标＋当前分支名＋下拉箭头；**点击展开分支列表**，列出项目其它分支、当前分支打勾高亮，可查看/选择；超长省略；**无分支则不渲染**。 |
| worktree 复选框 | 最右，原生 checkbox（主色），后跟 “worktree” 文本；勾选提示“将在独立 worktree 工作区执行（执行隔离后续接入）”。 |
| CLI 工具区 | `+`、CLI 切换、CLI 权限档位、模型、发送。 |
| 助理工具区 | `+`、平台权限档位、模型、发送；**无 CLI 切换**。 |

## 2. 状态与场景

| 场景 | 期望 |
| --- | --- |
| CLI 通道、普通会话 | 帽子栏 CLI 选中；工具区含 CLI 切换与 CLI 权限（如“默认模式”）；分支 chip 显示；worktree 未勾。 |
| 助理通道 | 帽子栏“助理”选中；CLI 切换消失；权限显示平台档位（默认“受限”）；点权限弹出“助理权限：只读／受限／完全访问”。 |
| worktree 勾选 | 复选框选中，提示独立工作区执行。 |
| 无仓库/读取失败 | 不显示分支 chip（不硬编码 main）。 |
| 运行中 | 分段、worktree 锁定禁用。 |
| 两布局与主题 | 侧栏与工作台一致；浅/深、1440×900、390×844 不溢出。 |

## 3. 证据与验证

- 截图（`docs/Test/screenshots/cr079-design/`）：`01-hat-cli-workbench.png`（CLI 通道）、`02-hat-butler.png`（助理，CLI 切换消失、权限“受限”）、`03-butler-permission.png`（助理平台权限三项）、`04-worktree-checked.png`（worktree 勾选）。
- 脚本 `scripts/shot-cr079.mjs`：真实原型渲染，校验助理下 `cliChip=false`、权限=`受限`、worktree 勾选成功、0 JS 异常。
- **UI-SCROLL-001**：帽子栏本身不是滚动容器，继承共享滚动规则（消息/历史/模型/textarea 实际滚动显示、停止约 700ms 隐藏，不改宽不禁滚）；本栏无新增横向滚动。
