- 顶栏返回替代详情页左侧品牌位置；管理页仍展示所选品牌。页面标题／favicon和品牌资产不变，不引入新风格。
- 删除项目页签行及知识／服务器／办公标题行重复的父级返回；业务内部的“返回关联需求／原Run”等不属于管理导航，仍保留。
- 返回使用明确所属管理页，不依赖浏览器历史。只改变查看状态，不触发 DEMO 派发、授权、重置或清空草稿；已有库内搜索／选中笔记、项目文件草稿及 AI 会话按原样保留。
- 隐藏针对一级管理栏，而非库内文件树、项目内容栏、服务器文件树、监控或 AI。设置及完整设计基线查看器保持既有语义，不将它们扩为新业务工作区。
- 加载／错误／空态继承各内容区域设计，导航不受异步业务结果影响；导航自身无加载、保存成功或无权限分支，因为它不调用真实业务或权限接口。未新增弹窗／展开区。

## 设计调整方案及验证边界

1. 在现有壳内按 page 区分管理与详情：project／knowledge-lib／server 为详情，管理栏 hidden 与单列网格一致变化，窄屏模块导航一并隐藏。
2. 顶栏返回文案及目标按详情类型映射；点击回到对应管理页，恢复选中菜单。保留内容级查看状态。
3. 当前稿 knowledge 原来直接进入固定阅读样例；补知识库列表和库 id，再把原阅读投影移为 knowledge-lib。保留原研发手册笔记样例，另用空库演示导航空态。缺失库不可误展示其他库内容。
4. 直接 file:// 打开并验证六个主场景、项目页签／办公、内容空态／失败、键盘、浅深与窄屏；保存设计截图。旧原型、正式 src/src-tauri、依赖和发布产物不编辑；不构建或运行正式应用。
5. 只验证设计稿可操作及可视状态，不做设计／正式软件对照，不宣称软件已实现或全量视觉统一。历史全量覆盖缺口仍按 [UI-BASELINE-001](UI-BASELINE-001-设计与实现覆盖核对.md) 跟踪。

DB 不适用：只变更设计内存查看投影，无数据库、真实接口、权限、知识写入或 SSH 行为。现有机制足够，无需外部项目调研或新增依赖。软件开发仍须另行取得明确编码授权并重新核对有效设计覆盖。
