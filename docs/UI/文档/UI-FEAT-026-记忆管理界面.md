## 1. 布局与信息层级

- 顶部：面包屑「知识库 · 记忆」+ 右侧「切换空态 / 深色 / ＋新增记忆」。
- 页签：**记忆（列表）／画像／统计**。
- 记忆页：搜索框 + 类型筛选（事实/偏好/目标/事件/决策/关系）+ 状态筛选（生效中/全部/已被取代）；卡片列表：类型徽标、重要度星（★1-5）、"已被取代""外部"标记、正文、来源+时间、行内"编辑/删除"（hover 显示，窄屏常显）。
- 画像页：顶部摘要块（`memory_profile.summary`）+ 结构化字段网格（身份/技术栈/沟通偏好/目标/环境/偏好）。
- 统计页：总记忆数 / 生效中 / 已被取代 / 各类型分布。

## 2. 场景覆盖（本次范围）

| 场景 | 状态/说明 |
| --- | --- |
| 列表有数据 | 默认，卡片渲染 |
| 搜索过滤 | 输入即时过滤 |
| 类型/状态筛选 | 下拉过滤；status=superseded 显示"已被取代" |
| 空态 | 「切换空态」或搜索无结果 |
| 编辑 | 行内编辑记忆内容 |
| 删除 | 软删（列表移除；Rust 侧 status=deleted） |
| 画像 | 摘要 + 字段网格 |
| 统计 | 计数与分布 |
| 深色 | 「深色」切换，全部区域跟随 |
| 窄屏（390） | 单列、行内操作常显、内边距收窄 |

未覆盖/不适用：多文档并排、记忆图谱（复用 kb_graph，后续）、跨设备同步（不在范围）。

## 3. UI-SCROLL-001（强制读取与验收）

- 采用版本：本稿 `memory-manager/index.html` 的 `.scroll-area` 规则——`scrollbar-color: transparent`，滚动时加 `.scrolling` 显示 `#b9c0cc`，停止 700ms 后隐藏；与 [UI-CR049 规范](./UI-CR049-滚动条按需显示.md) 一致。
- 适用滚动区域：记忆列表 `#listArea`、画像/统计滚动区。
- 验收：初始隐藏、滚动显示、连续滚动、停止隐藏；不得用 `overflow:hidden` 禁滚动；编辑态草稿/光标不因滚动条出现而跳动。实现侧逐场景动态截图留证。

## 4. 与软件对照计划

- 同视口（1440×900 / 390×844）、同主题（浅/深）、同样例状态，逐场景成对截图；
- 检查：布局层级、徽标/星级/来源行、空态、深色配色、窄屏、滚动条三帧；
- 差异登记编号并回 UI 修订，未解决偏离不得标视觉通过。

## 5. 数据与边界

- 仅只读展示 + 编辑/删除记忆；不展示整篇对话原文（来源只显示 `sourceRef` 引用）。
- 外部来源记忆标"外部"（trust=external），排序低于 own。
- 隐私：本地数据，界面不发起网络请求。
