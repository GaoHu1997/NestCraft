## 1. 画面与交互

左侧宽260px（较窄桌面220px）的紧凑文件树：目录行与文件行30px，共用14px线条图标、12px文件名、单行省略与hover完整路径。根／目录可选，展开折叠与搜索独立；顶部图标是新建文件夹、新建文件、添加资料。选中文件默认在其父目录新建，弹窗显示目标位置；空/同名/非法名称原位报错，不只toast。创建后展开父目录并选中新节点。

中间沿用公共页签、工具条、白底细分隔；保留报告白纸和多格式编辑，缩小办公独有徽章／大标题／重复提示。DEMO常驻轻量标记，异常场景按需从“演示状态”展开。资料不再以源／草稿／成果大卡片分组，但来源只读和草稿／版本状态不丢。

右侧 **直接使用 AIPanel.render() 与公共 ai.css/cr036.css/cr042.css**。不是复制出“像编码栏”的另一套HTML。历史浮层、子／后台下拉、等宽步骤框、CLI／权限／模型与能力标识、`+`／`@`／`/`、底部三统计、发送停止排队和拖宽均继承公共组件。只替换办公作用域的消息、文件引用和工具结果，原生成／解读／接受拒绝入口仍可操作。

## 2. 仿真样例与数据同源

- 市场研究资料：社区活动预约报告、活动预约台账、五页方案评审PPT、研究资料摘要PDF、本周研究进展MD。台账4场各容量20：总容量80，报名64，取消8，有效预约56，剩余24，利用率70%；报告与PPT引用同一口径。
- 品牌与官网：品牌发布方案、物料台账、四页汇报、视觉检查单、发布周会纪要。物料12份，已复核8份、待复核4份；计划与汇报同源。
- 每个项目各有两个办公会话及对应工具／来源样例。历史原MD内容原样保留在源资料/历史资料，不冒充本轮真实访谈。
- 文件夹结构：01源资料（含会议与访谈、历史资料）、02数据分析、03交付成果。PPT是明确合成的已保存版本，新的用户草稿仍经保存才晋升。
- 所有数字和身份都是合成；未读取真实文件、未访问模型、未真实导出。新增空项目需显式载入，不自动覆盖内容。

## 4. 正式软件实现注记（2026-11-20，编码授权批）

- 文件树/文档/草稿为**前端内存模型**（按项目隔离 Map）：树操作不落盘、不做真实 mkdir（评审 A 条件），界面常驻「仿真样例」标注，草稿不跨进程持久化如实呈现（评审 C 条件：不显示假成功）。
- 两个预置项目（市场研究资料/品牌与官网）首次启动经设置位一次性 seed 到 project 表，rootUri 指向 app_data 下真实**空容器目录**（仅满足 create_project 目录校验，属基础设施容器，非树内容落盘）；进入工作区自动载入内存样例，已有内容不覆盖；用户删除项目后不复活（设置位仍在）；新建 work 项目保持空树 + 「载入演示样例」按钮。
- 右侧直接复用 ChatPanel 同一渲染器（office 作用域）：@ 引用列出办公树文件并随发送快照注入提示词（`office:` 前缀 + content 快照，上限 12000 字），答复中文件名/`路径:行` 渲染为链接并可定位树节点/编码区行。
- 实现文件：`src/modules/office/`（office-model/office-samples/OfficeFileTree/OfficeViewer/office-seed/office-demo）、`src/modules/projects/Workspace.tsx`（OfficeWorkspace）、`src-tauri`（`app_data_ensure_dir`、ContextRef.content、`office-source` 注入）。
