## 1. 位置与尺寸

| 项目 | 规格 |
| --- | --- |
| 位置 | 标题栏 `.top-actions` 内最左，紧接「主题」之前；其后依次为主题、通知、账户，右侧仍是分隔线与最小化／最大化／关闭 |
| 外框 | 54×22px，圆角 6px，无独立边框、无阴影、透明底，垂直居中于 56px 顶栏 |
| 文字 | 11.5px／600，字距 .25px，行高 1，不换行；「更新」两字、「重启」两字 |
| 间距 | 与相邻控件 6px（`.top-actions` 的 gap）；不因出现徽标推动主题、通知、账户与窗口控制换位 |
| 占位 | `hidden` 时整个按钮不渲染，不保留空白宽度 |
| 窄屏 | ≤720px 沿用既有收敛规则：上下文与账户／通知隐藏，徽标保持可见且不挤压窗口控制；1100×700 与 390×844 已检查 |
| 焦点 | `:focus-visible` 使用既有 2px primary 外描边，偏移 2px；`:active` 仅 0.5px 位移 |

顶栏搜索框（原型 `.searchbox`）：按 2026-11-20 用户指令删除，右上角不再有搜索入口；软件侧同步移除按钮，`Ctrl K` 快捷键与搜索结果弹窗保留（功能不丢失，仅去掉可见入口）。

## 2. 状态与交互

| 场景 | 视觉 | 交互与状态 |
| --- | --- | --- |
| SC-046-01 无更新（hidden） | 不渲染按钮，右上角与现状完全一致 | 启动延迟检查与定时检查期间不占位；检查失败、离线、版本不高于当前、当前形态无匹配资产均回到此态。原型中以 `?update=hidden` 演示；不带参数默认展示 SC-046-02 |
| SC-046-02 有更新（available） | 浅绿底 `rgba(26,157,90,.10)`、细绿描边、绿色「更新」 | 悬停 title「发现新版本 vX.Y.Z，点击下载」；点击进入下载；不弹确认框、不打开设置页 |
| SC-046-03 下载中（downloading） | 浅绿底、2.5px 绿描边轨道，进度从顶部中点顺时针生长；内部半透明遮罩 + 12px 加载环，文字隐藏 | 按钮 `disabled`、`aria-busy=true`，重复点击无效；title 实时显示百分比；校验阶段保持进度 100% 与加载环 |
| SC-046-04 就绪（ready） | 浅橙底 `rgba(183,106,0,.11)`、橙色描边、橙色「重启」 | title「更新已下载并通过校验，点击重启并安装」；点击进入安装；重启应用后仍恢复此态 |
| SC-046-05 安装中（applying） | 橙色语义、橙色加载环，文字隐藏 | 按钮 `disabled`、`aria-busy=true`；成功后由新版本接管，失败回到 ready 并提示，不重复触发 |

状态机：`hidden → available → downloading → ready → applying →（新版本启动）`；`downloading → available`（下载或校验失败）、`applying → ready`（安装失败）。任何检查结果都不能把 `downloading`／`ready`／`applying` 直接改回 `available`，避免覆盖进行中的任务。

## 3. 颜色与主题

- 浅色：成功色 `#1a9d5a`（`--success`）、警示色 `#b76a00`（`--warning`）；底色取 10%／11% 透明，描边取 16%～50%。
- 深色：成功 `#4ccb83`、警示 `#e0a04a`；底色提高到 8%～15%，保证与深色顶栏有可见区分。
- 不使用品牌蓝作为更新语义色，避免与主按钮混淆；不使用红色，避免把可用更新表达成错误。
- 加载环用 `currentColor`，随状态取绿／橙；`prefers-reduced-motion` 下停止旋转。

## 4. 文案与无障碍

- 文案固定为「更新」「重启」，不显示版本号文字，避免撑宽顶栏；版本只放 `title` 与 `aria-label`。
- `aria-label`：available「发现新版本 vX.Y.Z，点击下载更新」；downloading「正在下载更新」；ready「更新已就绪，点击重启并安装」；applying「正在重启并安装更新」。
- 进度不只靠颜色：下载中保留加载环与 `aria-busy`；软件实现应同时提供可读进度（例如 `aria-valuenow` 或 title 百分比），不把颜色作为唯一信息。
- 键盘可达：Tab 可聚焦，Enter／Space 触发；disabled 时不可聚焦；失败提示走现有 Toast，不依赖颜色。

## 6. 实现准入与对照计划

- 准入结论：设计已制作、逐状态截图并登记，可进入正式实现；实现必须复用同一 54×22 尺寸、状态机与文案，不得改成图标按钮、常驻入口或弹窗式更新。
- 软件实现位置（预计）：`src-tauri/src/updater.rs`（检查／下载／校验／安装）、`src/App.tsx`（标题栏挂载）、新增更新徽标组件与其样式、`src/api/index.ts`（命令封装）。
- 对照计划：软件侧在 1440×900 浅色与深色、1100×700、390×844 下截取同样五态；逐项对照位置、尺寸、圆角、文字、颜色、边框、加载环与 disabled 行为；状态切换以真实检查／下载／安装流程为准，不以静态注入冒充。找不到可发布更新包时，以本机 feed 夹具验证下载与校验，安装路径按形态分别记录，未执行项标未验证。
- 设计变更规则：实现中若发现尺寸或状态不可行，先回本页更新并重新截图、登记新版本，再改软件；不得先改软件后补稿。
