# UI-CR104：搜索授权会话化

- 关联：[CR-104](../PRD/CR-104-本地搜索授权会话化.md)／[LLD-CR093](../../LLD/LLD-CR093-AI搜索工具.md)／[UI-CR093](UI-CR093-设置搜索.md)。
- 入口：唯一公开原型 [仿真原型UI.html](../仿真原型UI.html)，内部资源 `workbench-v4/index.html`。
- 设计版本：`UI-CR104-v1`（2026-11-26），改动两个场景：设置 · 搜索、AI 侧栏 · 搜索授权。
- 复用既有设置壳与 AI 侧栏弹层样式（`ai-pop` / `menu-item` / `pop-h` / `drop-empty` / `menu-hint` / `mono`），不新增全局视觉令牌。

## 1. 设置 · 搜索（删除本地授权卡片）

- 页面只剩一张卡片「联网搜索」：后端（默认/Tavily）、API 地址、API Key、超时、结果数上限、网页抓取开关、保存按钮；行为与文案不变。
- 卡片下方一行说明：「本地搜索默认搜索当前会话的项目根目录，无需在此授权；项目外目录请在 AI 侧栏「搜索授权」中按会话添加。」
- 删除原「本地搜索授权目录」整卡：项目下拉、添加目录、目录列表、移除、"该项目尚未授权任何目录"空态一并移除。
- 状态覆盖：加载中/加载失败/保存中/后端=默认（隐藏 Tavily 行）保持不变；无项目不再是本页状态。

## 2. AI 侧栏 · 搜索授权

### 2.1 菜单入口
- 位置：输入框「+」菜单 →「指令」分组，排在「权限」之后。
- 行内容：搜索图标＋「搜索授权」＋关键词 `search`＋说明「为当前会话添加项目外的搜索目录」。

### 2.2 弹窗（`ai-pop`，锚定输入框工具条）
自上而下：
1. 标题「搜索授权（本会话）」＋右上关闭按钮。
2. 说明：「本地搜索默认包含当前项目根目录，无需授权；此处添加的目录仅本会话有效。」
3. 项目根只读行：目录路径（mono）＋「项目根 · 默认包含，不可移除」，不可点击、不可移除。
4. 分隔线。
5. 额外目录列表：每行目录（mono）＋「本会话额外授权」＋行尾移除按钮（trash 图标）。
6. 空态：「尚未添加额外目录。」
7. 分隔线。
8. 主操作行：「＋ 添加目录（仅本会话）」，点击调用系统目录选择器（真实软件）／演示数据（原型）。
9. 底部提示：「规划模式会话只搜索项目根；需要项目外目录时在此添加。」

### 2.3 状态覆盖
- 无项目根（会话未绑定项目）：第 3 行显示「未绑定项目，本地搜索仅限本会话已授权目录」。
- 空列表：显示空态，不隐藏「添加目录」。
- 添加中/移除中：对应按钮禁用（真实软件）；原型仅演示即时增删。
- 规划模式：列表仍可编辑，但工具调用只使用项目根；弹窗底部提示常显，不额外禁用控件。
- 越界返回：工具错误文案指向本入口，不在设置页出现旧文案。
