## 布局与继承

延续左文件树、中阅读区、右正文／页导航。1440×900 下左232px、右206px，中区自适应，正文页最大760px；工具栏固定在正文上方，正文独立滚动。1050px以下右栏按按钮展开，760px以下左右栏按按钮开覆盖抽屉，Escape关闭并将焦点还给触发控件。浅／深主题复用现行设计令牌。文件图标在此仅作格式识别占位，正式实现应继承CR-080选定B图标，不以样稿占位覆盖有效图标设计。

只读预览顶部：文件名、格式／转换性质、下载原件；PDF／Word／PPT提供上一页、页码输入、下一页、适合宽度及缩放；右栏用实际页号导航。本版可视稿为页号导航，不包含真实缩略图；不能将尚未设计的缩略图样式直接作为开发基准。Excel明示打印页预览，ZIP保留原件状态。

Markdown提供阅读／原文；受限态给出「部分内容改用原文阅读」及完整原文入口；大文件给前后段导航、当前段数和末尾状态，不把单段标全文完成。编辑、上传、空间设置和回收站继承[UI-CR077](UI-CR077-知识库文档操作.md)，本稿不重设计这些界面，草稿／撤销保护仍需真实软件回归。
