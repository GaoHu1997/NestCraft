## 1. 视觉与交互基准

| 部位 | 基准 |
| --- | --- |
| 页面头 | 只保留“服务器管理”和右侧“N 台＋添加主机”；删除副标题与页脚说明。窄屏标题与按钮同一行，计数隐藏。 |
| 主机卡片 | 单列横向信息、三列自适应网格：官方系统标识 38px 方砖；名称＋分组；等宽地址；CPU／内存／磁盘三列，数值优先；底部系统名与上次采样。整卡可点进入工作台，右上仅“编辑／删除”图标。 |
| 连接语义 | 卡片与工作台都无“连接／断开”；卡片不显示常驻“已连接”状态。进入工作台自动连接，关闭页签断开；失败只提供“重试”。 |
| 弹窗 | 520px，按内容高度；字段顺序：名称 → 主机地址／端口 → 用户名／分组 → 认证方式 → 凭据；底部左侧“测试连接＋结果”，右侧“取消／保存”。无副标题、无免认证说明。正文仅在视口不足时滚动。 |

| 工作台 | 顶栏：官方系统标识＋名称＋地址＋连接状态（正在连接／已连接／连接失败）。中心：连接中与失败态只保留必要状态与“重试”，不写连接能力说明；文件与监控未连接时不显示陈旧数据。 |

## 4. UI-SCROLL-001 与实现边界

显式采用 [UI-CR049-v1](UI-CR049-滚动条按需显示.md) 与 [CR-049](../../PRD/CR-049-滚动条仅在滚动时显示.md)，采用版本/hash 以上述文档为准。适用区域：服务器列表页、弹窗正文、工作台文件树、监控区、终端历史。

- 初始隐藏；实际滚动只让目标容器显示；停止 700ms 隐藏；悬停／聚焦不单独唤醒；嵌套容器各自判断。
- 不以 `overflow:hidden` 禁滚、不切换滚动条宽度、不因显隐重绘丢失输入／滚动位置。
- 本轮动态证据：列表滚动前后卡片宽度 362→362（390 视口），滚动瞬间 `scrollbar-active` 为真、停止后为假；弹窗正文 `overflow-y:auto`、滚动 171px 时显示、停止后隐藏。截图见 §5。测试浏览器为 headless Edge，关闭 overlay scrollbar 以确保截图可复核；正式软件仍需同条件复验。
