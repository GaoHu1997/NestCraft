## 入口与布局

知识库阅读器右侧面板在原「大纲／反向链接／未解析」后新增 **「图谱」** 页签；进入后显示以当前笔记为中心的局部图（深度默认 1），右上角可切「整库总览」。窄屏（≤760px）图谱占满内容区，最小高度 320px。

## 视觉与交互

| 元素 | 规则 |
| --- | --- |
| 笔记节点 | 实心圆，主色描边；当前笔记加粗描边 |
| 附件节点 | 方形，灰色描边 |
| 未解析目标 | 虚线圆形，警示色 |
| 边 | 细实线；选中节点时邻接边高亮 |
| 标签 | 缩放 ≥0.7 时显示；否则悬停显示 |
| 交互 | 拖拽平移、滚轮 0.3–3x 缩放、单击选中高亮邻接、双击展开邻居、「打开」跳转笔记 |
| 筛选 | 深度 1/2/3、含附件、只看未解析 |
| 状态 | 加载骨架；空图谱「还没有链接关系」；截断「已显示前 200 个节点」；错误 + 重试 |
| 主题 | 浅/深均用现有令牌；不引入新色 |

## 语义相关界面（同批）

### 首次下载（2026-11-25 用户选定「首次启动联网下载」，模型不打进安装包）

设计稿：[cr089-model-setup/index.html](../cr089-model-setup/index.html)（可查看四态）。

| 场景 | 内容 |
| --- | --- |
| SC-M01 检测缺失 | 「本地语义模型·未安装」，说明约 41MB 一次性下载；按钮「立即下载」「使用关键词检索」 |
| SC-M02 下载中 | 进度条 + 已下载/总量 + 速度；「取消」；提示可继续阅读 |
| SC-M03 完成 | 「已就绪」；显示模型/维度/已编码块数；「重建语义索引」 |
| SC-M04 失败/离线 | 明确错误（含失败域名）+「已自动使用关键词检索」；「重试」「稍后再说」 |

入口：阅读器右侧索引状态区 / 设置·知识库。下载不阻塞窗口与阅读；失败一律降级为关键词检索，不伪装语义可用。

实现证据（2026-11-25，真实 `ModelPanelView` 组件四态夹具，14/14 断言通过）：`docs/Test/screenshots/cr089-model/`（01 未安装、02 下载中、03 已就绪、04 失败、05 深色、06 390）。**差异**：真实 Tauri 窗口整页截图未截取；下载中未做“取消”按钮（后台下载可随窗口一起结束），与设计稿 SC-M02 的取消按钮存在差距，登记为待办。

### 检索与索引

- 搜索结果命中若来自语义通道，条目加「语义」标签；语义不可用时列表顶部提示「语义检索不可用，已仅用关键词」。
- 设置/索引状态区展示：模型可用、已编码/总块数、最近更新时间、重建按钮（可取消）。

验证：实现后由组件 Playwright 检查截图（浅/深/390/空/截断/筛选）+ Rust 单测；真实 Tauri 窗口未截取时如实标注。
