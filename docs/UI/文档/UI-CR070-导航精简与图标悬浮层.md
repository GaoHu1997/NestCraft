## 1. 设计基准与继承

1. **侧栏精简**：删除"当前项目""快捷入口"两个分区（含项目快捷卡、运行队列、设计资料）。侧栏仅保留"工作空间"四项导航与底部用户头像入口（头像编辑角标保留）。底部头像仍承担"设置与账户"唯一入口职责。
2. **顶栏**：删除右上角头像按钮与悬停编辑角标；保留品牌、上下文路径、拖动热区、更新角标、主题切换、通知、窗口分隔线与窗口控制。
3. **图标悬浮层**：项目卡片与知识库卡片上的图标砖（36/40px）与名称保持并排；点击图标砖打开居中悬浮层：
   - 顶部：对象名称 + 关闭按钮。
   - 预览行：当前组合（图标砖 + 说明文字）。
   - "选择颜色"：一行 10 个整块色卡 + 清空回默认（外环 + 白对勾选中态，继承 CR-051 v6 样式）。
   - "选择图标"：50 图标按 6 组分组网格 + "默认"格（继承 CR-051 v6 分组样式）。
   - 底部：取消 / 保存；选择即时预览，保存成对写入 icon+iconColor；关闭按钮、遮罩按下、Escape 均视为取消，不落库。
   - 悬浮层内容超高时正文区 `overflow-y:auto`，滚动条遵守 UI-SCROLL-001（仅实际滚动显示，700ms 停止隐藏）。
4. **编辑项目弹窗**：移除 `<details>` 图标折叠区，改为只读当前组合预览 + "点击列表卡片上的图标修改"提示；其余字段（名称/标识/类型/负责人/描述/目录/成员）行为不变。
5. **知识库卡片**：原"图标"按钮改开悬浮层（保留调色板图标与"图标"文案，便于迁移习惯）；悬浮层保存语义与旧弹窗一致（`kb-icon` 默认回来源默认、背景回默认青绿）。
6. **数据契约不变**：50 图标/10 色卡白名单、icon/iconColor 成对保存、null=清空回默认，均沿用 CR-051；本设计不新增资产。

## 3. UI-SCROLL-001 义务

采用 [UI-CR049-v1](UI-CR049-滚动条按需显示.md) 与 [CR-049](../../PRD/CR-049-滚动条仅在滚动时显示.md)，700ms 停止隐藏、悬停不唤醒、不改宽度。本次受影响滚动区域：**图标悬浮层正文区**（`.icon-pop-b`，`overflow-y:auto`，共享 scrollbar 机制自动接管）；侧栏本体（`.nc-sidebar` overflow-y:auto）保持既有行为。设计侧自检未含动态滚动帧；软件实现验证时须补滚动三帧证据或如实登记未验证。
