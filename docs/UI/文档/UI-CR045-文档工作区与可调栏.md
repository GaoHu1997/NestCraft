## 2. 全栏登记（固定rail不是内容栏）

- 管理首页主菜单224（176–320）；详情按CR-044隐藏，禁止重新显示。
- 项目需求树320/目录240；设计目录240（160–360）；编码文件/Git260（180–480）；任务树320/详情360。
- 知识树260/目录220；服务器树248（180–480）/监控300（220–440）；Office文件260（180–480）/PPT缩略图124（96–220）；设置分类224（176–320）；AI372（320–620）/历史浮层296（240–420）。
- 其他模型供应商选择列112也为适用左右列：可调96–180，模型主区最少160；普通全宽卡片、表格列、上下分页、固定极窄功能轨道不属于内容侧栏。
- 宽度按对象/页面/栏记忆，仅在当前会话；不引入额外数据库迁移。容器变窄优先保证正文最小可用区；显示不下时用已有/明确新增的栏开关收起，窄屏覆盖栏不参与水平抢空间，不可拖动整页出屏。拖宽不关闭文件、不清草稿、不重连服务器或重新发送AI。

## 3. 实现与设计边界

- 设计新建/上传只修改合成内存夹具，无真实文件/网络/凭据；草稿和上传演示明确仿真。不让新夹具覆盖用户现有快照，缺字段增量默认不替换inventory。
- 正式知识写入仅用户显式创建/保存/上传；AI项目grant保持只读复检。允许上传原件不意味着任意格式已正文索引/Office编辑。
- 设计侧改变先更新此规范与可视资源；软件不得共享动态样式把设计随实现漂移。采用版本在锁版清单和Story记录。
- 对照计划：同样例、主题、视口及动作；SC01三弹层/SC02多Tab/SC03全量/SC04草稿预览/SC06创建及错误/SC08全类拖宽分别记录设计及软件截图。几何/DOM只辅助，无法目视则记未验证。
