## 布局

三栏：左 250px 文件树（文件夹 + 笔记 + 附件，附件带类型徽标）／中正文（标题、路径、阅读·编辑切换、重命名）／右 300px 面板（大纲 / 反向链接 / 未解析 三个页签）。1080px 以下文件树变抽屉，760px 以下右侧面板也变抽屉，均可用顶部按钮开、Escape 关。

刻意与 Obsidian 对齐的点：**库=本地文件夹**（标题旁标注「本地文件夹」）、文件即真相（页面不出现"在线文档"字样）、附件说明固定为「保存到你上传时所在的目录」。

## 视觉规则

| 元素 | 规则 |
| --- | --- |
| 已解析链接 | 主色实线下划线，可点击跳转 |
| 未解析链接 | 危险色虚线下划线，点击弹「新建笔记？」 |
| 歧义链接 | 警示色虚线下划线，点击弹候选（≥2），不自动选 |
| 悬停预览 | 描边卡片，显示目标路径 + 摘要；不预加载全文、不联网 |
| 反向链接条目 | 标题 + 路径 + 一行片段，可点击打开 |
| 空态 | 空库：「这个库还是空的」；无反链：「还没有笔记引用它」；统一左对齐、不居中大图 |
| 重命名 | 二次确认对话框，先给「N 个文件 / M 处链接」清单，并说明歧义链接不会被改 |
