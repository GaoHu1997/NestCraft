## 视觉基准

浅色白/浅灰面，细灰边线、蓝色选中/强调、灰次级文字、轻浮层阴影；头部不使用独立黑底。深色由同一令牌主题整体适配，不把黑色参考图当默认皮肤。400～440px侧栏、1440×900/1920×1080桌面、390×844窄屏、100%缩放。菜单文字13px左右、标题14px；不把宽图缩成小字。

头部：左30px历史线性图标；中「N个子智能体⌄」；右新建、关闭。删除左侧品牌/AI会话标题与常驻项目名、会话ID信息，scope只留可访问说明/状态里。消息主体可滚，输入与任务/目标/统计在底部，所有关键操作有aria名称。

底部从上到下：任务摘要圆角条 → 当前目标圆角条 → 大圆角输入框（引用chip/输入正文/框内控制行） → 三个统计入口。控制行左+、CLI Logo、权限图标及名称、项目分支；右供应商·模型·思考档位、蓝圆发送/停止。400px允许两行对齐，模型信息单一触发器，不另放一个孤立思考按钮破坏图例。

### 历史和子智能体浮层定位

历史不是输入框上的菜单：桌面以侧栏边界定位，右边缘贴AI侧栏左边，top/height对齐侧栏，不占布局、不把主区挤小；视口不足时缩小宽度或回落视口内全高抽屉，仍可关闭与切换。绿色/红色/黄色点在未读行最末，已读点隐藏；状态文字不能只依赖颜色。切换/new只换查看会话，旧本机任务回调继续；看过后置readRevision=eventRevision，后台新事件才重新标未读。

子任务必须保存独立任务总结taskName；样例使用“核对权限与CLI支持矩阵”“补全用量归因与统计”“检查窄屏浮层交互”等，不用“用户消息前20字”。耗时由开始/结束或当前演示时钟计算，token来自所属请求；不把未知显示0。点击查看完整任务名、状态、输出和来源。

### 统计详情

会话浮层：标题/轮与步骤，分隔线，请求次数（含后代且requestId去重）、模型用时、工具用时、平均TTFT、TPS。Token浮层：总量、缓存命中、未缓存输入、缓存读取、缓存写入、输出。上下文浮层：已用比例、used/limit、按系统/工具定义/对话分段进度条与分项。数字以单一UsageRequestLedger聚合；演示默认值明确标DEMO，未知场景各字段显示未知/—，不编真实账单。部分请求字段未知时加和指标显示“已知≥X，部分未知”或—，并显示coverage；混合来源显示“混合来源”而非实测。TTFT与TPS标有效样本覆盖，TPS只用output和generationMs同时已知的同一请求子集；不完整上下文不画完整比例。具体公式以[数据契约](../../LLD/LLD-CR019-AI会话与权限设计契约.md)为准。

修订r2补充：已读只在侧栏可见且本次目标会话消息已展示后更新；关闭、后台事件或仅展开历史列表不清未读。模型滑杆的UI标签必须有CLI+版本+模型的原生映射，未知映射显示不可用/拒绝发送，不能只改标签。权限plan/agent若原生内置工具限制/沙箱尚未验证，显示禁用原因及DEMO修复入口；外层Tool开关不是原生Bash/工具能力验证。有效场景需要明确载入“限制已验证的DEMO”，不默认宣称当前宿主已验证。

### 模型与CLI

恢复STORY024已授权供应商/模型两栏，不能用三行列表和不可点“思考”代替。选择模型后保持打开，可继续滑动档位；只有模型声明的档位可选（示例Low/Medium/High/Xhigh/Max只是配置样例，原生effort映射也要有），无档位显示默认。供应商/模型失效保留选择ID，禁止发送、不自动回落。切CLI与切模型不同：非空换CLI确认新建，原会话不被改写；运行/待审批不可原地改。

SDK同源要求：CLI菜单底部SDK入口和工作台原“设置→SDK”必须展示同一SdkCatalogue的installed/enabled样例状态，不能一处说Grok已安装、另一处不显示。原Task执行器配置/Runtime不是安装事实，需在设计投影中区分。可在SDK主入口补当前会话库存的明确DEMO状态投影/控件，与会话菜单共享源；不修改原项目任务状态机、不把状态checkbox当真实安装器，也不据此关闭CR020的完整SDK管理补稿缺口。

### 权限

恢复参考图的图标/标题/说明结构，但不照抄错误等价。五个产品模式需按具体CLI生成对应参数；未核实或宿主不能执行的模式禁用并说明，不因已安装CLI就全可选。点击有效项要更新permissionId/revision，显示生成的LaunchSpec与边界；危险模式二次确认，隔离不成立时禁用；不是只变名字。正式CLI版本/审批/OS边界未实测，本稿只模拟配置生成与拒绝，不能出现“权限已应用到真实CLI”。

## 可操作评审入口与设计覆盖

统一稿提供明显标DEMO的“载入完整会话场景”，覆盖全部7项而非只靠读文字；另有空会话/失败等待/未知用量/无模型/SDK未安装/权限不兼容场景。初始空会话不伪造真实任务、目标、子代理或tokens，样例需显式载入。

新任务/目标CRUD、历史切换、子任务查看、三统计、模型搜索/供应商/滑杆、CLI过滤/确认与权限配置都必须有实际设计交互；主流程不能仅toast。错误/危险确认保留输入，Esc可撤销；模态打开关闭本侧栏浮层。列表与资料不复制业务需求源，原执行配置源与AI演示数据按契约分开。

## 修订r3可观察状态

- 子任务仍进行/待处理/未确认停止时，父即使没有自身请求也属于busy，CLI/模型/权限控件锁定并解释原因；历史/新建/统计仍可用。提供明确完成/停止子任务DEMO或已完成场景用于查看可配置状态，停止不假算成功、不改变其它会话/项目Run。
- 版本证据过期或未知CLI：权限行禁用并说明需要重新核验；预览不再生成错误参数。Claude工具限制说明是--tools内置集合及未授权MCP拒绝，--allowedTools不能独自叫限制白名单；full说明逐CLI准确。
- 模型切换改变容量或计量版本时，上下文条显示新容量/未知待重估或明确上次模型，不能继续把旧922K当128K模型预算；累计token/消息不清。流式同ID补全后统计更新但请求次数不加，混合来源仍可见。

## 待用户处理的可操作闭环

C19-03/09中黄色未读会话和waiting场景必须在消息区显示对应的本机决策卡：完整问题/所需资料边界、确认继续、取消或拒绝操作。确认要记录decisionId/revision与用户答复，解除该本机等待并更新相应任务状态；取消/拒绝保留历史且不算任务成功。不能靠重载场景或偷偷清awaitingUser来表示已处理。查看已读与完成处理分开；看过黄色点消失不等于问题已解决。

这只是会话需求澄清/边界的DEMO交互，不是原生CLI工具审批传输，不授予权限；解除等待后仍须独立通过模型/权限/原生限制门禁才能发送。配置运行快照和原项目Task/Run保持不变。
