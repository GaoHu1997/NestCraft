- 授权：2026-11-19 用户要求调整需求和设计，并明确只指“项目类型为办公的”。新稿待评审，未授权正式软件修改。
- **唯一入口：[仿真原型UI](../仿真原型UI.html)** → 项目管理 → 办公 → 市场研究资料（PRJ-1018）／品牌与官网（PRJ-1009）。不能另造办公模式入口；Code及其它模块继承CR-036-v2。
- 当前状态：办公新增场景为“新设计待实现”。本轮仅验证原型；不宣称软件视觉一致。

## CR-043 局部替代

用户要求左树可建文件夹、AI与编码完全一致及公共风格／仿真样例。当前入口办公场景采用 [UI-CR043-v1](UI-CR043-办公文件树与统一侧栏.md)，取代下文左侧扁平分组和简化AI描述，其余草稿／审阅／导出边界继续继承。本页保留CR-038历史设计说明与证据，不作为并列入口。

## 1. 结构与继承

保留当前品牌、固定首页、项目窗口、页签44px贴顶、无重复页头、白蓝主题和单面1px分隔。work项目页签改为“文档／成果”，右端沿用AI开关；不显示研发需求树、任务队列或代码/Git。主体左资料、中正文、右AI，正文优先，额外来源／版本／导出用对话框或按需面板。

- 左：搜索／清空、来源和成果分组、文件类型与保存状态；空态提供添加资料，合成夹具须显式载入。
- 中：文件标签与格式对应操作，MD阅读编辑，DOCX白纸结构化正文，XLSX选格与公式条，PPT缩略图／页内容，PDF只读分页。
- 右：当前work项目的会话／来源选择／生成快捷入口／可折叠执行步骤／提案审阅，不复用预约服务代码会话。沿用栏宽与开关视觉，不复制全局模型配置表单。
- 成果：已保存的同源文件列表、来源与版本、历史恢复为新草稿、导出检查；不能把模拟状态当已生成真实二进制。
- 草稿：接受建议只入缓冲，保存后才是成果。来源只读，复制后可改。关闭未保存需决定；刷新内存丢失须提示。

## 3. 视觉、键盘与响应式规范

- 沿用已有tokens，不引入新品牌/渐变/动画；主操作蓝色，正文与表格白纸在深色仍保持足够对比。控件与说明文字不要靠颜色独自表达状态。
- 1440×900与1280×800：文档与AI各自滚动，来源和正文不挤成多余第四栏；左栏约220px，AI沿用现有可拖动宽度。
- 390×844：文件列表以切换面板/抽屉进入，正文与AI一次展示一个主面，不能仅隐藏AI使其不可用；宽表格在容器内滚动。
- 原生button、input、select、dialog；icon-only有aria-label；label关联输入；可见focus；保存Ctrl+S只在work内处理，不劫持code；Esc关闭弹窗不接受变更；关闭有草稿确认；错误显示在动作区域而不是只有toast。
- 导出成功标志不能出现于无引擎状态；候选、已接受草稿、已保存成果、导出检查通过四种文案不能混写。
