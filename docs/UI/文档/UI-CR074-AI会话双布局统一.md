## 1. 视觉与交互基准

| 部位 | 预期基准 |
| --- | --- |
| 双布局 | 同一消息／composer／history／统计与动作；工作台历史常驻、侧栏历史浮层是外壳差异。工作台弹层就地贴其真实按钮，不另开不可见 AI 面板承载 |
| 输入区 | 取消 textarea 聚焦内层描边及额外阴影；外层结构边界不因聚焦变成蓝框。保留可见输入光标、原生编辑与键盘可操作焦点，不全局清除其他控件焦点指示 |
| 工作中 | 标识14×14px，文字近同高、紧凑间距；工作状态位于当前消息流末尾，耗时与终态继承现行规则；失败 fallback 与减弱动画不得扩大占位 |
| 右侧工具组 | 模型＋发送保持一组、组内6px间距；模型为“供应商名称 · 模型名称 思考等级”及收展箭头。长名称省略但可读完整名称，档位与发送不挤丢；窄栏换行仍不拆组 |
| 模型弹层 | 浅色图1风格：圆角16px、轻分隔、搜索浅底、左供应商／候选数、右模型；选中用淡主色底与主色文字。内部设计参考424×450px，受视口限制，不以参考图片裁切尺寸作为固定全屏尺寸 |
| 模型能力 | 上下文数值文本（K/M、未知—），视觉用眼睛、思考用四芒星；按上下文／视觉／思考排序。支持／不支持以强调度与可读说明表达，不改为灯泡或仪表图标 |
| 思考档位 | 底部滑杆＋可点击可读标签、当前档位主色。该模型支持子集按语义低到高，图1为Off／Low／Medium／High；已知扩展序为Off／Minimal／Low／Medium／High／XHigh／Max，不新增未声明档位 |
| 统计条 | 相对输入框水平居中，三组依次为仪表＋“轮 步 · tok/s”、数据库＋“M/K tok · 缓存命中 %”、动态圆环＋百分比；保留详情入口。图2仅格式示例，真实未知为—，不写假数字 |
| 历史菜单 | 同一菜单与五项现行操作；外点／Escape／历史列表实际滚动收起，只收起菜单，不吞目标点击、不抢搜索焦点；菜单项点击不误触会话行 |
| 搜索 | 原始输入与查询文本分离；IME中不替换输入节点或查询中间词，结束后查询最终文字；局部更新结果，保留光标／选区，不强制移到末尾。250ms防抖沿用可逆默认值，不是用户指定时长 |

无供应商、无可用模型、当前值失效与运行锁定不得用正常三行模型列表冒充。供应商浏览不自动提交模型；选模型不关闭弹层，方便继续选择思考等级；过滤、生图排除和失效不回落规则继承。

## 4. UI-SCROLL-001与验证边界

显式采用[UI-CR049-v1](UI-CR049-滚动条按需显示.md)及[CR-049](../../PRD/CR-049-滚动条仅在滚动时显示.md)：消息、历史、模型供应商／候选和textarea默认透明；实际滚动仅目标容器显示，连续滚动重置最后滚动后700ms隐藏，hover／focus不唤醒。原生滚动、固定占位与正文宽度不变；不以`overflow:hidden`、切换滚动宽度或重绘丢失编辑来隐藏。动态挂载、嵌套与光标／选区保持均需证据。

主代理逐SC补实际浏览器操作、截图或动态序列、版本／hash、失败与未验证项，再同步总览。设计自身验证不能替代正式软件的同条件成对视觉／动态对照。**本子任务未运行浏览器、未修改软件、未执行软件测试或对照；不得登记视觉通过或软件已统一。** 步数真实口径依Q-CR074-01待确认；正式开发准入还需本范围明确编码授权与完整状态证据。
