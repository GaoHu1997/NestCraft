## 布局与交互基准

- 子菜单严格 **PRD → UI → 方案 → 数据库设计**，默认PRD；位于原设计区，不挪外层需求/设计/任务/编码。选中蓝色底边；支持Tab/方向键/Home/End；不在Tab展示数量。
- 主区内部布局`minmax(0,1fr) + 224px`右菜单，16px间隔；AI由原外层400px（1100视口380px）占位，不把文档/模型菜单塞入AI。主区≤720px时收起菜单，在主区内开合，Escape关闭；原窄屏AI顺序回落保持。
- Markdown白蓝/深色主题沿用冻结令牌，正文22px/30px内边距、标题/章节分层，窄主区18px；读默认不显示源码编辑框。右菜单有名称、简短摘要、选中状态、未保存标记和当前文档章节。
- UI为当前项目可操作入口，不先放文件卡或iframe递归嵌当前工作台。夹具明确标合成预约项目页面，不冒充本仓库/个人/生产样例；所有请求和预约为离线仿真。
- 数据库模型标`model://project/id`和修订，一模型一菜单；模型存库为未来数据方案，当前只本机aux。保存不执行SQL，不改供应商模型配置。
- 真实保存失败保留表名和字段完整草稿；dirty即时更新不逐键整页重建。确认放弃失败明确“本页生效、快照可能恢复旧草稿”。
- 索引/按需读不向AI发送；人类全篇阅读也不自动注入上下文。未保存草稿不可被read读取，源r2与静态r1夹具摘要不同步时显式stale-fixture。
