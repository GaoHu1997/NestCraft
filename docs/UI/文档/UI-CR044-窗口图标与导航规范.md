# UI-CR044-v1：窗口、品牌、图标与导航统一规范

- 需求：[CR-044](../../PRD/CR-044-窗口融合图标与Tab导航.md)；复用 STORY-061／064／FEAT-001。
- 工作层级：先可视设计再正式实现；用户本轮明确授权两层工作。历史 CR-033／036／品牌-v2 的被替代部分保留追溯。
- 唯一业务原型：[仿真原型UI](../仿真原型UI.html)。图标样例仅在 [UI规范资料](UI-ICON-001-图标样例.html)，不加入平台顶部、菜单、设置或业务原型；平台只替换现有不合适图标。
- 状态：三份独立评审3:0接受；可操作原型已制作并实际打开、32项资源锁版，正式软件随后采用同一图标／品牌资源和导航／窗口规格；本轮未用户验收，完整视觉及原生操作边界见REPORT-CR044。窗口控制融合为56px顶栏，不叠32＋56双标题栏；对象状态隔离与关闭保护、官方资产来源、最小原生权限和实际最大化状态同步是执行条件。

## 1. 外壳与导航

顶栏56px，背景 `--surface`，底边1px `--line`，软件名称只显示一次；左侧透明帆船24px＋独立“栖造／NESTCRAFT”。右側窗口最小化／最大化（还原）／关闭三按钮46×32px，使用公共图标12～16px；普通hover `--surface-3`，关闭hover `--danger`＋白色图标。品牌、上下文与窗口操作垂直中心对齐。中部空白区可拖动，按钮／输入／标签不参与拖动。最小化状态、实际最大化状态、拖动、键盘焦点与错误反馈均需覆盖。

Tab栏在顶栏下，40px整宽，从左边缘开始；“首页”固定第一项不可关闭，之后只列项目／知识库／服务器对象。不把工作台／项目列表／知识库列表／服务器列表分别注册Tab。管理页面显示主菜单＋右内容；详情隐藏主菜单，内部资料／文件／主机树保留。再次打开同类型同ID只聚焦，显式定位才更新内部位置。首页恢复原管理表面，切换不清草稿和会话。

## 2. 品牌与图标

- 界面帆船：原透明PNG，无框、无填充底、无阴影；图形不重绘，不加入文字。
- 系统图标：独立薄荷底、圆角承载的PNG／ICO，用于快捷方式与任务栏；不得影响界面Logo透明规则。
- UI-ICON-001-v1：24px viewBox／1.6px round stroke；14／16／20显示尺寸，默认图标按钮32／紧凑28，文字按钮32／28，图标文字gap6。
- 所有平台图标采用同一命名／资源版本：首页、文件目录与格式、Git、AI与能力、状态、编辑与布局、设置、窗口操作；缺失图标必须明确检测，不以任意图标替代语义。
- 官方CLI品牌图形按资源来源原样采用，尺寸16／20／24；来源与许可仅登记在UI规范资料和资源NOTICE中。平台不增加图标展示功能；没有可信资产的项标未就绪，不用字母占位。

## 3. 对齐与组件示例

空间阶梯4／8／12／16；顶栏横向padding20（窄屏12）；Tab内边距12。主菜单224px，仅管理显示。所有1px分割线同级连续；图标与文案中心线一致，文件树30px行中图标14px。组件弹层右对齐触发、内部滚动；浮层不压缩主内容。

设置1040×700；确认460；常规620；预检760；大文档820；视口左右至少12、上下24。仅最顶层处理Escape；不把浏览器模拟关闭当真实桌面窗口测试。
