## 1. 设计目标

1. 「图标 + 背景色」是项目／知识库的完整标识，不再用字母块或同一个书本图形。
2. 图标库覆盖真实项目类型：办公、商业、内容、产品、生活，不只服务编码项目。
3. 知识库树用图形区分文件夹与 14 类文件，颜色只作辅助。
4. 头像默认 B（品牌帆船），可切换 5 种风格，也可上传自己的图片。
5. 全部沿用 UI-ICON-001 的 24×24、1.6px、`currentColor` 语言，新增令牌不另起视觉体系。

## 4. 知识库标识

- 图标砖：40×40，圆角 10，图标 20×20；行结构与现有列表一致。
- 图标库：与项目共用同一套 **50 个**（6 组），可任意选择；不再单独限制 16 个。
- 来源默认：本地目录（`managed-directory`）`bookOpen` + 青绿；连接器／网页（`connector`）`globe` + 青绿；组合 `layers`；未标注 `library` + 青绿。
- 允许同一图标用于多个库；图标不是唯一身份，名称与授权标签仍是主信息。
- 未授权库图标正常显示：图标不表达权限；「进入」可用，「管理授权」按角色限制。

## 5. 文件树图标

### 5.1 结构

- 文件夹行：展开箭头（12px，仅表示展开状态）+ `folderOpen`／`folder`（16px，琥珀色）+ 名称 + 文件数；行高 30px。
- 文件行：16px 类型图标 + 名称（12px）+ 类型小字（9.5px 大写扩展名）；行高 ≥36px；悬停显示行尾「更多」。

### 6.1 图形、默认与尺寸

### 6.3 更换头像弹窗

入口统一为「头像框悬停出现编辑角标 → 点击打开弹窗」，不再把上传按钮平铺在设置页。

| 区域 | 内容 |
| 尺寸 | **固定 680×660**，切换内置／自定义、选图、报错都不改变弹窗大小；窄屏受 `max-width/height` 限制，内部滚动 |
| --- | --- |
| 弹窗标题 | 「更换头像」+ 一句说明；右上角关闭，支持 Esc 与点击遮罩关闭 |
| 左侧预览 | 96px 头像实时预览（按当前选择显示 Logo 或照片）+ 当前样式名称 + 「应用后同步顶栏、侧栏与设置」 |
| 内置头像 | 6 格：A～E 五种品牌样式，**最后一格为「自定义」**（虚线 + 相机图标） |
| 自定义 | 点击后打开系统文件选择；格式 PNG／JPG／WebP、≤200KB、建议 ≥256×256 |
| 裁剪预览（常驻） | 取景框**始终显示**：内置样式下框内显示 Logo、滑块禁用并提示无需裁剪；自定义选图后框内显示照片，可拖动摆放、缩放 100–300%、重新选择、文件名与大小；**已有头像重新打开时同样可调** |
| 报错 | 格式／超过 200KB／读取失败都在弹窗内以红色提示呈现，保留原头像与已选样式 |
| 实时预览 | 左侧 96px 预览与取景框同步（canvas 重绘），拖动或缩放时即时更新 |
| 底部 | 恢复默认 Logo｜取消｜应用；应用后同步三处，取消不改已保存值 |

状态：默认 B 选中；选择内置样式即预览；选择自定义但未选图时提示选择；已选图后切换内置样式会清除待应用照片（需重新选择）；恢复默认回到 B Logo；裁剪框形状随样式（圆形／10px 方砖），取景框内即最终结果。

图片仅本机读取，预览与裁剪在内存完成；不上传网络、不进入知识库／会话／审计。弹窗不锁定页面滚动（遵守 UI-SCROLL-001），只锁定焦点与遮罩。

## 8. 交互与状态

- 图标选择器：6 组折叠式分组，按钮 `aria-pressed` 表示当前项；点击立即预览，保存才生效。
- 色卡：按钮组，选中环 + `aria-pressed`；选择后图标砖即时变化；深色切换时按同一色卡取深色值。
- 头像风格：`radiogroup`／`radio`，点击或 Enter/Space 选中；焦点环 3px。
- 上传：原生文件选择器；失败显示 `role="alert"` 文案并保留原头像。
- 树折叠：箭头切换 `aria-expanded` 与 `folder`／`folderOpen`；不改变文件选择。
- 回退：图标缺失 → `file`；项目图标缺失 → 字母块；色卡缺失 → 默认蓝；不得显示空白砖。

## 9. 数据结论与实现边界

- 新增可选字段：`project.icon`、`project.icon_color`、`knowledge_library.icon`、`knowledge_library.icon_color`、`user_settings.avatar_style`（默认 `b`）、`user_settings.avatar_image`（本机引用 + hash）。
- 复用既有：`project.type`、`knowledge_library.sourceKind`、`setting_default`；不新增来源枚举。
- 旧数据保持原样、**不做批量映射**：旧项目沿用现有 tone 图标砖显示，旧知识库沿用现有图标；只有用户手动改图标或色卡后才写入新组合。
- 文件类型图标不持久化，映射表随程序版本发布。
- **工程约束**：既有 `icon()` 以 `<use href="./icon-sprite.svg#id">` 引用外部 sprite，`file://` 打开时会整片不可见（现状截图已证实）。实现时必须内联 sprite 或构建期注入，或提供可见回退。
- 正式实现需更新 [DB-FEAT-001](../../DB/DB-FEAT-001-知识授权与工作台数据设计.md) 并执行迁移与旧数据验证；本轮不建表、不改代码。
