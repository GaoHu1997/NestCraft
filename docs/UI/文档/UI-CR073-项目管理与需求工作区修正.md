## 1. 设计基准与继承

1. **图标悬浮层（第 1 项）**：以触发图标砖为锚点定位。默认出现在锚点下方 8px、左缘对齐（`data-side="below"`）；下方空间不足且上方更大时翻转（`above`）；左右夹紧 12px 视口边距；**整体最大高度 420px**（视口不足按 `calc(100dvh - 80px)`），超出内容在 `.icon-pop-b` 内滚动。遮罩改为**透明命中层**（不再变暗整屏）。窄屏 < 520px 退化为底部弹层（左右 12px、`max-height: min(420px, 70dvh)`）。10 色卡 + 清空项、50 图标 6 组 + 默认项、保存/取消/ESC/点外部语义全部沿用 UI-CR070。
2. **图标在编辑弹窗内可用**：编辑项目弹窗的名称行改为「图标砖 + 名称输入框」同一行；图标砖可点击打开**同一悬浮层**（挂在 `<dialog>` 内，避免被 top layer 遮挡），保存后弹窗重绘并保留其它未保存字段。新建项目时图标砖为只读类型默认，附「创建后可修改图标」提示。
3. **移除成员（第 4 项）**：新建/编辑项目弹窗不再有「成员」字段；保存逻辑不再读写 `members`。
4. **负责人／描述（第 3 项）**：两字段为可填写控件，占位提示为「填写负责人」「一句话说明项目目标」，**不出现「未接入存储」**。存储由 CR-072 承接。
5. **窗口页签省略（第 5 项）**：`.wtab-focus` 由居中改为起点对齐并 `overflow:hidden`；标题 `.ellipsis` 单行省略；页签最大宽 230px、高度 26px 不变；关闭按钮固定宽不被压缩；完整名称仍在 `title` 与「全部窗口」下拉中。
6. **需求工作区结构（第 6 项）**：新增 `.req-main` 容器，内部纵向为 `.req-topbar`（页签条 + 工具栏）与 `.req-body`（正文 + 目录）。页签条位于 `.req-main` 内，因此**横跨正文与目录两列、不覆盖左侧需求树**；需求树保持整列高度。「本页目录／全文目录」标题行整体位于页签区之下。三种阅读方式（文档／全文／导图）结构一致。
7. **需求树与目录导航（第 8 项）**：左轨只保留「文档／全文／导图」三个阅读方式；需求树、目录开关移到各自面板标题行右侧；需求树标题行顺序为「刷新 → 新增 Epic → 隐藏需求树」；面板隐藏后，工具栏右侧出现「需求树／目录」恢复按钮；两处底部说明文字、原底部刷新按钮全部删除。
8. **导图交互（第 7 项）**：画布默认抓手光标；空白处按下拖动即平移（4px 阈值内视为点击，平移后抑制一次点击防止误选）；`Ctrl／⌘ + 滚轮`以指针为锚点在 50%～180% 缩放（步进 10%），不按修饰键保持纵向滚动；工具栏补「空白处拖动平移 · Ctrl+滚轮缩放」说明。
9. **导图右侧编辑面板**：点击节点后右侧为**编辑表单**（标题、状态、负责人、摘要、工作量、最近更新只读、Story/Bug 的验收条目、正文 Markdown），底部「保存／取消」+「文档」跳转；模型节点保持只读。
10. **新建下级复用面板**：节点「＋」不再弹窗；画布出现虚线占位节点（带「未保存」标记），右侧切换为新建表单（含 Story 的验收条目）；保存按现有编号规则落库并选中新节点，取消移除占位、不产生文件。
11. **设计页 HTML 预览（第 9 项）**：`.html` 设计文件以**沙箱 iframe**（`sandbox` 为空属性 = 最严格，不执行脚本、不同源、不提交表单）渲染页面；顶部「预览 / 源码」切换；预览下方说明「不执行脚本、不加载外部资源；相对路径资源不显示」。`.md` 保持所见即所得编辑。
12. **设计页左轨（第 10 项）**：只保留 PRD／UI／方案／数据库四个分区入口；「关联」「目录」按钮删除；目录显隐移到顶部文档操作区（带 `aria-pressed`）；UI 分区内用顶部文件下拉在说明文档与 HTML 原型之间切换。

## 3. UI-SCROLL-001 义务

采用 [UI-CR049-v1](UI-CR049-滚动条按需显示.md) 与 [CR-049](../../PRD/CR-049-滚动条仅在滚动时显示.md)：滚动条仅实际滚动时显示，停止 700ms 后隐藏，悬停／聚焦不唤醒，不加宽不引发布局跳动。

本次受影响滚动区域：

| 区域 | 选择器 | 变化 |
| --- | --- | --- |
| 图标悬浮层正文 | `.icon-pop-b` | 新增限高 420px 后成为实际滚动容器（此前按视口高度滚动） |
| 需求树 | `.req-tree-scroll` | 结构未变，父级容器改为 `.req-main` 之外，滚动行为不变 |
| 目录 | `.req-toc-list` | 父级从 `.req-workspace` 移入 `.req-body`；高度减少页签区高度 |
| 导图目录 | `.req-map-outline` | 同上 |
| 导图编辑面板 | `.req-map-detail-scroll` | 由只读详情改为表单，内容更长，滚动更频繁 |
| 设计预览容器 | `.design-preview-host` / iframe | 预览本身由 iframe 内部滚动，外层不新增常显条 |

设计侧已执行四类容器滚动条动态三帧（需求树、目录、悬浮层正文、导图编辑面板）：初始无条 → 滚动出现 → 停止 700ms 后隐藏，`clientWidth` 全程不变，悬停不唤醒。**嵌套隔离（悬浮层与页面同时滚动）与反 `--hide-scrollbars` 校验未做**，软件实现阶段须补。
