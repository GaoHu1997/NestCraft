## 1. 视觉与交互基准（开发必读）

| 状态 | 滑块／轨道 | 时间与触发 |
| --- | --- | --- |
| 初始／静止 | 滑块、轨道及角落透明，原生滚动占位不变 | 初始无活动class |
| 实际滚动 | 滑块使用主题`--muted-2`，轨道透明 | 实际位置变化触发scroll；仅目标容器显示 |
| 连续滚动 | 保持显示 | 每次scroll重置700ms停止计时 |
| 停止滚动 | 滑块恢复透明 | 最后scroll后700ms；不要求额外动画 |
| 静止悬停／聚焦 | 不显示 | hover／focus不是唤醒条件 |
| 活动滑块悬停 | 滑块`--muted` | 仍按最后scroll计时，不无限延长 |
| 无溢出／空内容 | 无需滑块 | 不制造overflow或占位 |

700ms是代理采用的可逆默认值，并非用户指定。标准样式保持`scrollbar-width:thin`；WebKit保留10px轨道、3px透明内边、8px圆角。标准`scrollbar-color`与WebKit表现依浏览器支持，不承诺轨道实际像素相同；禁止通过切换宽度或display实现显隐。浅色活动色`#a4abb5`，深色`#7d8794`，悬停分别`#86909c`／`#9aa3ae`。
