设置“SDK管理”原地改“智能体管理”；内部只有2个下划线tab（CLI管理/SDK管理），保留原设置壳。参考卡宽约880px上限，卡堆间距10px、12px圆角、浅灰面、细边。行头左右14pxpadding，Logo30px/9px圆角；名称13px粗、次摘要11.5～12px，折叠箭头与32×18开关独立于button。内置行始终启用锁开关、内置/默认回退标记、无安装器；不声称已接入真实DSH宿主。

外CLI展开16pxpadding、组22px间距、模型左思考右≥240px列；窄屏自动单列。顺序：模型→独立最低任务难度→任务类型卡→权限。输入13px/8px圆角/6×10padding。类型卡4×10padding、8px圆角，只选中底/边蓝，不加复选勾。原13个四字类型：仓库探索/代码定位/资料检索/方案核验/影响分析/功能开发/缺陷修复/测试验证/代码审查/数据处理/模块重构/方案设计/文档整理。每类型唯一归属，四级难度独立；沿用主代理模型时思考默认不可选未声明档位。权限存子任务默认意图、按原生能力与前置解释，不改现会话，不仅换标签、不实际调用CLI。
