## 1. 设计目标

五项调整服务于同一个空间原则：**临时内容浮动在触发它的控件附近，稳定内容不因临时浮层改变尺寸**。

- 顶部计数与历史：浮层覆盖，不推挤布局。
- 模型能力：一行三列固定顺序，支持与不支持都可比较。
- 统计：贴着各自控件出现，并用位置明确「谁打开了它」。
- 步骤：在会话流内成为一个可折叠的等宽卡片，状态而不是动画承担主要表达。

## 3. 规格

### 3.1 历史浮层

| 项 | 规格 |
| --- | --- |
| 定位 | `position:absolute; top:0; bottom:0; right:100%`（相对 `.ai-panel`），右缘与侧栏左缘重合 |
| 尺寸 | 桌面宽 296px，与侧栏同高；窄屏 `position:fixed` 全宽抽屉，从顶栏下到视口底 |
| 容器 | `--surface` 底、1px `--line` 边、左侧圆角 8px、向左的浮层阴影；深色沿用令牌 |
| 头部 | 高约 42px：历史图标＋「会话历史」＋总数＋关闭按钮 |
| 行 | 状态点 7px、标题 12px 单行省略、元信息 10.5px；状态文字右对齐且完整，不用颜色代替文字 |
| 选中 | 浅蓝底＋主色边，当前会话同时有 `aria-current` |
| 交互 | 外点、Escape、关闭按钮、切换/新建会话均收起；浮层内点击不收起 |

### 3.2 顶部下拉

| 项 | 规格 |
| --- | --- |
| 触发 | 紧凑按钮，含图标、数量、名称与向下箭头；展开时按钮浅灰底并 `aria-expanded=true` |
| 定位 | `top:calc(100% + 6px)`；子智能体左对齐、后台任务右对齐；宽度 `min(330px, 100vw - 24px)` |
| 容器 | 白底、1px 边、8px 圆角、`--shadow-pop`、最大高 `min(460px, 100vh - 150px)`，列表内部滚动 |
| 后台行 | 状态点 6px（运行蓝／成功绿／失败红）、命令 11px、元信息 10px；展开区等宽 `pre`，最大高 150px |
| 分组 | 组头显示「进行中 n」「已结束 n」，已结束组右「清空已结束」；空组显示说明 |
| 互斥 | 与另一顶部下拉、底部模型/权限/CLI/统计浮层、`@`/`/` 菜单互斥 |

### 3.3 模型能力

| 项 | 规格 |
| --- | --- |
| 行结构 | 名称弹性省略；右侧 `上下文（50px，右对齐）＋视觉（14px）＋思考（14px）` |
| 上下文 | 仪表图标＋数值（922K/1M/200K/32K）；未知 `—`，不推测 |
| 视觉/思考 | 支持 `--teal` / `--violet`，不支持透明度 0.26；两者都保留占位，保证三列对齐 |
| 无障碍 | 每项 `aria-label` 与 `title`，例如「视觉：不支持」；不用颜色作为唯一信号 |
| 过滤 | `image:true` 或模态含「生图」的模型不渲染；供应商计数用过滤后的数组长度 |
| 档位 | 当前模型不支持思考时，滑杆禁用并显示说明；触发器显示「无思考档位」；切回支持模型恢复有效档位 |

### 3.4 统计浮层

| 项 | 规格 |
| --- | --- |
| 入口位置 | 输入框下方、页脚上方，一行三个轻按钮；输入框内不再有统计 |
| 定位 | 每个按钮外包 `position:relative`，浮层 `right:0; bottom:calc(100% + 4px)`，即右缘对齐控件右缘、下缘贴住控件上缘 |
| 尺寸 | 宽 296px，`max-width: calc(100vw - 20px)`；向上展开 |
| 箭头 | 底部右侧 8px 小箭头指向触发控件；窄屏隐藏 |
| 互斥 | 同时只开一个；再点同一入口、外点或 Escape 关闭 |
| 窄屏 | `position:fixed; left:12px; right:12px; bottom:132px`，不超出视口 |

### 3.5 步骤折叠框

| 项 | 规格 |
| --- | --- |
| 位置 | 会话流末尾、输入框上方；随消息区滚动；宽 100%（与消息区一致），左右 14px 内边距由消息区提供 |
| 容器 | 1px `--line`、8px 圆角、轻阴影；头部 `--surface-2` 底 |
| 头部 | 步骤图标、标题、进度 `done/total`、整体状态胶囊（进行中／已完成／有失败／等待继续）、折叠箭头 |
| 步骤行 | `--mono` 10.8px；左 2px 状态条；已完成绿勾、执行中蓝色旋转环与浅蓝底、未开始灰时钟、失败红色警示与浅红底 |
| 状态文字 | 已完成「已完成 · 耗时」；执行中「执行中」；未开始「未开始」；失败「失败 · 退出码」 |
| 折叠 | 收起后保留头部与计数；展开状态在本次会话内保持 |
| 演示边界 | 底部标注「合成演示 · 不调用真实模型」；「推进演示」只推进本会话步骤 |

## 6. 正式软件实现注记（2026-11-20，编码授权批）

用户于 2026-11-20 明确授权「据新需求设计开发调整」并完成 IPC 仿真测试。实现要点与设计对照：

- **历史浮层机制（评审 A/B/C 三人投票，2:1 多数决）**：采用设计稿原机制 `position:absolute; top:0; bottom:0; right:100%`（相对 `.chat-panel`），为此移除正式软件 `.chat-panel` 的 `overflow:hidden` 并以注释锁定该约束（不得加 overflow/transform，否则浮层被裁剪）。视觉规格（296px、右缘贴侧栏左缘、同高、左侧圆角、向左阴影、窄屏 fixed 全宽抽屉）与 §3.1 逐项一致。
- 顶部下拉、模型三列能力、底部三统计右对齐浮层、步骤折叠框均按 §3 规格实现；子智能体/后台任务数据为会话级合成演示（脚注标注），「清空已结束」只清展示；步骤来源为本会话真实 toolUse/toolResult 事件（评审 C 条件：不伪造步骤；demo 会话才显示「推进演示」）。
- 思考能力判定（评审 C 修正口径）：以 efforts 中存在**有效下发拼写（非 null）**的档位判定"支持思考"，全 null 视为"未声明思考档位"。
- 实现文件：`src/modules/chat/`（ChatPanel/ModelPicker/MessageList/SessionHistory/StatsBar/StepsBox/sessionRuntime/chat.css）、`src/modules/editor/index.tsx`（定位行高亮）、`src/modules/locate.ts`（定位总线）。
