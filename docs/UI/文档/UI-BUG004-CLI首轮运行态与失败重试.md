## 1. 状态与文案

| 场景 | 标题 | 原因/说明 | 主按钮 |
| --- | --- | --- | --- |
| CLI 首轮运行中 | 不显示 | 顶部「运行中」指示；消息区显示工作中 | 无（可停止） |
| 首轮 create 失败 | 不显示 | 系统错误卡：本轮未开始、没有可续接上下文 | 无；直接重发 |
| 已有输出但无引用 | 上下文待确认重建 | 引用缺失（历史无原生绑定） | 确认重建… |
| 旧版本无 turn | 上下文待确认重建 | 尚无原生线程引用（首轮未完成或历史来自旧版本） | 确认重建… |
| 原生不可续接 | 原线程不可续接，已暂停发送 | 既有原因码 | 重建上下文… |

文案与 BUG-003 保持一致，不新增长解释；「运行中」不写绑定相关字样。

## 2. 覆盖核对

- 新增：运行中（无横幅、输入可用、运行指示）、首轮失败（错误卡、无重建入口、可重发）。
- 保留：BUG-003 的 A CLI 已续接、B 平台正常态、C 首轮未完成、D 已结算无引用。
- 边界：运行中调用确认重建应被拒绝（后端保护，界面不提供入口）；平台/执行会话不显示绑定横幅。

## 3. 滚动条（UI-SCROLL-001）

本变更只调整横幅显示条件与发送放行，不新增/改变滚动容器，侧栏消息区沿用既有按需显示实现。结论：**不适用**，依据为本轮无滚动区域改动。
