## 2. 场景覆盖

| 场景 | 关键状态 | 设计行为 |
|---|---|---|
| C56-01 输入与 `+` | 空、含草稿、含 chip、发送中 | `+` 菜单按引用/会话状态/能力分组；选择后回焦输入 |
| C56-02 `@` 引用 | 文件、会话、知识、无匹配、加载失败 | 光标附近浮层，键盘上下/Enter/Escape，结构化 chip |
| C56-03 `/` 能力 | Skill、MCP、Tool、无启用能力 | 命令候选带风险/来源，选中只写请求引用 |
| C56-04 目标/任务 | 无目标、进行中、暂停、取消、失败 | 输入上方独立条，编辑/暂停/恢复/删除带确认与 revision |
| C56-05 步骤 | 运行、完成、未开始、失败、等待用户、折叠 | 等宽卡片、done/total、来源、耗时/退出码 |
| C56-06 消息时间线 | 用户正文、AI 正文、reasoning、子代理、工具、系统、错误 | 用户消息右侧紧凑内容块并显示时间；主 AI 无头像/角色前缀；reasoning 独立折叠块并显示思考持续时长；子代理/工具/系统用内容块语义区分；正文完成后提供复制操作 |
| C56-06A 运行与重试 | 思考中、生成中、429、502/503/504、最终失败 | 运行中显示 logo 粒子打散重组 +「工作中…」+ 运行时长；重试状态显示原因/次数/等待时间；最终失败保留错误和草稿 |
| C56-07 CLI | 已安装、未安装、失效、运行锁定、非空切换 | 可用候选可选；非空切换新建确认；锁定说明原因 |
| C56-08 权限 | 可用、缺审批、缺隔离、版本过期、危险确认 | 每行显示语义和证据；不可用行说明缺口 |
| C56-09 模型 | 供应商、搜索、空匹配、生图过滤、无思考档位 | 两栏模型菜单固定三项能力；选择不关闭；档位同步 |
| C56-10 多 Agent | 子代理运行/完成/失败/未知/重复/迟到 | 稳定 ID 去重；展开详情；终结后迟到事件不复活 |

## 3. 组件规格

### 输入与浮层

- 输入区使用稳定 DOM 节点，草稿由父级保存，候选浮层通过 portal/绝对定位跟随触发按钮；浮层不抢占输入焦点。
- 候选键盘：ArrowUp/ArrowDown 循环，Enter 选择，Escape 清查询后再关闭；IME composition 期间不触发发送。
- `+` 菜单不显示不可操作的“假按钮”；暂未接入功能显示原因和配置入口。

### 消息时间线

- 用户消息使用右侧紧凑内容块和轻量时间行，不显示“我”角色前缀或头像。
- 主 AI 回复使用左侧无头像正文流，不显示“AI · CLI/模型”标题；来源信息不抢占正文视觉层级。
- 思考过程使用独立 reasoning block：折叠态显示「思考」+ 思考持续时长（`持续 N 秒`，时长未知时退回字数），展开后在块内滚动；流式中显示「思考中…」。
- 运行态指示器：logo 自身像素被打散成粒子，绕中心旋转后重组成 logo，背景透明、颜色取自 logo；右侧依次是「工作中…」与运行时长（`x 秒` / `x 分 x 秒` / `x 时 x 分 x 秒`）。
- 子代理、工具、系统/审批和错误使用独立内容块；子代理显示 taskName、状态、输出和稳定 ID；子代理未上报 CLI 时继承本轮 CLI，不显示「未知」。
- 正文完成且未在流式中，消息底部提供复制操作：默认淡出，鼠标进入或键盘聚焦时显示，复制后 1.2s 内显示「已复制」。

### CLI/权限/模型菜单

- CLI 菜单：Logo、名称、版本、安装/启用状态、能力证据；不可用项展示原因而非警告式空菜单。
- 权限菜单：`permissionId`、原生语义、所需能力、证据版本、当前选择；不可用项 disabled + reason。
- 模型菜单：供应商列显示过滤后数量；模型行末固定 `上下文 → 视觉 → 思考`；图像专用模型不渲染；搜索支持多词 AND 与键盘导航。
- 思考档位：只显示模型 `efforts` 中存在有效 wire 映射的档位；未知/失效值保留并阻止发送。

### 滚动

- 采用 `UI-SCROLL-001` / UI-CR049-v1：消息、历史、候选、模型、输出、步骤等有溢出的容器实际滚动时显示，停止 700ms 隐藏；hover/focus 不单独唤醒；嵌套容器分别计时；输入光标、选区和草稿保持。
