## 1. 设计基准与继承

1. **模型获取**：一列、原生复选框＋名称/ID＋已知上下文；整行可点，取消／保存所选作为右侧按钮组。密钥范围小卡片保持原规则。
2. **模型编辑**：思考关闭隐藏档位／全部映射／默认强度，容量两列；开启才显示三列。映射全量位于一个默认关闭的折叠框，off/minimal/low/medium/high/xhigh/max 同名预填；自定义值不因选其它档位消失。容量支持K/M，非法保留输入并拒绝保存；成功保存供应商收起。
3. **设置壳**：左分类导航保留，取消右下分类按钮；左下删除冗余设置/账户及关闭文字；右上X关闭，生图图标与大标题同行且在最右业务位置，不与关闭X重叠。保存／取消／放弃统一右侧组。
4. **项目图标**：默认只有当前图标与轻提示，点击当前图标展开完整样式/配色；不直接铺满。选择即时预览，不丢其它字段草稿。v2补齐原型缺失的内联符号注册，采用[有效sprite](../workbench-v4/icon-sprite.svg)中与[图标设计稿](../icon-system/index.html)一致的33个扩展图形；六组纵向排列、组内自适应换行，不沿用旧平铺网格把六组并排挤出弹窗。未更改原图形定义或正式软件资产。
5. **短弹窗**：项目删除、知识图标、知识授权、主机表单按内容高度及窗口上限；正文滚动、footer紧随正文，不留大片下半空白。原型原生dialog的flex高度需fit-content，不能只写auto却仍拉满可用高度。
6. **会话**：消息独立滚动，输入固定底部，用户气泡右侧/时间下方；从发送开始唯一working在流尾；正文、真实思考、工具按稳定事件身份与序号交错。工具结果默认折叠，失败摘要可见，不把生成中误称思考中，不补造思考正文。
7. **计划**：专用计划/TODO快照，不是逐工具操作；默认折叠、贴输入区上方悬浮，展开内容限高可滚，空计划不造空框。工具证据仍在消息流。
8. **统计和入口**：工作台复用同一消息/思考/工具/working/统计渲染器；有真实数据时顶部显示智能体与后台入口，零记录仍沿旧规则隐藏；用量三入口继承有效设计，不把未知用量填成0，示例值保持合成身份。
9. **供应商候选**：模型管理是清单权威，检测/CLI/会话共享派生源；按CLI兼容端点＋密钥自身协议和范围过滤，不按品牌名猜协议。默认密钥仍继承供应商默认协议，不直接在两类端点复用。
10. **权限**：Claude的permissionMode、Codex审批策略/审核者/沙箱/计划轴、Grok ACP权限各自说明。未具备真实通道的项明确原因；目前仅菜单演示，不能宣称支持全部原生权限。

保留独立头像680×660裁剪尺寸、检测108px结果区、既有模态权限与续接异常安全交互。不用改稿掩盖软件偏离。
