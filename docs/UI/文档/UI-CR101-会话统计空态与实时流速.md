## 1. 视觉与交互基准

| 部位 | 预期基准 |
| --- | --- |
| 空态（三组全无可信数据） | 统计条**整条不渲染**：不出现容器、不留 `padding`／`min-height` 空白、不提供三个详情入口。输入框下方直接结束，不出现可点击却只能打开空白浮层的入口 |
| 组级可见 | 会话组、Token 组、上下文组各自独立判定；某组至少一个字段可信才显示，其余组省略。只有 Token 有值时就只出现 Token 一组 |
| 字段级省略 | 组内未知字段不生成片段，不输出「—」占位；分隔符按已有片段连接，不出现「4 轮 · · 148 tok/s」「— 轮 4 步」这类残缺写法 |
| 会话组 | 计数段「N 轮 M 步」（空格相连），TPS 为独立片段（`· ` 相连）。缺任一片段时只省略该片段：`4 轮` / `17 步 · 148 tok/s` / `148 tok/s` 均合法 |
| Token 组 | 总量与缓存各自独立：`6.1M tok · 缓存 95%`／`0 tok`／`缓存 0%` 均合法。统计条写**两字「缓存」**以省空间（侧栏 320 档不再因「缓存命中」四字额外换行）；详情浮层仍写完整「缓存命中」，避免在详情里丢失命中率语义 |
| 上下文组 | 圆环＋百分比；只在当前窗口占用可信时出现，不拿累计 token 或配置上限冒充 |
| 可信零值 | `0 轮 0 步 · 0 tok/s`、`0 tok · 缓存 0%`、`0%` 是已知数据，必须显示，不得因等于 0 被隐藏 |
| 生成中实时流速 | 有读数后显示**带 `~` 前缀**的估算值（例 `1 轮 2 步 · ~126 tok/s`）；口径为有界滑动窗口（200–2000ms，节拍 1s），token 按官方字符密度估算；从未测得读数时省略该片段，不显示 `0 tok/s` |
| 终态行为 | 完成／失败／停止后停止刷新；权威 TPS 可用则替换，不可用则**清除**实时值，不冻结过期数字 |
| 详情口径 | 详情浮层内 TPS 标注「生成中实时估算」或「本轮闭合测量」，两种口径不并列；未知字段写「未上报」，不显示「—」冒充数值 |
| 浮层与对齐 | 沿用 UI-CR074-v1：三入口相对输入框居中、浮层右缘对齐所点控件、同一时刻只开一个、外点与 Escape 收起；某组不显示时其入口同样不存在 |

窄栏与换行沿用既有规则：侧栏 320／372 档允许统计片段换行，不出现横向溢出、不改变正文宽度；换行不等于隐藏字段。

## 4. UI-SCROLL-001 与验证边界

显式采用 [UI-CR049-v1](UI-CR049-滚动条按需显示.md) 与 [CR-049](../../PRD/CR-049-滚动条仅在滚动时显示.md)：本版**不新增滚动容器**——统计条自身 `overflow` 仍为 `visible`；统计详情正文溢出沿用既有原生滚动与「最后滚动后 700ms 隐藏」，不改滚动宽度、不禁滚、不新增 hover／focus 唤醒。空态通过「不渲染容器」实现，**不使用 `overflow:hidden` 或零高度裁切冒充隐藏**。

本轮已执行（设计侧）：隔离浏览器检查 20 项通过、0 JS 异常、9 张截图（见 §5）。设计自身通过不能替代正式软件的同条件成对对照；软件侧实现与视觉对照须在编码授权后执行。
