## 2. 实现与设计边界

- **本稿是预期基准，软件截图才是实现证据**。设计稿不冒充软件、不以共享样式反向覆盖实现；软件不得以「已有实现」反向压低本设计。
- **跳转范围（第一版）**：Ctrl+点击跳转与多目标选择器均基于**符号索引**（symbol index），只做「跳转到定义」。**不含**实现类跳转（find implementations）、引用查找（find references）等语义级能力；界面文案与图标只表达「定义」，不显示「查找引用／实现」，不夸大能力。
- **语言能力如实标注**：仅对已建立符号索引的语言启用跳转；`.css`／`.json`／`.md` 等明确显示「暂不支持跳转」，不给出假的可点击下划线。
- **数据边界**：新建／重命名／删除只改合成内存夹具，不落真实磁盘、不发网络；失败态为合成仿真，不代表真实只读／占用检测已实现。
- **滚动条边界（UI-SCROLL-001）**：文件树、右键菜单、选择器列表均使用 `overflow:auto` 保留原生滚动占位，只在实际滚动时着色、停止 700ms 后隐藏；不用 `overflow:hidden` 或切换宽度假装。见 §5 单列验证。
- 设计侧如需调整外观或交互，先更新本说明与可视资源并升版本，再改软件。

## 4. 对照验证计划

- **同条件**：同一视口（1280×820 / 1100×700 / 390×844）、同一主题（浅／深）、同一合成样例数据与同一操作状态；记录浏览器 / WebView、缩放与字体差异。
- **逐场景成对证据**：SC-090-01～10 各保存设计与软件截图或等效可复核证据，登记设计版本、实现版本、预期、实际与差异结论。
- **重点核对**：栏宽／层级、菜单与弹层定位夹紧、行内输入错误提示位置、页签插入指示线、跳转目标行高亮、面包屑换行、深色与 390 下 SC-01／02／07 可用。
- **自动化辅助**：原型暴露 `window.designState()`，返回 `{scenario, theme, narrow, menuOpen, pickerOpen, deleteOpen, selectedFiles, activeFile, openTabs, breadcrumb, inline, ctrl, scrollbars}`，供后续脚本核对当前场景、菜单是否打开、选中文件数等；DOM／几何只作辅助，无法目视的项记未验证。

### 4.1 滚动条验证项（单列，UI-SCROLL-001）

1. 文件树超高：初始无着色→实际滚动显示→连续滚动保持→停止 700ms 后隐藏；滚动前后栏宽与内容宽度不变。
2. 右键菜单超高（超高时）：同规则内部滚动，不撑破视口；贴边夹紧。
3. 多目标选择器列表超高：列表内部独立滚动与计时，外层不跟随唤醒。
4. 嵌套隔离：编辑区／外层不因文件树或列表滚动而显示滚动条。
5. 不使用 `overflow:hidden`、不切换滚动条宽度或 `display` 实现隐藏；原生代码编辑滚动与光标、选区保持。
6. 证据为同条件动态序列（隐藏→显示→隐藏），不以静态无滚动条截图或 `--hide-scrollbars` 充数。
