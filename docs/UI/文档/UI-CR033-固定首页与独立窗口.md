## 页面与交互

### WIN-01：固定管理首页

首页仍是项目管理、知识库、服务器管理三个管理页，通过左侧模块导航（窄屏上方导航）切换；打开窗口不替换、不清空首页，关闭窗口回到原管理页。首页不出现“返回”按钮，列表与搜索保持。

### WIN-02：独立窗口

从首页条目打开项目／知识库／服务器后，当前工作区切换为对应窗口表面：
- 顶部窗口栏列出“首页 · 当前管理页”和所有已打开窗口，当前窗口高亮；
- 窗口标题条显示类型、名称与稳定 ID，右侧“关闭窗口”；
- 左侧管理栏与窄屏模块导航在窗口内隐藏，窗口内容占满主区；
- 项目窗口保留内部“需求／设计／任务／编码”页签，知识库窗口保留三栏阅读，服务器窗口保留主机／终端／监控。

窗口键为 `project:<id>`、`knowledge:<id>`、`server:<id>`。重复打开同一对象只激活并置前原窗口，保留其页签、选中项、滚动与草稿；同一名称不同 ID 不合并。

### WIN-03：取消返回按钮

详情窗口内不再出现“← 返回项目管理／知识库／服务器管理”；唯一返回路径是关闭窗口或点击窗口栏“首页”。关闭后焦点回到窗口栏首页入口或原触发项。

### WIN-04：关闭保护

- 无草稿、无运行任务：直接关闭，其他窗口保持。
- 有未保存文件／设计草稿：确认框列出草稿，可“取消”保留或“关闭窗口”丢弃；取消不改变任何状态。
- 有运行中任务：确认框明确“任务继续在后台执行”，关闭不停止、不取消、不重置任务。

### WIN-05：窗口栏与键盘

窗口栏是普通按钮组：首页与每个窗口均可 Tab 聚焦，Enter／Space 切换；每窗口带独立关闭按钮与可访问名称；窄屏横向滚动，不挤出整页。

## 样例真实性与保护

- 首页项目、知识库、服务器及窗口内容全部沿用既有合成预约夹具；窗口状态只存本页内存，不写正式存储、不调用真实 CLI／SSH／Git／网络。
- 关闭确认中的“草稿”来自原型文件草稿与设计资料草稿；确认丢弃会清除对应本机样例草稿并保存快照，取消不修改。
- 运行中任务来自既有仿真调度器；关闭窗口不调用停止或取消，任务状态与时间线保留。
- “窗口”是同一浏览器页内的独立表面，用于评审导航与状态模型，**不代表已实现 Tauri 系统窗口**；正式实现方式见[方案](../../LLD/LLD-CR033-窗口导航与状态隔离.md)。
- 管理首页由三个既有管理页组成，是本批实现选择；若改为单一合并首页需另行确认，不在本稿冒充已确认。
