## 4. 算法说明（设计稿内置，供软件实现参考）

- **农历**：1900–2100 农历信息表（`LUNAR_INFO`），逐日偏移法求年月日；除夕判定为「次日为另一农历年正月初一」。
- **节气**：太阳视黄经 Meeus 低阶近似（精度 ≈0.01°），按日搜索黄经跨越 15° 整数倍的日期；采样时刻为北京时间当日 12:00。对照 2025–2027 全部 72 个节气与权威日历一致（清明 2026 4/5、立春 2/4、冬至 12/22 等）。
- **干支**：年柱以立春为界；月柱按节气定支、五虎遁定干；日柱按儒略日连续推算（2000-01-01 甲辰）。2026-11-24 = 丙午年 戊戌月 癸卯日，与通书一致。
- **十二值日与宜忌**：按日柱地支对「建除满平定执破危成收开闭」，宜忌取传统通书口诀；**属近似规则，界面不声称权威黄历**。
- **调休**：内置 2025–2027 三年表，其他年份不显示。
