## 0. 版本变更

### v11（2026-11-26：排行去来源标签、序号图标居中、命中率曲线圆滑）

用户三点反馈：「按模型不需要排序标记是 cli 还是平台使用，没有意义」「按模型 / 按供应商排序序号和图标没有居中，视觉感受不好」「token 趋势的命中率曲线圆滑一点，现在太生硬」。

| 项 | v10 | v11 |
| --- | --- | --- |
| 排行来源标签 | 副行左侧为来源文字徽标（`CLI` / `平台主代理` / `子智能体` / `供应商`）+「· 占比」 | **删除来源文字**，副行改为「占比 xx.x%」+「缓存命中率 xx.x%」；来源仍由左侧图标表达（CLI 官方 logo / sparkles / bot / 供应商色块），信息不减少 |
| 序号与图标对位 | `align-items:flex-start` + 序号 `padding-top:3px`、图标 `margin-top:1px` 凑对齐；实测序号中心比行中心高 15.3px、图标高 13.4px | **整行垂直居中**（`align-items:center`），序号与图标同进 **20px 居中列**（`.c078-rank-n` / `.c078-rank-ic`），去掉 padding / margin hack；实测与行中心差 ≤1px |
| 命中率曲线 | `<polyline>` 折线段，小时之间硬转角 | **`<path>` 平滑曲线**：Catmull-Rom → 三次贝塞尔（23 段），`stroke-linecap:round`；控制点 y 夹在 [0,100]，曲线不冲出绘图区上下边界 |

- 保留项：热力图「较少 → 较多」色阶标尺、趋势堆叠按模型同色、悬停浮层明细、「按模型 / 按供应商」的行数与占比条宽度规则均不变。
- 设计侧断言 109→111：新增「命中率曲线为 23 段三次贝塞尔且无填充」「序号 / 图标与行中心 ±1px、同宽 20px 居中对齐且无 padding-top」「排行无来源文字标签」；软件由 57→59 同理新增。

| 周期外 | 不渲染 | 保留空框（白底 + 细边线，深色为深底框），保证网格完整 |
| 格宽 | 14px 固定，窄屏溢出 | **列宽自适应**（`minmax(0,1fr)` + `aspect-ratio:1`）；1440 下 ≈ 14.5px，390 下 ≈ 8px，不溢出不横向滚动 |
| 月份标签 | 各月都标 | 跨度不足 2 列的月份**不标**，消除「7月8月」重叠 |
| 同行面板对齐 | `align-items: start`，热力图 224px / 趋势 302px，**底部差 78px** | `align-items: stretch` + 面板改 flex 列、卡片体 `flex:1`，同行**等高**（302 / 302、356 / 356）；热力图内容垂直居中 |

## 3. 滚动条义务（UI-SCROLL-001）

## 4. 算法说明（设计稿内置，供软件实现参考）

- **农历**：1900–2100 农历信息表（`LUNAR_INFO`），逐日偏移法求年月日；除夕判定为「次日为另一农历年正月初一」。
- **节气**：太阳视黄经 Meeus 低阶近似（精度 ≈0.01°），按日搜索黄经跨越 15° 整数倍的日期；采样时刻为北京时间当日 12:00。对照 2025–2027 全部 72 个节气与权威日历一致（清明 2026 4/5、立春 2/4、冬至 12/22 等）。
- **干支**：年柱以立春为界；月柱按节气定支、五虎遁定干；日柱按儒略日连续推算（2000-01-01 甲辰）。2026-11-24 = 丙午年 戊戌月 癸卯日，与通书一致。
- **十二值日与宜忌**：按日柱地支对「建除满平定执破危成收开闭」，宜忌取传统通书口诀；**属近似规则，界面不声称权威黄历**。
- **调休**：内置 2025–2027 三年表，其他年份不显示。
