# UI-CR062：AI 侧栏子智能体只读详情

- 版本：UI-CR062-v1（2026-11-22）
- 关联需求：[CR-062](../../PRD/CR-062-AI侧栏子智能体只读详情.md)；Story：[STORY-080](../../Plan/Story/STORY-080-子智能体只读详情.md)
- 唯一设计入口：[仿真原型UI.html](../仿真原型UI.html) → `workbench-v4/index.html`（演示路径：打开 AI 侧栏 → 点顶部「n 子智能体」→ 点任一行）
- 继承：[UI-CR056 v1](UI-CR056-AI侧栏全面重构.md) 的侧栏宽度、主题 token、头部高度、历史浮层与滚动规范；本版只定义子智能体视图，主会话视图不变。
- 替代范围：仅替代 CR-056 头部在“子智能体视图”下的表现（计数入口、FEAT 标签、新建按钮不出现），不改主会话头部。

## 1. 结构

```text
┌────────────────────────────────────────────┐
│ [←]  主会话 / 核验容量事务边界        运行中 │  44px 头部
├────────────────────────────────────────────┤
│ dsh · deepseek-v4.1 · 12m31s · 8.6M tokens │  元信息条
├────────────────────────────────────────────┤
│ 子智能体记录仅本次运行可见…                  │  说明条
│ ├ 状态  运行中            14:22:03          │
│ ├ 说明  先核对事务边界与回补路径…            │
│ ├ 工具  code-search · capacity|rollback     │
│ ├ 结果  命中 3 处                    （折叠）│
│ ├ 产出  事务边界位于 …                       │
│                                               │
│ （滚动容器，按需显示滚动条）                  │
├────────────────────────────────────────────┤
│ 👁 子智能体由主会话派发，这里只读   [返回主会话]│  只读条
└────────────────────────────────────────────┘
```

- 头部：28×28 返回图标（`arrowLeft`，title/aria「返回主会话」）＋面包屑＋右侧状态点与文字；不使用历史图标、不显示两个计数按钮、FEAT 标签、绑定胶囊与新会话按钮。
- 面包屑：第一级固定「主会话」为按钮（可点返回），分隔符 `/`，第二级为子任务名（`ellipsis`，`title` 显示完整）；`nav aria-label="会话位置"`。
- 元信息条：`CliLogo` + CLI · 模型 · 耗时 · tokens；任务标识（有 `taskId` 时）右对齐为小标签。字段未知显示“未知”。
- 说明条：浅色 inset 底，说明“仅本次运行可见；未上报的内容保持未知”。
- 时间线行：左侧 2px 竖线，状态行用 accent，产出用 good，失败结果用 danger；行内为“种类标签 + 状态/工具名 + 时间 + 正文”。工具与结果正文使用等宽字体与 inset 底。
- 只读条：顶部边框 + panel-2 底；`eye` 图标 + 说明 + 次要按钮「返回主会话」。

## 2. 规格

| 项 | 值 |
| --- | --- |
| 侧栏宽度 | 继承主会话宽度（320–620），切换不改变栏宽 |
| 头部高度 | 44px，`border-bottom: 1px solid var(--line-soft)`，`padding: 0 8px` |
| 返回按钮 | 28×28，圆角 6，悬停 `--hover-bg`；focus-visible 2px 主色描边 |
| 面包屑字号 | 12.5px；第一级 `--muted`，当前级 `--ink`、字重 500 |
| 状态点 | 7px 圆；成功 `--good-dot`、失败 `--bad-dot`、运行中/待确认 `--warn-dot`、已停止 `--muted-2` |
| 元信息条 | 10.5px，`--muted`，padding 6px 12px，可换行 |
| 时间线 | 顶部 10px，行距 8px；状态/工具/结果/产出行左竖线 2px |
| 正文 | 11.5px / 1.55，`pre-wrap`，`overflow-wrap:anywhere` |
| 只读条 | 11px，padding 8px 12px；按钮为 `.btn.sm` |
| 深色主题 | 只使用 token（`--surface/--inset/--line-soft/--ink-2/--muted`），不新增固定色值 |
| 窄宽（320px） | 面包屑当前级截断；元信息条换行；时间线不横向滚动 |

## 3. 状态覆盖

| 状态 | 设计表现 |
| --- | --- |
| 运行中 | 状态琥珀点 + 1.4s 脉冲；时间线随事件追加；滚到底部，用户上滚后不强制跳底 |
| 待确认 | 琥珀点，不脉冲；说明未收到终态 |
| 成功 | 绿点 + “成功”；产出行为 good 竖线 |
| 失败 | 红点 + “失败”；失败结果行 danger 竖线 |
| 已停止 | 灰点 + “已停止” |
| 无过程事件 | “暂无过程记录”行 + 最终输出摘要（有则显示） |
| 记录不可用 | 居中提示“该子智能体记录已不可用”+ 说明 + 主按钮返回 |
| 空/长文本 | 正文 `pre-wrap` 自动换行；超长工具结果后端截断 4000 字 |
| 滚动 | 仅滚动时显示滚动条，停止 700ms 后隐藏（UI-SCROLL-001） |
| 减少动效 | `prefers-reduced-motion` 下状态点不脉冲 |
| 键盘 | 进入焦点落在返回按钮；Escape 返回；Tab 顺序：返回 → 面包屑 → 返回主会话 |

## 4. 交互

1. 入口：顶部下拉行整行为按钮（hover 高亮，尾部 `chevronRight`）；消息流子智能体卡片右上「查看」按钮。二者进入同一视图。
2. 进入：下拉先关闭；主会话隐藏但保持挂载（草稿、运行、滚动不丢）。
3. 返回：返回图标 / 面包屑第一级 / 底部按钮 / Escape；返回后焦点回到主会话输入框。
4. 阻止误操作：详情没有输入框；点击只读条按钮不会发送任何消息。
