## 1. 视觉与交互基准

| 区域 | 基准 |
| --- | --- |
| 命中区 | 6px 宽、全高、绝对定位的 `.pane-handle`，`role=separator`、`tabIndex=0`；不改变宽度与位置 |
| 可见指示 | 仅 `::after` 一条 2px 竖线；hover / 键盘焦点 / 拖动中显示 `--primary`（浅色 `#2b6cf6`、深色 `#5b8dff`） |
| **禁止态** | 把手 6px 命中区之外**不出现**任何 `outline` / `border` / 蓝色矩形框 / 满高竖线 / 顶部横边；不因 `:focus`、`:focus-visible`、程序化 `focus()` 或拖动结束后的焦点残留而画外描边 |
| 键盘可辨 | 键盘 Tab 聚焦时仍由 2px 主色握把线指示；不删除全局 `:focus-visible`（CR-068 结论） |
| 拖动态 | 鼠标／触控拖动时 `.pane-dragging` 抑制文本选中、光标为 `col-resize`；宽度限幅、双击恢复默认、方向键微调不变 |
| 不新增 | 不新增厚卡片、宽装饰、占位 ghost、配置开关、业务状态或弹窗 |

设计资源落地规则（`workbench-v4/pane-resize.css`）：

```css
/* UI-BUG006-v1：6px 命中区外不画任何焦点环；键盘焦点与拖动只由 2px 握把线指示。 */
.pane-handle:focus, .pane-handle:focus-visible { outline: none; }
```

## 6. 软件侧对照计划与结论

- 计划：同视口、缩放、主题、同一四状态，运行 `--target=software [--theme=dark] --phase=after`（隔离预览 `?preview=design` 渲染真实 React／CSS），逐场景保存成对 PNG 与 JSON；检查整体壳、栏宽／层级、把手轮廓、握把线颜色、键盘焦点可辨性与拖动态。
- 实际：`--target=software --phase=before` **7/11（4 项失败＝蓝色框复现证据）**；改后浅／深各 **11/11 通过**，四状态 `outline-style=none`、`frameLines=[]`、`wideRows=0`；`npm run build`（含 `tsc --noEmit`）exit 0。逐项结果与差异结论见 [REPORT-BUG006](../../Test/REPORT-BUG006-拖动侧栏分隔条蓝色框修复验证.md)。
- 差异结论：软件改前偏离已编号 BUG-006 并修复；设计／软件裁剪高度不同（956 vs 905，因把手在页内 y 与高度不同）已如实登记，不构成视觉偏离；软件拖动中 `is-resizing` 只把同一条 2px 握把线着色，与设计 hover 表现一致。人工目视对照未执行，不得记视觉验收通过。
