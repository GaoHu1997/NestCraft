- 版本：**UI-CR103-v2**（2026-11-26；v1 同日被 v2 替代——用户追加「待发队列也需要可以折叠」，v1 历史验证记录留档）
- 设计稿：[cr103-queue-compact/index.html](../cr103-queue-compact/index.html)（自包含，可直接打开；浅／深切换、侧栏 390 窄档演示、列表滚动与折叠演示；支持 `?theme=dark`、`?narrow=1` 直达）。sha256 前16 `74ca6be079d0eddc`，20161 bytes。

## 1. 场景覆盖

| 场景编号 | 场景 | 呈现 |
| --- | --- | --- |
| SC-103-01 | 单条消息（默认态） | 每条消息固定单行：全文超宽截断省略，完整内容悬浮 `title`；「编辑／立即发送／删除」同行右侧，删除危险色；面板总高 ≈ 头部 29px + 条目 26px/条 + 底注 24px + 边框，不随消息长度变化 |
| SC-103-02 | 带引用／附件条目 | 紧凑小标 `🔗n` `📎n` 内联在文本前（warn 胶囊样式，沿用现行 `.chat-queue-tag` 视觉口径），仅有内容时显示；「已暂停」不逐条标注，由头部按钮统一表达（代理细化默认值，待确认） |
| SC-103-03 | 暂停态 + 多条消息 | 暂停时头部按钮为「继续」（warn 态）；列表限高约 5 行，超出列表自身滚动，按 UI-SCROLL-001 按需显示滚动条；外部布局不跳动 |
| SC-103-04 | 编辑态 | 仅编辑中的条目临时展开为多行编辑框 + 「保存／取消」；其余条目保持单行；取消或保存后恢复单行 |
| SC-103-05 | 折叠态（v2 新增） | 头部左侧 ▾／▸ 折叠开关：折叠仅保留头部一行（≈29px），条目与底注隐藏不销毁，队列内容与暂停状态不受影响；默认展开，状态会话内记忆（内存）；折叠开关与「暂停／继续」相互独立 |
| 不适用 | 空队列 | 沿用现行「无消息不渲染面板」，无空态样式 |

## 2. 视觉与文案基准

- 结构沿用现行面板：头部（`待发队列 N` + 暂停／继续）与底注（内存队列说明）不变；仅条目区由三行改单行。
- 条目行：`display:flex`，元信息小标（flex:none）→ 文本（`flex:1;min-width:0;nowrap;ellipsis`）→ 操作按钮组（flex:none）；字号 11.5px、按钮 10.5px，沿用现行 `.chat-queue-*` 尺寸与色彩 token，不新增第二套视觉。
- 列表限高 130px（约 5 行，代理细化默认值，待确认）；编辑展开时该条目脱离单行约束，编辑框 44px 起可纵向拖高。
- 折叠开关（v2）：头部左侧 ▾／▸ 字符按钮（`--muted`，hover `--accent`），11px；与「暂停／继续」按钮并列但互不替代；折叠实现用条件渲染（`display:none` 于列表与底注），头部边线随之收起，不用零高度裁切或 `overflow:hidden` 规避。
- 主题：浅／深成对；视口覆盖桌面与侧栏 390 窄档；窄档下文本先截断、操作按钮不折行不消失，折叠箭头与按钮可达。

## 3. 滚动条（UI-SCROLL-001）

本版**新增一个滚动容器**：队列列表限高区（SC-103-03，消息数超出限高时）。该区按 [UI-CR049 规范](UI-CR049-滚动条按需显示.md) 实现：初始透明，实际滚动时显示（浅 `#a4abb5`／深 `#7d8794`），连续滚动保持，停止 700ms 后隐藏，悬停不单独唤醒，`scrollbar-width:thin`、WebKit 10px 轨道 3px 透明内边 8px 圆角；禁止以禁用滚动、切宽度或 `display` 方式实现隐藏，不因限高引发布局跳动。头部与底注不新增滚动行为；适用场景登记为 SC-049-03（AI 会话输入区）继承。

## 4. 覆盖核对与准入

- 列出受影响存量界面：AI 侧栏会话输入区队列面板、工作台会话输入区队列面板（同一组件）；头部、底注、输入区其余部分不变。
- 设计确认依据：2026-11-26 用户提出「待发队列太高了，需要更折叠后的高度一样」，并在代理给出的两种解读（单行紧凑／加折叠箭头／两者都要）中确认「**每条消息单行紧凑**」；同日追加「**待发队列也需要可以折叠**」（v2 依据）；同日用户明确「授权开发」，按本稿实现。
- 实现位置（已实现）：软件源码 `src/modules/chat/ChatPanel.tsx`（`ChatQueuePanel`）、`src/modules/chat/chat-actions.css`（`.chat-queue-*`）、`src/modules/chat/sessionRuntime.ts`（`queueFolded` 折叠记忆）；滚动按需显示复用共享机制 `src/components/scrollbar.ts`，未新增滚动 JS。
- 对照验证计划与结果：软件真实组件验证 16/16、0 JS 异常，SC-103-01～05 浅／深、390 成对对照无未解决视觉偏离；列表限高滚动含动态滚动条证据；折叠态实测 32.5px。详见 [REPORT-CR103](../../Test/REPORT-CR103-待发队列单行紧凑与折叠.md)；全应用端到端待用户验收。断言脚本 `scripts/verify-cr103-software.mjs` 可复跑。
