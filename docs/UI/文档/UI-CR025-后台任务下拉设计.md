## 布局与继承

AI头左历史30px、右新建/关闭各30px固定；中间弹性容器顺序为已有子智能体控件、后台控件，gap4～8px。紧凑无底座，后台用层叠线性图标、12px文字“n 个后台任务”、12px箭头，28px最小高。子智能体原执行器Logo汇总／Token上时间下保持。两者同时很长时中间自然折行且完整名称可读，不遮左/右按钮，不隐藏执行器。零后台隐藏整个button，零子智能体独立隐藏；中间容器空时仅保留两侧定位，不留后台专属占位。

后台下拉从顶部控件下沿+6px展开，右侧对齐侧栏内容边缘，最大600px／视口-16px；400px侧栏不扩大，浮层可向左扩展。圆角14px、细边、浅面板与轻阴影；采用现有paper/panel-2/ink/muted/line/good-dot/bad-dot主题令牌，深色不套白底。上下限高min(520px,剩余视口)，列表内部滚动。

## 场景与状态

| 场景 | 可操作设计及状态 | 验收关联 |
| --- | --- | --- |
| C25-01无后台 | 默认空会话整块隐藏；有子智能体但无后台只显示子智能体；新会话不显示旧后台 | AC-11/15 |
| C25-02混合记录 | 显式“后台任务混合DEMO”载入4条（1运行/2完成/1失败）；组头“进行中1”“已结束3”，分组可折叠；状态点绿运行/完成、红失败、灰取消/未知，同时文字状态 | AC-12/13 |
| C25-03全部结束 | “11条已结束后台DEMO”全部11条完成，入口仍显示11；保留参考图已结束分组与右侧清空 | AC-11/12/14 |
| C25-04明细 | 状态点6px、工具约48px、命令弹性、退出码/耗时尾部、28px独立箭头；行38px起。命令单行省略，展开完整命令/jobId/来源/状态与pre输出，未知时间/退出码明确未知，无输出显示暂无输出；长输出内部滚动 | AC-13/16 |
| C25-05清空 | “清空”仅已结束项，无结束禁用；混合清空保留运行项；全结束清空后入口隐藏/弹层关闭，焦点回历史，不终止真实任务、不清别的会话或用量 | AC-14/17 |
| C25-06异步归属 | 菜单末“推进运行任务DEMO”显式合成延迟更新，提示只演示；新建/切换/关闭不取消原回调，原会话完成记录、未读同源，当前新会话不被污染 | AC-15 |
| C25-07未知/兼容 | “未知后台记录DEMO”独立待核验组，未知退出/起止/暂无输出，不误计完成／可清；1440×1000、1920×1080、390×844、320×844浅深／Enter/Space/Escape／外点关闭／菜单互斥 | AC-16/17 |

组头左折叠箭头/状态标签/数量，已结束组右“清空”，不嵌套两个button。行命令13px、元数据11px、展开箭头有aria-expanded和完整aria-label，退出码不是项目验收结论。菜单底部只一条“合成DEMO，不执行命令”与可选推进控件，不加新任务中心/取消权限/全局操作。

## 状态覆盖／不适用

空、运行、成功、失败、取消、未知、已结束折叠/展开、单行折叠/展开、清空禁用/最后项、切换／后台事件、长命令／无输出／多输出、浅深和窄屏覆盖。加载/接口错误/无权限不适用本轮内存设计（无远程读取或权限动作）；真实读取失败与恢复页面需后续正式设计，不将合成任务失败当网络错误。
