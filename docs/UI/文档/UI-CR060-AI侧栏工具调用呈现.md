## 2. 工具名中文映射（S1/S2 唯一新增设计规则）

模型侧工具名固定为 `mcp__workbench__<tool>`。侧栏显示时去除前缀并映射：

| 工具名（后缀） | 显示名 |
| --- | --- |
| get_context | 工作台·当前上下文 |
| list_projects | 工作台·项目清单 |
| create_project | 工作台·创建项目 |
| update_project | 工作台·更新项目 |
| get_requirements | 工作台·需求树 |
| read_requirement_doc | 工作台·读需求文档 |
| write_requirement_doc | 工作台·写需求文档 |
| list_kbs | 工作台·知识库清单 |
| create_kb | 工作台·创建知识库 |
| set_kb_grant | 工作台·设置知识授权 |
| list_servers | 工作台·服务器清单 |
| save_server | 工作台·保存服务器 |

- 映射未命中的工具名（用户新增自配 MCP、CLI 原生工具等）保持现行显示，不做任何猜测性改写。
- 该映射仅影响显示文案；步骤的运行/成功/失败状态、耗时、折叠、演示步逻辑全部沿用现行实现（不伪造步骤——无真实调用不产生条目）。

## 3. 设置-工具页（S3/S6）数据规则

- 新增 12 个内置工具行，字段：`tool:workbench.<name>`、中文名+一句用途、风险 low/medium、默认启用。
- 开关行为与既有工具一致：停用写 capability 表（kind='tool'），MCP 服务器 `tools/list` 实时过滤。
- S6 全局总闸：写设置键 `aiTools.enabled`（"1"/"0"，缺省启用）。位置与文案见 S6；控件复用既有 `SettingsSwitch`，不新增样式。
- 页面布局、排序、风险徽章样式零改动——本场景为纯数据行新增，原型（workbench-v4）演示数据不含真实 MCP 工具名，无需改动原型；对照验证以软件实际截图为准。
