## 1. 阅读方式分离（SC-066-01）

需求工作区左侧轨道有三个入口，三者互不重复导航：

| 方式 | 左侧 | 中部 | 右侧 |
| --- | --- | --- | --- |
| 文档 | 需求树（搜索、折叠、新增） | 当前文档正文 | 本页目录（可折叠子章节） |
| 全文（预览） | **无** | 全项目连续长文，按 Vision/Epic/Feature/Story 分级 | 全文目录（**四级需求菜单**） |
| 导图 | **导图目录** | 导图画布 | 节点悬浮详情框（选中时出现） |

顶部工具栏**不再重复**「全文预览」「思维导图」按钮，只保留当前文档相关操作（编辑、派发预检）与一行模式说明文字。

## 2. 标准思维导图（SC-066-02）

- **整块是导图**：进入导图后主区没有「上导图下正文」的拼接，正文容器整体隐藏，画布占满工作区剩余高度（页签条与工具栏在导图区内部）。
- **从左到右的层级树**：父节点在左、子节点在右，子节点纵向排开，父节点垂直居中于其子树。
- **连线**：父节点右边缘到子节点左边缘的贝塞尔曲线。关系缺失（父项编号不在集合内）的节点用虚线边框标记，不静默丢弃。
- **节点**：圆角卡片，显示类型+编号（小字）与标题，宽度按中英文字符估算，右侧固定图标按钮：新增下级（按类型）、在文档中打开；模型节点则是「打开模型文档」。
- **折叠控件在连线连接处**：折叠按钮是父节点右边缘的 18px 圆形控件，**默认隐藏（`opacity:0`、`pointer-events:none`），悬浮画布或该控件时才显示**；已折叠的分支控件常驻可见（`aria-expanded="false"`）。这样折叠与「新增下级」不再挤在同一处。
- **导图目录**：左栏，与画布同源同一份实体集合与同一套折叠状态；条目显示类型、编号、标题，按层级缩进。点击条目同时选中画布节点并把画布滚动定位到该节点。
- **右侧悬浮详情框**：点击节点后从右侧浮出（320px，带阴影），显示类型、编号、标题、状态、负责人、来源文件，并提供「在文档中打开」「编辑」。关闭后画布恢复全宽。
- **页内新增**：Vision 节点 → 新增 Epic；Epic → 新增 Feature；Feature → 新增 Story；Story／Bug 无下级新增。
- **模型融入**：数据库／领域设计模型（项目 `docs/DB/` 下的设计文档）是 **Vision 下的项目级独立分支**，用**虚线关联**（不是父子实线），节点用虚线边框；不成为 Story 的第二父项，不按名称猜关联。未关联模型单独收纳在同一分支内。
- **画布工具**：缩放 −／百分比／＋（50%～180%）、重置 100%、**适应窗口**、全部展开。

## 3. 预览与目录（SC-066-03）

- **四级全量**：预览正文按实体层级分级排版（Vision H2 / Epic H3 / Feature H4 / Story H5，正文小节再下沉一级），四类需求**全部出现**，不按折叠、搜索或派发资格过滤。
- **四级目录**：右侧目录按 **Vision → Epic → Feature → Story 四级需求结构**组织，每条显示类型标签与标题，可折叠其下级；模型作为项目级分支列在目录末尾。目录不再以正文小节为主体。
- **模型段落**：预览正文末尾有独立的「数据库／领域设计模型」段落，逐个列出模型标题、编号与源文件，可直接跳转到「设计 → 数据库」打开。
- 文档方式仍以当前文档标题为 H1，右侧为本页目录（按正文标题层级，可折叠子章节）。

## 5. 样例真实性

原型夹具的 `VISION-01` 与 `DB-001`／`DB-002`／`DB-003`／`DB-011` 是**显式合成**的父级与模型，只用于演示层级、连线、目录与模型分支的位置；正文为合成叙述，不代表任何真实项目愿景或表结构。正式软件中 Vision 来自项目 `docs/Plan` 的真实 VISION 源文件，模型来自真实 `docs/DB/` 文档标题；无愿景源时导图显示「愿景源未提供」，无 DB 目录时模型列表为空且不伪造。
