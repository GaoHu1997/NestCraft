## 1. 视觉与交互基准（开发必读）

### 1.1 需求内部文档页签（紧凑态）

| 项目 | 基准值 |
| --- | --- |
| 页签条高度 | 28px（原 40px） |
| 页签高度 | 27px，含 2px 顶部选中指示线 |
| 页签宽度 | 最小 92px，最大 196px，宽随内容但不超出 |
| 单行结构 | 编号（10px 等宽，弱化为 `--muted`）＋ 标题（11px，单行 `ellipsis`，最大 132px） |
| 选中态 | 标题与编号为 `--primary`，`--surface` 底、顶部 2px `--primary` 线 |
| 关闭按钮 | 16×16，`--r-xs` 级圆角，hover `--surface-3` |
| 类型文案 | 愿景实体编号位显示「愿景」，其余显示实体编号（如 `STORY-0102`） |

不再显示第二行的完整标题、状态标签或路径；这些信息通过标题 `title` 属性、需求树与正文区获取。

### 1.2 溢出规则（四条页签条共用）

| 状态 | 表现 |
| --- | --- |
| 全部放得下 | 页签自然排列，**不显示**「更多」图标，不占位 |
| 放不下 | 末尾出现 26px 下箭头图标按钮，左边框分隔；其余放不下的页签隐藏 |
| 保留顺序 | 当前选中页签**必须完整可见**，其余从前往后依次保留 |
| 点击「更多」 | 悬浮下拉，标题「共 N 个页签」，按页签原顺序列出全部（含已显示的） |
| 下拉项 | 编号（需求页签）＋ 标题单行省略；当前页签以 `--primary-soft` 底＋主题色文字标注 |
| 选择下拉项 | 切换至该页签并关闭下拉 |
| 关闭下拉 | 点击外部、再次点击图标、按 `Escape` |
| 横向滚动条 | **任何情况下都不出现**；页签条 `overflow:hidden` |

下拉定位：右对齐图标、`r.bottom + 4`，超出视口底部时翻转到图标上方；左右各留 8px 安全边距；最大高 320px、内容超出时下拉自身纵向滚动。

### 1.3 适用页签条清单

| 页签条 | DOM | 备注 |
| --- | --- | --- |
| 对象窗口页签 | `.tabbar > .wtab` | 首页 + 已打开项目／知识库／服务器，页面级 |
| 项目页签 | `.ws-tabs > .ws-tab` | 需求／设计／任务／编码；右侧固定 AI 入口不受收缩影响 |
| 需求内部文档页签 | `.req-tabs > .req-tab` | 本次主要反馈对象 |
| 办公打开文件页签 | `.office-open-tabs > .office-open-tab` | 多文件同时打开时 |

新增页签条必须接入同一规则（在 `tab-overflow.js` 的 `BARS` 登记），不得各自再实现横向滚动。

## 2. 场景覆盖

| 场景编号 | 区域／适用状态 | 验证要求 |
| --- | --- | --- |
| SC-052-01 | 需求内部页签：1 个／多个／全部放得下 | 28px、单行、编号弱化、标题省略；无「更多」 |
| SC-052-02 | 需求内部页签溢出 | 出现「更多」，选中项可见，下拉列出全部并可切换 |
| SC-052-03 | 对象窗口页签溢出（含首页） | 同上；首页不可关闭但可被收起进下拉 |
| SC-052-04 | 项目页签溢出 | AI 入口固定在右端不被挤压；「更多」位于页签组末尾 |
| SC-052-05 | 办公打开文件页签溢出 | 同上；文件名过长时单行省略 |
| SC-052-06 | 主题与窄屏 | 浅／深主题、1440×900 与 1100×700；均不出现横向滚动条 |
| SC-052-07 | 交互边界 | 点击外部／再次点击图标／`Escape` 关闭；选择后下拉消失；重绘后重新计算 |

主题：浅／深；参考视口 1440×900、1100×700、390×844；浏览器 100% 缩放，字体沿用当前 tokens。上述为设计覆盖清单，**并非声称全部已逐场景实测**；实际检查范围见 [REPORT-CR052](../../Test/REPORT-CR052-页签设计验证.md)。

## 3. AI 识别、派发与验收义务

1. 任何涉及页签／页签条的 UI 任务，先读本规范，在工作包 UI 义务清单登记 `UI-TAB-001`、采用版本、受影响页签条、责任实现文件与验证方法；不适用须说明该任务无页签条，不得静默漏项。
2. 派发子代理时携带本规范链接与稳定编号，不能只传截图或「按稿实现」。
3. 通过条件同时包含：页签高度与单行信息、溢出时「更多」出现、下拉可切换、选中项恒可见、**四种页签条均无横向滚动条**，以及同条件设计／软件视觉对照。
4. 只检查 DOM 结构、`overflow` 计算值或构建通过不能替代视觉验证；截图须包含溢出态与下拉展开态。
