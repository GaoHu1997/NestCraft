## 1. 当前版本与准入结论

`UI-CR037-v2` 采用唯一公开入口下的现行 `workbench-v4` 资源。从「预约服务 → AI 侧栏 → CR-037」查看续接、显式 fresh、引用撤销、CLI 切换和历史重开。从原会话的「子智能体 → 生成并发测试数据 → 打开原任务」查看受管返工，在候选卡选择「按冻结计划直投 B」或「由大管家转发引用」。原型夹具使用 `PRJ-1042`、`S-1042-01`、`RUN-2087` 和合成调用，刷新页面会重置夹具。

### 原型核验结果

- 环境：Windows／Chrome 158.0.8127.36，浅色、DPR 1、1440×900。选择弹窗滚动取样使用 1440×305。Playwright 从唯一公开入口打开，退出 0，`pageerror=[]`。
- 通过：原生续接恢复、切换 CLI 新会话、同 CLI 确认 fresh、取消 fresh、引用过期／缺失／不兼容、权限撤销、历史往返恢复绑定和断点，以及双路交接同一 r1、B 缺陷、旧调用停写、A 原线程续接、r2 待验证、返工阻塞和旧轮回执归档。确认 fresh 时断言反向选区 1–4 保持。撤销返工未新增任务或替代调用，预算消耗为零。
- 原型在普通聊天、长草稿、任务详情和短视口选择弹窗展示 `UI-SCROLL-001` 的四阶段序列。截图记录初始隐藏、滚轮触发显示、连续滚动可见及空闲后隐藏。精确到 700ms 的边界待测。[滚动取样记录](../workbench-v4/evidence/cr037-v2/scroll-tracks.json)
- 未验证：正式软件、真实 CLI、进程重启后的持久化、数据库、runner 和软件与设计稿成对视觉验收。原型刷新重置属于演示夹具行为，不证明持久化。

按 AGENTS.md §6.3.1，原型核验可支持设计版本登记和后续软件准入，不能替代正式实现验证。

协作能力涉及新的可见状态与操作入口（未关闭问题、待决策、返工轮次、审查结论、协调者离线）。按 AGENTS.md §6.3.1，**这些界面在有效可视稿制作并登记前，不得进入实现**。

本批结论：

- 可执行：需求、方案、数据、测试设计和 `UI-CR037-v2` 原型核验。
- 待正式实现：任何正式软件实现、真实 CLI/runner 接入和数据库变更。
- 证据状态：原型场景及动态滚动序列已登记，正式软件视觉对照和运行时验收仍为未验证。
