# UI-CR071-v1：长会话上下文设计

- Feature：FEAT-025；Story：094/093；补 CR-069 SC-069-07。状态：设计资源／状态覆盖登记，尚未软件视觉验收。
- 来源：2026-11-24 用户授权执行者评审后开发；继承2026-11-23“说明文字不要写到平台界面上”。
- 唯一公开入口：[仿真原型UI.html](../仿真原型UI.html)；采用 UI-CR069-v2 的壳／输入区，以及既有消息、工具步骤、错误、统计组件。本增量**不新增前端布局、设置、按钮或说明长文案**。

## 1. 设计结论

自动压缩是后台模型输入投影，不是聊天消息修改。用户仍看到完整原聊天历史；内部摘要和thinking不变成助手回答，也不新增“已压缩”长说明卡。模型主动搜索／恢复时复用现有工具步骤（正常/错误/折叠/展开），原文结果为数据。失败走现有错误反馈，输入草稿保留；停止走既有停止状态。

## 2. 场景与状态

| 编号 | 预期展示／交互 | 覆盖与继承 |
| --- | --- | --- |
| SC-070-01 | 短会话和原历史 | 与当前消息流一致，消息数与正文不因压缩变化 |
| SC-070-02 | 自动压缩／成功 | 原有运行状态与停止按钮继续可用；不插摘要内容／新组件 |
| SC-070-03 | 模型搜索／恢复 | 普通 tool_use/tool_result，默认沿用既有折叠与错误状态；不提供跨会话切换入口 |
| SC-070-04 | 预算／摘要失败 | 现有错误呈现，原输入／附件／引用保留；不虚报成功、不生成新会话 |
| SC-070-05 | 原文无匹配／失效／撤权 | 普通工具错误或空结果；不展示失效正文／摘要 |
| SC-070-06 | 停止／流中断 | 已收到文本保留、结束运行、不显示成功；不新增常显告警 |

空历史/无工具/无压缩需求使用现有空态。模型配置、runner选择、CLI权限选择不在本增量变更。SC-069-07从“未定义”更新为上述自动摘要＋安全失败行为，但不把未验证代码写成已实现。
