## 1. 设计目标

让编码与办公两类项目的用户都能在**一个会话主区**里推进工作，且不丢失三件事：

1. **会话不隔离**：同一项目的会话只有一套，左栏、右栏 AI 栏、历史浮层共用；
2. **执行不中断**：切页签、切页面再回来，还是那条会话，不会新建；
3. **上下文就地可见**：文件、需求、成果在右栏只读预览，不打断会话、不跳页签。

硬约束：不内置浏览器内核；右栏只读、不扩大权限；分批加载是呈现策略不是数据裁剪；两类项目共用同一容器，不复制第二套会话界面。

### 1bis. 已确认决策（2026-11-22）

| 决策 | 结论 |
| --- | --- |
| 页签形态 | **纯图标「坐在电脑前的小人」（`atDesk`），不显示文字**；可读名称由 `aria-label`／`title` 提供为「工作台」。**2026-11-25 由 CR-082 修订为「电脑（显示器）图标 `monitor` + 文字『工作台』」**，现行形态见 [UI-CR082](UI-CR082-工作台页签电脑图标与文字.md) |
| 默认页签 | **两类项目新建窗口默认进入工作台**；用户主动切走后不强制拉回 |
| 左栏与会话区 | **复用 AI 侧栏现行渲染与公共样式**（`.ai-history`／`.ai-session`／`.msg`／`.ai-steps`），不另建外观 |
| 右栏打开来源 | ① 用户点击会话链接（需求/史诗/特性/文件/文件行）→ 开栏定位；② AI 请求开栏（验证 UI 预览、调用浏览器类工具等） |
| AI 开栏确认 | **不需要人工逐次确认**；前端按规则放行，用户可随时关闭 |
| AI 开栏约束 | 用户关闭后同轮不重开；非法/未支持类型拒绝并给原因码 |
| 浏览器 | 内核与自动化**独立立项**，本稿只呈现请求通道与结果占位 |

## 2. 界面结构

### 2.1 页签

| 项目类型 | 页签序列 |
| --- | --- |
| 编码 | **工作台** · 需求 · 设计 · 任务 · 编码 |
| 办公 | **工作台** · 文档 · 成果 |

- “工作台”固定在最前并默认选中；可读名称沿用产品整体叫法。
- **页签为纯图标：`atDesk`（坐在电脑前的小人），不显示文字**；`aria-label`／`title` 提供「工作台」。这是本项目第一处纯图标项目页签。**CR-082（2026-11-25）已改为电脑图标＋文字『工作台』**：图标 `monitor` 16px、间距 6px、页签高度与下划线沿用文字页签口径；详见 [UI-CR082](UI-CR082-工作台页签电脑图标与文字.md)。
- 溢出沿用 CR-052：末尾「更多」下拉，不出现横向滚动条；右侧固定入口不参与收缩。

### 2.2 三栏

| 栏位 | 宽度（1440 / 1100） | 内容 |
| --- | --- | --- |
| 左：会话历史 | 288px / 236px，可拖 | **复用 `.ai-history`**：20/全部计数、搜索与重置、置顶、双圈状态点、运行环、分批「继续加载」、已到全部 |
| 中：当前会话 | 最小 320px，弹性 | 标题与共享标识、**复用 `.msg`／工具卡／`.ai-steps`**、**复用 `.ai-composer` 输入区（`+`／CLI／权限／模型／发送＋`.ai-stats` 统计）** |
| 右：辅助栏 | 360px / 308px，默认关闭，可拖 | 标签页、只读预览、AI 请求来源条、在对应页签打开 |

- 分隔条 6px，悬停显示 2px 主色；拖动时全局 `col-resize` 并禁用选中。
- 宽度按项目独立记忆（实现按 CR-045 `pane-resize` 契约，不在设计稿内伪造持久化）。
- 690 以下不适用；**960 以下**左栏与右栏改为覆盖式抽屉，中栏保持可用。

### 2.3 左栏：会话历史

- 只表达必要信息，沿用 CR-065 的列表语义：**状态用左侧 10px 标识、当前会话用背景高亮（无边框）、行操作收进「…」**。
- 状态标识：运行中＝旋转环；未读成功＝绿点；未读失败＝红点；已读＝留空占位。
- 行内附「来源页签」（需求／设计／任务／编码／文档／成果），用于证明**同一集合**而不是按页签分家。
- 分组：运行中置顶 → 今天 → 昨天 → 更早；底部「继续加载」按 CR-063 每批 20 条。
- 搜索框占位文案「搜索当前项目全部会话」，旁为「重置」；分批准入与搜索口径以 CR-063/065 为准。

### 2.4 中栏：当前会话

- 标题行：会话标题、来源与状态、`运行中` 徽标、**「项目级共享」**徽标、右栏开关。
- 消息：用户与 AI 以排版区分，不加「我 / AI · 模型」前缀（CR-056 规则）；引用 chip 可点击开右栏。
- 步骤条：沿用现行呈现（done/total、状态、耗时），不伪造步骤。
- 输入区：`+ 添加`、`@ 引用`、`/ 能力`、CLI、权限、发送／停止、统计与提示文案。
- 提示文案固定写明「切换页签、切换到首页或其他项目再回来，都会回到这条会话；执行不会中断」。

### 2.5 右栏：辅助栏

- 默认关闭；用户可开可关；顶部标签可多个并存并可单独关闭。
- 未选目标时显示**可预览入口列表**（文件／需求／知识／工具结果；办公为成果／知识／工具结果），不伪造内容。
- 预览类型：

| 类型 | 呈现 | 说明 |
| --- | --- | --- |
| 代码文件 | 行号 + 高亮目标行 | 只读，不触发编辑与自动保存 |
| 需求实体 | 标题、元信息、正文、AC 列表 | 只读；显示版本 |
| 知识文件 | 只读正文 | 受授权约束 |
| 办公成果 | 只读正文／表格文本 | 不宣称 Office 引擎能力 |
| 工具结果 | 摘要 + 说明 | 显式标注不内置浏览器 |

- 底部「在编码中打开／在需求中打开／在文档中打开」为显式回退；工作台内点击不跳页签。
- 不支持、无权限、目标不存在均显示明确错误，不阻塞会话输入、不伪造正文。

## 4. 未覆盖／需实现阶段补

- 真实持久化：宽度与右栏开闭按项目记忆需实现后验证，设计稿与原型均为内存态。

- 搜索、继续加载、行「…」菜单只呈现入口与文案，未做完整交互。
- Office 真实预览能力以实现阶段既有查看器为准；本稿不证明格式保真。
- **AI 请求开栏**的请求来源（真实工具事件）、审计与权限校验待 LLD；原型只实现请求通道与四种返回码。
- **浏览器内核、网页抓取、浏览器自动化**不在本稿，独立立项；原型只呈现请求占位与结果容器。
- 史诗/特性的预览目前回落到需求实体预览（同一数据源），其「子项摘要」形态待细化。

关键设计决定：

1. **不新建会话数据源**。编码项目读 `D.ai.sessions`，办公项目读 `OfficeAI` 的项目级会话（`OFFICE-*`），与右侧 AI 栏完全同源，这直接证明“会话不隔离”。
2. **单实例**。工作台本身就是会话视图，进入时收起右侧 AI 栏并记住原偏好，离开时恢复，避免同一会话出现两个视图或两套订阅。
3. **不重写既有视图**。其他页签只替换页签条以加入“工作台”入口，正文视图仍由原实现渲染。
4. **左栏、会话区与输入区全部复用 AI 侧栏现行设计**（2026-11-22 用户要求）：直接使用 `.ai-history`／`.ai-history-h`／`.ai-history-search`／`.ai-history-list`／`.ai-session`／`.ai-hist-*` 与 `.msg`／`.msg-body`／`.msg-time`／`.msg-user-block`／`.text`／`.tool`／`.ai-steps` 等现行类名，以及输入区 `.ai-composer-wrap`／`.ai-composer`／`.ai-tools`／`.ai-chip`／`.ai-send`／`.ai-stats`；样式全部来自 `ai.css`＋`cr063.css`＋`cr065.css`；工作台只在 `workbench.css` 里约束“常驻栏尺寸/边界”，不重定义内部外观。原有的 `wb-hrow`／`wb-msg`／`wb-bubble`／`wb-step`／`wb-box`／`wb-cbar`／`wb-cbtn`／`wb-send`／`wb-hint` 等自造样式已删除。
6. **借用 AI 侧栏浮层的机制**：工作台的 CLI／权限／模型／`+` 直接复用 AI 侧栏同一套浮层；浮层锚点在 `.ai-panel` 内，因此借用态（`body.wb-borrow-ai`）让面板以透明、仅承载浮层的方式渲染，隐藏面板自身 chip／textarea／统计但保留 `.ai-composer` 布局尺寸（否则浮层尺寸会算成 0），并让 `ai-anchors` 优先锚到工作台里可见的按钮。
7. **页签图标与文字页签必须视觉对齐**：图标用与文字相同的 flex 居中并加 1px 光学补偿（文字页签为 44px 行盒，中文视觉中心略低于几何中心），选中下划线与文字页签同宽内缩。**CR-082 后**：页签为「电脑图标 16px + 文字『工作台』」，改为 `gap:6px` 的普通 flex 行内对齐，去掉最小宽度与光学补偿，下划线回到文字页签口径；见 [UI-CR082](UI-CR082-工作台页签电脑图标与文字.md)。
5. **未使用的并行产物保留**：`workbench-v4/cr054.css`（22:11，`sc-` 命名空间，无任何引用）不是本稿产物，未修改、未引用、未删除。

## 6. 设计与实现的关系

- 本轮只改需求与设计／原型资源，未修改 `src/`、`src-tauri/`、依赖或构建产物；设计稿与原型均不读写磁盘、不连接模型、不发网络请求。
- 设计稿确认与授权后，实现须先登记采用版本，再按 AGENTS §6.3.1 做同条件设计/软件对照。
- **原型同步不等于正式实现**：原型只证明设计可在真实业务数据上成立，不证明桌面端已具备该能力。
