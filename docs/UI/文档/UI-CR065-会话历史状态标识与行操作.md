## 1. 设计目标

1. 列表安静：不写「已读 / 未读 / 当前」，状态只用一个 10px 标识。
2. 选中明确但不打扰：只用背景色，不加边框、不引起位移。
3. 常用操作就近：hover 出现「…」，复制 / 分叉 / 置顶 / 重命名 / 删除都在一行内完成。
4. 底部不重复：去掉重复的「新会话」与 token 汇总，列表直接延伸到底。

## 3. 规格

### 3.1 行与选中

| 项 | 规格 |
| --- | --- |
| 行容器 | `padding: 9px 10px`、`border-radius: 6px`、`border: 0`（不设边框，避免选中时 1px 位移） |
| 选中 | 背景 `--primary-soft`（浅色 `rgb(238,243,255)`）；hover 保持同色，不叠加 |
| hover | 背景 `--hover-bg` |
| 左侧标识位 | 固定 10×10，`margin-top: 5px`；空状态也占位 |
| 行尾 | 只有「…」按钮（24×24），不再有状态文字或删除图标 |

### 3.2 状态标识

| 状态 | 视觉 |
| --- | --- |
| 运行中 | 10px 圆环，1.5px `--primary-line` 边框 + `--primary` 顶边，`.8s linear infinite` 旋转 |
| 已读 | 空（透明占位） |
| 成功未读 | **双圈靶心**：1px 绿环 `--good-dot` + 4px 绿点，10px 容器居中 |
| 失败未读 | **双圈靶心**：1px 红环 `--bad-dot` + 4px 红点 |
| 待处理 | **双圈靶心**：1px 橘环 `--warn-dot` + 4px 橘点 |

> 2026-11-22 用户选定方案 E「双圈靶心」替换原 6px 实心圆点（理由：实心点视觉过重）。

- 每个非空标识带 `role` 与 `aria-label`（运行中 / 未读 · 成功 / 未读 · 失败 / 待处理），颜色不是唯一信号。
- 当前会话已读时同为空（进入会话即 markRead）。

### 3.3 底部

- 浮层底部**不保留任何栏位**：没有按钮、没有 token 汇总、没有分隔线。
- 历史列表直接延伸到底边；每行的元信息已显示 tokens，不在底部重复。
- 原「新会话」入口由 AI 侧栏头部 `+` 承担。

### 3.3.1 底部三统计的空态（2026-11-22 追加）

- **无数据不显示内容、但保留占位高度**（用户追加要求：否则有数据时会把输入区顶上去造成位移）。
- 三项各自判断，只有存在真实数据才可见：
  - 会话统计：`rounds > 0` 或 `msgs > 0`；
  - Token 用量：`tokensIn + tokensOut > 0`（未知不显示）；
  - 上下文：`contextUsed / contextLimit` 可计算（只有窗口未知时也不显示「上下文 未知」）。
- 三项都无数据时，`.chat-stats` 仍渲染并保持 `min-height: 25px`，内容 `visibility: hidden`；有数据后同一高度内直接出现，不改变输入区位置。

### 3.4 重置按钮

- 文案「重置」，胶囊样式与搜索行一致。
- 搜索态：主色字 + 浅色底（`.on` 语义），可点击。
- 空关键词：`opacity: .45`、`cursor: not-allowed`、`disabled`。
- 点击：清空关键词、回到第 1 页 20 条。

### 3.5 行操作与菜单

| 项 | 规格 |
| --- | --- |
| 「…」按钮 | 24×24、图标 `more`、默认 `visibility:hidden`；行 hover 或 `:focus-within` 显示；聚焦有 2px 主色外框 |
| 菜单容器 | 绝对定位在按钮下方 4px、右对齐；`min-width: 168px`；1px `--line` 边、8px 圆角、`--shadow-pop`、`z-index: 72` |
| 菜单项 | 高 30px、11.5px、图标 13px + 文案；hover `--hover-bg`；删除项 `--danger` |
| 置顶项 | 未置顶显示「置顶」，已置顶显示「取消置顶」 |
| 分叉项 | 运行中 `disabled` + `opacity: .45`，`title` 说明原因 |
| 关闭 | 外点、Escape、滚动、切换会话 |

### 3.6 置顶

- 置顶行标题前显示 12px 向上箭头（`--primary`），行排到列表最前。
- 不新增分组标题；置顶组内按置顶时间倒序由后端排序保证。
- 取消置顶后箭头消失，回到时间序。

### 3.7 原位重命名

- 点击菜单「重命名」后，该行标题**原位**变为输入框：预填当前标题、自动聚焦并全选。
- 输入框与标题同位置、同字号（12px），只有 1px 主色下边线；不改变行高与行内其他元素位置。
- 保存：Enter 或失焦；取消：Escape。
- 空标题：提示「标题不能为空」并结束编辑，恢复原标题。
- 编辑态行不触发会话切换；「…」按钮仍可见，菜单关闭。
- 不出现弹窗。

## 6. 覆盖缺口与限制

1. **设计稿窄屏限制**：`workbench-v4` 在视口 <960px 时由 `pane-resize` 收起 AI 侧栏，历史浮层隶属该面板，设计稿无法直接呈现窄屏抽屉（与 UI-CR063 §6 同一既有机制）。窄屏对照以正式软件为准：软件侧 `chat.css` 已有 `@media (max-width:960px)` 全宽规则，需在本版实现后单独验证菜单不溢出。
2. **菜单裁剪**：设计稿菜单在行内绝对定位，列表底部行的菜单可能被列表 `overflow:auto` 裁剪；正式实现建议用 portal/fixed 定位，或确保菜单在下拉时列表可滚动。设计说明按“菜单向上/向下自适应”实现。
3. **复制 ID**：设计稿仅在 `localhost`/`file://` 演示剪贴板，`file://` 下浏览器可能拒绝；正式软件需用 `navigator.clipboard` + `execCommand` 回退，并提示失败。
4. **分叉的后端语义**：设计稿只复制前端对象；正式实现须按 LLD-CR065 §2.4 复制消息且不继承原生绑定。

- 逐场景：C64-01～C64-09，重点检查无边框选中、无状态文字、token 格式、重置禁用、菜单五项与置顶图标。
