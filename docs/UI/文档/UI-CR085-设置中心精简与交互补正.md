## 1. 视觉和保存边界

模型管理标题和“新增供应商”放在设置固定头部；生图仍为独立图标，右上X保留。供应商展开不挤动操作栏。密钥行显示启用复选框、别名、首尾掩码、紧随复制图标、协议浮层入口、全部模型/N个模型、编辑、删除。添加密钥为36px整行居中按钮。桌面列表一行，窄屏保留可达动作并自然换行。

供应商ID／名称一行两列，已有ID字段连同外框置灰禁用；创建首次保存前ID可指定，留空生成。端点无开关，空值默认仅显示“＋ OpenAI 地址／＋ Anthropic 地址”，点击打开输入；填入自动启用，清空禁用。两个入口在编辑时都存在，不限制新增时机。

密钥编辑为别名／密钥同行两框，取消、保存右对齐；新增同形表单。模型范围只在一个按钮处显示，内联卡片选择独立草稿，明确保存／取消，不另展示第二个范围文本。协议为挂载在顶层dialog内的fixed菜单，默认向下、下方不足向上，禁用未配端点协议。模型获取清单单行28px，名称和ID横排，长内容省略；清单结果不等待能力查询。自动能力回填有来源才标模态选中，未知不猜，已有手选不覆盖。

模型检测结果桌面固定108px，六个固定槽位：状态、评分、等级、真伪、渠道、耗时；所有历史同锚点，摘要两行固定高度，长值省略；窄屏固定三列两行182px。模型候选仅显示名称，值仍为稳定ID。保留20针与归因面板。

CLI按各自能力获取权限；跟随主agent保留默认，兜底可指定兼容模型。思考档位按当前模型配置，未配禁用。SDK折叠头过期时显示当前→最新及“有新版本”，不显示已安装标签。合并安装按钮按当前/目标关系呈现，安装中禁重入。刷新合并本机检测与版本更新。操作记录右下sticky入口，打开最近五条记录与对应日志，长日志独立滚动。

Skill列表统一行高，描述两行省略，完整说明及正文在编辑查看；导入副本与本地技能同样可编辑。MCP列表直接显示启停／编辑／验证连接，表单内无启停；命令与args分开保存；结构化导入不二次拆分字符串。Tools默认折叠，不含CLI原生，内置分基础／项目与需求／知识库／服务器等业务分类，仅标“内置”。
