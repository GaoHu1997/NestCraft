# UI-ICON-001-v1：平台图标与组件基准

- 归属：CR-044／FEAT-001／STORY-064 AC27～29。
- 可查看样例：[平台图标样例](UI-ICON-001-图标样例.html)，仅为UI规范资料，不是产品页面或第二原型入口。平台及业务原型无图标展示入口，只有现有图标替换。
- 资源：`workbench-v4/icon-sprite.svg`、`cr044.css`；图标样例位于 `文档/`，不接入软件或业务原型。
- 平台通用113个语义图标＋兼容别名；每个 symbol 24×24，描边1.6px、round cap/join，默认无fill。unknown单独错误标识不包含在113个产品语义中。
- 分组：窗口／导航、文件／资料与格式、编辑／布局、AI／工具／运行、状态／设置；不是业务权限库存。
- 显示：14px紧凑／16px默认／20px大入口；不以字符×、✓或字母块代替正式图标；图标按钮32／28，窗口控制46×32，文字间隔6。
- 颜色：平台图形使用 currentColor＋主题令牌，支持hover／focus／disabled／selected；官方品牌保留原图形与原色，不强套平台stroke。
- 官方CLI：Claude品牌星芒、Codex采用OpenAI官方厂商标志、Grok产品图形，来源与派生方式在 `workbench-v4/brand-icons/NOTICE.json`。它们不是已核定的CLI专属新Logo。Dsh仅原型演示且无核定官方标志，明确not available，不映射其他品牌。
- 界面帆船透明无背景／边框，系统shortcut/taskbar使用独立薄荷底图；两个用途不得混用。
- 弹窗基准：确认460／普通620／预检760／文档820／设置1040×700，视口内边距至少12×24、仅正文滚动、最顶层Escape。
- 对齐：56px顶栏；整宽40px首页／对象Tab；对象内部44px页签与AI头共用基线；1px结构分割線连续，间距使用4／8／12／16阶梯。
- 验证边界：语法／symbol映射／DOM加载检查不等于图像视觉一致。实际测试与采用版本见 [REPORT-CR044](../../Test/REPORT-CR044-窗口图标与导航调整.md)。
- 滚动条统一义务（2026-11-21，UI-SCROLL-001／CR-049）：任何超高内容区域只在实际滚动时显示，最后滚动700ms后隐藏；悬停／聚焦不单独唤醒，显隐不改变正文宽度、不禁用原生滚动、不丢编辑状态。开发必读[UI-CR049-v1](UI-CR049-滚动条按需显示.md)，纳入工作包及动态行为／视觉验证，不以静态截图无滚动条视为通过。本项是现行新增设计约束，尚非正式软件实现事实。


## CR-051：内置图标与用户头像风格增量（r1 已实现；r2 增量仅设计）

- r1 已落地：原型与正式软件新增 7 个符号（`ICON_NAMES` 113→120）、文件类型 14 类映射、项目 12／知识库 8 图标、头像 5 风格与内联 sprite 修复，见 [REPORT-CR051-正式软件实现](../../Test/REPORT-CR051-正式软件实现.md)。
- r2／r3 设计增量（未实现）：新增 33 个通用符号（总计 40）、项目与知识库共用 50 图标、10 个纯色块背景色卡、默认 B 与头像上传（≤200KB）、旧项目不动；设计稿见 [UI-CR051-v2](UI-CR051-内置图标与头像风格.md)。
- r1 新增 7 个符号：`fileMarkdown`、`fileHtml`、`fileAudio`、`fileVideo`、`fileUnknown`、`briefcase`、`library`；沿用 24×24、1.6px 描边、round cap/join、无填充，平台 113 图标与官方 CLI 品牌图形规则不变。
- 文件类型映射扩为 14 类（md／txt／pdf／docx／xlsx／csv／pptx／图片／代码／html／压缩包／音频／视频／未知），并新增文件类型色令牌（浅深各一套）；类型色只换颜色令牌，不改变图形与线宽。
- 项目／知识库使用图标砖：项目 36／26px（编码 `code`、办公 `briefcase`，12 选 1）；知识库 40px（按来源 `bookOpen`／`globe`／`layers`／`library`，8 选 1）。
- 用户头像使用品牌帆船 Logo，提供 5 种容器风格（A 原彩透明／B 薄荷／C 方砖／D 墨青反白／E 双环），在设置内切换；风格只改容器，不重绘 Logo、不加字母。
- 工程约束：既有 `icon()` 以外部 `icon-sprite.svg#id` 引用，`file://` 下会整片不可见；设计稿改为内联 sprite，实施时必须内联或构建期注入，并提供可见回退。
- 资源与覆盖：[UI-CR051](UI-CR051-内置图标与头像风格.md)、[设计稿](../icon-system/index.html)、[验证](../../Test/REPORT-CR051-内置图标与头像设计验证.md)。本项为增量设计，未修改正式软件；不替代既有基准。
