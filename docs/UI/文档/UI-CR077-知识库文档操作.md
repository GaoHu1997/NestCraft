## 左侧目录

- 背景 `#fafafa`，行高 35px。
- 顶部：返回首页按钮与当前库下拉。
- 「空间目录」旁的加号菜单：新建富文本、新建 Markdown、新建文件夹、导入、上传附件。导入提示为「支持MD，ZIP格式（图片和MD文件请放到同级目录并配置同级相对路径）」。上传附件不限类型。
- 行悬停显示加号和更多。更多含重命名、移动文档（复制文档、迁移文档）、删除。
- 文件夹图标为展开／收起两种，颜色 `#ffd149`。富文本图标 `#498ba7`，Markdown 图标 `#558ff2`。
- 底部：设置、回收站。
- 既有索引搜索框保留，不改其检索行为。

## 右侧编辑

- 阅读：标题、最近修改、编辑、更多（导出为 Word、删除）。
- 编辑顶栏：标题最多 40 字、保存、取消。取消确认文案为「确定要离开编辑页吗？离开后编辑的内容将不会被保存」。
- 富文本为居中纸张：工具栏宽 980px，正文容器宽 850px，白底、边框和阴影。
- Markdown 工具包含粗体、斜体、标题、下划线、删除线、标记、上下角标、引用、列表、链接、图片、代码、表格、撤销、重做、清空、保存、双栏、预览、全屏、阅读、导航、对齐。

## 设置与回收站

- 设置卡片：空间名最多 25 字，空间说明最多 250 字，保存设置。
- 回收站表：名字、删除时间、操作人、恢复、彻底删除。恢复确认文案为「确定要恢复此页面吗？如果该页面的父页面也被删除，则需父页面恢复后才可看见此页面」。彻底删除确认文案为「确定要彻底删除此页面吗?」。
