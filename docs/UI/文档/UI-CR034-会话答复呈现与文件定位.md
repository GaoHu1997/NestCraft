## 0. 设计目的

把「模型答复」从纯文本流提升为可操作结构：工具调用与结果成为一个可读单元，代码有格式框，图片有预览框，文件路径可点击并在左侧定位到行。本轮只产出可视设计与规格，不修改正式软件。

## 2. 布局与尺寸规格

### 2.1 工具块（Tool Block）

```
┌──────────────────────────────────────────────┐
│▌ Read   src-tauri/src/commands/chat.rs:500-530│  ← 头部：3px 状态条 + 工具名 + 参数摘要
│  成功 · 12ms                        ⌄ 结果    │  ← 状态 + 耗时 + 折叠开关
├──────────────────────────────────────────────┤
│ 500  let trimmed = line.trim();              │  ← 展开区（默认折叠）
│ 510  eprintln!("...", &trimmed[..120]);      │
└──────────────────────────────────────────────┘
```

| 项 | 规格 |
| --- | --- |
| 容器 | 宽 max 92% 对齐消息列；`--paper` 底；1px `--line-soft`；圆角 `--radius-card`；左内嵌 3px 状态条 |
| 状态条颜色 | 运行中 `--accent`；成功 `--good-dot`；失败 `--bad-dot` |
| 头部 | 单行，高 32px；工具名 13px/600；参数摘要 12px `--muted` 省略号；状态文字 12px（不只靠颜色） |
| 折叠开关 | 右侧「结果 ⌄」，`aria-expanded`；键盘可聚焦 |
| 展开区 | 顶部 1px `--line-soft` 分隔；`--pre-bg` 底；等宽 12px/1.6；内边距 8px 10px；最大高 240px 内部滚动 |
| 失败态 | 头部状态条与状态文字用 `--danger`；默认展开；错误摘要保留尾部诊断，中部截断并标注「已截断」 |
| 空结果 | 展开区显示「无输出」，不上空框 |
| 配对缺失 | 头部右侧加 `tag warn`：「结果未返回」或「来源调用未记录」 |
| 多个工具 | 同一 assistant 消息内按出现顺序纵向排列，间距 6px |

### 2.2 图片预览（Image Preview）

| 项 | 规格 |
| --- | --- |
| 容器 | `display:inline-block`；`max-width:100%`；圆角 `--radius-ctl`；1px `--line`；`--paper` 底 |
| 图片 | `max-width:100%`；`max-height:360px`；`object-fit:contain`；`display:block`；不裁切 |
| 说明 | 底部 12px `--muted`，内容为 `alt`，缺省用文件名；左对齐内边距 8px |
| 放大 | 点击打开浮层：遮罩 `--backdrop`；图片 `max-width:90vw`/`max-height:86vh`；右上关闭；Esc/遮罩点击关闭；关闭后焦点回到原图 |
| 失败 | 160×120 占位框（`--inset` 底 + `--line` 虚线边）+ 「图片加载失败」+ 原始路径 12px 可选中 |
| 加载中 | 同占位框尺寸 + 骨架条 400ms 起显示 |

### 2.3 文件定位链接（File Link）

| 项 | 规格 |
| --- | --- |
| 触发 | 文本中匹配 `路径:行[:列]`；路径须为项目根内相对路径或绝对路径 |
| 形态 | 主色 `--accent`；hover 下划线；`cursor:pointer`；键盘 `Tab` 可聚焦并显示焦点环；`title`=完整路径+行列 |
| 行号 | 紧随路径，等宽 12px，浅底徽标（`--tag-bg` + `--tag-ink`），与路径视觉分离 |
| 不可用 | 路径越界 → 渲染为普通 `code`，不可点击，`title` 说明「不在项目目录内」 |
| 非项目上下文 | 渲染为链接但点击行为为「复制路径」并 toast 说明 |
| 失败 | 文件不存在/读取失败 → toast 明确原因，不改变当前打开文件 |

### 2.4 代码块（Code Block）

| 项 | 规格 |
| --- | --- |
| 容器 | 沿用现行（`--pre-bg`、1px `--line-soft`、圆角 6px、内边距 9px 11px、横向滚动） |
| 语言标识 | 右上角 11px `--muted`，取自 fence 语言；未知不显示 |
| 长块折叠 | >40 行默认折叠，底部按钮「展开全部（共 N 行）」；展开后可「收起」 |
| 行内代码 | 沿用现行（`--pre-bg` + 1px 边 + 4px 圆角） |

### 2.5 思考块（Thinking）

| 项 | 规格 |
| --- | --- |
| 形态 | 沿用虚线框 + `--inset` 底 |
| 收起态 | 「思考过程 · {N} 字」；流式中自动展开并显示「…」光标 |
| 展开态 | 最大高 220px 内部滚动；12px `--muted`；保留换行 |

### 2.6 执行配置回填（Composer）

| 项 | 规格 |
| --- | --- |
| 正常 | CLI / 模型 / 思考档位下拉显示会话已存的实际值 |
| 失效 | 值以删除线或 `tag bad` 标注「已失效」，下拉仍可打开修复；发送按钮禁用并显示原因 |
| 未选择 | 仅当会话从未存过值时显示「未选择」 |

## 4. 交互流程

1. **点击文件链接**：解析路径与行列 → 校验在项目根内 → 若当前非编码页签则切换 → 左侧文件树定位并在编辑区打开（已开则激活）→ 编辑器滚动到行 → 行号槽高亮 2s 渐隐 → 焦点交给编辑器。
2. **点击图片**：打开浮层 → 加载原图 → Esc/遮罩/关闭按钮关闭 → 焦点回到原 `<img>`。
3. **工具块展开**：点击头部或「结果 ⌄」→ 展开内容（懒加载，避免长会话一次性渲染）。
4. **配置失效**：检测到已存 CLI/模型不可用 → 下拉值保留并标注 → 发送禁用 + 原因条 → 用户改选后恢复。

## CR-076 聊天输入与答复呈现

本节为用户授权代码先行后的交互回填，覆盖侧栏与工作台的共享聊天区。可操作设计版本和成对证据由集成记录登记。

| 场景 | 交互 |
| --- | --- |
| 输入和引用 | `+` 提供图片及引用入口。`@`、`/` 按光标位置唤出选择层，支持键盘选择、Esc、点击外部关闭；插入后恢复输入焦点。已选引用可移除。MCP按服务或工具名过滤，服务命中保留其工具、工具命中仅显示匹配项；闭合服务的工具和禁用/不可见行不进入上下键序列，展开不触发全页重绘。 |
