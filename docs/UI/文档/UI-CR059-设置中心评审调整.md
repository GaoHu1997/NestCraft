- 拖动手柄：grab 光标，按住上下拖动出现插入指示线（目标卡片上/下缘 2px 主色线），松手保存顺序；键盘聚焦手柄后 Alt+↑/↓ 等价移动。
- **协议＝一行均分卡片**（r5/G8）：Chat/Responses/Anthropic 三个等宽按钮，选中高亮；不是下拉，无对勾。
- **端点固定两种**（r5/G7）：只有 OpenAI 与 Anthropic 两个地址输入框；「更多端点」只展开/收起第二个；**没有「添加端点」，也没有其他协议**。
- **供应商 ID 与名称分离**（r5/G6）：ID 只读、创建后不可改、路由按 ID；名称可改、不影响引用。
- 密钥协议下拉只列「默认＋已有端点地址的协议」；Chat 与 Responses 同属 OpenAI 端点。
- **浮层定位（r7/G10）**：`position:fixed` 由脚本锚定协议按钮——右边缘对齐按钮、**默认向下展开**（下方空间不足才向上）；视口 8px 内夹取，容器最高 260px 并可滚；正文滚动时浮层自动关闭（避免与按钮脱位）。原 `absolute` 方案会被 `.key-list{overflow:hidden}` 与 `.set-scroll` 裁掉，已废弃。
- 密钥模型小卡片全不选＝全部模型；选中态**只用高亮**（描边＋浅底＋字色），不放对勾、角标或任何其他标识（r5/G5）。
- 密钥行内表单与获取模型弹层的按钮：**取消在左、保存在右**（r5/G5）。
- 底部：「放弃修改」（左）→「保存供应商」（右）。

### 1.2 模型配置（STORY-076 AC-06～10、13）

- 工具栏：`N 个模型 · 拖动手柄排序 · 点击展开` ＋右侧文字按钮「自动获取思考等级」「手动添加」「获取模型」。
- **「自动获取思考等级」＝批量**（r5/G1）：只处理**尚未配置档位且非生图**的模型，逐个解析并回显；命中标注来源，未命中的保持空并提示「N 个未找到可信档位，需手动配置」。
- **模型表单内「一键获取」**（r5/G1）：作用域仅当前模型，同一解析器。
- **思考开关位置**（r6/G9）：开关紧跟「思考」标题右侧（间距 8px），不再推到行末；「一键获取」仍在行尾（右对齐）。
- **模型表单没有「保存模型」**（r5/G2）：底部左侧说明「修改随『保存供应商』一并保存」，右侧「放弃修改」；保存统一走供应商。
- **模型列表可拖动排序**（r5/G3）：每行行首拖动手柄，插入指示线，松手保存；键盘 Alt+↑/↓ 等价；顺序即会话候选顺序。
- 获取模型弹层：卡片网格，每卡＝显示名＋mono ID＋上游明确给出的上下文；点选高亮（r5/G5：**无对勾**，只用高亮）；保存只收清单字段，视觉未知直接存未知。
- 模型行标签：模态 tag、视觉未知（琥珀）、档位未配（琥珀，提示可批量补齐）。
- 两级来源规则：①供应商推理信号 false → 清空档位并标注；②本地知识库命中 → 填档位＋默认档＋已知容量；③未命中但供应商确认 true → 通用阶梯（中置信）；④全未知 → 提示手动配置，不猜测。
- 表单底部三列一行：默认思考强度（默认「跟随记忆」）／上下文窗口／最大输出；无「状态」字段。

```
收起（默认，整块只占一行）：

│ 权限模式 [代理模式 ▾]                                    │
│ [保存] [重新检测]  保存仅影响之后的新会话。              │

悬浮模型标签（出现 × 删除）：
│ [兜底模型][模型1 ×][模型2][＋新增]                  2/5 [˅]│

展开「模型1」：
│ [兜底模型][模型1][模型2][＋新增]                    2/5 [˄]│
│ ├ 模型 [TierFlow · tierflow-pro ▾] 思考等级 [high ▾]   │

│ [兜底模型][模型1][模型2][＋新增]                    2/5 [˄]│

│ │  思考等级 [沿用会话 ▾]                                │
│ └ 任一模型槽不可用时使用；兜底模型不可删除              │
```

- **唯一折叠行**：整块路由只有一个 `.route-bar`，不含任何逐槽卡片。行首为标签组 `兜底模型` + `模型1 … 模型5` + 未达上限时末尾的「＋新增」（2026-11-23 调序：兜底置首）；行尾 `N/5` 与折叠箭头。默认收起并选中兜底模型。
- **标签样式统一**：模型标签与兜底标签同一结构、字号 12px、高度 26px、圆角 6px、同样的悬浮与选中态；不再有任何「已配置」圆点或角标。
- **展开与切换**：点行内空白或箭头展开下方唯一详情区；点任一标签切换详情内容并保证展开；`aria-selected` 仅一项为真。
- **详情内容一致**：模型标签＝模型下拉 + 思考等级 + 13 类任务 chips + 「删除此模型槽」；兜底标签＝兜底模型下拉（默认「跟随主 agent」）+ **思考等级**（选项同为「沿用会话」/off/low/medium/high/xhigh/max）+ 说明，**无删除入口**。
- **删除入口（×）**：模型标签为 × 预留右侧内距（避免悬浮时文字被挤压跳动）；默认 `opacity:0` 且不接收指针事件，标签悬浮或 × 自身聚焦时显示；点击即删除该槽，与详情区底部「删除此模型槽」等价。**兜底标签不渲染 ×，不可删除。**`@media (hover:none)` 触摸设备上 × 常显以保证可操作。
- **新增**：点「＋新增」追加空槽并选中该标签；5 个后不再渲染新增按钮，行尾 `5/5`。
- **删除归位**：删除后标签重排、选中态落到原位置（越界取末位）；删至 0 个只剩「兜底模型」且自动选中，行尾「仅兜底」。
- 无「最低任务难度」、无 CLI 级「任务类型」字段。
- 同一任务类型命中多槽时按槽位顺序取第一个（设计说明；实现契约在 LLD 固化）。
- Grok 标志（2026-11-23 修正）：官方资源画布为 88×33，但图形实际只占左侧约 33×32，右侧是空白；按高度缩放会把可见图形推到左侧、视觉重心偏移。现把 SVG 的 `viewBox` 裁到图形真实边界（`0.36 0.5 33.34 32`，即方形），与其他方形标志同样按 `object-fit: contain` 填满槽位（20px 槽 → 20×20），左缘对齐、等比不裁切不变形。原「横版字标按高度缩放＋定宽槽居中」特例规则已移除。
- 加载演示：打开页签首帧即渲染缓存列表，逐卡短暂「检测中…」tag 后定格（stale-while-revalidate 演示）；「重新检测」强制单项刷新。
