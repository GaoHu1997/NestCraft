## 1. 布局

设置左栏在「模型管理」下方新增「模型检测」页签；页签内容为独立检测页，**不使用外层卡片框**，与通用 / 模型管理等设置页一致采用「小节标题 + 平铺内容」结构（`.probe-section` 仅作布局容器，无背景、边框、圆角、阴影）。

r6 纵向顺序（自上而下）：**标题行（含历史记录入口） → 供应商/模型选择 → 结果区 → 19 针探测列表**。

> r6 调整：结果区必须**紧贴 19 针列表上方**，中间不插入供应商选择框或说明文字；结果区与逐针列表构成一组「结论 + 明细」，视觉上不可拆开。

```
┌──────────────────────────────────────────────────────┐
│ 🛡 模型检测                              [🕘 历史记录] │
│    固定 9 针黑盒探针 · 检测中转掺水 · 结果仅本地展示      │
│ ┌──────────────┐ ┌──────────────────────┐ ┌─────────┐ │
│ │ 选择供应商 ▾  │ │ 选择模型（联动）▾     │ │ 开始检测 │ │
│ └──────────────┘ └──────────────────────┘ └─────────┘ │
│ 端点与密钥自动取自已保存配置，无需填写；历史保留最近 10 次 │
│ ┌──────────────────────────────────────────────────┐ │
│ │ P1 ● 连通与鉴权握手            HTTP 200 · 214ms   │ │（9 行，超高滚动）
│ │ P2 ● 模型回显与跨档偷换         请求 lite → 回显 mini│ │
│ │ …                                                    │ │
│ └──────────────────────────────────────────────────┘ │
│ 96/100  [S]  真伪·真实  渠道·官方直连  9.8s            │
│ 流式真实、金丝雀与锚点完整回显、原生工具调用正常…          │
└──────────────────────────────────────────────────────┘
```

- 供应商下拉只列**已启用**供应商；模型下拉联动列出该供应商已配置且非生图模型；未选供应商时模型下拉禁用并显示「先选择供应商」。
- 「开始检测」在未选齐或运行中时禁用；运行中按钮显示「检测中…」，供应商/模型下拉同步禁用。
- 历史记录按钮固定在区块头部右上角，**点击展开悬浮下拉框（不是弹窗）**：下拉内每行只显示「探测时间 + 供应商名 + 模型 ID + 分数 + 等级」；点击某行后下拉立即收起，结果区与下方 19 针列表同时切换为该次历史结果（结果区额外标注「历史回看 · 时间」）；点击外部或按 Esc 收起下拉。
- 结果区三态（**高度固定 108px，三态切换不引起下方 19 针列表位移**）：
  - ① **待检测**：虚线边框；单行「待检测 + 当前目标（供应商 · 模型）」。不铺 19 针 chip，也不放上次检测摘要——保持与另两态等高、视觉稳定。
  - ② **检测中**：高亮边框 + 当前探针名（如「P7 隐藏注入与套壳嗅探」）+ `已完成数/19` + 进度条。
  - ③ **已检测**：分数 / 等级徽章 / 真伪 / 渠道 / 耗时 / 一句话结论（结论最多 2 行，超出省略，不撑破固定高度）。

## 2. 状态覆盖

| 状态 | 呈现 |
| --- | --- |
| 初始（未选供应商） | 模型下拉禁用、开始检测禁用；无进度与结论区 |
| 已选供应商未选模型 | 模型下拉可选；开始检测仍禁用 |
| 运行中 | 9 行逐针列表：已完成行显示状态点+耗时+证据摘要；当前行蓝色脉冲点「探针执行中…」；未到行灰色等待点；按钮「检测中…」 |
| 完成 | 逐针全部定格；结论条：总分/100 + 等级徽章（S/A 绿、B 蓝、C 黄、D 红）+ 真伪标签 + 渠道标签 + 总耗时 + 一句话结论；toast 提示完成并标注演示数据 |
| 检测失败前置条件 | 停用供应商不入下拉；正式软件中无启用密钥/端点时报错提示且不产生历史（AC-10） |
| 历史悬浮下拉 · 有数据 | 右上角按钮点击后在其下方展开悬浮框（宽 320px，右对齐，最多 10 条）；行：探测时间、供应商 + 模型 ID、分数、等级徽章；点击行收起下拉并回填结果区与 19 针列表 |
| 历史悬浮下拉 · 空态 | 「还没有检测记录」 |
| 历史回看态 | 结果区显示该次分数/等级/真伪/渠道/耗时 + 「历史回看 · 时间」标签；下方 19 针列表显示该次逐针明细；选择器旁出现「退出历史回看」按钮 |

探针状态语义：通过（绿）/ 警示（黄）/ 不通过（红）/ 未执行（灰）/ 不适用（浅灰，非视觉模型的识图针、Anthropic 协议的 responses 与缓存针等协议或能力边界）；运行中为蓝色脉冲。19 针名称与顺序见 CR-058 §2 表格，UI 不提供任何选择入口。逐针列表 19 行仍受 max-height 滚动约束（CR-049 适用）。

## 3. 交互一致性

- 与供应商卡片同卡片语言：surface 面板、line 边框、r-md 圆角；结论徽章沿用 tag/状态色令牌。
- 历史弹层沿用 dlgShell 子弹层机制，关闭按钮 data-act="close-sub"。
- 检测运行中禁止：重复开始、切换供应商/模型（禁用）；完成后可再次运行覆盖当前展示（历史已保存）。
- 演示行为说明：原型中点击开始检测播放逐针动画（约 2.7s），结论按所选模型命中夹具（lite/mini/flash → 检出偷换；local-* → P8 警示；其余 → 全通过）；正式软件为真实请求。

## 4. CR-049 滚动条适用（UI-SCROLL-001）

- 适用滚动区域：① 逐针进度列表 `.probe-rows`（max-height 264px）；② 历史弹层列表 `.probe-hist-list`（max-height 380px）。
- 行为：滚动条默认隐藏，实际滚动时显示、停止 700ms 后隐藏；由 `scrollbar.js` 全局捕获滚动统一驱动，本区块 CSS 仅声明 `overflow-y:auto` 与 max-height，不使用 `overflow:hidden` 禁滚、不切换滚动条宽度，正文宽度与输入状态不受影响。
- 正式软件义务：同规则登记于 STORY-075（AC-12），验收需动态滚动证据，静态截图不作数。
