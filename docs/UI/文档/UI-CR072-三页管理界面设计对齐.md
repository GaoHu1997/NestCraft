## 3. 关键视觉要点（与当前软件差异）

- 项目卡片：缺 描述、标签、进度条、负责人；当前为「本地路径/类型标签/暂未接入文字/删除」。
- 搜索 placeholder：软件「搜索项目名称、编号或目录」→ 设计「搜索项目、负责人或标签」。
- 知识库卡片：软件网格 + 来源路径 + 多按钮 → 设计单列 + 描述·负责人 + 授权项目名。
- 服务器卡片：软件指标「未知」+ 行内按钮 → 设计 百分比指标 + 分组·系统 + 点击进入。
- 页脚统计：软件缺或口径不同 → 设计有页脚统计（正式软件用真实口径）。

## 4. 允许差异（明示）

- 设计稿为虚构夹具（4 个样例项目、负责人、进度、指标为演示值）；正式软件用**真实数据**，因此数值与项目数量会不同，属于预期差异，不算视觉偏离。
- 页脚文案：设计稿「全部为虚构样例，不读取真实目录」不适用于正式软件，改为真实口径（如「共 N 个项目」）。

## 5. 对照与验证计划

- 同视口（1440 浅色为主，深色/窄屏按现有能力）、同数据口径下对三页做设计—软件截图对照，登记设计版本、实现版本、预期/实际/差异结论。
- 功能验证：搜索、筛选、打开、编辑保存、连接采样、空态与错误态。
- 滚动条按 UI-SCROLL-001：列表超高时仅滚动时显示。
