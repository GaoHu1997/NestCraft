## 1. 布局

设置弹窗尺寸不变（1040×700，左栏 224px）。正文顶部是一条粘附工具条：左侧六个分组跳转（个人资料 / 外观 / 会话 / 主机默认 / 数据 / 关于），右侧为“已保存”或“N 项未保存”＋“放弃”＋“保存”。

正文为六张分组卡片，卡头为图标＋组名＋可选状态标签（仅用于显示 / 不影响已建主机 / 重启后生效 / 版本号）。卡内采用 168px 标签列＋控件列：

1. **个人资料**：第一行是独立字段“头像”，控件只有一个小头像按钮（34px，悬停出现相机角标），点击在浮层内修改；其后是显示名称、邮箱、角色、时区。组标题行不放头像，也不常驻头像预览、更换按钮或风格按钮。
   浮层（318px 宽，锚定在入口下方，空间不足时翻到上方）内含：60px 大预览、五个风格选项（各自按自身风格渲染）、上传图片、恢复默认、取消与应用。点外部、Escape、取消都回到打开前；点应用后入口头像与草稿同步并计入未保存；保存前不写入设置。
2. **外观与显示**：界面主题（三档）、界面密度（两档）；“代码编辑器”子块含代码高亮（跟随界面/浅色/深色）、字号（12–16）、Tab（2/4）、自动换行、预览。
3. **会话与行为**：生成中再次发送（立即发送/排队）、完成后通知、启动时恢复窗口。
4. **新建主机默认值**：默认端口、默认用户、默认认证；高风险命令确认以只读策略行呈现（锁图标＋“属强制安全策略，不能在此关闭”）。
5. **数据与存储**：数据存储位置（输入＋选择目录＋打开目录）、占用明细（四行，含占比条）、知识库目录（只读＋复制路径）。
6. **关于**：版本 v0.0.5＋检查更新、日志目录（只读＋打开）、恢复本页默认值。

保存入口只在顶部工具条，不再在页尾重复；恢复默认放在“关于”组，属次要危险操作并需二次确认。

## 2. 交互与状态

- 所有控件只写草稿；保存前界面已即时预览主题与密度。
- 头像在浮层内预览，只有点“应用”才进入草稿；浮层未应用时点外部、Escape 或取消都回滚。放弃或确认放弃即回滚已预览的主题与密度。
- 校验收敛到一次保存：邮箱格式、名称 ≤40 字、角色 ≤24 字、字号 12–16 整数、Tab 2/4、端口 1–65535、用户名 `[A-Za-z0-9._-]{1,32}`、各枚举合法。错误字段 `aria-invalid="true"`＋标红＋一句原因，焦点落到首个错误。
- 有未保存改动时，X、遮罩、Escape 都先弹出“放弃未保存的更改？”二次确认，确认后关闭并回滚。
- 分组跳转点击后滚到对应分组；滚动时高亮当前分组（`aria-current`）。
- 说明文字上限一句，不恢复被 CR-085 删除的说明块；保留 `placeholder`、`aria-label` 与开关自身语义。

## 4. UI-SCROLL-001

采用 [UI-CR049-v1](UI-CR049-滚动条按需显示.md) 与 [CR-049](../../PRD/CR-049-滚动条仅在滚动时显示.md)。本页不新增滚动容器：正文仍用 `.set-scroll` 原生滚动，代码预览随字段说明自动换行或按需横排，不设独立 overflow。顶部工具条为 `position: sticky`，不产生第二滚动条。动态证据为 `09-scroll-idle`／`10-scroll-active`／`11-scroll-stopped` 三帧；嵌套与原生编辑区保持沿用设置页既有结论。

## 5. 版本、继承与准入

- v1 建立于 2026-11-25，基于 CR-091。与 CR-085 的关系：CR-085 的“说明精简”“设置头只留标题与业务操作”“保存按钮在右侧”继续有效；本版在其上细化通用页分组，并明确允许“每字段一句必要说明”，不恢复说明块与重复引导。
- 被替代：`legacySetContent('general')` 的六区块顺序与 `main.js` 中 `set-code-theme`／`set-send-mode` 的“关闭并重开”行为，仅在通用页范围内不再适用；其它页原样保留。
- 正式开发前须逐条核对 AC、本表场景与资源指纹，并取得明确编码授权；设计通过不等于软件修复或验收。
