# UI-CR093：设置 · 搜索

- 关联：[CR-093](../PRD/CR-093-AI本地与联网搜索工具.md)／[LLD-CR093](../LLD/LLD-CR093-AI搜索工具.md)。
- 入口：设置弹窗左栏新增「搜索」页签（list 分类，位于「能力 · Tools」之后）。
- 复用现有设置壳（`set-modal` / `set-nav` / `set-body` / `card` / `btn` / `SettingsSwitch`），不新增全局视觉令牌。

## 页面结构（自上而下两张卡片）

### 卡片一：联网搜索
- 标题「联网搜索」+ 说明：默认免 API key（DuckDuckGo，Bing 备用）；配置 Tavily 后优先，失败/未配置回退默认。
- 行「后端」：单选 `默认（免 key）` / `Tavily`。
- 选中 Tavily 时显示：「API 地址」（默认 `https://api.tavily.com`）、「API Key」（password；已配置时 placeholder 显示「已配置（留空保持不变）」）。
- 行「超时（秒）」数字（3–120，默认 20）。
- 行「结果数上限」数字（1–30，默认 10）。
- 行「启用网页抓取 web_fetch」开关。
- 行「保存搜索配置」主按钮。

### 卡片二：本地搜索授权目录
- 标题「本地搜索授权目录」+ 说明：fs_grep/fs_glob 只在当前项目已授权目录内搜索。
- 行「项目」下拉（列出全部项目）＋「添加目录…」按钮（调系统目录选择器）。
- 已授权目录列表：每行显示绝对路径（mono）+「移除」；空态显示「该项目尚未授权任何目录」。

## 状态覆盖
- 加载中：`加载搜索配置中…`。
- 加载失败：`set-err` + 重试。
- 保存中：按钮「保存中…」禁用。
- 后端=默认：隐藏 Tavily 地址/密钥行。
- 无项目 / 无授权目录：下拉占位「（暂无项目）」、目录空态文案。
- 添加/移除目录进行中：按钮 `disabled`。
