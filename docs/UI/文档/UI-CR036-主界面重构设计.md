## 1. 本版结构变化

### 1.1 工作台（新增默认首页）

- 顶部四个统计：运行中、等待依赖、已完成需求、待我处理。
- 四个区块：活动运行（CLI 标识＋进度）、待我处理（类型＋状态）、最近完成、最近更新的知识。
- 项目管理页移除“活动中／待我处理”，只保留卡片与过滤。

### 1.2 项目管理

- 三列卡片（≤1180 两列、≤720 单列）：名称／ID／类型、描述、标签、运行数、进度、负责人、更新时间、打开。
- 卡片点击或“打开”进入；右上铅笔打开编辑弹窗；新建/编辑为 620px 固定弹窗。
- 本地目录：目录选择器（面包屑＋文件夹列表＋选择此文件夹），往返弹窗保留已填表单。

### 1.3 需求

- 整宽树，无右侧信息卡片；行首层级缩进＋类型点＋ID＋标题＋状态＋`...`。
- `...` 菜单固定 184×（条目自适应高度）：史诗/特性“新增下级”，全部“编辑／派发／删除”。
- 详情、表单、删除确认分别固定 620／620／460px；表单含类型、状态、标题、摘要、负责人、工作量、AC（每行一条）。
- 派发预检仍为 760px 宽固定弹窗，确认后真实创建运行并更新 Story。

### 1.4 设计

- 单一容器三段：56px 图标栏（PRD／UI／方案／模型／关联／目录，hover 显示名称）＋正文＋240px 目录。
- 目录顶部：版本、更新、关联 Story、负责人、同步按钮；下方页内目录。目录可收起，收起后正文占满。
- 文档可编辑并保存到设计数据；导出为真实 `.md` 下载。

### 1.5 任务

- 行首 CLI 标识块（dsh 青、Claude 橙、Codex 绿、Grok 灰），详情头部同款 34px。
- 任务暂停、验收、查看运行记录（日志／产物／用量）均改变状态或打开可读记录。

### 1.6 编码与 Git

- 三段：52px 菜单（资源管理／Git 管理／外部编辑器）＋管理面板＋编辑器。
- 文件树按目录分组，变更文件带 M/A 标记；编辑器支持编辑／保存／取消，保存写入本机草稿。
- Git 面板：未提交变更（提取／更新当前分支／推送当前分支、文件勾选、提交信息、AI 生成、提交）、分支（搜索／新建／当前／本地／远程）、提交历史；提交写入历史并减少未提交项。

### 1.7 AI 侧栏

- 无标题头：顶部仅历史、子智能体计数、后台任务计数、新会话。
- 左边缘拖拽 320–620px；历史栏在面板左侧、等高、260px。
- 历史状态：已读无点、成功绿、失败红、待确认黄；标题为任务摘要。
- 输入区：＋（添加／指令浮层）、CLI、权限、模型、发送；CLI 仅列已安装；权限五种；模型两列＋思考滑杆。
- `@` / `/`：输入触发独立浮层，按关键字筛选文件、对话、知识、Skill／MCP／Tool；选择替换触发词。
- 统计：轮次与 TPS、Token 总量与缓存命中、上下文占比，均可点开明细。
- 生成中：按钮变停止；再次发送按设置“立即发送／排队”处理；新会话不打断当前会话。

### 1.8 知识库

- 卡片带授权按钮；授权弹窗项目多选＋“所有项目开放”。
- 阅读：左树（目录分组、md／pdf／xlsx／png／csv 图标）、中正文（按格式预览）、右页内目录或文件信息。

### 1.9 服务器

- 移除 AI 运维；满高三栏：文件树（路径、文件、离线提示）、终端（shell 标签、白名单命令）、实时监控（系统／地址／运行时长、CPU 曲线与核心、内存、磁盘、负载）。

### 1.10 设置

- 固定 1040×700 弹窗；左栏顶部用户头像／名称／邮箱；分类切换尺寸不变。
- 通用：用户信息、代码样式（主题／字号／Tab／预览）、服务器配置、发送行为。
- 模型：供应商卡片（多密钥、多端点、模型数）＋供应商弹窗三页签（供应商配置／模型配置／高级配置），无指纹检测。
- SDK 与 CLI：CLI 管理（模型、思考、最低难度、任务类型、权限）与 SDK 管理（registry、版本、装／卸／检测）。
- 能力：Skill／MCP 添加与导入；Tools 开关。

## 2. 交互一致性

- 固定弹窗宽度：460（小）／620（中）／760（预检）／820（大）／1040（设置）；高度随视口上限内部滚动。
- 菜单点击外部关闭，但同一次点击仍执行目标操作；`Esc` 关闭菜单与弹窗。
- 破坏性操作二次确认；删除需求连同子项。
- 所有列表变更即时反映到统计与其它页面；数据仅存在本页内存。
