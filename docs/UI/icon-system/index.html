状态与可访问性

逐状态可见，不靠单一颜色
默认 / 悬停
悬停行底色变化，图标不放大、不变色

树行 hover 只改行底色；图标尺寸与颜色保持，避免「动一下就跳」。

选中
预约接口约定

选中行使用 primary-soft 底 + primary-strong 文字；图标仍保留类型色，不整行染成主色。

未授权 / 禁用
未授权知识库：图标正常，动作按钮受限

图标不表达权限；「进入」可用，「管理授权」按角色限制，权限状态由标签与按钮说明。

未知类型
显示通用未知图标 + 原始扩展名

不猜测类型、不阻断上传；阅读页只展示元信息，并提示「未识别格式，不提供预览」。

资源缺失 / 回退
通用文件 → 项目首字母块

图标 id 未登记时回退 file；项目图标完全缺失时回退现有字母块，不显示空白砖。

图标 + 背景色组合

同一图标换色卡即换项目气质；背景与图形色成对取，禁止只换背景导致对比不足。

上传失败 / 恢复默认
超过 200KB 保留原头像并提示

格式、超过 200KB 或读取失败都不替换当前头像；「恢复默认 Logo」立即回到 B 风格品牌头像。

C 方砖 TabEnter

图标选择器与头像风格均为可聚焦按钮/单选组，方向键或 Tab 切换，Enter/Space 选中，焦点环 3px。

可访问性与文案
  • 语义装饰图标 aria-hidden="true"；文件/项目/知识库名称是文本，不依赖图标。
  • 头像按钮 aria-label="用户头像，打开设置"；风格组用 role="radiogroup"。
  • 不报假状态图标不承载「已保存/失败/授权」状态，这些仍由既有状态标签与文案表达。
  • 语言类型小字用大写扩展名（MD/PDF/DOCX），不本地化成「便携文档」等长文案。

边界与待确认

设计已出，未进入开发
本页只更新需求与设计资源：未修改 docs/UI/workbench-v4/ 现有原型、未改 src/ 正式源码、依赖或构建产物。按项目 AGENTS 默认边界，确认设计不等于编码授权。
数据结论（设计层）
  • 项目新增可选 icon 与 icon_color（色卡 id，成对保存）；空值按 kind 推导图标、按既有 tone 显示。旧数据不动、不自动映射，手动切换后才写入。
  • 知识库新增可选 icon 与 icon_color；默认按既有 sourceKind 推导，不新增来源枚举。
  • 用户新增 avatar_style（默认 b）与可选 avatar_image（本机文件引用 + hash，不存原图字节）；上传上限 200KB。
  • 隐私头像图片仅本机读取，不上传网络、不进入知识库/会话/审计；删除引用即恢复默认 Logo。
  • 不持久化文件类型图标由扩展名即时推导，不入库；图标映射表随程序版本走。

以上字段为设计结论，正式实现时补 DB-FEAT-001 与迁移；本轮不建表、不改代码。

待确认（不阻塞设计评审）
  • 已定头像默认 B、可上传（≤200KB）；项目与知识库共用 50 个图标任意选择；10 个整块填充的方形色卡、不显示文字；旧项目／旧库保持原样，手动切换才写入。
  • Q10200KB 是原始文件大小还是裁剪后大小？本稿按选择时的原始文件校验。
  • Q11旧项目「保持原样」具体指沿用当前 tone 图标砖；是否需要在编辑弹窗里提供「恢复默认」入口？本稿只做手动选择，不做批量迁移。
