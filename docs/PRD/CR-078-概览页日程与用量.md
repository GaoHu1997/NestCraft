## 2. 需求范围

### 2.1 本次包含

**A. 更名与图标**

1. 侧栏导航第一项「工作台」→「概览」。路由键 `workbench` 保持不变（不改 `Route` 类型、窗口页签与既有跳转）。
2. 顶栏面包屑同步为「个人工作台 / 概览」。
3. 图标调整：概览导航图标改为 `layout`（四格仪表盘语义，区别于窗口页签「首页」的 `home`）；日程 Tab 用 `calendar`、用量 Tab 用 `tokenUsage`；项目 / 知识库 / 服务器三项导航图标不变。均取自既有 locked sprite，不新增图标资产。

**B. 日程 Tab（第一个 Tab）**

1. **月日历视图**：7 列（一～日）网格，顶部切换上一年 / 上月 / 下月 / 下一年与「今天」，显示「2026年11月」。今天高亮；点击任一天切换选中；选中日同时是详情栏的日期。选中日期以**中性浅底 + 主色描边**标示，与日程条带颜色不冲突。**点击「YYYY年M月」弹出年月快速选择**（年步进 + 12 个月网格，点月直接跳转），避免跨多个月连点。
2. **节假日与节气**：
   - 法定节假日（元旦、春节、清明、劳动节、端午、中秋、国庆）显示节日名角标（红字）。
   - 中国传统节日：春节、元宵、龙抬头、清明、端午、七夕、中元、中秋、重阳、腊八、小年（北方 / 南方）、除夕。
   - 二十四节气按各自日期显示节气角标（绿色）。
   - 农历日期：每月初一显示月份名（如「十一月」、闰月为「闰二月」），其余日显示农历日名；除夕优先于普通农历日名。
   - 展示优先级：法定节日 > 传统节日 > 节气 > 农历日。节日与节气同日时都显示（节日在上、节气在下）。
   - **数据来源**：节日与节气按本地内置表 + 农历算法计算，不联网。调休「休 / 班」标记依赖国务院年度安排，**本期只内置 2025–2027 三年安排**，其他年份不显示调休。
3. **创建日程**：入口为月历右上「新建日程」、选中日单元格悬停「+」、详情栏「新增日程」。
4. **日程可跨天**：开始日期与结束日期可选，结束不早于开始；跨天日程在月历上以连续条带横跨多天（起始日左侧圆角、结束日右侧圆角、中间段两端平直）；跨月时在相邻月视图里从月初或到月末截断显示。
5. **日程字段**：标题（必填，最长 80 字）、日期范围（开始 / 结束）、时间（全天或起止时间，默认全天）、备注（可选）、颜色（5 选 1）。
6. **当日显示上限**：每格最多显示 3 条，超出显示「+N」；点击「+N」在详情栏查看全部。
7. **编辑 / 删除**：详情栏日程项可**编辑**（详情栏「编辑」入口或点击月历条带 → 弹窗回填原值，保存以同一 id 更新原日程、不新增重复条目），可删除（需确认）。
8. **待办**：待办与日程同属「当天的事项」。详情栏列出该日待办，可勾选完成、可新增（标题必填）、**可编辑**（行内编辑标题，Enter / 失焦保存、Esc 取消，空值不覆盖）。
9. **右侧详情栏**：点击某一天后，页面右侧出现当天详情，**高度与月历卡相等、顶部对齐**：
   - **顶部蓝条 = 当前位置天气**（v3，2026-11-24 深夜用户反馈）：天气图标、当前温度、天气文字、位置（城市 · 区）、低温 / 高温、更新时间；农历 / 干支 / 生肖不在蓝条重复。
   - 日期标题（2026年11月24日 星期二）与今天 / 未来 / 过去标识；
   - 中国黄历：农历日期、干支（年柱 / 月柱 / 日柱）、生肖、十二值日、宜 / 忌；
   - 当天的节日 / 节气；
   - 黄历下方为「日程 / 待办」**两个可切换页签**：日程页签列出当天日程（含跨天日程覆盖当天）并提供「新增」；待办页签列出当天待办，可勾选完成、可新增（标题必填）。切换页签不改变选中日期。

10. **天气数据来源**（新增能力，软件当前无联网 / 定位依赖；决策见 §3）：
    - 位置：**系统定位（Tauri geolocation 插件）优先，拒绝授权或失败时回退 IP 定位**；反解为「城市 · 区」（IP 定位只到城市时显示「城市」）。
    - 天气：**Open-Meteo 免密钥**（`api.open-meteo.com`），按坐标取当前温度、天气代码、当日最低 / 最高温；天气代码映射到 6 种图标（晴 / 多云 / 阴 / 雨 / 雪 / 雷雨）与中文文字。
    - 缓存：最近一次成功结果落 `setting_default[weather.last]`；启动先显示缓存（标注「更新 HH:mm」）再后台刷新，30 分钟内不重复请求。
    - 设置：「关闭天气」开关（`setting_default[weather.enabled]`，默认开）；关闭后蓝条退回 v2 形态，不定位不联网。
    - 降级：定位未授权 / 失败 → 用上次缓存位置或 IP 定位；网络失败 → 缓存 +「更新失败 · 重试」；无缓存无网络 → 「天气不可用」，蓝条不塌陷。
    - **不做**：多城市、预报、空气质量；不申请后台常驻定位；不引入和风 Key。

**C. 用量 Tab（第二个 Tab）**

1. **统计范围**：本平台全部 token 用量，包含三类来源：① AI 侧栏 / 项目工作台的 CLI 会话（Claude / Codex / Grok）；② 平台主代理会话；③ 子智能体与工具循环内的模型调用。
2. **周期切换**：今日 / 近 3 天 / 近 7 天 / 近 1 月 / 近 3 月 / 自定义（起止日期）；**默认选中「今日」**（v9，2026-11-26）。
3. **指标卡（六张）**：总 Tokens、输入 Tokens、输出 Tokens、缓存 Tokens、缓存命中率、请求量。
4. **活跃热力图**：完整矩阵——行 = 周一～周日，列 = 周数（首列按周一对齐补空位、末列补到整周），**所有格子都渲染**：有数据按五档色阶，无数据 / 范围外为带边线白框；各格宽高间距一致、月份标签与列对齐，图例「较少 → 较多」。
5. **按小时 Token 趟势**：24 个桶的堆叠柱（输入 / 输出 / 缓存）+ 缓存命中率折线（右轴）。
6. **排行**：按模型、按供应商，显示用量、占比、缓存命中率。
7. **来源缺省规则**：某来源用量未知（旧数据、上游未上报）时，**对应指标不累加、不按字符数估算**；排行榜对该来源显示「未上报」且不显示占比条。
8. **页面框架（v9～v11）**：用量页不显示底部来源说明条与品牌标识；四张卡片标题与其右侧图例 / 计数同行右对齐，作为「标题样式统一」的最低要求；「按小时 Token 趋势」卡不显示模型图例，模型识别依赖悬停浮层与「按模型」排行同色。
9. **排行与曲线（v11）**：按模型 / 按供应商排行不显示来源文字标签，来源只由图标表达；序号与图标整行垂直居中；按小时趋势的缓存命中率为平滑曲线，端点不超出绘图区。
