# CR-104：本地搜索授权会话化

- 状态：**已确认（用户 2026-11-26 授权开发）** — 范围与方案见 §2～§5，用户明确选择「默认继承会话权限、不单独授权」，并授权同步更新 PRD／UI／LLD 后进入实现。
- 来源：用户 2026-11-26 反馈「本地搜索工具有问题，这里的权限应该按会话上的授权来，而不是要单独授权」；随后指定只读调研 PI-Desktop、ZCode、DSH Desktop 三个项目的本地搜索授权方式（结论见 [RESEARCH-010](../调研/RESEARCH-010-本地搜索工具授权机制对照.md)）。
- 关联：CR-093（本地与联网搜索工具，已实现待验收）、LLD-CR093、UI-CR093；已建 [FEAT-027](../Plan/Feature/FEAT-027-AI搜索工具.md) / [STORY-117](../Plan/Story/STORY-117-本地搜索会话级授权.md)，替换 CR-093 原「设置页按项目配置授权目录」的授权模型。
- 变更性质：**行为变更**（授权模型、设置页界面、工具默认范围），不是新增联网能力。

## 1. 背景与问题

CR-093 已实现 `fs_grep` / `fs_glob`，但授权模型是 `setting_default(scope=projectId, key='search.authDirs')` 的项目级白名单，默认空数组；未配置时工具直接报「尚未授权任何本地搜索目录，请到设置·搜索授权」。用户认为这是多此一举：会话本身已绑定项目与工作目录，搜索工具应按会话已有的权限工作。

只读调研三个参考项目的结论一致：**它们都没有「设置页为本地搜索单独配置授权目录」的做法**。共同结构是「默认范围＝会话工作区、默认可用；越界才授权，且授权是会话级或规则化」。

## 2. 本次范围

### 包含
- `fs_grep` / `fs_glob` 默认搜索范围＝**会话绑定项目的根目录**，无需任何前置授权。
- 删除「设置 · 搜索」中的「本地搜索授权目录」卡片；联网搜索配置保持不变。
- 新增**会话级授权**：在 AI 侧栏为当前会话添加/移除额外搜索目录（仅本会话有效，不写入项目设置）。
- 越界访问（`path` 明确指向项目根与会话授权目录之外）返回可读错误，指向会话授权入口，不静默放行。
- **会话权限档位落库**：`permissionMode` 持久化到 `session`；只读/规划（`plan`）会话仅允许搜索项目根，不允许追加额外目录。
- 同步更新需求、UI、LLD、DB、验证记录与需求汇总。

### 不包含
- 联网搜索、`web_fetch`、Tavily 配置的任何改动。
- 平台会话的「逐次审批卡」（参考项目的弹窗式审批）——本轮以会话授权入口替代；平台审批卡列为后续。
- 全盘索引、Everything SDK、跨设备搜索。
- 修改 CLI 原生权限档位的语义；只做「随会话持久化 + 搜索范围按档位收紧」。

## 3. 业务流程与规则

### 3.1 默认范围
- 会话绑定项目时，范围＝项目 `rootUri` 的 canonical 绝对路径。
- 会话额外授权目录（§3.2）追加在其后；两者都去重、只保留存在的目录。
- 会话未绑定项目且未授权任何目录时，工具返回明确错误：需要先选择项目或在会话中授权目录。

### 3.2 会话级授权
- 入口：AI 侧栏「搜索授权」菜单 → 弹窗。
- 只读展示当前项目根（不可移除，随会话绑定变化）。
- 可添加/移除额外目录，添加时校验为存在的绝对目录并 canonical 化；移除即时生效。
- 授权按会话存储（`setting_default`，`scope='session:<sessionId>'`，`key='search.extraDirs'`），会话删除不影响其他会话；不写入项目设置。
- 授权在每次工具调用时实时读取，与知识库「每次调用实时复检」一致。

### 3.3 权限档位
- 会话 `permissionMode='plan'`（只读/规划）时：范围固定为项目根，会话额外目录不生效；越界直接拒绝并说明原因。
- 其他档位（`default` / `agent`）：项目根＋会话额外目录。
- 平台会话沿用其助理权限（readonly/limited/full）现有语义，本轮不改平台工具白名单；平台会话的搜索范围同为项目根＋会话授权目录。

### 3.4 越界与错误
- `path` 为绝对路径且不在任何可用范围内：返回「搜索范围外」错误，包含该目录与「在 AI 侧栏『搜索授权』中为本会话添加」的指引。
- `path` 为相对路径：相对项目根解析；`..` 逃逸经 canonicalize + 前缀校验拒绝。
- 不泄露应用私有数据目录内容；符号链接按 canonical 结果校验。

## 4. 界面变化
- 设置 · 搜索：只剩「联网搜索」一张卡片；删除「本地搜索授权目录」整卡及其状态与接口调用。
- AI 侧栏：新增「搜索授权」入口（与「权限」同组菜单），弹窗含说明、项目根只读行、额外目录列表、添加/移除按钮、空态文案。
- 视觉遵循既有设置弹窗与 AI 侧栏弹层样式，不新增全局视觉令牌。详见 [UI-CR104](../UI/文档/UI-CR104-搜索授权会话化.md)。

## 5. 验收标准
- **AC-095-01**：新会话绑定项目后直接调用 `fs_grep`，无需任何授权即可返回项目根内结果；结果标注实际搜索根。
- **AC-095-02**：「设置 · 搜索」不再出现「本地搜索授权目录」卡片；联网配置仍可读取与保存。
- **AC-095-03**：AI 侧栏「搜索授权」可为当前会话添加/移除额外目录，添加后本会话 `fs_grep`/`fs_glob` 立即可搜；其他会话不受影响。
- **AC-095-04**：`path` 指向项目根与会话授权目录之外时，返回明确错误并指向会话授权入口；`../` 与符号链接逃逸被拒绝。
- **AC-095-05**：`permissionMode='plan'` 的会话只搜项目根，额外的会话目录不生效；`default`/`agent` 会话正常使用额外目录。
- **AC-095-06**：会话权限档位在重新打开应用后仍保持（持久化），不因重启丢失。
- **AC-095-07**：未绑定项目且无会话授权时，工具错误可读，不出现「请到设置·搜索授权」的旧文案。
- **AC-095-08**：不修改联网搜索行为；`web_search`/`web_fetch` 回归不受影响。
