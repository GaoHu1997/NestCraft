## 背景与目标

本项目已有本地知识库（FTS5+本地语义+双链图谱+5 个知识工具+授权体系）与本地对话存储（`message` / `session_context_block`）。本轮在其上补一层「个人记忆」：默认就存在的记忆库、把对话自动提炼成记忆与画像、新对话自动注入画像与相关记忆，从而"越来越懂我"。原则是"加一层、不造轮子、全本地、用户可控"。

## 用户已确认的关键决定（D1～D5，全部取推荐值）

| 编号 | 决策 | 取值 |
| --- | --- | --- |
| D1 | 记忆存储形态 | **内置独立「个人记忆库」**（`sourceKind='personal-memory'`，目录 `data/knowledge/memory/`），复用知识库检索/图谱/可读可改 |

## 范围

**包含**
- 内置「个人记忆库」首启幂等创建（`memory/画像/`、`memory/记忆/`、`memory/日志/`）。
- `memory_item`（原子记忆）/`memory_profile`（画像摘要）派生表与幂等迁移。
- 记忆工具：`memory_search`/`memory_save`/`memory_list`/`memory_forget`/`profile_get`，注册进 `workbench_tools`（MCP 与平台 runtime 共用），授权复检、预算、可选审计、可单独停用。
- 抽取—合并—落盘管道（Mem0 式 ADD/UPDATE/DELETE/NOOP + supersede），会话结束后台抽取 + 手动沉淀。
- 新会话注入：画像摘要（≤2KB）+ 相关记忆 TopK（≤1.5KB），可关闭。
- 记忆管理界面：列表/画像/搜索/编辑/删除/来源溯源；空态/深色/窄屏/UI-SCROLL-001。

**不包含**
- 云端 embedding、独立向量数据库、多租户/IM 同步、跨设备同步。
- 改写 `message`/`session`/`knowledge_*`/`kb_embed`/`kb_link`/`project_library_grant` 任何字段。
- LLM 抽取式 GraphRAG、cross-encoder 重排。

## 业务流程、规则、权限与边界

- **权限**：记忆工具沿用知识工具语义——库 `enabled=1`，`scope=project:<id>` 时必须该项目可见；`global` 记忆归 owner，默认可见。写类工具记审计。
- **合并规则**：同 `scope+kind+memKey` 或语义近邻 → `ADD/UPDATE/DELETE/NOOP`；冲突新盖旧，旧条 `status=superseded` + `supersededBy`，不物理删。
- **信任**：`sourceType∈{message,session,manual,doc}`；来自网页/工具结果/MCP 的外部内容 `trust=external`，注入优先级低、需显式。
- **预算**：search/list ≤20 条、片段≤200 字；read 单条≤1KB 写入；注入画像≤2KB、记忆≤1.5KB。
- **降级**：抽取失败只记日志、不影响对话；模型通道不可用时该会话跳过自动抽取并记原因（不改手动/AI 主动路径）。

## 验收标准

- **AC-092-01** 首启（幂等）存在内置「个人记忆库」，`sourceKind='personal-memory'`、enabled=1，目录含 `画像/记忆/日志`；重复启动不重复创建。
- **AC-092-02** `memory_item`/`memory_profile` 建表迁移幂等；旧库升级不改原表、不重建 message/session；`cargo test` 覆盖迁移幂等。
- **AC-092-03** `memory_save` 对同 `scope+kind+memKey` 走合并（更新而非重复新增）；不同事实新增。
- **AC-092-04** `memory_search` 仅返回记忆库命中，有界（≤20 条/片段≤200 字），带库启用与（project 时）授权复检；`memory_list`/`profile_get` 正常。
- **AC-092-05** `memory_forget` 软删（status=deleted），可被列表过滤；UI 可彻底删除。
- **AC-092-06** 5 个工具注册进 `workbench_tools`，`TOOL_COUNT` 同步；可单独停用（`tool_enabled`）；MCP 与平台 runtime 均可见。
- **AC-092-07** 新会话注入画像摘要 + 相关记忆（按预算截断）；关闭开关后不注入、行为回现状。
- **AC-092-08** 会话结束后台抽取（可失败降级、不阻塞、可取消）；手动「沉淀本会话」可触发同一管道；模型通道不可用时不报错崩溃、记原因。
- **AC-092-09** 记忆管理界面：列表/画像/搜索/编辑/删除/来源；空态/深色/窄屏；滚动条按 UI-SCROLL-001（滚动时显示、停止隐藏）。
- **AC-092-10** 外部来源记忆 `trust=external`，注入排序低于 `own`。
- **AC-092-11** 删除/关闭记忆后系统行为回退现状（检索无记忆污染、注入为空）。
- **AC-092-12** 验证：定向 `cargo test` 与全量 `cargo test --lib`、`npm run build`（tsc+vite）exit 0；真实 Tauri 端到端如未跑需如实标注未验证。

## 待确认/风险

- 抽取质量与 token 成本未实测；需建小评测集（换说法召回、重复抑制、纠错率）后再承诺"更准"。
