# CR-048：文档自动保存与预览内编辑

- 状态：用户明确提出本轮需求；需求／交互设计修正，**不修改正式软件、依赖、运行配置或构建产物**。设计交付待评审，不视为软件实现或用户验收。正式开发需要独立编码授权，并按各Feature建立执行包。
- 来源（2026-11-20）：用户要求代码及所有文档自动保存，不应有保存按钮；Markdown不能「点击编辑然后用语法写完了再保存再看效果」，应在预览排版下直接编辑，包含项目管理、知识库等文档。原话允许知识库存在「保存/编辑两种视图」，前一种是为了防止误操作修改。
- 解释纠正：按上述防误改目的，知识库使用**只读阅读／所见即所得编辑**两视图；阅读不能改正文，编辑仍直接显示排版并自动保存。此前代理写成「源码恢复视图」，不是用户要求，已撤回。源码编辑不替代所见即所得。
- 归属：编码[STORY-034](../Plan/Story/STORY-034-编码区正式实现.md)／[FEAT-007](../Plan/Feature/FEAT-007-文件草稿与分支上下文.md)，需求正文[STORY-010](../Plan/Story/STORY-010-需求树与详细文档预览.md)／[FEAT-003](../Plan/Feature/FEAT-003-需求维护与交付验收.md)，设计正文[STORY-016](../Plan/Story/STORY-016-局部导航与项目设计工作区.md)／[FEAT-004](../Plan/Feature/FEAT-004-设计评审与跨文档同步.md)，知识阅读[STORY-014](../Plan/Story/STORY-014-服务器列表与知识库三栏阅读.md)／[FEAT-009](../Plan/Feature/FEAT-009-知识库目录与正文阅读.md)，知识写入[STORY-036](../Plan/Story/STORY-036-知识库正式实现.md)／[FEAT-008](../Plan/Feature/FEAT-008-项目知识授权与只读检索.md)，办公[STORY-065](../Plan/Story/STORY-065-办公项目资料与连续编辑.md)／[FEAT-006](../Plan/Feature/FEAT-006-办公资料解读与产物预览.md)。不新增Epic／Feature／Story，不改变父项。

## 1. 目标与替代范围

这不是只移除一个按钮，而是统一写作流程：**打开文档 → 在正文排版中改 → 自动保存**。正常写作不用先点编辑、切源码、点保存再看效果。

CR-045等既有布局、源文件权威、权限与安全约束继续有效；其中Markdown只读预览＋源码框＋显式保存的交互由本轮替代。历史验证只证明旧交互，不代表新需求通过。

## 2. 现行行为

1. 所有**已支持编辑**的代码／正文编辑面自动保存。停笔约1秒、离开编辑区、切文件或页签时提交相应对象的最新缓冲；正常成功只给轻量状态，不弹成功对话框。Ctrl/Cmd+S可立即触发同一提交，但不是必经步骤。
2. 编码MD、需求正文、PRD／方案及办公MD默认直接在排版中编辑。标题、段落、列表、加粗、斜体、表格、链接与代码块不以原始Markdown语法输入框作为默认写作面；格式动作应作用于真实光标／选区。程序源码仍为代码编辑器，不能当富文档渲染。
3. 知识库为防误改可默认只读阅读；进入编辑后仍是同样排版的直接编辑，不切换整页textarea。切回阅读锁定正文，不取消或丢弃修改，不把「阅读」当手工保存动作。正文目录跟随当前缓冲，右栏仍不是AI。
4. 不提供日常保存按钮。元信息、授权、配置等事务表单不属于正文写作；其确认／提交不因为本需求被取消。知识库唯一例外是防误改阅读／编辑切换，而非所有页面都必须点编辑。
5. 新文件采用明确父目录与文件名；**Enter或文件名失焦表示确认命名**，合法且不重名后自动创建。不能用户刚键入半个名字就创建。未命名或命名非法保留缓冲；尚未创建时可放弃，成功创建后继续自动保存，不显示首保存按钮。
6. 每个保存任务绑定稳定的项目／库＋文件ID、源版本和写入代次；延迟回调不从当前选中的文件猜身份。切换后旧内容不能串写，新内容不被迟到回调覆盖。
7. 保存失败显示「内容已保留」及重试，不承诺没有实现的无限自动重试。外部版本冲突停止自动覆盖，保留当前／基线／最新内容；载入最新需确认，保留我的修改不能暗含强制覆盖。关闭失败缓冲必须保留恢复状态或提示，不能静默丢弃。
8. 撤销／重做不因为自动保存清空，误改已经保存后仍可撤销并再次自动保存。未修改的块及格式保持；只打开、切视图或失焦不能触发全篇重序列化，不能损坏空行、表格、代码缩进、标题层级和链接。
9. 无写权限、不可读源、只读原件及尚不支持编辑的格式维持真实边界。知识库Office／PDF／图片／压缩包不因此获原生编辑引擎；办公现有基础编辑样例仅为演示，不证明原件格式保真。AI知识授权仍只读，自动保存不等于确认需求、审批、同步设计、接受AI候选或发布成果。

## 3. 交付边界

本轮只在[唯一原型](../UI/仿真原型UI.html)内操作合成内存样例，不写项目源文件、不读私密资料、不调用业务接口／CLI／模型／网络。刷新浏览器会丢失内存编辑；正式文件持久化、崩溃恢复、跨平台保存和完整Markdown格式兼容需另行实现验证。

[UI-CR048](../UI/文档/UI-CR048-文档自动保存与预览内编辑.md)定义当前可视基准；[LLD-CR048](../LLD/LLD-CR048-文档编辑与保存契约.md)定义设计保存契约、保护和后续技术门槛；[REPORT-CR048](../Test/REPORT-CR048-文档编辑设计验证.md)只登记真实检查。
