## 2. 替代与保护

- 获取模型的旧卡片无对勾要求被 M01 替代；**密钥的模型范围小卡片**不在本项范围，仍保持旧规则。
- M02 替代无条件三列布局；思考关闭隐藏不等于删除容量、ID、名称、模态或用户映射草稿，保存时不下发思考配置。
- J09 替代旧 CR-042「工具记录即步骤、默认展开、随消息滚动」的对应部分；工具记录仍保留于消息流，不能删工具证据来达成计划语义。
- S03 中“取消在左、保存在右”指**右侧按钮组内部顺序**，不再将取消／放弃独自放在表单最左。
- 生图图标位置、会话统计的既有结构、消息滚动和项目单会话要求已有有效设计，优先修正实现，不反向覆盖设计。
- 保留头像 680×660 固定裁剪弹窗、模型检测 108px 结果区、会话选择浮层等有效尺寸。短业务弹窗按内容高度；长内容内滚动，不全局抹掉所有固定尺寸。
- 不修改知识授权边界、文件失效的草稿保护、删除不复活、续接 CAS／授权复检、危险权限确认和 SSH 风险门禁。

## 3. 输入与执行规则

- 容量演示默认十进制：K=1,000、M=1,000,000；大小写不敏感，允许小数产生正整数，留空=未知；禁止负数、零、非法字母、非整数结果和安全整数越界。此为可逆方案默认值，不伪称用户指定倍率。
- 双协议不是跨协议试探发送：发送前按 CLI 的可执行协议选路，并复核启用端点、密钥自身协议／范围、模型、版本与续接身份；无兼容组合明确拒绝并保留草稿，不能把同一消息重复发送到两个端点。
- 权限菜单的名称必须同时说明原生审批／隔离参数。参考适配器已经使用某类型不代表本应用具备对应审批通道。未具备通道的项显示具体原因，不自动切换或升级权限。
- 计划来自专用计划快照／任务 API，与 toolId 操作记录分离；TaskCreate 使用工具结果中的真实 taskId，不用工具调用索引代替。只有计划存在才显示计划浮层；缺失事件不补造思考、子任务、上下文或 token。
