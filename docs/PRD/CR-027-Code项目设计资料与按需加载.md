# CR-027：Code项目设计资料四入口与AI按需加载

- 类型：既有设计工作区细化；状态：需求范围已确认，设计待视觉评审，正式能力设计中。
- 日期/来源：2026-11-19（Asia/Shanghai）用户要求“设计中再增加几个菜单，摆放顺序是：prd、ui、方案、数据库设计”，PRD/方案可编辑MD，右侧有菜单且不挤占AI侧栏；UI直接显示仿真入口；数据库模型可保存在数据库，一个模型一个菜单；AI知道资料位置与内容，按需自动加载以节省token。
- 工作层级：**仅需求、方案、可操作设计与设计验证**。没有正式编码、软件运行/测试/构建、数据库迁移、部署或推送授权。
- 归属：[FEAT-004](../Plan/Feature/FEAT-004-设计评审与跨文档同步.md)下既有[STORY-016](../Plan/Story/STORY-016-局部导航与项目设计工作区.md#cr-027四分类设计资料工作区)、[STORY-018](../Plan/Story/STORY-018-设计模型与需求一致调整.md#cr-027数据库模型的权威记录)；AI独立可交付价值新增[STORY-060](../Plan/Story/STORY-060-项目设计资料索引与按需读取.md)，唯一父项[FEAT-010](../Plan/Feature/FEAT-010-AI上下文与能力引用.md)。不新增Epic/Feature或第二任务体系。

## 1. 范围与页面规则

1. 保持项目外层“需求、设计、任务、编码”及现行返回导航。**仅Code项目的设计区**子菜单固定为：**PRD → UI → 方案 → 数据库设计**；默认PRD，切换不重置项目、分支、AI会话或输入草稿。
2. PRD读取该项目`docs/PRD/`下Markdown正文；方案读取`docs/LLD/`下Markdown正文。默认排版阅读，不以卡片、路径列表或纯源码代替文档；可切换Markdown编辑，保存、放弃二次确认、失败保留草稿，跨分类/页签保持。继承原差异、权限、版本与待同步规则；保存文档不代表同步需求/AC或授权正式开发。
3. PRD/方案**右文档菜单**位于AI左边的主内容区内：文件列表（名称、简短内容摘要、选中/草稿）+当前文档章节定位。不是占用AI侧栏或取代AI；主区宽度不足时回落为主区内部的可收起菜单，不缩小AI、覆盖AI或造成整页横向溢出。
4. UI直接显示该项目唯一公开`docs/UI/仿真原型UI.html`对应的可操作入口页面；不先展示资料卡、另建第二入口、递归嵌入整个本工作台或拷贝另一套工作台状态。UI仍只读评审，手工编辑权仅覆盖本次PRD/方案与已有数据库模型维护，不能推导为手工改图授权。设计夹具只演示预约项目首页，不冒充已托管当前项目真实入口文件。
5. 数据库设计采用“主区模型详情 + 主区右模型菜单”，一个模型一个菜单项。展示表名、字段、类型、约束、说明及关联；可手工维护设计草稿，非法数据拒绝、失败保留。不执行SQL、建表、连接业务数据库、迁移或自动修改需求。
6. 采用用户本次允许的存储建议：**数据库设计模型在同一应用SQLite中以独立的版本化设计记录为权威**，与供应商AI模型配置`model`区分。PRD/方案依旧Markdown文件权威。这是CR-027对历史模型“源文档权威”规则的明确局部变更；旧模型文档仅保留历史/导入来源，不能成为第二可编辑权威。数据细节见[DB-CR027](../DB/DB-CR027-设计资料索引与模型记录.md)，本批仅设计未建表/迁移。

## 2. AI节约上下文的规则

- UI中的完整人类阅读/编辑不等于AI加载。初始会话仅提供当前项目/任务稳定身份及两工具用途，不自动注入资料列表和全部正文。
- 拟议只读工具`project_design_list`：按分类、关键词、关联Story/AC、分页获取标题、受管定位、摘要、源版本、同步状态和受限章节信息；**不返回正文**。
- 拟议只读工具`project_design_read`：使用索引返回的ID与版本，指定章节/行范围/模型字段组，再加载必要片段；返回可继续游标、来源引用、截断和计量状态。UI原型需内容时读结构说明/相关资源，不默认把整个HTML/CSS/JS塞入上下文。
- 主机/项目/会话/工具能力范围由宿主确定，每次调用、复用缓存与发送都复查；AI不可自行选择任意绝对路径或别项目ID。未授权资料连标题/数量也不泄露。
- 版本变化拒绝旧分段读取，不静默混合；缓存以项目+对象+版本+范围+权限修订隔离，未保存草稿不自动提供。子任务只接所需片段与引用，不再整包复制。
- 按当前窗口编译输入预算控制检索和输出预留；不使用会话累计账单tokens作为上下文余额，未知不得写成0。默认小片段分页，额外资料由任务需要决定，不预设必须读四分类。
- 具体工具schema、建议默认值、错误与缓存规则见[LLD-CR027](../LLD/LLD-CR027-设计资料与按需工具契约.md)。工具名称是**拟议契约**，离线演示不是已注册给真实AI的工具。
