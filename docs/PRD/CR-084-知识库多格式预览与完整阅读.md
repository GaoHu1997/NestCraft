## 现状与归类

1. PDF／Office 不是仅有错误文案：当前后端 `knowledge_files.rs:752–755` 明确返回 `preview_supported=false`，`data:789` 不返回这些格式的正文或二进制；阅读器没有对应查看组件。属于补齐阅读能力，并修订旧格式边界。
2. Markdown 的 `limited` 提示来自超大 token 原文降级，本身不是截断证明。但 `MarkdownContent.tsx:32/55` 达节点或 HTML 留存预算后终止 Worker，已有段组继续显示，后续内容不可达。属于既有完整阅读要求的缺陷。用户具体文件未取得，不断言其命中了哪一项阈值。
3. CR-045 的 AC-STORY-014-12、CR-077 的附件条目曾把 Office 限定为原件操作。本次仅将下列支持格式的**只读预览**改为目标态；既有上传、编辑、原件保管、下载、回收站与 AI 权限契约继续有效。历史验收不改写。

## 目标范围

| 格式 | 目标阅读能力 | 失败或限制 |
| --- | --- | --- |
| Markdown／MD | 阅读与源码均能访问完整内容；保留标题目录、既有编辑与草稿 | 格式超限时连续退为有界原文分段，覆盖首、中、尾；不停止在前缀并宣称完整 |
| PDF | 库内分页查看、缩放、适合宽度、页导航；扫描件也能看页面 | 文本层不存在时不提供假搜索结果；加密、损坏、源不可用分别反馈 |
| Word（doc／docx／rtf） | 本机转换后的分页只读预览，标注「转换预览」 | 字体或复杂版式可能变化；转换组件缺失、失败明确原因，可重试或下载 |
| 演示文稿（ppt／pptx／pps／pot） | 按幻灯片查看、页号导航、缩放 | 只读静态页面，不播放动画、宏或嵌入媒体 |
| 表格（xls／xlsx） | 本机转换的静态打印页预览，标注其页数与视图性质 | 只代表已有打印范围，不宣称覆盖所有工作表／单元格；完整表格浏览另行确认 |
| 已支持图片／UTF-8 纯文本／JSON／CSV／富文本 | 保持既有阅读能力 | CSV 仍按文本，不自动变为电子表格 |
| ZIP／未知格式／未支持格式 | 文件信息、下载原件、明确不支持 | 不把静态元信息计为预览成功 |

此格式表为需求／设计目标，不能当成当前软件支持清单。PDF 与 Office 预览不得依赖将私人原件上传到公共在线服务。预览成功与正文检索／AI 可读分开；本次不改索引、tool、授权、OCR 或模型能力。

## 交互规则

- 延续左文件树／中阅读／右标题或页导航。只读文档显示格式、预览类型、页数；保留独立的「下载原件」。页数未取得时显示未知，不填 0 或虚构进度。
- 加载、转换中、取消、转换器缺失、损坏、加密、无本机读取权限、原件消失、原件变化、不支持格式均有就地反馈与可行出路；切换文件不展示上一文件的正文或迟到预览。
- Markdown 格式受限时提示「部分内容改用原文阅读」，同时提供原文出路。只有源范围覆盖到 EOF 且无遗漏时，才可显示「全文已加载」。单页或单窗口不得冒称全文。
- 预算用于限制峰值资源，不用于隐藏后半正文。大文件采用可前后导航、跳转、明确覆盖范围的只读窗口；下载始终取得完整原件，不能拼接预览窗口代替。
- 遵守 [UI-SCROLL-001](../UI/文档/UI-CR049-滚动条按需显示.md)：实际滚动时出现、停止 700ms 隐藏，悬停不唤醒，不禁滚、不改宽、不丢草稿。
