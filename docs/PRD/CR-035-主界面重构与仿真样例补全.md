# PRD CR-035：主界面重构与仿真样例补全

- 状态：已确认范围（设计待评审）；仅需求／可操作设计，无正式编码授权。
- 来源：2026-11-19 用户反馈与指令：「ui 重做，另外样例数据要全，要仿真，我要的是仿真原型 ui，不是示意图」，并确认参考基准为 CR-014 的十三张参考截图（白蓝研发管理风：PingCode / zyplayer / cc-gui / TermX / openidea）。
- 关联：[FEAT-001](../Plan/Feature/FEAT-001-工作台框架与可操作评审.md) / [STORY-063](../Plan/Story/STORY-063-主界面视觉重构与仿真样例补全.md) / [EPIC-001](../Plan/Epic/EPIC-001-工作台导航与视觉体验.md)。

## 背景与问题

现有多轮追加的仿真原型（`docs/UI/task-workbench/`）在信息层级与视觉执行上累积了以下问题：

1. 顶部与内容区堆叠多层栏（顶栏、窗口栏、窗口标题卡、页签、提示条），进入内容前占用过多高度。
2. 卡片层层套框、边框与底色接近，主次关系弱；标题、正文与元信息字号差距小。
3. 项目、任务、设计等布局在打开 AI 侧栏后被压缩，出现换行、截断与横向挤压。
4. 样例数据量小且跨页不一致（项目统计、知识库篇数、任务状态与需求状态不同源）。
5. 「设计稿」与「截图拼贴」边界模糊，用户难以判断哪些状态真正可操作。

## 本次范围

### 1. 视觉基线（沿用 CR-014 参考语言）

- 白底与浅灰画布（`#ffffff` / `#f5f6f8`），1px 分隔线（`#e6e8eb`），蓝色主操作（`#2b6cf6`）。
- 字号 11/12/13/16/20，正文 13px；列表行高 52px，控件高 32px；圆角 4/6/8px。
- 卡片仅用边框，不叠加阴影；弹层与菜单使用轻阴影；状态用圆点＋文字，色彩只表达语义。
- 悬浮、选中、禁用、聚焦四态明确；焦点环可见。

### 2. 导航与窗口

- 固定管理首页：项目管理／知识库／服务器管理三个管理页。
- 项目、知识库、服务器、设置在独立窗口打开；窗口栏列出「首页＋已打开窗口」，可切换、关闭；同一对象只聚焦原窗口。
- 关闭窗口回到首页；不设返回按钮。

### 3. 页面

- 项目管理：搜索、类型切换、项目表（负责人、进度、运行中、更新时间）、活动运行与待处理。
- 项目工作区：需求树＋详情（AC、依赖、修订）、派发预检对话框、设计资料四入口（PRD/UI/方案/数据库）、任务队列＋运行详情（步骤、产物、日志、用量）、编码（文件树、语法高亮、Git 变更与差异）；办公项目为文档工作区。
- 知识库：库列表、授权拦截、检索命中、三栏阅读（目录／正文／页内目录）。
- 服务器：主机卡片、终端（白名单命令、离线失败）、性能指标、只读巡检入口。
- 设置：通用、模型管理、智能体、SDK 与 CLI、能力（Skill / MCP / Tools）。
- AI 侧栏：目标、会话、工具卡、审批、任务条、后台任务、模型／思考／权限、统计与输入区。

### 4. 样例数据

全部为虚构夹具，不采集生产、个人或真实凭证数据。为了可评审，数据必须跨页自洽：

- 4 个项目（2 编码、2 办公），11 条需求（预约服务）、4 条（运维控制台）、3 条（研究）、2 条（品牌）。
- 7 个运行，含运行中、等待依赖、验证中、待验收、已交付、失败六种状态；失败保留原记录并提供重试入口。
- 设计与编码样例仅对预约服务提供完整内容，其余项目给出明确空态与引导，不用同一份数据冒充所有项目。
- 3 个知识库、12 篇文档、授权与未授权各覆盖；3 台主机（2 在线、1 离线）。
- 模型供应商 3 个、模型 4 个；SDK 4 个（含未安装）；智能体 4 个；Skill 3、MCP 3、Tools 6。

### 5. 状态覆盖

正常、空数据、未授权、离线、阻塞、失败、待验收、运行中、等待依赖、禁用按钮、对话框、全局搜索、浅色／深色、1440／390 宽度。

## 不做事项

- 不修改 `src/`、`src-tauri/`、构建配置或依赖；不运行正式应用或生成安装包。
- 不接入真实 CLI、SSH、Git、模型或数据库；不创建本机定时任务。
- 不删除旧原型文件，不把旧原型登记为第二公开入口。
- 不新增业务权限、计费、发布或真实执行规则。

## 入口调整

唯一公开入口保持 `docs/UI/仿真原型UI.html`，目标由 `task-workbench/index.html` 改为 `workbench-v4/index.html`。旧原型原位保留为历史资源，可在设计资源索引中追溯；不并行维护两套当前稿。
