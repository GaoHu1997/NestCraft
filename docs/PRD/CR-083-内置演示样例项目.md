## 目标

首次启动时预置 4 个演示项目，使项目管理页能呈现与设计稿一致的信息与版式：预约服务、运维控制台、市场研究资料、品牌与官网，含负责人、描述、标签、图标配色与需求进度。

## 范围

- 新增后端启动钩子 `commands/demo_seed.rs`：一次性、幂等写入 4 个演示项目与需求文档，并重建 `requirement_index` 生成进度。
- 项目元数据：owner / description / tagsJson / icon / iconColor（复用 CR-072 已加字段）。
- 需求进度演示值：预约服务 3/11、运维控制台 2/4、市场研究资料 1/3、品牌与官网 2/2。

## 不包含 / 边界

- **不伪造运行**：不写 `execution_task`，卡片不显示「N 个运行」（真实运行数保持 0），避免与执行账本/状态机冲突。
- 不覆盖同名用户项目；不复活用户删除后的演示项；不阻塞启动（失败仅日志）。
- 不改动真实用户的既有项目；不修改运行中的便携版。

## 规则

- 版本标记 `demo.seed.version=1`；存在即跳过。
- 项目 id 固定：`proj-demo-booking / -ops / -research / -brand`。
- 需求文档写入 `<data_dir>/demo-projects/v1/<slug>/docs/Plan/{Epic,Story}`，由既有 `scan_requirements` 建立索引。
