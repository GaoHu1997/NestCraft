## 1. 背景与目标

侧栏已经有“n 子智能体”下拉，但只能看到任务名、CLI、模型、耗时、tokens、状态与最终输出摘要；消息流里的子智能体卡片同样不可展开。用户需要在不离开 AI 侧栏的前提下，查看某个子智能体在本轮执行中做了什么（正文、工具调用、结果、产出），再回到主会话继续对话。

目标：复用侧栏位置承载子智能体只读详情，以面包屑表达“主会话 / 子任务”的层级，以返回图标回到主会话；主会话保持运行与草稿状态不丢。

## 2. 本次范围

包含：

1. 从顶部“n 子智能体”下拉的每一行、以及消息流子智能体卡片的“查看”入口进入只读详情。
2. 详情顶部替换为：返回图标 + 面包屑「主会话 / 子智能体任务名」+ 当前状态；隐藏“n 子智能体”“n 后台任务”两个计数入口、FEAT 标签、绑定胶囊与新会话按钮。
3. 面包屑第一级固定文案“主会话”，点击返回；第二级为子智能体任务名（过长截断，悬停显示完整）。
4. 详情只读：不提供消息输入、发送、停止、配置切换；底部固定只读提示与“返回主会话”。
5. 内容区展示：子智能体元信息（CLI、模型、耗时、tokens、任务标识）与过程时间线（状态、正文、工具调用、工具结果、产出）；未上报字段显示“未知”，不补造。
6. 记录只来自本次运行：刷新、重启或运行态清理后不承诺恢复，界面明确标注。
7. 返回路径：返回图标、面包屑第一级、底部按钮、Escape 均可返回；主会话的运行轮次、草稿、滚动位置保留。
8. 失效兜底：记录已不可用时显示说明与返回按钮，不白屏。
9. 子智能体事件缺失时，详情显示“暂无过程记录”并回退到最终输出摘要。
10. 记录规范：新增滚动容器执行 UI-SCROLL-001；顶部计数入口在详情内不出现。

不包含：

- 向子智能体追加指令、停止子智能体、切换兄弟子智能体。
- 多级子智能体面包屑（数据保留 `parentId`，本期只渲染一级）。
- 子智能体记录持久化到数据库；刷新后恢复。
- 后台任务详情视图、子智能体独立会话/独立窗口。
- 对未实测 CLI 版本的子代理消息格式作兼容承诺；解析按协议字段容错，缺失时不报错。

## 3. 流程与规则

1. 主会话运行中或已结束都可进入详情；进入不改变主会话运行状态，也不触发已读、排队或绑定变化。
2. 详情打开期间主会话继续接收事件；返回后显示最新消息与状态。
3. 子智能体状态为运行中/待确认时显示状态点与脉冲；成功、失败、已停止分别用固定色。
4. 流结束仍未收到子智能体终态时标为“待确认”（用户停止时“已停止”），不替它宣布成功。
5. 切换主会话、新建会话、删除会话不会自动清空子智能体记录，但详情始终归属于进入时的父会话；父会话记录不可用时按失效兜底处理。
6. 同一子智能体重复上报相同文本不重复追加；事件总量上限 200 条，超出从最早丢弃。
7. Escape 优先级：系统弹窗 > 浮层 > 子智能体详情返回 > 无操作。

## 4. 数据与权限

- 不新增数据库表或字段；复用会话运行态 `SubagentRow`，新增运行内 `events` 数组与 `taskId`。
- 后端只增加事件字段（`taskId/content/kind/toolName/isError`），对旧数据 `serde` 可选字段兼容。
- 只读详情不提供写操作，不改变项目、知识授权或会话权限。

## 5. 验收标准

- AC-062-01：给定顶部存在 n 个子智能体，点击下拉任一行，侧栏切换为该子智能体只读详情；再点返回回到主会话，主会话消息、草稿与滚动位置保留。
- AC-062-02：详情顶部只有返回图标、面包屑「主会话 / 子任务名」与状态；不出现子智能体计数、后台任务计数、FEAT 标签、绑定胶囊、新会话按钮。
- AC-062-03：面包屑第一级固定“主会话”，点击与底部“返回主会话”、Escape 等价返回。
- AC-062-04：详情内没有输入框与发送/停止按钮；底部只读提示说明子智能体由主会话派发。
- AC-062-05：时间线按顺序显示状态、正文、工具、结果与产出；未上报的 CLI/模型/耗时/tokens 显示“未知”，不显示 0 或编造值。
- AC-062-06：无过程事件时显示“暂无过程记录”并回退最终输出；记录不可用显示失效说明与返回按钮。
- AC-062-07：运行中状态点脉冲且可随事件更新；成功/失败/已停止颜色与文案正确；`prefers-reduced-motion` 下不脉冲。
- AC-062-08：主会话运行中进入详情，主会话继续运行；返回后消息与运行状态是最新值，且未产生额外请求、未触发已读写入。
- AC-062-09：详情滚动容器按 UI-SCROLL-001 仅在滚动时显示滚动条，停止后隐藏；不改变内容宽度或丢失选中状态。
- AC-062-10：消息流子智能体卡片的“查看”入口与下拉行进入同一详情；无 `producerId` 时不显示入口。
