# CR-087：顶部面包屑第一段改为小房子图标

- 状态：已确认（用户直接指令）／已实现（设计先行 + 正式软件）
- 日期：2026-11-25
- 类型：界面调整（顶栏面包屑）
- 来源：用户 2026-11-25 原话「顶部的面包屑，个人固定的个人工作台改成 一个小房子的图标」
- 关联：[STORY-064](../Plan/Story/STORY-064-主界面按评审意见重构.md)（主界面顶栏）／[UI-CR087](../UI/文档/UI-CR087-面包屑小房子图标.md)
- 授权：本条为界面修改的直接指令，登记为正式编码授权；范围仅限顶栏面包屑第一段。

## 1. 变更内容

| 项 | 变更前 | 变更后 |
| --- | --- | --- |
| 面包屑第一段 | 固定文案「个人工作台」（原型另带 `grid` 图标） | **小房子图标 `home`（14px）**，不显示文字 |
| 后续层级 | `/` + 当前页面或对象名 | 不变 |
| 可读名称 | 文字本身可读 | `role="img"` + `aria-label`／`title`＝「个人工作台」 |
| 颜色 | 第一段 `--ink-2` | 不变（图标继承 `--ink-2`，未被 `--muted` 覆盖） |
| 容器 | 原型 `chip-workspace` 胶囊；软件无底色 | 各自沿用既有容器，仅替换内容 |

## 2. 不包含

- 不改面包屑第二段（页面／对象名）、分隔符、窗口页签条与导航。
- 不改侧栏底部用户角色文案、`profile.role` 默认值「个人工作台」。
- 不改 1120／720 以下隐藏上下文、390 窄屏隐藏的既有响应式规则。
- 不新增图标符号（`home` 已在原型与软件图标库中）。

## 3. 验收标准

- AC-CR087-01：给定任意页面，顶栏面包屑第一段显示小房子图标且不含「个人工作台」文字；`aria-label`／`title` 仍为「个人工作台」。
- AC-CR087-02：图标 14px，颜色与面包屑主体一致（`--ink-2`），未降为分隔符的 `--muted`。
- AC-CR087-03：面包屑其余部分不变：分隔符 `/` + 当前页面名；进入项目后为 `/ 项目名`。
- AC-CR087-04：深色主题下图标可见；390 窄屏沿用既有规则隐藏整个上下文且无横向滚动。
- AC-CR087-05：设计稿与正式软件使用同一图标符号与尺寸，同条件截图对照无未解决差异。
