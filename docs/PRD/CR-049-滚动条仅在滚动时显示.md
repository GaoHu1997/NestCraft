# CR-049：滚动条仅在滚动时显示

- 状态：需求范围已确认；仅需求／可操作设计，待设计评审；无本次正式编码授权。
- 来源：2026-11-20 用户反馈「当页面高度超过窗口大小时，会出现滚动条，比较碍眼。我需要滚动条只在滚动的时候出现，滚动停止后隐藏」；记录更新于2026-11-21。
- 归属：[EPIC-001](../Plan/Epic/EPIC-001-工作台导航与视觉体验.md) → [FEAT-001](../Plan/Feature/FEAT-001-工作台框架与可操作评审.md) → [STORY-064 AC-40～43](../Plan/Story/STORY-064-主界面按评审意见重构.md#cr-049滚动条按滚动状态显隐)。复用共享视觉体验，不新增业务层级。

## 范围与行为

1. 当前原型中超高页面、正文、侧栏、列表、弹窗及编辑区的原生滚动条默认透明；实际滚动时仅该容器的滑块可见。
2. 最后一次滚动事件后700ms自动隐藏；连续滚动重新计时。700ms为代理采用的可逆设计默认值，不是用户指定时长。仅悬停、聚焦或不产生位置变化的滚轮操作不唤醒。
3. 不改变原有overflow、滚动条宽度、容器布局与滚动位置，不以隐藏滚动条禁用滚动。滚轮、触控、键盘及滑块拖动继续使用原生滚动机制；显隐不重绘正文，不清编辑草稿或选区。
4. 共用样式自然涵盖已有可见的横向滚动条；原本永久隐藏的Tab／统计横条继续隐藏，不新增横向溢出或第二套滚动控件。
5. 浅／深主题均使用现行主题色；嵌套、动态生成的滚动容器分别计时，不让子区滚动唤醒不滚动的父区。

## 不包含与依赖

- 不修改正式软件源码、运行配置、依赖、构建或发布产物；既有其他CR的正式授权不延伸到本次。
- 不改变导航、栏宽、业务状态、保存或权限；不读取生产数据、凭证或真实私密会话。
- 当前原型没有实际iframe或原生PDF插件；未来跨文档／跨源嵌入、原生编辑器及系统滚动条不承诺由父页统一控制，需要另行覆盖设计与验证。
- 无数据库需求：仅瞬时展示状态，不持久化、不迁移。
