### 2.2 顶栏两个新能力

**国内加速**

- 语义：写操作与私有仓库仍走直连；仅对 GitHub 读取（fetch／更新）按前缀重写，等价 `git -c url.<prefix>https://github.com/.insteadOf=https://github.com/`。
- 默认关闭；默认前缀 `https://gh-proxy.com/`；前缀必须以 `http(s)://` 开头且不含空白，否则不入参（失败即直连，不阻断操作）。
- 启用时顶栏按钮显示绿点。

**密钥配置**

- 语义：凭据按**远端主机**保存（一个 `github.com` 令牌服务本机所有仓库），不按项目或仓库保存。
- 存储：写入应用受管密钥文件（与既有 MCP 令牌同一 `secrets.json` 机制、同一互斥锁、原子替换）；列表接口只返回主机名、用户名与保存时间，**永不回显令牌**。
- 注入：网络命令按主机拼 `credential.<scheme>://<host>.helper` 与账号参数，令牌不进命令行以外的日志、不进 AI 上下文；无凭据时保持既有行为（系统 credential helper 照常生效）。
- 输入为空表示「保留原令牌」；删除入口按主机移除。

### 2.3 明确不包含

- 不改侧栏的位置、宽度调节与遮挡行为；不改编辑器、AI 侧栏与项目页签。
- 不做标签创建／推送、新建分支于指定提交、远程删除分支等参考实现里的右键菜单能力（本次不扩范围）。
- 不做 worktree 管理、设备流 OAuth 登录（参考实现特有），本次凭据只支持粘贴 Personal Access Token。
- 不改 Git 执行层的权限模型：仍只对已检出仓库开放，提交、推送等写操作沿用现有确认框。

## 3. 验收标准

- AC-CR067-01：编码 Tab 左侧切到 Git 管理时，面板结构与参考图一致：顶栏药丸 + 三个入口；三张卡片按 2:1:2 分配高度、各自圆角描边；未提交卡片内文件列表滚动而提交区固定。
- AC-CR067-02：变更行勾选即暂存／取消暂存；「全部暂存」「全部取消暂存」对相应分组整体生效；提交拆分按钮仅在「有已暂存文件且提交信息非空」时可用，▾ 菜单两项可用性同步。
- AC-CR067-03：分支区按「本地 / 远程」两棵树展示，当前分支整行高亮带 ✓；全部展开／全部折叠作用于两棵树；搜索同时过滤本地与远程；新建分支与切换沿用现有确认流程。
- AC-CR067-04：提交历史按图谱显示父子关系（合并提交为空心点），refs 显示 HEAD／tag／远程徽章，右侧为绝对时间；点击行展开变更文件与增删行数，同时只展开一条。
- AC-CR067-05：提交人、分支、时间三个筛选改变时重新查询（不是只过滤当前页）；无匹配时显示空态而非旧列表。
- AC-CR067-06：国内加速启用时顶栏显示绿点；前缀非法时给出提示且不生效；关闭后网络命令恢复直连。
- AC-CR067-07：密钥配置弹层只显示主机与掩码，保存后不回显令牌；空输入保存表示保留原值；删除按主机生效。
- AC-CR067-08：滚动条遵循 [UI-SCROLL-001](../UI/文档/UI-CR049-滚动条按需显示.md)：初始隐藏、滚动时出现、停止后隐藏；未提交列表、分支树、历史三个滚动区域分别独立，不互相唤醒。
- AC-CR067-09：空工作区、非 Git 目录、detached HEAD、读取失败、未设上游、无更多提交均显示对应状态，不假报成功。
- AC-CR067-10：深色主题与窄侧栏（默认 260px、最小 180px）下结构不重叠、不出现横向溢出；186px 以下按现状不新增断点。
