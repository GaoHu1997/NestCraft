# CR-082：工作台页签改为电脑图标 + 文字「工作台」

- 状态：已确认（用户直接指令）／已实现（设计先行 + 正式软件）
- 日期：2026-11-25
- 类型：需求变更（修订 CR-054 已确认的页签形态）
- 来源：用户 2026-11-25 原话「项目中 那个工作台，现在是一个图标，需要修改一下，改成一个 电脑图标 后面 写 工作台 三个字。」
- 关联：[CR-054](CR-054-会话中心工作台.md)／[FEAT-021](../Plan/Feature/FEAT-021-会话中心工作台.md)／[STORY-071](../Plan/Story/STORY-071-工作台页签与三栏布局.md)／[UI-CR082](../UI/文档/UI-CR082-工作台页签电脑图标与文字.md)
- 授权：本条为界面修改的直接指令，按 AGENTS §4.3 登记为正式编码授权；仍先更新设计稿（UI-CR082），再改软件，范围仅限项目页签条的工作台页签。

## 1. 背景

CR-054 于 2026-11-22 确认工作台页签为**纯图标**（`atDesk`「坐在电脑前的小人」），不显示文字，名称只由 `aria-label`／`title` 提供。实际使用中纯图标不易识别，用户要求改为**电脑图标 + 文字「工作台」**。

## 2. 变更内容

| 项 | 变更前（CR-054） | 变更后（CR-082） |
| --- | --- | --- |
| 页签内容 | 仅图标 `atDesk`（坐在电脑前的小人），18px | **电脑（显示器）图标 `monitor` 16px + 文字「工作台」** |
| 图标符号 | 复用 `atDesk` | 新增 `monitor`：24×24、1.6px 描边、`<rect x="3" y="4.5" width="18" height="12" rx="2"/>` + 支架底座 `M9 20.5h6`、`M12 16.5v4` |
| 排版 | `gap:0`、`min-width:44px`、图标 1px 光学补偿、下划线 10px 内缩 | `gap:6px`、padding 与相邻文字页签一致（原型 0 12px／软件 0 14px）、下划线回到文字页签口径（原型 8px／软件 10px），去掉最小宽度与光学补偿 |
| 可读名称 | `aria-label`／`title` =「工作台」 | 不变；`aria-label`／`title` 仍为「工作台」，文字内容同步为「工作台」 |

## 3. 不包含

- 不改默认进入工作台、三栏布局、左右栏宽度记忆、会话运行时与单实例约束。
- 不改右栏辅助栏、AI 请求开栏协议、链接定位分流。
- 不改项目页签顺序、页签高度（44px）、CR-052 溢出「更多」下拉机制。
- 不改 `atDesk` 符号本身（保留在图标库中，供其他用途或追溯）。

## 4. 验收标准

- AC-CR082-01：给定任一编码或办公项目窗口，则项目页签条最前的页签同时显示电脑（显示器）图标与文字「工作台」，`aria-label`／`title` 均为「工作台」。
- AC-CR082-02：图标为新增 `monitor` 符号、渲染 16px，与 13px 文字垂直中心对齐（误差 ≤1px），图标与文字间距 6px。
- AC-CR082-03：页签高度与其他项目页签一致（软件 44px），选中下划线内缩与文字页签同一口径；未选中态与深色主题下图标与文字均可见。
- AC-CR082-04：窄屏（390）页签条不产生横向滚动，溢出仍走 CR-052「更多」下拉；页签可读、可点击切换。
- AC-CR082-05：设计稿与正式软件使用同一图标符号与同一排版参数；设计/软件同条件下截图对照无未解决差异。
