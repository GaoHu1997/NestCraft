# CR-044：窗口融合、统一图标与详情 Tab 导航

- 来源：2026-11-20 用户逐项要求先调整需求／设计，再调整代码：窗口操作区融合、透明界面 Logo、系统图标有底、平台统一图标、CLI 官方 Logo、尺寸／颜色／分割线／对齐、详情隐藏主菜单与唯一对象 Tab。
- 状态：本次需求／设计与正式编码均明确授权；设计评审与验证进行中，未验收。
- 归属：EPIC-001／FEAT-001，复用 STORY-061（导航）、STORY-064（公共视觉），品牌沿用 UI-BRAND-001 已选帆船，不重绘。
- 不包含：新业务功能、Task／Run 执行内核、权限升级、真实服务测试、数据库迁移或安装包发布。应用 identifier 与用户数据目录保持不变。

## 1. 确定的导航模式

采用用户优先提出的统一方式，不混用“详情隐藏”与“固定宽主菜单”两套：

1. 工作台／项目管理／知识库／服务器管理属于同一个管理首页，切换只更新首页内容，不新建列表 Tab。
2. 顶部 Tab 栏移到整个内容宽度的最左侧，不再从右侧主内容列开始。第一项固定为“首页”，不可关闭；已有对象 Tab 依次排列，长列表仅栏内横向滚动。
3. 打开具体项目／知识库／服务器隐藏整个左侧主菜单，内部文件树／资料导航保留；点击首页恢复管理主菜单及上次管理列表。
4. 对象键为类型＋稳定 ID。普通“打开”命中已有对象只聚焦原 Tab，不重置子页签、选中项、滚动、草稿或会话；显式文件定位可以更新目标内部位置，但不新增重复 Tab。
5. 同名不同 ID 是不同对象。关闭某对象不影响其他 Tab；关闭前检查／提示未保存内容与运行状态。未知草稿状态不得当作无草稿，取消保留全部状态；不以关闭 Tab 隐式删除文件或停止会话。
6. 主菜单仅在管理首页显示。本批不增加第二套可折叠图标轨道，避免不同模块使用不同导航规则。

## 2. 桌面窗口与品牌

- 统一56px顶栏：品牌、当前上下文、常用操作与最小化／最大化（还原）／关闭操作共享主题底色与分割线，不叠加旧系统标题栏或重复的软件名称。
- 原生窗口允许拖动、双击最大化／还原、调整大小；可点击控件排除拖动热区；最大化图标根据实际窗口状态显示。
- 界面帆船为透明 PNG，无承载底色、无边框／阴影；中文与英文独立排版，图形本身无文字。
- 快捷方式／文件图标／任务栏图标使用有薄荷色承载底的独立 PNG／ICO。不得把系统图标重新用于界面透明 Logo。
- 浏览器原型的窗口控制只模拟状态，不实际关闭浏览器或调用宿主；正式桌面调用原生窗口 API，失败明确提示。

## 3. 平台图标与视觉规格

- 建立 UI-ICON-001-v1：平台线图标24×24 viewBox、1.6px round stroke、无实心底；14px紧凑／16px默认／20px大入口，图标不可裁切，不用缺省网格冒充缺失语义。
- 常见范围：首页／项目／知识／服务器、目录／文件与格式、Git、AI／会话／工具／能力、状态／审批、窗口操作、编辑／删除／搜索／筛选／上传下载、设置／主题／对齐布局。
- 图标样例仅存放于 `docs/UI/文档/` 的UI规范资料，供评审与后续开发参考；平台和可操作业务原型不提供图标展示页、顶部／菜单／设置入口或弹窗。平台只替换现有不合适图标，继续使用统一图标资产。
- CLI 图标使用可核来源的官方图形，不使用 CL／CX／GK／DS 字母占位。若产品无独立 CLI 标志，准确注明采用官方厂商品牌标志；不得自绘后称官方，资源来源／许可随资源留存。
- 默认图标按钮32px，紧凑28px，窗口操作46×32px；文本按钮32px／紧凑28px。图标和文字垂直居中，默认6px间隔，内边距采用4／8／12／16px阶梯。
- 分割线统一1px主题线色；同级栏头／页签基线对齐；悬浮框按触发控件定位，不推动布局。
- 普通弹窗460／620／760／820px档，设置1040×700px；均受视口内边距约束、内容内部滚动，不能裁切关闭与确认按钮；只顶层响应 Escape。
