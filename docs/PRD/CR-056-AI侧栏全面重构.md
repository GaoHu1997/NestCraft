# CR-056：AI 侧栏全面重构

- 状态：已确认范围，进入设计与开发；来源：用户 2026-11-21 要求基于现有参考实现全面调整需求、设计与编码。
- 目标：把 AI 侧栏改成可长期使用的会话工作区，输入、会话状态、执行步骤、CLI/权限、消息身份和模型配置都必须有真实可观察的状态来源。
- 归属：复用 EPIC-006、FEAT-010/011/012/014/015，覆盖 STORY-021/022/024/025/048/049/062；不新增第二套会话体系。

## 1. 用户结果

用户在一个侧栏内可以：

1. 用 `+` 快速添加文件、会话、知识、目标、任务和已启用能力；目标与任务会在输入框上方形成可编辑、可暂停、可取消的会话状态。
2. 直接在输入框输入 `@` 或 `/`，得到跟随光标的候选浮层；候选支持键盘上下、Enter、Escape、鼠标选择、模糊过滤和 IME，不丢失草稿或光标。
3. 清楚看到消息是谁产生的：用户与 AI 以排版和时间区分，不使用「我」「AI · CLI/模型」这类角色前缀；子代理、工具、系统/审批各有独立内容块和稳定身份；模型、CLI、任务和工具结果不会混成一条「AI 未上报」。
4. 在非运行状态切换已安装且启用的 CLI、模型、思考档位和权限；运行中或有未结束子任务时配置冻结，并给出原因。
5. 看到每一轮的执行步骤、目标、任务、子代理和工具结果；步骤状态不能用普通消息伪造，失败不能显示成成功。
6. 在模型配置中看到供应商、可用端点、文本/视觉/生图能力、上下文窗口、思考档位以及证据状态；生图模型不进入会话候选，未知信息显示未知。

## 2. 范围

### 2.1 输入与 `+` 菜单

- `+` 是一个输入上下文菜单，分为“引用”“会话状态”“能力”三组；点击外部、Escape 或再次点击关闭，焦点回到输入框。
- 引用：项目文件、当前项目会话、已授权知识库、办公文件；选中后形成可删除 chip，并在发送前再次校验归属和权限。
- 会话状态：新建/编辑目标、新建任务、查看任务与步骤；所有操作仅作用于当前 Session，不修改项目 Task/Run。
- 能力：Skill、MCP、Tool；候选必须来自已启用清单，选择只形成请求引用，真实执行以事件为准。

### 2.2 `@` 与 `/`

- 触发条件为光标前最近一个 token；`@` 展示引用候选，`/` 展示 Skill/MCP/Tool/命令候选。
- 浮层锚定输入框和光标附近，窄屏不超出视口；候选列表内部滚动，滚动条遵守 `UI-SCROLL-001`。
- 上下键移动高亮，Enter 插入候选，Escape 先关闭候选再关闭输入菜单；IME 组合期间不发送、不抢占 Enter。
- 插入后保留可见 token 与结构化引用，发送时使用结构化对象，不把展示文本当权限或工具调用。

### 2.3 目标、任务与步骤

- 目标是当前 Session 的可编辑状态：进行中、已暂停、已取消；编辑、暂停/恢复、删除均保留 revision/history。
- 任务显示独立 taskName、状态、来源和耗时；不能取最近一条消息作为任务名。
- 执行步骤显示在消息流尾部，状态为未开始、进行中、已完成、失败、等待用户；显示 done/total、耗时、退出码和来源。
- 子代理步骤与工具步骤分开；子代理结束后允许展开查看任务、模型/CLI、耗时、tokens、输出和归属，未知值显示“未知”，禁止显示“未上报”作为身份替代。

### 2.4 CLI、权限和模型

- CLI 候选只来自 SDK 支持且 installed + enabled 的清单；显示 Logo、版本、安装状态、能力证据和当前会话是否锁定。
- 空会话可切换 CLI；非空会话切换弹出“新建会话继续”确认，原会话历史与运行回调不变。
- 权限模式按 CLI 能力矩阵显示：可用项可选，不可用项显示具体缺口（审批通道、隔离、版本证据、工具限制）；按钮名称不得伪装成已生效能力。
- 发送前后端重新解析 `permissionId + capabilityRevision + sdkVersion + modelId + effort`，生成并冻结 LaunchSpec；前端不能直接拼接 argv。
- 模型候选过滤生图/非文本/无可用端点/无有效凭据的模型；每行固定显示上下文、视觉、思考三项。思考档位仅显示当前模型声明且有 wire 映射的档位，未知不回落为默认。
- 模型列表支持供应商分组、搜索、键盘导航、空态、重试和配置入口；选择模型不会关闭配置层，切换模型后上下文快照标记为待重估。

### 2.5 消息与多 Agent 展示

- 消息时间线按 producer 分组：用户消息、主 AI、子代理、工具调用/结果、系统/审批、错误。
- 用户消息使用右侧内容块 + 时间行；主 AI 回复不显示头像和「AI · CLI/模型」标题，来源信息不抢占正文层级。
- 每条 AI 消息显示时间；模型未知时显示明确的未知状态，不显示含糊的「模型未上报」。
- 子代理结果必须带稳定 agentId/taskName/状态/父会话归属；迟到事件不能复活已结束任务，重复结果去重。
- 工具块显示工具名、参数摘要、执行中/完成/失败、输入与输出；审批请求显示实际请求内容、风险、可用决定和超时，不用普通系统文案代替。

## 3. 不做事项

- 不复制项目 Task/Run、需求状态或真实账单为另一套可编辑数据。
- 不把未知能力、未知权限、未知 tokens 或未知耗时填成 0 或成功。
- 不在没有后端能力证据时开放 full/auto 等危险模式；不以修改按钮文字代替真实 CLI 参数。
- 不新增外部依赖，不读取真实凭据到前端，不把参考项目代码整体复制进本项目。

## 4. 验收标准

- AC-056-01：`+`、`@`、`/` 在浅色/深色、桌面/390px 窄屏下可打开、筛选、键盘选择、Escape 关闭且不丢草稿/光标。
- AC-056-02：目标、任务和步骤有独立状态源；创建、编辑、暂停、恢复、取消和失败状态可见，项目 Task/Run 不被修改。
- AC-056-03：消息流不使用「我」「AI · CLI/模型」角色前缀，用户与 AI 以排版、时间和内容块区分；思考折叠块、子代理、工具、系统/审批各有独立语义块；模型未知时显示明确的未知状态，不出现「AI 未上报」占位。
- AC-056-04：CLI 只显示已安装启用候选；非空切换创建新会话；运行/未结束子任务时 CLI/模型/权限冻结并解释原因。
- AC-056-05：权限候选按 CLI/版本/能力证据过滤，可用项显示真实语义，不可用项显示原因；发送前后端复检配置快照。
- AC-056-06：模型列表按供应商分组、搜索、过滤生图，展示上下文/视觉/思考，思考档位与模型声明同步，未知不推测。
- AC-056-07：子代理和工具事件按稳定 ID 去重、终结状态不可被迟到事件复活，步骤与消息来源可追溯。
- AC-056-08：AI 侧栏所有列表/浮层/正文滚动遵守 `UI-SCROLL-001`：滚动显示、停止 700ms 隐藏、嵌套隔离、输入光标与草稿保持。
- AC-056-09：发送轮次显示用户消息时间；运行中显示 logo 粒子打散重组的运行指示与运行时长；没有正文时显示「思考中…」；思考结束后的折叠块显示思考持续时长；供应商返回 429/限流/502/503/504 时，同一轮最多退避重试 2 次，重试次数、等待时间和原因进入消息流，最终失败保留错误和草稿。
