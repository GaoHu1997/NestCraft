## 1. 目标

让正式软件的「项目管理」「知识库」「服务器管理」三页在结构、信息层级、视觉与关键状态上与 workbench-v4 设计稿一致，并把设计稿展示的信息接入真实数据（后端命令 + 数据库），不再以「暂未接入」占位。

## 2. 本次范围（包含）

1. **项目管理页**
   - 卡片结构对齐设计稿：图标砖＋名称＋`项目编号 · 类型`＋编辑；**项目描述**；**项目标签**＋`N 个运行`；**需求进度进度条（完成数/总数）**；底部**负责人头像＋姓名＋更新时间＋打开**。
   - 搜索框 placeholder 改为「搜索项目、负责人或标签」，搜索范围含名称/编号/负责人/描述/标签/目录。
   - 副标题、页脚统计对齐设计稿文案（页脚用真实口径）。
   - 项目 `负责人 / 描述 / 标签` 可新建与编辑（当前为 disabled 占位）。
2. **知识库页**
   - 卡片改为设计稿的纵向单列结构：图标＋名称＋「描述 · 负责人」＋授权项目名标签＋篇数·更新时间＋图标/管理授权/进入。
   - 副标题、页脚文案对齐；知识库 `描述 / 负责人` 可编辑并入库。
3. **服务器管理页**
   - 卡片展示 CPU／内存／磁盘 百分比、分组·系统（OS）、更新时间；未连接/未采样显示「—/未知」。
   - 主交互改为点击卡片进入工作台；「添加主机」文案对齐；页脚文案对齐。
4. **数据接入（后端 + DB）**：project 增 `owner/description/tags`，派生 `需求进度(完成/总数)` 与 `运行数`；knowledge_library 增 `owner/description`；server_host 增指标缓存列（`os/lastSeenAt/cpuPct/memPct/diskPct`）。详见 DB-CR072。

## 3. 不做事项（边界）

- 不预置或改写用户的真实项目/知识库/主机列表，不以演示样例覆盖真实数据。
- 不改知识库授权边界、SSH 审批与风险门禁、执行任务状态机与运行语义；仅新增展示字段与只读统计。
- 不改三页之外的页面；不改变项目图标体系（CR-070）与整体导航（CR-070）。
- 不新增网络请求、不写入远端主机；服务器指标仅在已连接时按既有 `server_metrics` 采样缓存。

## 4. 规则与口径

- 需求进度口径：`requirement_index` 中 `type='story'` 为总数，`status='completed'` 为完成数；无数据为 0/0（进度条 0%）。
- 运行数口径：`execution_task` 中该项目处于活跃状态（非 `succeeded/failed/cancelled/blocked/paused`）的任务数；无该表或无记录为 0。
- 负责人头像：取负责人姓名首字生成首字母圆（无负责人时留空/显示默认）。
- 与设计稿的已知差异按 §6.3.1 记录：设计稿为虚构夹具（4 个样例项目、负责人、进度、指标为演示），本次保留其**结构与视觉**，数据改为真实来源；不复制演示数值。
