# CR-081：本地数据统一存储与目录分类

- 状态：已实现，待验收（2026-11-24）
- 来源：用户要求"数据存储也要到 data 中，统一管理，不要到处放"，并点名 AI 聊天历史、skill/mcp、日志等本项目数据都要迁入、按分类划分。
- 关联：[CR-077](CR-077-知识库文档操作.md)、[LLD-CR078](../LLD/LLD-CR078-本地数据统一存储.md)

## 目标

本项目产生的持久数据集中在一个数据根下，按类别分目录；默认是安装目录的 `data`，可在设置里改到其它本机目录。旧版本散落在系统应用目录的数据在启动时安全迁入，不覆盖既有文件。

## 目录分类

| 目录 | 内容 |
| --- | --- |
| `db/` | `workbench.db`（含 -wal/-shm）与冒烟隔离库 |
| `chat/` | CLI 会话线程存储 `<cli-id>-profiles/<session-id>/`（`--resume` 续接依赖） |
| `knowledge/` | 知识库明文文件 `<库名>/`，可直接拷入文件 |
| `recycle/` | 知识库回收站 |
| `index/` | 检索索引（Tantivy 快照） |
| `skills/` | Skill 受管副本 |
| `secrets/` | `secrets.json`（MCP/供应商）与 `server-secrets.json` |
| `avatar/` | 头像图片 |
| `logs/` | 冒烟报告、进度与冒烟夹具 |
| `editor/` | 文档保存恢复材料 |
| `git/` | `git-credentials` |
| `office/` | 办公演示容器目录 |
| `generated-images/` | 生图输出 |
| `examples/` | 内置示例 |

## 规则

- 数据根在启动时确定一次；运行中修改"数据存储位置"只写偏好并标记需重启，避免数据库连接与写入分叉。
- 切换位置后，下次启动以旧根为迁移来源搬入新根；目标已存在则保留，不覆盖。
- 不迁移、不改动第三方 CLI 自身目录（如 `~/.claude`、`~/.codex`）与用户项目目录；只处理本项目受管数据。
- 知识库仍为明文目录；索引与原件分离，删除回收后重建索引，AI 不会命中已移走文件。
