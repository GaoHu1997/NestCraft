## 1. 背景与用户目标

知识库已经具备文件树、Markdown 阅读编辑、PDF/Office 只读预览、本地语义检索与图谱。用户在实际使用中提出五条体验问题：一处多余按钮、三类格式仍看不到、模型没有落在统一数据目录、图片只能看小图不能缩放查看、Markdown 阅读页的操作条常驻且正文不能滚动。本轮目标是逐项收敛为可验收的行为，且不扩大知识库业务范围。

## 3. 本次范围

### 3.1 包含

- 左栏顶部独立「上传」按钮移除；上传入口收敛到目录 `+` 菜单与拖拽，能力不减少（AC-01、AC-02）。
- PDF 打开即预览，不再请求转换组件（AC-03）。
- Office 缺组件时改为可理解的状态卡：说明原因、提供「准备组件／下载原件／重试」，组件就绪后可只读分页预览（AC-04、AC-05）。
- 语义模型目录改到数据根下 `semantic-model`，旧位置幂等迁移；界面显示实际目录（AC-06、AC-07）。
- 图片查看器：适应窗口 / 100% / 放大缩小 / 滚轮缩放 / 拖拽平移 / Esc 关闭 / 焦点回归（AC-08、AC-09）。
- Markdown 阅读页右上操作组默认隐藏、悬停或聚焦浮现、触摸常显；正文修复为可完整纵向滚动，滚动条按需显示（AC-10、AC-11）。
- 五个场景的浅／深／窄屏设计稿与验证证据（AC-12）。

### 3.2 不包含

- 不把 LibreOffice 塞进安装包，不改变“转换器需要本机组件”的既有安全边界；具体准备方式见待确认项 D2。
- 不支持旧 `.doc/.ppt/.xls`（沿用 CR-084 的 `UNSUPPORTED_RESTRICTED`），不承诺宏、外链、加密文档。
- 不改动知识索引、全文检索、AI 只读授权、知识图谱与文档操作的既有业务范围。
- 不做图片 OCR、格式转换、原图编辑；缩放只影响查看，不写回原件。

## 4. 业务流程与边界

1. **文件树**：左栏顶部只剩「首页／切换空间」；文件树「空间目录」与每个目录行的 `+` 菜单保留新建与「上传」；拖拽仍可移动文件。上传结果、索引失败提示与现状一致。
2. **格式分流**：`.pdf` → 直接 PDF 预览（不调用转换器）；`.docx/.pptx/.xlsx/.rtf` → 需要转换器；转换器缺失 → 状态卡；转换进行中 → 进度与取消；转换成功 → 分页只读预览；`.doc/.ppt/.xls` → 明确不支持并提示另存。
3. **模型目录**：启动时计算数据根 → `semantic-model`；若旧 `%APPDATA%` 目录存在且新目录不完整，则逐文件补齐、不覆盖；进程内注入 `NESTCRAFT_EMBED_MODEL`/`ORT_DYLIB_PATH`；缺失时检索回落关键词（现状不变）。
4. **图片**：正文图片点击打开查看器；查看器初始“适应窗口”，可 100%、±10%、滚轮缩放（10%–800% 边界），拖拽平移，Esc/关闭返回并回焦原图；不修改原件。
5. **Markdown 阅读**：右上操作组（编辑、更多）默认 `opacity:0` 且不接收指针；鼠标进入正文区或键盘聚焦时显示；`@media (hover:none)` 常显；正文滚动容器整链 `min-height:0`，可滚动到文末，滚动条按 UI-SCROLL-001 仅滚动时显示。

## 5. 质量与外部依赖

- 滚动条：适用 [UI-CR049 滚动条按需显示](../UI/文档/UI-CR049-滚动条按需显示.md)（UI-SCROLL-001）；本次涉及正文阅读区、文件树、图片查看器。
- 可访问性：查看器与操作组支持键盘，Esc 关闭；操作组隐藏时不可聚焦（避免隐形 tab 停靠点），显示后可聚焦。
- 安全：Office 转换沿用既有宏/外链安全校验与私有临时目录；图片查看不加载外部地址；模型迁移不覆盖已有完整文件。
- 依赖：Office 预览依赖本机受管转换组件（运行配置）；PDF 依赖现有 pdf.js。
