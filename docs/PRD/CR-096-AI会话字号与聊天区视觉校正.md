## 1. 背景与问题

用户在日常使用 AI 会话时发现 5 处观感／一致性问题，逐条对应现状证据：

| 编号 | 用户原话 | 现状事实（代码位置） |
| --- | --- | --- |
| R1 | 「ai 答复的文字太大了，跟我发出去的文字不协调，需要缩小成一致的」 | 助手正文 `16px`，宽容器下升到 `18px`（`src/modules/chat/message-zcode.css:8`、同文件 `@container` 段）；用户气泡 `12.5px`（`src/modules/chat/chat.css:60`）。设计基线二者同为 `12.5px`（`docs/UI/workbench-v4/ai.css:30、32`） |
| R2 | 「右侧悬浮显示的每轮会话的概览的悬浮框也有问题，调整一下，现在大小不合适」 | 软件有右侧回合导航（`src/modules/chat/TurnNavigator.tsx`）：标签 `max-width:132px`、`font-size:11px`、单行省略；容器 `width:180px`、`top:50%` 垂直居中。设计稿侧**完全没有该组件** |
| R3 | 「背景色就是白色跟其他位置保持一致就好了，消息位置为什么要搞个别景色」 | 消息区写死 `background:#f8f8f8`（暗色 `#161616`），与面板 `--surface` 不一致（`message-zcode.css:13、27`）。设计稿消息区无独立背景，继承面板 `--surface`（`ai.css:6、21`） |
| R4 | 「会话位置的帽子为什么顶部还有个白条，都是灰色就好了啊。会话输入框和帽子样式参考图2」 | 软件 `.chat-composer` 为 `border-radius:28px` 的一体白卡，帽子 `.chat-hat` 是卡内子元素且 `padding-top:8px` 让卡片白底在帽子上方露出形成「白条」（`composer-reference.css:3-21`、`composer-hat.css:9-13`）。设计稿帽子贴卡片顶端、卡片 `border-radius:12px`（`cr079.css`） |
| R5 | 「工作台模式下，有上角的 ai侧栏图标就不要显示了」 | 软件 `pw-ai-toggle` 按钮在工作台页签仍渲染（`src/modules/projects/Workspace.tsx:106`）；设计稿已有 `body.wb-active .ai-toggle-btn { display:none }`（`docs/UI/workbench-v4/workbench.css:134`），软件未落地该规则 |

判定结论：R1、R3、R4、R5 为**软件偏离有效设计**（应先登记差异、修软件符合设计），R2 为**设计缺失**（需先补可查看设计）。

## 3. 本次范围

**包含**

1. 助手答复正文、列表、标题、行内代码、代码块、表格的字号收敛到与用户气泡一致的可读尺度；对话内工具/思考/子智能体等摘要行同步收敛，避免正文与摘要反差过大。
2. 消息区背景统一为面板背景（浅色白、暗色随主题），不再使用独立灰底。
3. 会话框帽子：取消帽子上方的白条；帽子灰底铺满卡片顶部宽度并贴合圆角；输入框与帽子同属一张卡片，卡片圆角按图 2 收敛。
4. 右侧每轮概览浮框：放大为可读卡片（字号、宽度、两行摘要、序号与摘要层级），并给出连续刻度条的合理尺度与滚动规则。
5. 工作台页签下不显示右上角 AI 侧栏开关按钮；其它页签保持现状。

**不包含**

- 不改变消息的生成、流式、重试、编辑重发等行为与数据结构；无 DB 变更。
- 不改动 CR-079 定义的功能控件集合与交互（分段、分支、worktree 的语义不变）。
- 不引入图 2 中软件还没有的项目名下拉、`＋` 新建等新控件。
- 不调整统计条、模型选择器、历史菜单等 CR-074 已定义区域。
- 不做全局字号缩放体系或「字号设置项」；本次是默认值校正。
- 不调整侧栏（非工作台）与工作台两布局的其余差异。

## 4. 业务规则与边界

| 规则 | 内容 |
| --- | --- |
| 字号一致 | 同一条消息流中，用户气泡与助手正文的 `font-size` 相同；不允许按容器宽度把正文升到更大字号。标题、行内代码、代码块允许按层级差异化，但最大标题不超过正文的 1.6 倍 |
| 背景一致 | 消息区不得定义与面板不同的背景色；浅色主题下与面板同为白，暗色主题下同为暗色 `--surface` |
| 卡片一体 | 帽子与输入区在同一张卡片内；帽子上边缘与卡片上边缘重合，帽子上方不得露出卡片底色；卡片圆角与帽子顶角一致裁切 |
| 浮框可读 | 浮框宽度足以显示「第 N 轮」与一段中等长度摘要；摘要超长时最多两行后省略；浮框不得遮挡消息正文的可点击区域（指针事件只在其自身边界内生效） |
| 工作台互斥 | 工作台页签已内含会话区，右上角不再出现 AI 侧栏开关；切回其它页签时恢复 |
| 滚动 | 全部适用滚动区域遵循 UI-SCROLL-001：静止隐藏、实际滚动显示、停止后约 700ms 隐藏；禁止 `overflow:hidden` 禁用滚动或用宽度变化实现隐藏 |
| 编辑状态 | 任何视觉调整不得导致输入框光标、选区、草稿丢失；不得改变输入框可编辑性 |

权限、数据归属、付费服务：本次不涉及。
