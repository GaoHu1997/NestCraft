# CR-103：待发队列面板单行紧凑化＋可折叠

- 类型：既有能力呈现调整（密度优化＋可折叠）；不改变队列功能（删除/编辑/立即发送/暂停继续）与数据口径（本机内存队列）
- 状态：**已实现，技术验证通过，待验收**（2026-11-26）。用户同日明确「授权开发」后实现；证据见 [REPORT-CR103](../Test/REPORT-CR103-待发队列单行紧凑与折叠.md)。
- 来源：2026-11-26 用户附软件截图——会话输入区上方待发队列面板仅 1 条消息时即占约 4 行高度（头部行 + 全文行 + 操作按钮行 + 底注行），并提出：**「待发队列太高了，需要更折叠后的高度一样」**；同轮澄清确认采用方案：**每条消息单行紧凑**；同日再次追加：**「待发队列也需要可以折叠」**（单行紧凑＋面板可折叠组合）。
- 归属：FEAT-010 侧栏会话输入区（工作台布局继承同一组件）；AC 挂 [STORY-062 会话答复呈现与文件定位](../Plan/Story/STORY-062-会话答复呈现与文件定位.md) CR-103 增量节。队列能力本体来自 CR-076 消息呈现第三批（AC-STORY-062-CR076-16），其既有验证记录不改写。

## 1. 现状问题（依据用户截图；软件代码位置 `ChatPanel.tsx` `ChatQueuePanel` / `chat-actions.css` `.chat-queue-*`，实现授权后只读核对补记）

| 问题 | 表现 |
| --- | --- |
| 每条消息占高过大 | 消息全文不限行数换行平铺 + 独立元信息行 + 独立操作按钮行，一条消息约 3 行；随消息变长继续增高 |
| 面板高度不可控 | 多条排队消息时面板成倍增高，持续压缩输入区与消息区可视高度 |
| 高度与信息价值不匹配 | 队列条目是"待发便签"而非阅读正文，完整平铺的阅读价值低 |

## 2. 需求规则

| 编号 | 规则 |
| --- | --- |
| R-CR103-1 单行条目 | 每条排队消息固定单行呈现：全文超宽时截断省略（`text-overflow:ellipsis`，不换行），完整内容保留在 `title` 悬浮提示；行高与面板总高不随消息长度增长 |
| R-CR103-2 行内操作 | 「编辑／立即发送／删除」收进同一行（条目行右侧），不再单独占一行；删除为危险色，其余中性，间距与现行按钮规范一致 |
| R-CR103-3 元信息压缩 | 引用数、附件数不单独占行，以紧凑小标内联在文本前（如 `🔗2` `📎1`），仅在有内容时显示；「已暂停」不再逐条重复标注（暂停状态由头部「暂停／继续」按钮统一表达），此为代理细化默认值，实现前可推翻 |
| R-CR103-4 编辑态例外 | 点「编辑」时该条目临时展开为多行编辑框 + 「保存／取消」，其余条目保持单行；编辑取消或保存后恢复单行 |
| R-CR103-5 列表限高滚动 | 排队消息较多时列表区限高（约 5 行），超出部分列表自身滚动；适用 UI-SCROLL-001（初始隐藏、滚动显示、停止约 700ms 隐藏、悬停不单独唤醒），不得因此禁用滚动或引发布局跳动 |
| R-CR103-6 结构保持 | 头部（`待发队列 N` + 暂停／继续）与底注（内存队列说明）保留不变；不改变队列操作行为与内存持久化口径 |
| R-CR103-7 全局适配 | 浅／深主题、侧栏窄容器（390）与工作台两布局下单行条目、行内操作无溢出、无横向滚动，动作可达 |
| R-CR103-8 面板可折叠 | 头部左侧提供 ▾／▸ 折叠开关：折叠时仅保留头部一行（≈29px），条目与底注隐藏但不销毁，队列内容与暂停状态不受影响；默认展开（保持现行为），折叠状态在会话内记忆（内存）；此默认值为代理细化，实现前可推翻。折叠开关与「暂停／继续」为两个独立控件，互不替代 |

## 3. 验收标准（唯一事实来源登记于 STORY-062 增量节）

- AC-CR103-01：给定队列含 1 条排队消息，当面板显示，则该消息为单行截断省略（完整内容见悬浮 title），操作按钮同行右侧；面板总高约为头部行 + 1 条目行 + 底注行，不随消息文本长度变化。
- AC-CR103-02：给定条目带引用／附件，当显示，则以紧凑小标内联呈现，不新增行；队列暂停时头部按钮为「继续」，条目不再重复「已暂停」标注（或按最终确认结果呈现）。
- AC-CR103-03：给定点某条目「编辑」，则仅该条目展开为编辑框 + 保存／取消，其余条目保持单行；取消或保存后该条目恢复单行。
- AC-CR103-04：给定队列消息数超过限高，则列表区自身滚动，按 UI-SCROLL-001 按需显示滚动条（滚动显示、停止后隐藏、悬停不唤醒，含动态证据）；面板外部布局不跳动。
- AC-CR103-05：浅／深、390 侧栏与工作台布局下无溢出、无横向滚动，行内按钮可达；与旧版相比同场景面板高度明显下降且有同条件成对对照证据。
- AC-CR103-06：给定点头部折叠开关，当切换，则折叠时仅保留头部一行（≈29px，条目与底注隐藏不销毁），展开恢复单行列表；折叠状态不改变队列内容与暂停状态，会话内切换会话后保持记忆（内存）。

## 4. 范围外（明确不做）

- 不改变队列功能语义：暂停／继续、编辑保存、立即发送、删除行为与数据流不变；不新增持久化（折叠状态与会话同生命周期，内存记忆）。
- 不改动队列面板以外的输入区、运行栏、消息流布局。
