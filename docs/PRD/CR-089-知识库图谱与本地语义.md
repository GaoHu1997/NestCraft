## 背景与目标

知识库已是本地文件夹库（CR-088 后有 `[[双链]]` 与反链）。本轮补三件事：
1. **看得见关系**：知识图谱（节点=笔记/附件，边=已解析双链）。
2. **AI 能按需读库**：5 个内置工具（进程内，不经 MCP/网络）。
3. **换个说法也能搜到**：本地小模型语义检索，与关键词混合。

## 用户已确认的关键决定（2026-11-25）

| 议题 | 决定 |
| --- | --- |
| 对外暴露 | **不对外**，只做平台内置工具 |
| 语义模型 | **需要**，用本地小模型（int8 量化，目标 ≤30MB） |
| 图谱默认视图 | **局部图（当前笔记为中心）**，可切整库总览 |
| 语义索引建立 | **首启后台自动建立**，可取消、有进度；模型缺失时明确降级 |
| 模型分发方式 | **首次启动联网下载**（用户 2026-11-25 决定）：模型与运行时**不打进安装包**，安装包体积不增加；下载完成后自动建索引 |

## 范围

**包含**
- 图谱：局部/总览、深度 1–3、含附件、只看未解析、点击跳转、双击展开、截断提示。
- 工具：`knowledge_search` / `knowledge_read` / `knowledge_links` / `knowledge_graph` / `knowledge_list`，复用项目授权与片段预算，可单独停用。
- 语义：本地模型编码（int8/512 维）、`kb_embed` 派生索引、增量更新、关键词+语义 RRF 融合、模型缺失降级为纯关键词并在界面/工具结果标注。
- 索引进度与状态可见（模型可用性、已编码/总块数、最近更新时间）。

**不包含**
- MCP/HTTP 对外服务；云端 embedding；LLM 抽取式 GraphRAG（实体/社区摘要）；cross-encoder 重排；`![[嵌入]]`、块锚点。
