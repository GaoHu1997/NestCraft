- 来源：用户 2026-11-22 指令「打包完成之后平台中有示例项目，打包自己就放进去了，不需要我再说」，并指定三套示例（编码 / 办公 / 知识库）的内容与质量要求（文件真实、类型齐全、与 NestCraft 相关、不要占位文本）；同时明确「整个执行过程不要问我，一切都按照推荐的执行」。
- 关联：[FEAT-001 工作台框架](../Plan/Feature/FEAT-001-工作台框架与可操作评审.md)（唯一父项）、[STORY-074](../Plan/Story/STORY-074-内置示例项目随包发布.md)；延续 2026-11-18 产品评审纪要决议「示例项目随包 + 首次启动安装」（纪要全文收录在知识库示例 `05-会议与纪要`，用户确认依据见 STORY-074 元数据）。

## 1. 背景与目标

新装用户首次打开 NestCraft 时，项目列表与知识库为空，用户不知道平台能做什么、第一步点什么。2026-11-18 产品评审已决议采用「示例项目随包 + 首次启动安装」，上一批次（c4cbe8e）落入了示例内容与安装模块骨架，但存在三个缺口：

1. **安装从未接线**：`ensure_seeded` 未被任何启动路径调用，命令未注册——打包后示例永远不会出现。
2. **办公示例只有 README**：说明文件里描述的源资料、数据分析、交付 PPT 等目录并不存在；评审遗留问题 Q-057-01（办公示例是否在磁盘生成真实 pptx）未决。
3. **隐藏缺陷**：文件写入路径以子目录为根重复拼接，实际会把全部内容写到双层嵌套目录（如 `examples/v1/code/calculator/code/calculator/`），项目绑定指向空目录；且「删除后不复活」的评审决议在代码里未生效（记录缺失会触发重播种）。

目标：首次启动自动、幂等地安装三套真实、可直接使用的示例；删除不复活；不覆盖用户数据；安装失败不阻塞启动。

## 2. 本次范围／不做事项

**包含**

1. `setup` 阶段自动调用安装（非冒烟模式），并注册 `seed_example_workspace` 命令供查询 / 手动补装（幂等）。
2. 编码示例「计算器 · 示例项目」：需求树（愿景 / Epic / Feature / Story）、PRD、UI 设计稿与交互说明、LLD 与 ADR、可运行 HTML/CSS/JS 代码、Node 测试与验证记录（上一批次内容，本轮修复其落盘路径）。
3. 办公示例「NestCraft 产品介绍 · 示例项目」：01 源资料（定位速览 md、白皮书 docx、问答摘编 md）、会议与访谈（评审纪要 md）、02 数据分析（能力地图 xlsx、演示素材清单 csv）、03 交付成果（**11 页真实 pptx，含演讲者备注与出处标注**）、历史资料（v1 草稿）。Q-057-01 拍板：**落盘真实 pptx**。
4. 知识库示例「NestCraft 产品资料库（示例）」：7 个目录、11 种格式（md / docx / xlsx / pptx / pdf / png / drawio / csv / json / txt / pos），全部为 NestCraft 相关真实内容。
5. 安装语义：幂等、不覆盖已有文件、同名不同目录不冒用、**删除不复活**、失败不阻塞、冒烟模式跳过、版本升级只补新文件并复用记录（`SEED_VERSION` 1→2）。
6. 单元测试覆盖安装全生命周期（8 项，含新增 4 项集成级用例）。

**不包含**

1. 不新增 / 修改任何界面元素——示例出现在既有项目列表与知识库列表中，无 UI 变更，§6.3.1 视觉对照不适用（理由：本轮零界面改动）。
2. 不提供「恢复示例」入口（纪要决议：下个迭代再议）。
3. 不在示例中预置真实模型密钥、真实服务器或生产数据；示例内容全部标注为合成 / 内置样例。
4. 不改变项目、办公、知识库的既有功能逻辑。

## 3. 业务流程

1. 用户安装并首次启动 NestCraft。
2. `setup`（`lib.rs`）完成建库与迁移后调用 `ensure_seeded`：读取 `examples.seed.version`；已安装且记录齐全则直接返回。
3. 首次安装：示例内容从二进制内嵌资源（`include_bytes!`，随包发布、无外部资源目录依赖）解压到 `<应用数据目录>/examples/v2/`，并在本地库登记两个项目（`type='code'` / `type='work'`）与一个知识库（`managed-directory`）。
4. 前端既有列表接口自然读出示例；用户可直接打开计算器项目走「需求 → 设计 → 代码 → 测试」，或打开办公项目查看资料与成品 PPT。
5. 用户删除示例项目 / 知识库后：版本标记仍在，下次启动**不重建**（记警告）。
6. 升级：`SEED_VERSION` 变化触发重播种；已有文件跳过（用户改动不覆盖）、缺失文件补齐、项目 / 库记录按目录复用。

## 4. 规则与边界

- **只安装一次**：以 `examples.seed.version` + 示例记录 ID（`examples.seed.projects` / `examples.seed.libraries`）双重判定；不按名称猜测身份。
- **不覆盖**：逐文件跳过已存在文件；同名不同目录的项目 / 知识库不冒用，记警告跳过创建。
- **不复活**：版本相同但记录缺失视为用户已删除，保留版本标记并不再重建。
- **不阻塞**：安装失败只返回错误 / 警告日志，应用正常启动；未完整安装时下次启动重试（版本未写全时自然重触发）。
- **冒烟隔离**：`TAURI_SMOKE=1` 跳过安装，保持冒烟库由夹具自建的确定性。
- **体积约束**（纪要风险项）：三套示例合计约 1 MB（编码 109K / 知识库 501K / 办公 380K，含 11 页 PPT 310K），无音频 / 大图。
- **内容边界**：示例数据为合成内容，在示例 README 与 PPT 中明确标注；不引用 `docs/参考/`，不残留参考项目标识。
