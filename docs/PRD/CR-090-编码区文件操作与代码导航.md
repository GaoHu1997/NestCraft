## 1. 背景与目标

编码区当初按 openidea 的「文件树＋行号编辑器」两个部件落地（见 [CR-015](CR-015-启动Tauri正式实现.md)），骨架同源但能力断代：文件树只有单击打开与刷新，编辑区只有多页签/脏点与行号，**没有文件操作、没有语义导航**，与成熟 IDE 的操作手感差距明显。本 CR 目标是在不重做整个工具窗口体系的前提下，先补齐「操作感」与「代码导航第一版」，让日常编码可用。

### 1.1 事实边界（分清已确认事实 / 计划 / 未确认）

- **事实（有调研证据）**：`src/modules/editor/` 现有文件树**无右键菜单、无新建、无重命名、无删除**；编辑区**无 LSP、无 Ctrl+点击、无面包屑、无导航历史**。证据见 [RESEARCH-007 §9.3](../调研/RESEARCH-007-openidea编码区与代码导航.md)。
- **计划**：本轮「做吧」按调研建议的 **P0＋P1 第一版**推进——P0 文件树与页签操作（S1／S2），P1 定义跳转与面包屑（S3，基于符号索引）。实现范围以本 CR 为准；P2（实现类跳转、引用、类型层级、gutter 标记）不在本轮。
- **未确认**：跳转到实现类、完整 LSP 语义（引用/类型层级/悬停文档/用法高亮）**未获范围确认**，一律不作为本轮承诺，留作后续 CR。

## 2. 本次范围

### S1 文件树操作（→ STORY-101）
右键菜单（新建文件／新建文件夹／重命名／删除／刷新／在编辑器中打开）、行内输入、键盘 F2／F5／Delete、删除二次确认、失败提示。

### S2 页签与打开交互（→ STORY-102）
页签拖拽排序；「单击打开」开关（默认关，默认双击打开）；预览页签（斜体、可被替换、双击或编辑即固定）；关闭脏页签的确认。

### S3 代码导航第一版（→ STORY-103）
Ctrl+悬停下划线＋Ctrl+点击跳转**定义**；多目标选择器；面包屑（文件 › 符号链）；Alt+←/→ 导航历史。**第一版基于符号索引，不做完整 LSP 语义**：跳转到实现类／查找引用／类型层级**不在本 CR**，留作后续 CR。

## 3. 不做事项

1. 完整 LSP 接入（`textDocument/implementation|references|typeHierarchy`、悬停文档、用法高亮、gutter 标记）。
2. 多语言类型推导与跨语言语义分析。
3. 分屏编辑、拖出成独立窗口、双击最大化。
4. 调试、运行、重构（重命名重构、安全删除重构等）。
5. 工具窗口体系重做（stripe 图标条、命名布局快照、面板头多视图等）。
6. 本轮只做需求文档，不写设计稿、不改 `src/**`／`src-tauri/**`／`docs/UI/**`。

## 4. 规则、权限与边界

1. **路径边界**：所有文件树写操作（新建/重命名/删除）的路径必须落在当前项目根内，`..` 与符号链接越界须在后端拒绝并提示，磁盘不得越界写入。
2. **失败不丢内容**：任何文件操作失败（只读、占用、权限、网络盘断连）只提示失败，**不得丢失已打开的编辑内容或未保存缓冲**。
3. **只读真实边界**：只读文件／目录、超大只读窗口、二进制只读提示等既有边界继续有效；操作被拒须有明确提示。
4. **键盘可达**：文件树与页签的关键操作可用键盘完成（F2 重命名、F5 刷新、Delete 删除、Escape 取消；页签切换/关闭）。
5. **深色与窄屏**：右键菜单、行内输入、页签条、面包屑在深色主题与窄屏下不破版、不横向溢出。
6. **导航只读**：定义跳转、面包屑、导航历史均为只读导航，**不修改文件内容**、不自动插入或格式化。
7. **滚动条**：涉及滚动容器遵循 [UI-SCROLL-001](CR-049-滚动条仅在滚动时显示.md)，滚动时显示、停止隐藏；不得用 `overflow:hidden` 实现隐藏。
8. **预览页签语义**：预览页签只占一个槽位，被下一个预览替换；双击或开始编辑即固定为正式页签。

## 5. 质量要求与外部依赖

- 交互须先有可查看设计（UI-CR090-v1）并登记版本，再进入软件实现（AGENTS.md §6.3.1）。
- 代码导航第一版**基于符号索引**，不依赖完整语言服务器；对不支持的语言明确降级文案。
- 文件操作复用现有 `fs_*` Tauri 命令；如需 rename/move/create 等新增后端命令，在 LLD 中暂定接口。
- 性能边界（大目录、超大文件）沿用 [CR-055](CR-055-大规模编码与知识库性能.md) 既有约束，不另立数值。
