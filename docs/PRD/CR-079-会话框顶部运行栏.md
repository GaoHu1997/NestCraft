- 状态：**已实现，待验收**（2026-11-25 用户「修改代码」授权）。 依据 2026-11-24 用户提供参考截图并要求“调整会话框”：在上面加一个浅灰色“帽子”，放 CLI 和助理切换；右侧显示当前 git 分支（无则不显示）；最右 worktree 复选框；CLI 才有 CLI 切换，助理没有 CLI 切换、只有权限，权限按 runtime 选项来。

## 1. 目标与范围

| 区域 | 规则 |
| --- | --- |
| 顶部“帽子”栏 | 输入框上方的浅灰色条（圆角、与输入框衔接），左侧放运行通道切换。 |
| 运行通道切换 | 分段控件「CLI ／ 助理」，当前项高亮；运行中锁定。 |
| 右侧分支 | 显示当前项目 git 分支；**无仓库/读取失败不显示**，不硬编码 `main`。 |
| worktree 复选框 | 最右；勾选后当前会话**将在独立 git worktree 工作区执行**。本轮为界面开关＋明确提示，真实 worktree 隔离执行后续执行层接入（用户已确认）。 |
| CLI 模式工具区 | 显示 CLI 切换与 CLI 权限档位；由已安装 CLI 作答。 |
| 助理模式工具区 | **不显示 CLI 切换**；只显示平台专属权限档位（只读／受限／完全访问），由平台工具白名单与运行策略决定。CLI 与平台权限档位分开。 |

不包含：真实 git worktree 创建与执行隔离；新增持久化；改变模型/工具/上下文/审批规则；CLI 内部步骤统计。

## 2. 已确认决策

- **worktree**：先做界面开关 + 明确提示，真实独立工作区执行作为后续执行层工作单独接入（用户 2026-11-24 选择）。
- **助理权限**：用平台专属档位（只读／受限／完全访问），与 CLI 档位分开（用户 2026-11-24 选择）。助理＝现有“平台主代理”（platform 运行通道）。

## 3. 验收标准（设计与实现共用）

- AC-CR079-01 给定会话输入框，当渲染，则在输入框上方显示浅灰“帽子”运行栏，左侧为「CLI／助理」分段切换；运行中两端均禁用。
- AC-CR079-02 给定 CLI 运行通道，则工具区显示 CLI 切换与 CLI 权限档位；切换为助理后 CLI 切换消失。
- AC-CR079-03 给定助理运行通道，则只显示平台专属权限档位（只读／受限／完全访问），不出现 CLI 切换；权限弹层标题为“助理权限”。
- AC-CR079-04 给定当前项目有 git 分支，则帽子栏右侧显示分支 chip，点击可展开分支列表查看项目其它分支（当前分支高亮）；无仓库／读取失败时不显示，不硬编码分支名。
- AC-CR079-04b 给定会话框，则浅灰“帽子”栏与输入框等宽对齐（两端不超出、不缩进）。
- AC-CR079-05 给定最右 worktree 复选框，勾选时为勾选态并提示“将在独立 worktree 工作区执行”；取消还原；运行中禁用。
- AC-CR079-06 两布局（侧栏／工作台）、浅／深主题、1440×900 与 390×844 下帽子栏不溢出、控件可操作；遵守 UI-SCROLL-001（本栏无独立滚动容器，继承共享规则）。
- AC-CR079-07 视觉以 UI-CR079-v1 为基准，设计稿与实现同条件对照；未实现真实 worktree 执行时不得宣称工作区已隔离。
