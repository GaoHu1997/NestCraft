## 范围与选定方式

用户确认的是“外层一个入口＋文档集中＋不改原视觉／业务”，不是指定浏览器跳转实现。主代理原考虑移动原型HTML本体，收敛后选择保留内部运行页以保持原相对资源基址和 file:// 存储来源：新增 [仿真原型UI.html](../UI/仿真原型UI.html) 为唯一公开入口，以0秒meta refresh直接打开当前内部原型并提供唯一fallback链接；不使用iframe，不复制工作台或状态，绝不转去历史稿。这是主代理选定的可逆目录技术方案，不伪写成用户另给了“跳转壳”指令。

内部 `docs/UI/task-workbench/index.html`、CSS/JS、样例数据和会话／任务逻辑仍为原运行资源；公开导航只推荐根入口。原型内部仅使用说明链接因文档搬迁而修复，具体资源与布局检查由主代理负责。
