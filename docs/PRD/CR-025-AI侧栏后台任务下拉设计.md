# CR-025：AI侧栏后台任务下拉设计

- 日期：2026-11-19，Asia/Shanghai；类型：既有能力细化；负责人：lead。
- 来源：用户原话“ai侧栏，顶部，n个子智能体 旁边增加 后台任务的下拉框。大模型可能有一些后台执行的任务，也需要记录展示。如果没有后台任务，这里不展示”，附后台记录参考图。
- 确认范围：上述位置、后台执行记录与零记录隐藏由用户指令确认。仅需求／设计调整，未获得正式编码、运行或构建授权。
- 归属：沿用 [STORY-021](../Plan/Story/STORY-021-多会话历史与后台任务.md)，唯一父项 [FEAT-011](../Plan/Feature/FEAT-011-会话历史与后台任务.md)，所属 EPIC-006。不新建重复任务体系。

## 本次范围与规则

1. AI头部历史按钮与右侧新建／关闭保留；中间子智能体后面增加“n 个后台任务⌄”，采用紧凑线性图标和浅色无底座样式。后台记录数为0时隐藏整个控件，无“0个”、禁用按钮或空占位。
2. 数量为**当前会话保留的后台执行记录总数**，包含运行中与已结束。仅运行数归零不隐藏；清除全部结束记录且无运行项后才隐藏。后台作业不是会话Todo、目标、项目Task/Run或子智能体，分别计数，不把子代理实例重复算作作业。子智能体启动的后台作业可以归父会话，详情标注来源。
3. 下拉分“进行中”“已结束”两组，组头数量来自同一记录源，组可折叠。行显示状态点、工具／执行方式、单行省略的命令或名称、状态／退出码、耗时与独立展开箭头。展开可读完整命令、jobId、归属、状态、已收集输出及错误；无输出明确显示“暂无输出”。
4. 状态文字明确区分运行、完成、失败、取消与未知；未知退出码／起止时间不填0，显示未知。退出码0只说明命令正常退出，不意味着项目技术验证或用户验收完成。
5. 参考图“清空”采用低风险语义：只清除当前会话的已结束展示记录，不终止运行作业，不清会话消息／用量／子智能体／其他会话，不删除正式执行审计。无已结束项时禁用并说明。
6. 切换会话／工作区、隐藏侧栏／打开其他菜单不终止已记录后台作业；异步状态更新严格按原scope/session/jobId归属，不写入当前新会话。新建空会话不继承其他会话记录。
7. 桌面固定400px侧栏保留，中间控件可折行（不缩成只有图标的不可识别入口）；浮层右对齐侧栏，宽度至多600px、受视口限制，允许向左扩展而不挤主区。窄屏视口内可滚，深色继承令牌。支持点击、键盘Enter/Space/Escape和外点关闭，菜单互斥，清空最后一项回到可见控件焦点。

## 不包含与边界

不接真实CLI/AI/job服务、不新增执行或取消权限、不增全局任务中心、定时任务／持久化／自动清理策略。原型仅受限合成夹具与显式DEMO事件，关闭页面不保证后台常驻。既有会话busy/权限/模型门禁不被此只读列表改变；真实后台执行与恢复仍待正式方案及明确编码授权。已有参考图与本项目菜单复用足够，不额外获取外部源码。
