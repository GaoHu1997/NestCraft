## 2. 本次范围

包含（呈现与定位层）：

1. 工具调用与工具结果的**配对分组**与统一卡片视觉层级（含运行中、成功、失败、空结果状态）。
2. **图片预览框**：约束尺寸、边框、圆角、说明文字、点击放大、加载失败占位。
3. **文件定位链接**：识别 `路径:行[:列]` 并渲染为可点击链接样式。
4. **点击在左侧打开并定位**：在编码页签左侧文件区打开目标文件，滚动到目标行并高亮；跨页签（需求/设计页签点击时）的行为见 §4。
5. **CLI 显示回填**：会话已存执行配置时，底部控件必须显示实际值。
6. 思考块收起态给出内容规模提示。

不包含：

- 会话控制（模型/思考档位/权限/子智能体/统计）——属 CR-019，本轮不并入。
- 附件解析与图片上传（本轮只处理模型输出中的图片引用与项目内图片路径）。
- 外部 URL 的图片抓取与代理（安全边界见 §5）。
- 真实工具审批通道（仍为 permission-mode 决定，见 LLD-FEAT-002 §3.1）。
- 任何正式源码修改（本轮为设计与需求）。

## 3. 业务规则与行为

### 3.1 工具调用与结果配对

- 以 `toolId` 为主键配对 `tool_use` 与 `tool_result`；同一 `toolId` 的调用与结果合并为一个「工具块」，不再各占一条独立消息外观。
- 工具块头部：工具名、关键参数摘要（如命令、文件路径）、状态（运行中/成功/失败）、耗时（未知显示未知，不填 0）。
- 结果正文默认折叠；失败时默认展开错误摘要（尾部保留诊断信息，中部截断）。
- 空结果显式标注「无输出」，不显示空卡片。
- 配对缺失（只有调用无结果，或只有结果无调用）时，单侧成块并标注「结果未返回」/「来源调用未记录」，不伪造配对。
- 同一条 assistant 消息内的多个工具调用按出现顺序排列，保持与文本的因果顺序。

### 3.2 代码块

维持现有格式框（灰底、圆角、边框、等宽、横向滚动）。补充：

- 语言标识（`rust`、`json` 等）显示在块右上角，未知则不显示。
- 长代码块超过阈值（默认 40 行）默认折叠，提供展开；复制按钮可选，不属于本次必需项。

### 3.3 图片预览

- 图片渲染必须在容器内等比缩放：最大宽度 100%，最大高度默认 360px，不超出消息卡边界。
- 有边框、圆角、浅底；下方显示替代文本（`alt`）作为说明；无 `alt` 时显示文件名。
- 点击图片打开放大浮层（覆盖当前会话区，Esc/点击遮罩关闭），支持按容器等比适配。
- 加载失败显示占位框与「图片加载失败」及原始路径。
- 图片来源规则见 §5。

### 3.4 文件定位

- 识别格式：`路径:行`、`路径:行:列`；路径可为相对项目根或绝对路径；Windows 反斜杠与正斜杠等价。
- 渲染为链接样式（主色、可聚焦、hover 明确、`title` 显示完整路径与行列），并保留行号。
- 不可解析（文件不存在/越界）时仍渲染链接但点击后给出明确失败提示，不静默失败。
- 行号必须是可选的：仅有路径时点击定位到文件开头。

### 3.5 点击在左侧打开与定位

- 在项目「编码」页签：左侧文件区打开目标文件页签（已打开则复用并激活），编辑器滚动到目标行并在行号槽高亮。
- 在「需求」「设计」页签点击文件链接：切换到「编码」页签并完成上述打开与定位，用户可返回原页签（保持原页签上下文）。
- 非项目上下文（服务器会话、无项目会话）无左侧编辑器：链接退化为「复制路径」并提示原因。
- 定位失败（文件已删除、工作区变更）提示原因，不改变当前打开的文件。
- 跳转不修改文件内容，不触发保存。

### 3.6 执行配置回填

- 会话已存 `cliId` / `modelId` / `effort` 时，底部控件显示实际值。
- 已存值失效（CLI 卸载、供应商删除）时，保留显示原值并标注失效状态，阻止发送并给出修复入口；不静默回落到第一个候选项。
- 从未选择过执行配置时，才显示「未选择」。

## 4. 边界与非目标

- 文件链接只允许解析项目根内路径；越界路径渲染为普通代码，不做点击。
- 图片只允许项目内相对路径（受管目录）与 `data:`/`blob:` 内联；外部 `http(s)` 图片默认不自动加载（隐私与越权风险），显示链接并提示。
- 定位只读；不提供「在此处运行」「跳转并修改」等隐式写操作。
- 不改变已有工具调用协议与后端事件契约；配对与呈现均在前端完成（后端仅需保证 `toolId` 稳定，现已满足）。

## 5. 质量要求

- 无障碍：链接可键盘聚焦，放大浮层可 Esc 关闭并管理焦点；状态不只依赖颜色（成功/失败均有文字）。
- 性能：长会话中配对计算按消息批次进行，不得每次渲染全量重算导致卡顿；折叠块内容懒渲染。
- 兼容：浅色与深色主题均需检查；窄视口（390×844）下图片与代码块不产生整页横向溢出。
- 可观察验收：每条 AC 需在真实应用窗口中截图取证，不以 DOM 存在性替代视觉判定。

## 6. 验收标准

- AC-CR034-01：同一 `toolId` 的调用与结果合并为一个工具块；头部含工具名、参数摘要与状态。
- AC-CR034-02：工具结果默认折叠；失败时展开错误摘要并保留诊断信息；空结果标注「无输出」。
- AC-CR034-03：配对缺失时单侧成块并明确标注，不伪造配对。
- AC-CR034-04：图片在消息卡内等比缩放（宽≤100%、高≤360px），有边框与说明，不撑破容器不裁切。
- AC-CR034-05：点击图片可放大，Esc 与点击遮罩均可关闭，焦点回到原位置。
- AC-CR034-06：图片加载失败显示占位框、失败文案与原始路径。
- AC-CR034-07：`路径:行[:列]` 渲染为可点击链接样式（可直接观察颜色、hover、焦点态）。
- AC-CR034-08：点击链接后在编码页签左侧打开该文件，滚动到目标行并高亮该行。
- AC-CR034-09：从需求/设计页签点击时切到编码页签完成定位，且可返回原页签。
- AC-CR034-10：路径越界或文件不存在时给出明确失败提示，不改变当前打开文件。
- AC-CR034-11：非项目上下文下链接退化为复制路径并说明原因。
- AC-CR034-12：会话已存执行配置时底部控件显示实际值；失效值保留显示并标注、阻止发送。
- AC-CR034-13：思考块收起态显示内容规模提示（如字数或行数）。
- AC-CR034-14：深色主题与 390×844 窄视口下，上述各场景不出现横向溢出或遮挡。
