## 2. 交互规则与替代

- 地址仍只分 OpenAI／Anthropic 两种；Chat 与 Responses 共享 OpenAI 地址。两个地址的补填入口在新增和编辑均存在。替代旧稿按“新增时是否建端点”限制后续入口的行为，不增加第三种端点协议。
- 供应商 ID 只在首次保存之前可编辑；未指定时生成稳定唯一 ID，重名拒绝保存。已有引用按 ID 绑定，改名称不改变引用。
- 密钥列表范围仅一个按钮，选择在草稿中进行，保存后更新范围、取消不改变；供应商仍为整体提交边界。明文复制是用户主动点击行为，密钥不写提示、日志或DOM属性；原型只用 `demo-not-a-real-key-*` 合成值。
- 自动能力补齐有来源才选中模态；上游未返回、知识库未知时不能猜。已手动选择的模态不覆盖。思考档位仍按现行来源链解析，不因“能获取清单”推断支持视觉。
- 检测固定字段在所有历史记录中使用相同网格，长值省略，摘要固定空间；已有 20 针及归因面板语义保留，不把概率性提示改为确定判断。
- CLI 的跟随主 agent 保留为默认，另可指定兼容已配置模型；模型未配置思考档位时选择器禁用。CLI权限选项按其自身能力获取，不借用当前侧栏所选另一CLI的数据。
- SDK近期日志只保存操作类型、时间、SDK和版本、结果与脱敏日志，最多五条。刷新同时更新本机状态与最新版本，不将最新版本伪写成已安装版本。安装中的同SDK禁止重复操作。
- Skill导入后成为本地副本，编辑与外部源无关。列表描述两行省略；编辑可查看完整说明正文。
- MCP JSON采用结构化字段：`command` 可含空格、`args: string[]`每项完整保留、`env`值按原字符串；已结构化参数不再次分词。纯文本旧命令行只在明确的兼容入口做词法解析。格式错误显示字段／行号并保留输入，不保存半份配置。
