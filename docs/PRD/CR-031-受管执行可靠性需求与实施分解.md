## 2. 用户价值与当前事实

用户在派发授权范围后，能够辨别执行是否接纳、是否仍有子工作、结果是否完整、审批是否对实际动作生效；刷新、断线、重启和兄弟任务失败不会制造重复执行或虚假成功。权限不足、恢复不确定、产物结构错误都有明确原因与下一步。

现有会话桥有CLI启动、流式展示、会话/消息持久化与配置注入；消息结束后分类保存不能完整保留交错时序，交互式审批仍预留，直接child取消不足以证明整树停止。持久runner、DAG、产物验证、受控集成和outbox为已有设计，不将其记成已运行能力。本次只读核验依据是现行源码与既有LLD，不执行正式软件。

## 3. 本次需求规则

### 3.1 身份和状态

- 项目、根会话、Agent、执行Task/Attempt、后台Job、真实Process分别有稳定身份和明确关联；普通项目聊天以sessionTurn运行，不造Story/Task/Step/Attempt。所有运行对象共用完整InvocationBinding（root/parent/来源/fence/generation），同一Task子调用挂父Attempt，不另领Task级fence；子停止/重试不改变父/兄弟或释放父activeKey。
- 指令接纳仅表示被有效记录／排队；提示结束不等于执行静止。executionSettled要求无活动进程、排队执行、安排续行、待审批或正在消费的内部结果；sessionSettled聚合会话全部根。deliveryPending是UI/历史通知未确认的独立事实，UI离线不能让已完成执行假running。内部必需子结果由runner稳定consumer收录，失败有限等待，到期阻塞不假成功；静止本身不等于Story验收。
- 实际状态由runner与运行存储决定。UI查看指针和面板开关不改变运行归属；旧Attempt、旧子代次和停止后的迟到结果只留审计，不更新新阶段或复活运行。暂停/retry_wait/可恢复blocked在安全释放物理资源后仍保activeKey，禁止同Story/基线重复派发；不可恢复终态或明确finalBlocked且整树停止/清理完成才释放业务防重键。

### 3.2 事件与输出

- 接收工具调用、结果、文本和错误后，按归属与序号记录事实，部分回答在失败时保留；内容可以有界批量持久化，异常丢失的未确认尾段必须可识别，不作零丢失承诺。
- 完成通知可重复投递，消费需要幂等并确认；未读提醒不等于投递ACK，打开详情不触发任务重试。游标缺口、历史裁剪、服务重启均走明确补读或重取快照路径。
- 摘要与完整资源分开。输出明确完整、头尾样本／截断、捕获失败、未知；读取完整日志依然复查项目/资源授权。未知usage沿既有计量契约处理。

### 3.3 审批与规则

- 对完成规范化、策略编译和插件改写后的最终调用参数审批；后续参数／目标、计划／规则／授权修订改变，旧批准不可继续使用。执行前再次核对撤权、路径与目标实际身份。
- Host Tool、CLI原生工具、MCP、脚本桥分别证明受管门禁的覆盖。需要人工批准但当前运行模式无可靠传输时拒绝该调用／组合，不把免审批或直接失败冒充人工审批。
- 常驻授权底线不能按需省略；适用规则按项目/目录/任务/阶段选择并固定来源版本。首版规则源为可信宿主baseline、授权项目根及范围内祖先/子目录AGENTS.md、已选Skill，独立RuleResolver只读发现和hash，不借CR027设计资料工具读取规则。必须源不可读/未接入阻塞；子目录变化按scope相交使相关Plan失效，独立兄弟不受影响，根规则影响全项目；自然语言冲突不自动裁决扩权。执行门禁独立强制，有限修复沿原总预算/额度，不更改AC或扩大授权。

### 3.4 子代理、评审与交付

- 子计划独立冻结，权限/能力/预算受父交集限制。需要下游自动消费的交付采用严格ResultEnvelope；无法提供原生schema输出的适配器可通过受管结果收集实现，但必须有能力证据，不能只解析一段任意自然语言就放行。
- 结构合法、进程结束、产物成功、集成成功、用户验收分别记录。失败兄弟不抹掉有效独立成果；父会话结束不自动取消仍受权子任务，也不能在必需子任务未结束时交付成功。
- 阶段评审按冻结ValidationPlan选择只读human/builtin/模型方式，不暗增付费模型：designGate绑定需求/设计/AC快照，不要求未出现产物；artifactDelivery绑定产物修订与适用输入基线；integratedReview另须非空实际消费/验证基线。相应版本变化使旧Finding失效，不能代用户验收、必需测试或成对视觉证据。
- 完整交付报告、长日志与证据资源存文件，DB保存结构化状态、清单、短摘要和URI/hash。文件/DB中途失败必须可对账，未完整封存不得标成完整有效证据。
