## 实现方案（实现前）

1. 复用原型的 state、需求校验/草稿/原子审批、授权只读网关、会话历史/引用、SDK 队列；不改真实服务契约与正式 DB 设计。
2. 为避免并行覆盖，增量视图分别落在 cr014-shell.js/css（主代理）、cr014-project.js/css（项目代理）、cr014-settings.js/css（设置代理）。采用经典脚本同源载入，file 协议可直接打开，无框架依赖；页面最后统一 render，旧接口保留。
3. 主代理负责入口文件、导航与共享主题；项目代理只修改自己的两个模块，覆盖 project/design/requirementsPreview/architecture/files/gitPanel/assistantPanel；设置代理只修改自己的两个模块，覆盖 settingsPane/provider*/sdk*，不得覆盖 render、assistantPanel。
4. 顶部仅保留项目页签和信息入口；AI 独立高度和内部滚动。桌面目标 1440×900 / 1920×1080，390×844 纵向回落且不横溢；悬浮操作同样支持 focus-within。
5. 错误/空状态沿用明确反馈；全局开关撤销立即生效。模型编辑需草稿提交/取消，指纹为固定样例而非真实身份凭证，容量不代表实测。
6. 验证：JS 语法、浏览器 DOM/交互、权限与审批回归、截图审查、需求文档层级检查；既有测试与本次移除控件冲突时按新规格更新断言，不删除安全回归。
7. 无数据库变更、无部署和迁移。回退仅撤回本批独立视图/入口引用，保留用户原文件与历史产物；不使用 git reset。
