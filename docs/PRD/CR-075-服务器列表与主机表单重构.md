## 1. 来源、目标与范围

用户以软件「编辑主机」截图提出五项问题：

1. 编辑时弹窗下半部分空白。
2. 新增／编辑整体排列有问题，看起来不舒服，需要重新设计。
3. 服务器图标不使用自有图标、不可配置，使用连接服务器系统的官方 logo。
4. 不应再有连接／断开选项；进入工作台自动连接，关掉自动断开；新增／编辑时需要测试连接。
5. 说明文字太多，删掉说明。

目标：服务器页从「连接开关 + 表单堆叠」改为「主机对象卡片 + 按需自动连接 + 保存前验证」；弹窗按内容呈现，不再出现半屏空白；主机标识由检测到的系统决定，用户不可选择。

本次包含：服务器列表、新增／编辑主机弹窗、测试连接、进入／关闭工作台时的连接生命周期、工作台连接状态、系统标识与无标识占位、空／加载／错误／窄屏／深色状态，以及上述范围的 UI-SCROLL-001 义务。

不包含：真实 SSH 连接结果、真实操作系统检测实现、数据库结构变更、权限／审批规则变更、AI 运维会话、文件上传下载、连接池或断线推送；正式源码、配置、依赖、构建与发布产物不在本轮授权内。

## 2. 规则与行为

### 2.1 弹窗与表单

1. 新增／编辑共用同一结构：名称；主机地址＋端口；用户名＋分组（可选）；认证方式（密码／私钥／免认证）；对应凭据字段。分组保持可选。
2. 弹窗按内容高度呈现，底部操作栏始终可见；只有视口高度不足时才滚动正文，正文滚动不得把操作栏滚出屏幕，不得用固定高度或空白占位撑开。内容与操作栏之间不出现下半屏空白。
3. 校验错误就近显示在对应字段下，不把全部错误合并到底部一句话；保存失败保留输入与已选认证方式。
4. 字段标签、占位符、校验文案属于必要信息；解释性段落（页面副标题、页脚说明、免认证长解释、连接后能做什么）删除。编辑时仅保留“已保存，留空不修改”这类会改变操作结果的必要提示。
5. 密码／私钥口令输入不回显；编辑态留空表示沿用已保存凭据，不读取、不回传原值。

### 2.2 服务器标识

1. 列表卡片、工作台标题、服务器窗口页签统一使用连接后检测到的系统官方标识；检测结果来自系统本身，不由用户选择。
2. 不提供图标选择器、图标字段或“上传图标”；图标不可配置，不能从内置图标库替换。
3. 未连接或系统未知时使用中性服务器占位并标注系统未知；不得用错误品牌标识冒充。
4. 官方标识仅用于识别系统，不表示官方背书；商标归各自权利人，资源来源与许可见 UI 文档。

### 2.3 连接生命周期

1. 列表不再提供连接／断开按钮，也不以“已连接”徽标暗示常驻连接；列表只展示最近一次采样指标与采样时间，未采样显示 —。
2. 打开主机工作台时自动连接：先呈现连接中，再进入已连接或失败；同一工作台不得重复发起并发连接。
3. 关闭工作台页签（对象窗口）自动断开并释放该主机连接；切换其他页签时工作台仍打开，连接保持。
4. 失败状态只提供“重试”（恢复动作），不恢复成手动连接／断开开关；重试仍失败保持失败原因，不伪造已连接。
5. 自动连接不改变 SSH 审批、主机授权或高风险命令逐次确认规则；连接失败时终端、文件与监控均不可用且状态可辨。
6. 列表页不因连接生命周期改变主机数量、编辑／删除入口或进入工作台行为。

### 2.4 测试连接

1. 新增与编辑均提供“测试连接”，位置在底部操作区左侧；取消与保存保持右侧主次关系。
2. 测试使用当前表单中的地址、端口、用户名、认证方式与当前输入凭据；编辑态凭据留空时使用已保存凭据。测试不得先保存主机、不得写入连接列表或改变列表状态。
3. 状态：空闲 → 测试中（按钮禁用）→ 成功（显示检测到的系统）／失败（短原因）。测试成功不自动保存；用户仍需点保存。
4. 必填项缺失时先就近提示并停止测试；不可达、认证失败、超时等失败不得显示成功或系统名称。
5. 测试成功后保存，可将本次检测到的系统写入现有 `os` 字段；测试失败或未测试时，保留上次已知系统，未知仍显示占位。

## 3. 验收标准

完整可执行验收标准以 [STORY-035 CR-075 增量](../Plan/Story/STORY-035-服务器管理正式实现.md#cr-075增量) 的 AC-STORY-035-CR075-01～11 为单源，本文不重复维护。覆盖维度：

1. 弹窗按内容高度、底栏可见、短视口只滚正文。
2. 表单分组与字段顺序，去掉说明段。
3. 官方系统标识、未知占位、无图标配置入口。
4. 列表／工作台无连接断开按钮，自动连接、关闭断开、失败重试。
5. 测试连接的成功／失败／进行中，不先保存、不伪造。
6. 文案收敛。
7. 1440／390 无整页横向溢出，窄屏关键操作可见。
8. 浅／深主题可辨。
9. UI-SCROLL-001 动态显示与停止隐藏。
10. 键盘与可读名称。
11. 自动连接不放宽授权与审批，断开后不显示陈旧数据。

不适用：本轮无数据库结构变更、无新权限模型、无迁移；真实 SSH 与真实系统探测结果不在设计稿中宣称通过。

## 5. 待确认与决定

- Q-CR075-01（实现取舍，已有可逆默认）：关闭工作台“页签”即断开；切换页签不断开。若用户要求“关闭应用窗口也立即断开”，在正式实现中由进程退出兜底，不改变本设计。
- Q-CR075-02（非阻塞）：多主机并发工作时，列表是否显示“工作台已打开”提示。本版不显示，避免重新引入连接开关语义；如需要另行评审。
- 已决定：不使用自有服务器图标；不提供图标配置；不保留手动连接／断开双态按钮；测试连接仅用于保存前验证。
