## 运行正式应用

环境要求：Node 24+、Rust 1.99+（MSVC）、git、WebView2。

```text
npm install
npm run tauri dev     # 开发运行（首次需编译 Rust）
npm run build         # 仅前端构建
cargo build --manifest-path src-tauri/Cargo.toml   # 仅后端构建
```

SQLite 位于系统应用数据目录（%APPDATA%/com.agentworkbench.app/workbench.db）；CLI SDK 经「设置 → SDK 管理」安装后可用于会话。

**应用内自检**（不影响正式数据，使用独立库）：

```bash
PATH="$PWD/mockbin:$PATH" TAURI_SMOKE=1 SMOKE_MOCKBIN="$PWD/mockbin"   ./src-tauri/target/debug/agent-workbench.exe
# 报告输出到 %APPDATA%/com.agentworkbench.app/smoke-report.md
```
