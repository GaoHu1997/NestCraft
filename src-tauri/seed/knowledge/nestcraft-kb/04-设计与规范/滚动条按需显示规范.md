# 滚动条按需显示规范

> 编号：UI-SCROLL-001 · 关联 CR-049 · 适用于所有可滚动容器

## 1. 规则

1. 滚动条默认隐藏外观；只有**实际滚动**时才显示。
2. 停止滚动后，经过约定的静止时长（当前 700ms）再次隐藏。
3. 悬停、聚焦、鼠标进入容器都不单独唤醒滚动条。
4. 不得用 `overflow: hidden` 禁用滚动来「解决」滚动条问题。
5. 不得通过改动滚动条宽度引发布局跳动，也不得因重绘导致草稿、光标或选区丢失。

## 2. 适用范围

| 容器 | 是否适用 | 说明 |
| --- | --- | --- |
| 长文档正文 | ✅ | 阅读区、需求全文、知识库 Markdown |
| 文件树与列表 | ✅ | 项目文件树、知识库目录、会话历史 |
| 弹窗内容区 | ✅ | 设置、表单等超高弹窗 |
| 编辑区 | ✅ | 编辑器与文本域，滚动时不得丢失编辑状态 |
| 横向滚动容器 | 按需 | 原本要求不出现的横条不得重新显示 |

## 3. 嵌套容器

嵌套滚动区域分别判定：内层滚动只显示内层条，外层保持隐藏；外层滚动时内层不跟随显示。

## 4. 验证方法

静态截图不能作为验收证据。每处适用容器需验证 5 个状态：

1. 初始静止：不可见。
2. 开始滚动：目标容器内出现。
3. 连续滚动：保持可见并跟随位置。
4. 停止 700ms：隐藏。
5. 嵌套场景：只影响目标容器。

## 5. 例外

原生控件（如系统下拉、原生文件选择框）由系统绘制，不纳入控制范围，需在实现登记中说明。
