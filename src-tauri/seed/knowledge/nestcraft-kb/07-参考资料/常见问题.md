# 常见问题（FAQ）

## 通用

**Q1：NestCraft 需要联网吗？**
A：界面、项目、知识库都是本地能力；只有调用 AI 模型时需要网络。

**Q2：数据存在哪里？**
A：项目文件在你的项目目录里；索引、会话、设置存在本机应用数据目录的 SQLite 数据库里。

**Q3：卸载会不会删我的项目？**
A：不会。项目目录由你选择，卸载只影响应用自身文件。

**Q4：首次打开为什么已经有项目和知识库？**
A：平台自带示例（编码项目「计算器」、办公项目「NestCraft 产品介绍」、知识库「NestCraft 产品资料库」）。它们只安装一次，删除后不会自动重建，也不会覆盖你已有的目录。

## 项目与需求

**Q5：需求树为什么只显示部分文档？**
A：只有 `docs/Plan/` 下带稳定编号（front matter `id`）的文档进入树；其它文档出现在「源清单」并可全文阅读。

**Q6：可以不用 Markdown 吗？**
A：需求与设计建议用 Markdown；办公项目用办公工作区，支持 docx/xlsx/pptx/pdf 预览。

**Q7：项目能换目录吗？**
A：可以，但不会自动迁移文件；运行中的会话需要先停止。

## 知识库

**Q8：为什么 Word 文件点开只有元数据？**
A：二进制格式不在 WebView 内联渲染，避免解析风险；平台提供原件导出。需要 AI 阅读时，请转为 Markdown 笔记。

**Q9：知识库会复制我的文件吗？**
A：不会。平台只记录目录路径并建立索引，文件仍在原位置。

**Q10：授权给项目后，AI 能看到哪些内容？**
A：只有被检索命中并引用进入本次请求的片段，不是整库上传。

## AI 与会话

**Q11：为什么模型列表里没有图像模型？**
A：生图模型不参与对话候选，避免误用；图像能力按模型标签单独配置。

**Q12：会话能续接上一次吗？**
A：CLI 会话支持原生续接；绑定失效时会提示重建，不会静默丢失上下文。

**Q13：Token 消耗在哪里看？**
A：输入框下方的会话统计，可展开查看输入/输出与上下文占比。

## 更新

**Q14：免安装版怎么更新？**
A：右上角更新入口检查新版本，下载完成后提示重启应用；`portable.marker` 用于识别免安装形态。

**Q15：更新会覆盖设置吗？**
A：不会。设置、项目与知识库数据都在用户数据目录，更新只替换程序文件。

## 故障

| 现象 | 先检查 |
| --- | --- |
| 界面空白 | 重新打开应用；检查日志目录是否有渲染错误 |
| 模型请求 401 | 密钥、端点、协议是否匹配 |
| 知识库列表为空 | 目录是否存在、是否被禁用、索引是否失败 |
| 文件打不开 | 文件是否在项目目录内、是否被其它程序占用 |
