# AI 会话与模型接入

> 适用版本：平台 0.0.1 · 更新 2026-11-21

## 1. 三种执行方式

| 方式 | 说明 | 适用场景 |
| --- | --- | --- |
| 直连模型 | 平台按 Anthropic / OpenAI 兼容协议直接请求模型 | 日常问答、文档撰写、代码解释 |
| CLI 子代理 | 平台调用本机安装的 Claude Code / Codex / Grok | 需要工具调用、仓库探索、长任务 |
| 后台任务 | 派发后的任务在后台继续执行，可回看步骤 | 批量改造、回归验证 |

## 2. 模型供应商配置

设置 → 模型：

1. 新建供应商，选择协议（`anthropic` 或 `openai`）与基础地址。
2. 添加密钥（可多把，按别名管理，界面只显示掩码尾部）。
3. 拉取或手工登记模型；每个模型可单独设置能力标签：文本、视觉、生图。
4. 为模型配置思考档位映射（如 `off/low/medium/high` → 实际下发参数）。

注意：

- 密钥仅保存在本机数据库，不随项目目录同步。
- 端点不可用时，错误会回到会话里，不会静默换用其他供应商。
- 视觉模型才能接收图片；不支持的模型在候选列表中被过滤。

## 3. 会话界面要点

| 区域 | 作用 |
| --- | --- |
| 顶部模型选择 | 切换供应商/模型与思考档位，当前会话内生效 |
| 输入框 `@` | 引用文件、需求、知识库笔记、历史会话 |
| 输入框 `/` | 命令与 Skill |
| 权限选择 | 只读 / 工作区写入 / 完全访问等模式 |
| 步骤折叠框 | 展示工具调用与子代理执行过程 |
| 底部统计 | 会话数、Token、上下文占用；点击展开明细 |

## 4. 上下文与费用

- 每次发送都会把引用对象的内容快照附加到请求中，引用即冻结。
- 上下文占用接近窗口上限时，界面提示新建会话或精简引用。
- 生图模型不出现在对话模型候选里，避免误用。

## 5. 失败与重试

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 401/403 | 密钥无效或无权限 | 检查密钥与端点 |
| 429 | 触发限流 | 平台按退避重试；持续失败需降低频率 |
| 超时 | 网络或模型响应慢 | 检查网络；必要时换端点 |
| CLI 启动失败 | 命令工具路径错误 | 设置 → CLI 命令工具，改选自动探测或指定路径 |

## 6. 安全边界

- 会话不自动把整个项目上传；只有被引用的内容会进入请求。
- 知识库内容需要显式授权才可被 AI 读取。
- 工具调用中的写操作按权限模式与审批策略执行。
