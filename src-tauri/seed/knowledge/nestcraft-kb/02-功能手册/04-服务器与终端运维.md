# 服务器与终端运维

> 适用版本：平台 0.0.1 · 更新 2026-11-21

## 1. 能力范围

| 功能 | 说明 |
| --- | --- |
| 主机管理 | 保存主机地址、端口、用户名与认证方式（密码或密钥） |
| 连接与会话 | 建立 SSH 连接，打开交互式终端 |
| 文件浏览 | 远端目录树与文件查看 |
| 命令执行 | 单条命令执行与结果回看 |
| 监控 | CPU 核数、平均负载、内存、运行时长等基础指标 |

## 2. 使用流程

1. 服务器管理 → 新建主机，填写地址与认证信息。
2. 连接后进入工作台：左侧主机与目录，中间终端，右侧监控。
3. 终端里可直接执行命令；涉及写操作或高风险命令时按权限策略处理。
4. 断开连接不会删除主机记录，下次可继续使用。

## 3. 安全建议

- 优先使用密钥认证；密码仅保存在本机数据库。
- 生产主机单独分组，避免在演示或测试时误连。
- 高风险命令（删除、重启、权限变更）建议先在同环境验证再执行。
- 不要把含有密钥、令牌的输出粘贴进会话或知识库。

## 4. 常见故障

| 现象 | 排查 |
| --- | --- |
| 连接超时 | 网络、防火墙、端口是否正确 |
| 认证失败 | 密钥权限、用户名、密码是否匹配 |
| 终端无输出 | 远端 shell 是否正常；尝试重新打开终端 |
| 指标为空 | 远端缺少读取来源或权限不足 |

## 5. 与其他模块的关系

- 编码项目通常在本地目录工作；服务器模块用于部署、查看日志与临时排查。
- 服务器命令输出可以引用到会话里，但平台不会自动把它当作项目事实。
- 知识库与服务器模块互不授权：知识库只读本机受管目录。
