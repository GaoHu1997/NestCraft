# 知识库授权与检索

> 适用版本：平台 0.0.1 · 更新 2026-11-21

## 1. 知识库是什么

知识库 = 一个受管的本机目录。平台对它做三件事：

1. **列目录**：按目录树展示全部文件，不隐藏任何格式。
2. **建索引**：Markdown 与文本格式切片建全文索引；其它格式只登记文件名与路径。
3. **受控读取**：AI 或阅读器读取正文前，检查知识库是否启用、是否被授权给当前项目。

## 2. 支持的格式与能力

| 格式 | 目录可见 | 正文预览 | 全文检索 | AI 可读 |
| --- | --- | --- | --- | --- |
| `.md` / `.markdown` | ✅ | ✅ 渲染 | ✅ | ✅ |
| `.txt` / `.log` / `.json` / `.csv` | ✅ | ✅ 纯文本 | ✅ | 受限（按接口） |
| `.png` / `.jpg` / `.gif` / `.webp` | ✅ | ✅ 图片 | 仅文件名 | ❌ |
| `.pdf` | ✅ | 元数据 + 导出原件 | 仅文件名 | ❌ |
| `.docx` / `.pptx` / `.xlsx` | ✅ | 元数据 + 导出原件 | 仅文件名 | ❌ |
| `.drawio` / 其它 | ✅ | 元数据 + 导出原件 | 仅文件名 | ❌ |

> 结论：格式越「重」，平台越保守。二进制格式不进入 WebView 内联渲染，正文也不进入模型上下文。

## 3. 授权模型

- 授权粒度：**项目 × 知识库**，只读。
- 默认不授权；新建项目不会自动获得任何知识库。
- 关闭知识库或取消授权后，下一次调用立即失效（每次调用都复核）。
- AI 网关只读，不提供写入、删除、重命名能力。

## 4. 检索怎么工作

1. 收到问题后，按已授权的库逐个检索。
2. 库若尚未建索引，会先做一次惰性回填，失败则该库退出本轮检索（不会返回空结果冒充「没有资料」）。
3. 命中结果带来源：库名、文件相对路径、片段。
4. 引用进入会话时携带内容快照，后续即使文件被修改，本轮结论仍可追溯。

## 5. 操作建议

| 目标 | 做法 |
| --- | --- |
| 新建库 | 知识库 → 新建，选择本机目录；平台只记录路径，不复制文件 |
| 上传资料 | 在库内目录上传，支持大文件任务化导入与进度显示 |
| 导出原件 | 在文件详情选择导出，平台复制到指定位置，不修改原件 |
| 清理索引 | 库设置里重建索引；不影响原始文件 |

## 6. 常见误区

- **误区：把整个硬盘根目录设为知识库。** 索引量与权限风险都会放大，建议一库一主题。
- **误区：以为 Word 内容能被 AI 直接问答。** 当前只有 Markdown 与文本格式进入检索与 AI 读取；Word/PPT/PDF 需要转成 Markdown 或摘要笔记。
- **误区：授权一次永久有效。** 取消授权或禁用库即生效，不需要重启。
