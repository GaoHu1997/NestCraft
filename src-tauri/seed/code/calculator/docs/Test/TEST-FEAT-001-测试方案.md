# TEST-FEAT-001：测试方案

- 关联：[FEAT-001](../Plan/Feature/FEAT-001-基础四则运算.md)、[FEAT-002](../Plan/Feature/FEAT-002-键盘输入与历史记录.md)
- 被测对象：`src/calculator.js`（内核）、`src/index.html`（界面）
- 运行方式：`npm test`（Node 内置测试运行器）

## 1. 策略

| 层级 | 范围 | 方式 |
| --- | --- | --- |
| 单元测试 | 状态机的每个动作、求值函数、格式化函数 | `node:test` + `assert`，直接 import 内核 |
| 键盘映射测试 | `actionForKey` 的键位映射 | 构造伪 `KeyboardEvent` 对象 |
| 集成/人工 | 按钮点击、显示区渲染、历史面板、深色模式 | 手工在浏览器操作，对照 [UI-FEAT-001](../UI/文档/UI-FEAT-001-交互设计.md) |
| 回归 | 全部 AC 用例 | 每次改动后运行 `npm test` |

## 3. 手工检查清单

1. 打开 `src/index.html`，显示区为 `0`，历史面板显示空态。
2. 依次点击 `7`、`×`、`6`、`=`，表达式行显示 `7 × 6 = 42`。
3. 键盘输入 `1/3=`，结果行显示 `0.3333333333`。
4. 点击历史条目，结果回填且历史条数不变。
5. 切换系统深色模式，确认文字与背景对比度可读、等号键保持主色。
6. 窗口宽度缩到 600px 以下，确认历史面板移到下方且无横向滚动条。

## 4. 不在本方案内

- 性能基准：内核为同步计算，单次按键耗时远低于 16ms，不做基准测试。
- 跨浏览器矩阵：目标为现代 Chromium/WebView，仅在 Edge/Chrome 手工检查。
