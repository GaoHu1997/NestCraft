# 计算器需求规格

- 编号：PRD-001
- 状态：已确认（2026-11-20 产品评审通过）
- 关联：EPIC-001、FEAT-001、FEAT-002
- 来源：产品组需求评审纪要；用户场景见 [VISION-001](../Plan/VISION-001-产品愿景.md)

## 背景与目标

办公与学习场景中的算术需求高频、低复杂度，但现有工具在「过程可见」和「结果复用」上体验不足。本规格定义一个零依赖、打开即用的四则运算计算器，重点是四则运算正确性、连续运算顺手、键盘可用与历史可复用。

## 本次范围

| 能力 | 规则 |
| --- | --- |
| 数字输入 | 0-9，最多 15 位；单次输入只允许一个小数点；前导零归一为单 0 |
| 四则运算 | `+ − × ÷`，顺序计算，无优先级 |
| 连续运算 | 上一次结果作为下一次左操作数；连续按运算符只替换运算符 |
| 等号 | 执行待运算；无待运算时固定当前值；重复等号重复上一次运算 |
| 清除 | `C` 清当前输入；`AC` 清全部状态 |
| 退格 | 逐位删除，最少到 `0` |
| 正负号 | 切换当前输入符号 |
| 百分比 | 当前输入 ÷ 100 |
| 历史 | 成功计算后记录「表达式 = 结果」，最多 20 条，点击回填，可清空 |
| 键盘 | `0-9 . + - * / Enter = Backspace Escape %` |

## 业务规则

1. 除数为 0 时不得输出结果，必须提示「不能除以 0」。
2. 结果超出 JavaScript 安全数值范围时提示「结果超出范围」。
3. 出错后，下一次数字输入或 `AC` 回到可用状态。
4. 显示格式：最多 10 位小数，去掉末尾多余的 0；`1/3` 显示 `0.3333333333`。
5. 历史只在计算成功时写入；失败计算不入历史。
6. 历史与当前状态均不写入磁盘，刷新即清空。

## 权限与边界

- 无账户体系、无网络请求、无文件读写。
- 不解析表达式字符串，不执行 `eval` 或任何动态代码。

## 质量要求

| 项目 | 要求 |
| --- | --- |
| 正确性 | 核心用例全部通过自动化测试 |
| 可用性 | 键盘与鼠标行为一致；错误提示为中文 |
| 性能 | 单次按键响应 < 16ms（同步状态更新） |
| 可维护性 | 内核与界面分离，内核无 DOM 依赖 |
