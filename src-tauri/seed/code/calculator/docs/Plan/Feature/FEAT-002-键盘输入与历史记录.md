# FEAT-002：键盘输入与历史记录

## 价值

熟练用户不必移动鼠标即可完成全部操作；历史记录让上一次结果可被追溯和复用，避免重复输入。

## 范围

- 键盘映射：`0-9`、`.`、`+`、`-`、`*`、`/`、`Enter`/`=`、`Backspace`、`Escape`、`%`。
- 键盘输入与按钮点击走同一条状态机路径，行为完全一致。
- 历史记录：每次按下等号且计算成功时追加一条「表达式 = 结果」。
- 历史容量：最近 20 条，超过后丢弃最旧一条。
- 历史交互：点击某条历史把结果回填为当前输入；「清空历史」按钮清空全部记录。
- 历史不写入磁盘，刷新页面即清空。

## 不包含

- 历史导出、搜索、分组。
- 跨会话持久化。
