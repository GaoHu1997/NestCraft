# FEAT-001：基础四则运算

## 价值

用户无需学习任何语法，按「数字 → 运算符 → 数字 → 等号」即可得到结果；连续运算时上一次结果自动成为下一次的左操作数。

## 范围

- 数字输入：`0-9`，纯整数、小数，单一小数点，前导零归一。
- 运算符：`+`、`-`、`×`、`÷`。
- 等号：执行当前待运算；重复按等号重复上一次运算。
- 清除：`C` 清空当前输入，`AC` 清空全部状态。
- 退格：删除当前输入最后一位。
- 正负号：切换当前输入符号；若当前是结果则对结果取反。
- 百分比：当前输入除以 100。
- 错误：除零显示「不能除以 0」，随后任何数字输入恢复可用状态。

## 不包含

- 键盘输入与历史记录（见 [FEAT-002](FEAT-002-键盘输入与历史记录.md)）。
- 运算符优先级与括号。
