# EPIC-001：四则运算计算器

## 目标用户与价值

让办公用户、开发者和学生在桌面端用一次点击或一次按键完成四则运算，并能回看最近的计算过程。

## 范围

| 包含 | 说明 |
| --- | --- |
| 基础运算 | 加、减、乘、除、等号、清除、退格、小数点、正负号、百分比 |
| 连续运算 | 上一次结果直接参与下一次运算 |
| 键盘输入 | 完整键位映射，与点击按钮行为一致 |
| 历史记录 | 最近 20 条，支持点击回填 |
| 错误处理 | 除零、非法输入、结果溢出均有明确提示 |

## 不包含

- 科学计算（详见 [VISION-001](../VISION-001-产品愿景.md#不包含)）。
- 表达式优先级解析与括号。
- 账户、同步、导出。
