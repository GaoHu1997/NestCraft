# VISION-001：计算器产品愿景

## 一句话定位

一个打开就能算、算完看得懂、出错不糊弄的桌面计算器。

## 目标用户

| 用户 | 场景 | 现在的问题 |
| --- | --- | --- |
| 办公用户 | 会议中快速做加减乘除、算折扣与分摊 | 系统计算器不能保存过程，历史结果要重新输入 |
| 开发者 | 验证一段数值逻辑或在调试时做临时运算 | 命令行计算器语法学习成本高，结果不可回看 |
| 学生 | 做作业时核对四则运算步骤 | 部分计算器不显示当前表达式，容易误操作 |

## 价值主张

1. **零学习成本**：布局与实体计算器一致，键盘可直接输入。
2. **过程可见**：显示区同时展示当前表达式与结果，避免「不知道按了什么」。
3. **结果可复用**：历史记录保留最近 20 条，点击即可回填。
4. **错误显式**：除零等异常给出明确提示，不静默返回 `NaN` 或 `Infinity`。

## 范围

- 四则运算、连续运算、百分比、正负号、小数点、退格、清除。
- 键盘输入与鼠标输入行为一致。
- 历史记录（本次会话内，刷新页面后清空）。

## 不包含

- 科学计算函数（三角函数、幂、对数、阶乘）。
- 括号与运算符优先级表达式求值。
- 单位换算、汇率、日期计算。
- 跨设备同步与云端历史。

## 成功指标

| 指标 | 目标 | 衡量方式 |
| --- | --- | --- |
| 首次可用时间 | 打开后 5 秒内可完成一次计算 | 手工首次使用测试 |
| 关键路径正确率 | 四则运算与连续运算用例 100% 通过 | `npm test` |
| 键盘完整度 | 数字、四则运算符、回车、退格、Esc 全覆盖 | 交互说明逐项核对 |
| 错误可理解性 | 除零等异常均有中文提示 | 手工异常测试 |

## 约束

- 纯前端、零依赖，单目录即可运行，不引入构建工具。
- 不在浏览器中保存任何用户数据到磁盘。
