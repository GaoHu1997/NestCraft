# STORY-001：四则运算与连续计算

- 类型：用户故事
- 所属 Feature：[FEAT-001](../Feature/FEAT-001-基础四则运算.md)
- 来源与确认依据：产品组 2026-11-20 需求评审结论；范围见 [PRD-001](../../PRD/PRD-001-计算器需求规格.md)
- 负责人 / 优先级 / 状态：前端组 / P0 / 已完成
- 依赖：无

## 目标

作为办公用户，我希望按「数字 → 运算符 → 数字 → 等号」直接得到结果，并在连续运算时复用上一次结果，以便快速完成日常算术且不用重复输入。

## 本次包含

- 数字、小数点、四则运算符、等号、清除、退格、正负号、百分比。
- 连续运算：上一次结果作为下一次左操作数。
- 重复按等号重复上一次运算。
- 除零等异常提示与恢复。

## 不包含

- 键盘输入与历史记录（[STORY-002](STORY-002-键盘输入与历史记录.md)）。
- 优先级与括号。

## 验收标准

- AC-STORY-001-01：给定已输入 `1`，当依次点击 `+`、`2`、`=`，则显示结果 `3`。
- AC-STORY-001-02：给定已完成 `1 + 2 = 3`，当再点击 `×`、`4`、`=`，则显示结果 `12`，且不要求用户重新输入 `3`。
- AC-STORY-001-03：给定当前输入为 `0.1`，当再输入 `.`，则小数点被忽略，输入仍为 `0.1`。
- AC-STORY-001-04：给定当前输入为 `5`，当点击正负号，则显示 `-5`；再次点击恢复 `5`。
- AC-STORY-001-05：给定当前输入为 `50`，当点击 `%`，则当前输入变为 `0.5`。
- AC-STORY-001-06：给定当前输入为 `123`，当点击一次退格，则显示 `12`；连续退格到只剩一位时显示 `0`。
- AC-STORY-001-07：给定当前输入为 `8`、待执行除数为 `0`，当点击等号，则显示错误提示「不能除以 0」，且不显示 `Infinity` 或 `NaN`。
- AC-STORY-001-08：给定出现除零错误后，当输入任意数字，则错误提示清除并开始新的输入。
- AC-STORY-001-09：给定已完成一次运算，当点击 `AC`，则当前值、待执行运算符与表达式全部清空为 `0`。
- AC-STORY-001-10：给定结果为 `1/3`，当显示时，则最多保留 10 位小数并去掉末尾多余的 `0`。
