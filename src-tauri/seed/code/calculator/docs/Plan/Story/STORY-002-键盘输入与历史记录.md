# STORY-002：键盘输入与历史记录

- 类型：用户故事
- 所属 Feature：[FEAT-002](../Feature/FEAT-002-键盘输入与历史记录.md)
- 来源与确认依据：产品组 2026-11-20 需求评审结论；范围见 [PRD-001](../../PRD/PRD-001-计算器需求规格.md)
- 负责人 / 优先级 / 状态：前端组 / P1 / 已完成
- 依赖：[STORY-001](STORY-001-四则运算与连续计算.md)（复用同一状态机）

## 目标

作为熟练用户，我希望不移动鼠标就用键盘完成全部计算，并能从历史记录里找回上一次结果，以便在连续核对时少输入几次。

## 本次包含

- 数字、`.`、`+ - * /`、`Enter`/`=`、`Backspace`、`Escape`、`%` 键位映射。
- 历史记录：成功计算后追加，最多 20 条，点击回填，可清空。

## 不包含

- 历史导出与持久化。

## 验收标准

- AC-STORY-002-01：给定焦点在页面内，当依次按下 `1`、`+`、`2`、`Enter`，则结果与点击按钮完成 `1 + 2 =` 完全一致。
- AC-STORY-002-02：给定当前输入 `12`，当按 `Backspace`，则显示 `1`。
- AC-STORY-002-03：给定存在表达式，当按 `Escape`，则执行与 `AC` 相同的全部清空。
- AC-STORY-002-04：给定按下了 `*` 或 `/`，则分别按乘号、除号处理，且显示为 `×`、`÷`。
- AC-STORY-002-05：给定完成一次成功计算，则历史列表最上方新增一条「表达式 = 结果」。
- AC-STORY-002-06：给定历史已有 20 条，当再完成一次计算，则历史仍为 20 条且最旧一条被移除。
- AC-STORY-002-07：给定点击某条历史记录，则其结果回填为当前输入，且不触发新的历史写入。
- AC-STORY-002-08：给定点击「清空历史」，则历史列表为空且不弹出确认框。
- AC-STORY-002-09：给定发生除零错误，则该次计算不写入历史。
