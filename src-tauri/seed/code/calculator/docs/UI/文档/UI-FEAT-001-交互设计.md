- 版本：UI-CALC-v1（2026-11-20）
- 关联：[FEAT-001](../Plan/Feature/FEAT-001-基础四则运算.md)、[FEAT-002](../Plan/Feature/FEAT-002-键盘输入与历史记录.md)
- 可操作原型：[docs/UI/仿真原型UI.html](../仿真原型UI.html)
- 实现位置：`src/index.html`、`src/calculator.css`

## 1. 布局

桌面宽度下为两栏：左侧计算器主体（最宽 340px），右侧历史面板（220-280px）。视口 ≤620px 时改为上下堆叠，历史面板高度上限 220px。

```text
┌───────────────────────────┬──────────────────────┐
│  ┌─ 显示区 ─────────────┐ │ 历史记录      清空   │
│  │ 1 + 2 = 3            │ │ ──────────────────  │
│  │                     3 │ │ 4 + 5 = 9           │
│  └──────────────────────┘ │ 1 + 2 = 3           │
│  [AC][ C][ %][ ÷]         │                      │
│  [7][8][9][×]             │                      │
│  [4][5][6][−]             │                      │
│  [1][2][3][+]             │                      │
│  [±][0][.][=]             │                      │
│  键盘提示                  │                      │
└───────────────────────────┴──────────────────────┘
```

## 2. 显示区

| 区域 | 规则 |
| --- | --- |
| 表达式行 | 13px、次要色，单行省略；无内容时显示空行占位，避免高度跳动 |
| 结果行 | 34px、600 字重、右对齐、等宽数字（`tabular-nums`），长数字换行不横向滚动 |
| 错误态 | 结果行自动降为 18px + 危险色，显示中文错误文案 |

## 3. 按键

| 分组 | 键 | 视觉 |
| --- | --- | --- |
| 功能键 | AC、C、% | 次要文字色，普通底 |
| 运算键 | ÷ × − + | 主色文字 + 主色浅底，无边框 |
| 数字键 | 0-9、.、± | 普通文字 |
| 等号 | = | 主色实底、白色文字 |

- 高度 44px 以上，`:hover` 换浅背景，`:active` 轻微缩放，`:focus-visible` 显示 2px 主色外描边。
- 按钮使用 `<button>` 元素，具备可访问名称（`aria-label`）。

## 4. 键盘映射

| 按键 | 行为 |
| --- | --- |
| `0`-`9`、`.` | 数字与小数点 |
| `+`、`-` | 加、减 |
| `*`、`x`、`X` | 乘（显示 `×`） |
| `/` | 除（显示 `÷`） |
| `Enter`、`=` | 等于 |
| `Backspace` | 退格 |
| `Escape`、`c`、`C` | 全部清除 |
| `%` | 百分比 |

## 5. 历史面板

- 头部：标题 + 「清空」文字按钮（无确认弹窗，AC-STORY-002-08）。
- 条目：上行为表达式（12px 次要色），下行为结果（15px 600 字重），右对齐；悬停显示浅背景。
- 点击条目：结果回填到当前输入，表达式行清空，不新增历史。
- 无记录时显示「还没有计算记录」。

## 6. 状态覆盖

| 状态 | 表现 |
| --- | --- |
| 初始 | 结果 `0`，表达式行空白 |
| 输入中 | 结果行实时跟随输入 |
| 等待运算符 | 表达式行显示「左值 运算符」 |
| 运算后 | 表达式行显示完整等式，结果行显示结果 |
| 错误 | 结果行显示错误文案，颜色为危险色 |
| 历史为空 | 面板显示空态文案 |
| 深色模式 | 跟随 `prefers-color-scheme`，使用同一套令牌的深色取值 |

## 7. 不适用

- 无弹窗、无菜单、无加载态：本界面不发起网络与磁盘请求。
- 无权限态：单用户本地工具，无账户体系。
