# NestCraft 产品介绍 · 办公示例项目

这是一个办公项目示例，用来演示「拿到资料 → 整理 → 产出 PPT」的完整路径。

## 项目里有什么

| 目录 | 内容 |
| --- | --- |
| 01 源资料 | 平台定位、能力说明、产品白皮书（docx）、常见问答（md）、平台介绍（pdf） |
| 会议与访谈 | 产品评审纪要（md） |
| 02 数据分析 | 能力地图与统计口径（xlsx） |
| 03 交付成果 | **NestCraft 产品介绍.pptx**（8 页演示，含封面、痛点、平台结构、项目与知识库能力、安全边界与下一步） |
| 历史资料 | 早期稿件，只读保留 |

## 怎么用

1. 在工作台打开本项目，进入「编码」页签（办公项目的工作区）。
2. 左侧文件树按目录查看资料；右侧查看器打开文档、表格、演示与 PDF。
3. 选择 `03 交付成果/NestCraft 产品介绍.pptx` 查看成品演示。
4. 在右侧 AI 侧栏提问，例如「把这份演示压缩成 5 页，突出安全与边界」，AI 会引用当前文件内容。

## 数据说明

- 办公示例的资料与产物由平台内置样例生成，属于合成内容，不代表对外发布的正式材料。
- 办公文件保存在工作台内（不写入本项目目录），保存草稿会产生版本记录，可回滚。
- 本项目目录只保存本说明文件，避免与工作台内文件重复。
