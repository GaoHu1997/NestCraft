# NestCraft 产品介绍 · 办公示例项目

这是一个办公项目示例，演示「拿到资料 → 整理分析 → 产出 PPT」的完整路径。
**`03 交付成果/NestCraft 产品介绍.pptx` 就是这套资料产出的成品**——它每页的演讲者备注都引用了本项目里的源资料。

## 项目里有什么

| 目录 | 文件 | 说明 |
| --- | --- | --- |
| 01 源资料 | NestCraft-平台定位速览.md | 演示底稿：30 秒版本、五类高频问答事实、边界与差异点 |
| 01 源资料 | NestCraft-产品白皮书.docx | 与知识库示例同源的白皮书（真实 Word 文件） |
| 01 源资料 | 常见问答摘编.md | 从知识库 FAQ 摘编的演示 Q&A 备稿 |
| 会议与访谈 | 2026-11-18-产品评审纪要.md | 「示例项目随包发布」决议的出处（真实评审记录节选） |
| 02 数据分析 | NestCraft-能力地图.xlsx | 模块 × 能力清单，带公式统计（真实 Excel 文件） |
| 02 数据分析 | 演示素材清单.csv | 每个素材用在哪一页、怎么用——素材到页面的可追溯登记 |
| 03 交付成果 | **NestCraft 产品介绍.pptx** | 成品演示：11 页，含封面、痛点对照、平台全景、编码 / 办公 / 知识库能力、数据、安全边界与下一步 |
| 历史资料 | 讲稿草稿v1-已被v2替代.md | 早期叙事草稿，记录被砍掉的内容与原因，只读保留 |

## 怎么用

1. 在工作台打开本项目，左侧文件树按目录查看资料；双击文件用右侧查看器打开（Markdown / Word / Excel / PDF / PPT）。
2. 打开 `03 交付成果/NestCraft 产品介绍.pptx` 查看成品，对照「演示素材清单.csv」可以看到每页内容的出处。
3. 在右侧 AI 侧栏提问，例如「把这份演示压缩成 5 页，突出安全与边界」，AI 会引用当前文件内容作答。

## 数据说明

- 所有资料与产物由平台内置样例生成，属于合成内容，已在界面与文档中标注，不代表对外发布的正式材料。
- 本项目所有文件都保存在项目目录里，可复制、可导出；删除文件不会被示例安装过程自动恢复。
- 三套示例（编码 / 办公 / 知识库）只安装一次，不会覆盖已有目录，删除后不会自动重建。
